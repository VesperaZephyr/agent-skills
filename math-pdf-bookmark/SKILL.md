# math-pdf-bookmark — 数学 PDF 批量精确书签

## When to use
- User wants bookmarks / 目录 / 书签 on a folder of math PDFs.
- Requirement (from this user): bookmarks must jump to the **heading's y position**,
  not the top of the printed page. This is the single hardest correctness constraint.
- Secondary requirement (stated for Conway): the reader's page number should equal the
  book's **printed folio** → see "Page labels" below.
- Rework requests ("书签有缺失 / 层级不好 / 有乱码 / 效果不好") → start with
  `references/bm_quality.py`, never with `verify.py` alone (it only checks existence).
- **有文字层的书先分流**：正文文字层可信、印刷目录能解析 → 先试 **ROUTE H**
  （`heading_scan.py`，零手抄、零 OCR，一本几秒；七道闸门不过就 REJECT）；
  旧骨架忠实只是 dest 落在页顶 → ROUTE R（重锚，几分钟一本）；
  骨架塌平/只有章一级/标题是裸页码 → ROUTE P（重解析印刷目录）。三条都在
  "ROUTE H / R / P …" 一节，别一上来就走 Phase 2 全量管线。
- "这一本必须完美"的单本精修：英文扫描巨著走 **Phase 5**（人肉抄目录，靠字高分层），
  中文教科书扫描本走 **Phase 6**（旧列表当骨架，靠 `N.M` 编号分层）；两者都要求
  渲染→OCR→定位→写入→看图验收全流程，且 0 MISS 才落盘。
- **精品单本、且正文完全没有文字层** → **ROUTE P-IMG**（全本 OCR 只写到 PDF **外面**的证据文件，
  目录人眼转录，两遍定位；见 ROUTE 分流表）。**不要**给它注入不可见文字层——那是 Phase 1b 自匹配缺陷的根源。

## Hard rules (non-negotiable)
1. `set_toc` 第 4 字段（destination）必须是**数字**（距页顶磅数 `top`），不能是 dict，否则链接失效。
2. `set_toc` 第 3 字段（page）是 **1-based**（实测 `page=0` 被夹到第 1 页）；写进去的数字 y 会变成
   `{'kind':1,'page':p-1,'to':Point(72.0, y)}`。校验必须用 `get_toc(simple=False)` 才能看到 dest。
3. 定位失败 / 偏移算错的条目**一律丢弃**，绝不退化成 `p=cursor` 兜底——那会指向错误页。
4. 匹配必须用**词元重合率**（`toks()` + `overlap()`），不能用精确子串，也不能从 `norm()` 结果分词
   （`norm()` 删空格会把英文标题压成超长"单词"，重合率恒 0）。
5. 单进程串行跑书签生成；OCR 至多 2 路。开 6+ 并行进程会**跑死机**。
6. **书签标题必须逐字来自原书印刷目录**（"方式A"）。目录里没有的小节（如正文里的 `Exercises`
   标题、`Notes`、`Comments`）**不要**自作主张挂成书签——条目集合以目录为准，多挂也是错。
   （若已有一份结构完整的旧书签列表，可以拿它当**骨架**省掉人肉抄目录，但编号与用字仍以印刷
   目录/正文标题为权威，见 Phase 6；骨架里发现错页、错字必须改，不能因为"旧列表有"就照抄。）
7. 标题里**不许**残留目录的点线＋页码（`§3 Prime Ends …… 55`）、不许残留 `\u00a7` 式转义或乱码；
   出现了说明这条书签其实锚在目录页上，必须重做而不是"改标题"。
8. 判断"这本书做完了"的标准是 **dest y > 0 且落在标题行**，不是"有书签"。`/Fit`、`to=(0,0)`、
   以及 `y` 恰好等于页顶的条目全部算未完成（GTM11/Ahlfors/Bak 都是这类历史遗留）。
9. **`set_toc` 的数字 y 完全不认 CropBox**。实测定律（4/4 本验证；**⚠️ 硬规则 20 有反例：有的书
   media==crop 且 `landing = H − input`、斜率 −1，单点 shift 探针不可跨书外推——用两次探针标定 k,b**）：
   `landing(= get_toc(simple=False)['to'].y) = input + shift(page)`，
   `shift(page) = page.mediabox.y1 - page.cropbox.y1`（**不是** `cropbox.y0`！只有版心上下
   对称时两者才巧合相等——钟玉泉就是巧合，北大高代6 因此被写坏过一次）。
   → 写之前**逐页**算 `shift` 并打印直方图：同一本书常有**多个值**（北大高代6 有 11 个：
   -14.52 主导，章扉页 +16.68/+19.08/+20.04/+22.92…），必须 `input = y - shift[p-1]` 逐条补偿。
   → 写完必须读回断言 `max|landing - y| < 0.05`；只看 `set_toc` 不报错＝没验。
   测量法：把文件拷成 ASCII 临时件，`set_toc([[1,'probe',P,100.0]])` 后读 `['to'].y`，
   `shift = land - 100`（模板 `references/shift_probe.py`）。
   ⚠️ **补偿只做一次**：读回的 `to.y` **已经是**页面（CropBox 顶起算）空间的落点，与
   `get_text('dict')` 的 span bbox、与渲染图的墨迹带**同一坐标系**。所以**验收/审计脚本里
   绝不能再 `+ shift`**（Ahlfors 中译本因此把 171 条全判成"偏移 80 pt"，假性 BAD 35/171）。
   判据：`to.y` 与文字层标题行 y 相差应 ≤2 pt；若整本书所有条目都差一个常数，那是**你在审计里
   重复补偿了**，不是书签错了。
10. **墨迹带（ink band）验收可以 100% 覆盖，比抽样看图强**（模板 `references/ink_audit.py`）：
    渲染 200 dpi 灰度条 → `dark = a < min(max(percentile(a,12), 100), GREY=200)` → 行暗像素占比 >0.004 成带。
    两个必须记住的坑：
    ① **窗口要宽**（`landing-40 .. landing+70`）。窗口收窄到 `landing-20..+90` 会改变该 clip 的
      12 分位灰度阈值，整窗文字糊成一条带 → 假性 NO-BAND（实测 4 条）。
      ⚠️ **同一个 12 分位阈值自己也会退化，必须封顶**（孙永生《泛函分析讲义》实测，工具里叫 rule 8）：
      只要那条 clip 大部分是空白（章末只剩半页＋短标题），`percentile(a,12)` 就等于**纸张灰度**
      （测到 254.0，p50 也是 254）→ `a < 254` 把纸张纹理全算成墨 → 标题与上方一切并成 36–39 pt
      巨带 → 完美锚点被误判 NO-BAND。`min(..., 200)` 一行修好，**52/54 → 54/54**，
      150..230 之间读数不变，`--grey 255` 可回到旧行为。⚠️ `--rowfrac` **不是**解法
      （非单调，且把另一条 `#31 p158` 从 BAD 变成 `h=3.2`）。
    ② **宽度要用"左连续簇"而不是带的外跨度**：从带的最左列向右桥接 ≤40 pt 的空隙为止。
      标题行右侧常有**公式编号**（`(39)` 落在 x≈455），外跨度会把它算进标题宽度，
      把 92 pt 的小节标题判成 393 pt 的正文行（实测 #53 `3.4.3 初等黎曼面`）。
    判据：落点在带顶下方 0–8 pt、带高 5–17 pt（L1 只需 ≥8 pt）、左簇宽 ≤265 pt。
    ⚠️ **不要用文字层的 x 判事**：脏 OCR 会截断 x-bbox（Ahlfors 中译本实测偏差最大 −174 pt），
    而 y 仍然准。x 只打印不判分。
    ⚠️ 自己写 `ink_top()` 这类"绝对灰度"版时，取像素**必须**
    `np.frombuffer(pix.samples, np.uint8).reshape(pix.height, pix.stride)[:, :pix.width]`
    ——直接 `reshape(w, h)` 在 stride≠width 时整幅错位（200 dpi 灰度图实测 stride 有 4 字节补齐）。
11. **`ink_audit` 有一个结构性盲区：它分不清"标题"和"页眉 running head"**（《101泛函分析》实测）。
    页眉本身就是一条**短墨带**、也在 x 版心内、也在渲染图里，所以旧树 **12 条锚在 y≈42–44 的页眉**
    竟然**全量 PASS**。两条对策，缺一不可：
    ① **页眉/页脚过滤必须长在定位器里**（整条 span 扔掉：`y1 ≤ 0.10*H or y0 ≥ 0.90*H`）。
      中文教科书的页眉**常印本章/本节同名标题**，不过滤就是必中陷阱；别指望审计兜底。
    ② **第二道闸＝`页码偏差直方图`**：`Counter(落点物理页 - (印刷页 + K))` 应为 `{0: N}`。
      页眉锚往往伴随**指错页**（本书另有 5 条错页锚），直方图会立刻露馅；墨迹审计则不会。
    配套：`ink_audit.py --every 1` 才是**逐条**出 contact sheet（默认每 6 条抽 1 条）。
    看图时要主动认"这是标题还是页眉"——每页同一位置、同一串字、字小 = 页眉。
12. **印刷目录本身会印错页码**，别把定位器当被告（本书附录 F 目录印 221、正文实起 222；附录 G 印 222、实起 223）。
    直方图出现非零桶时**先证明不是自己的错**：跑逐页 folio 游程（p233=221 / p234=222 / p235=223 严格 +1
    ⇒ 中间没漏页，模板 `references/folio_runs.py`）＋人眼看过那两页正文，确认后才允许
    `{0: N-k, r: k}`，且**每个非零桶都要能指名道姓地解释**。书签**跟正文标题走**，不跟目录的错号走；
    标题文字仍逐字抄目录（只有页码让位）。

13. **`bm_quality.py` 报 `OK` 不等于这本书做好了**（孙永生《泛函分析讲义》坐实）。出版社/Anna's Archive
    自带的第三方树可以同时满足：`top=0`（它有页内 y，只是常落在正文中段或页眉）、`dirty=0`
    （`∙` U+2219 是**可打印**数学符号，`CTRL_RE`/`LEADER_RE`/`MOJI_MARKS` 三个判别器全都放行）、
    `flat=0`、`nonmono=0` ⇒ verdict=**OK**。而它实际**缺 5 条**（49 vs 印刷目录 54）、**10 条标题拖 `∙`**、
    1 条混进 `庵`、`§N` 的 `§` 全丢、章名写成"一 距离空间"、层级只有一级、`/PageLabels` 是 246 段
    扫描器文件名（阅读器页码显示 `cov001.pdg`）。
    ⇒ **条目集合与标题只能用"人眼转录的印刷目录白名单 + 差集"证明**；页码只能用逐条 `/PageLabels`
    反查证明。任何自动检查器的 `OK` 都只是**必要条件**。
    **差的"缺几条/脏几条"必须能自动复算**：模板 `_工作产物/孙永生/_sy_negctl.py`
    （同页同身份先配对 → 真缺条/挂错页/标题脏三支 → 三条 `assert` 兜住），
    本书输出 `47 条配上 / 真缺 5 / 挂错页 1 / 标题脏 1`，其中净差 54−49=5 与"真缺 5"必须相等。
    （已同步把两类盲区补进 `label_folio_check.py`：新增 `(0) LABEL SANITY`＝文件名前缀/每页一段
    → `LABELS-BAD`；`(1)` 新增 `JUNK_END`＝标题以点线残留符号结尾 → 计进 `bad_title`。
    在 `_pre1` 上跑出 `LABELS-BAD 246/246 + bad_title=10`，在 101泛函/Terse/Lax/Rudin/Bogachev
    五本成品上仍是 `labels ok + bad_title=0`——**开关有牙且不冤枉人**才算修好。）

14. **每道闸门都要"证明它在干活"，两次实测教训**：
    ① **先证明开关真的接线了**：我曾把 `--grey` 加进 argparse 却没替换 `dark = a < ...` 里的常数
    （Edit 的 old_string 写成 `100.0`、文件里是 `100`，静默没替换），于是 `--grey 170..255` 扫出
    **逐字节相同的报告**，我据此下了"灰度不是病因"的**错结论**。空结果 ≠ 无影响。
    正确顺序：改一处 → **和 pristine 输出 diff 证明它变了** → 再做实验；或者直接独立量一次病因
    （后来是**独立实现**——对同一 clip 直接打印 `np.percentile(a,12)`——量出 `254.0` 才翻案）。
    ② **负对照要人造**：旧树几何上竟接近正确时，"跑一遍旧文件"抓不到"落点在页顶/页眉/正文里/退一条"
    这四类错，所以要用 `_pre1` 复制件**合成**四棵错树（页顶 y=61、页眉 y=50、真值+15 落正文、整体退一条）
    喂给每道闸，确认每道闸至少对一类失败。

15. **OCR 字符框（`get_text('rawdict')` 的 per-char bbox）只有**跨 span** 的间距可信**
    （吉田中译本坐实，"空格到底印没印"只能这么量）：
    ① **同一 span 内部**的字符框是**按字数等分**的，`gap` 恒 ≈ −0.1 pt，量不出任何空隙；
       而扫描本的**目录行几乎每行都是一个 span** ⇒ 在目录层量空隙＝在量噪声，**必须去正文层量**
       （正文 p69 `B－空间和F－空间` 实测 `2`→`(` gap = −0.06 紧贴、`1`→`(` = 4.81 有空隙，
       同页两种写法并存，全局规则必错其一）。
    ② **一行字的字顶是斜的**（实测同一行 186.1→186.7）：按**每个字符自己的 y** 过滤会**静默吃掉行尾**
       （第一版 96 条"跳过"就是这个原因）。要按**整行 bbox** ±4.5 pt 过滤。
    ③ 判"标题里有没有空格"不能用 `"%s %s" in title`：章标题 `第二章  B…` 是**双**空格，
       要用 `re.search(escape(a) + r"\s+" + escape(b), t)`。
    ④ 同一条排版规律在这本书里**自己就不一致**（`B－空间和 F－空间` gap 6.10 vs `B－格和F－格` gap 1.14），
       所以正确结构是**统一规则 + 逐条实测例外表**（`TITLE_FIX`），而不是"代价已知，接受"。
       例外表必须**断言全部命中**（`len(TF_HIT) == len(TITLE_FIX)`），否则规则失效了也没人知道。

16. **阿拉伯数字页码标签风格必须 `'D'`，不是 `'a'`**（Dummit & Foote 坐实，且是同一坑第二次咬人：
    林源渠数分习题集修过 `'a'→'D'`，写新书又照抄 `'a'`——读者会在正文显示 a,b,c… 而非 1,2,3）。
    PDF 规范 `/S/a`＝小写字母序列、`/S/D`＝十进制。**验收必须看 `xref_get_key(catalog,'PageLabels')`
    的原始 `/S`**：`get_page_labels()` 返回的 `style` 字段只是转写，a/D 之差容易看漏。
    ⇒ **不要跨书复制标签风格配置**，每本书的每段风格逐书实证。

17. **「有文字层」不等于「文字层可信」；ROUTE P-TXT 变体 7 只对 born-clean 的书成立**。
    扫描书的文字层是 OCR 垃圾（实测三个样本 学习指南/柯朗/精选 无一幸免）：`\xa0` 连字、
    丢数学符号（`\mathcal{D}`→空、`Fourier`→丢失）、`Sobolev空间与嵌人定理`、`乡一`。
    ⇒ 扫描书的题名**一律目视目录页/裁片**，文字层只许用来量 y 坐标与 x0 缩进定层级
    （参考文献/索引与章标题同 x0 列 ⇒ L1），题名仍须目视核对。
    配套：目录行上方有残留标记时，裁剪用 `cropY0≈0` 方案（裁剪原点定在页面顶部附近）。

18. **页码标签三坑（2026-10-06 下午五本实测）**：
    ① 封面/封底这类**不编号段，`get_page_labels()` 不返回** ⇒ 活标签段数可少于实际分段数，
      不能拿「段数是否等于预期」判断正确性（张恭庆上册 330 页只有一段 `/S/D` 是对的）。
    ② `set_toc` 的页码是 **1-based**（与物理页一致），而 `set_page_labels` 的 `startpage` 是
      **0-based** ——差一层，容易错位。
    ③ 扫描数学习题集的标签普遍 **2–3 段**：封面(`A`)／书上前区(`r`)／正文(`D`)；
      `firstpagenum=1` 对每段独立生效，**不可省略**（否则阅读器页码漂移）。

19. **Windows git-bash 工具注意**：`> nul` 会把输出写成同名文件（`nul` 是保留设备名的坑），
    应改用 `> /dev/null`；`fitz` API 已弃用，统一 `import pymupdf as fitz` 并以 `-W ignore` 压弃用告警。
    ⚠️ **含反引号/backtick 的字符串严禁放进 `python -c "..."`**（双引号里 bash 把反引号当命令替换）：
    实测事故（2026-10-06 晚）——想写 `` `'`+chr(2) `` 时反引号对被 bash 吞掉，`bad` 变成空串，
    `s.replace('', lit)` 在**每个字符之间**插入 10 字符串，轮次文档瞬间膨胀 11 倍、所有标题打散。
    幸好插入是均匀规则的 ⇒ `s.replace(lit, '')` 精确逆变换可完全恢复。
    **含反引号/反斜杠/控制字符的文本操作一律写成 .py 脚本文件再运行。**

20. **落点标定必须逐书实测仿射系数 `landing = k·input + b`，不许跨书照抄 shift 律**
    （《泛函分析学习指南》坐实，2026-10-06）：
    ① 旧律「`landing = input + shift(page)`」隐含**斜率 +1**；该书 media==crop（旧 shift 公式恒 0），
      实测却是 **`landing = 842 − input`，斜率 −1**（写门回读 max 偏 1345.7 pt 才暴露）。
    ② **y=100 单点探针量 shift 完全不能外推**：斜率为负时输入 100→landing 742（看似 shift +642），
      输入 500→landing 342（同页"shift"变成 −158）。
    ③ 正确姿势：**每条目标 y 打两发探针（y 与 y+37）**，`k=(L2−L1)/37`、`b=L1−k·y`、
      `input=(y−b)/k`，断言 `|k|≈1`，回读闸逐条 `≤0.05 pt` 验证。前 15 本全是 +1 不代表第 16 本还是 +1。
    ④ 配套：ink_audit 的**左簇宽 ≤265 pt 上限会把超长标题误判 BAD**（实测 273 pt 的
      「共轭空间·弱收敛·自反空间」与 341 pt 的「紧算子的谱理论（Riesz-Schauder 理论）」，
      红线都确实压在标题上）——长标题书的 BAD 必须逐条看拼版裁决，不能自动判死。

22. **超大开本扫描本 + WinOCR 盲区的 P-IMG 变体**（柯朗《微积分和数学分析引论》第一卷第二分册
    345p/206 条坐实，2026-10-07）：
    ① **大间距居中标题（『问 题』『附 录』）WinOCR 整行丢失**——字间距 ~100pt 击穿行检测。
      兜底 = numpy 居中短墨带检测器：行墨带 → 列簇（>30pt 间隙分簇）→ **丢弃 <12pt 的孤立簇
      （扫描墨点会假增宽度）**→ 按 titlе 种类限宽（问题 100-260 / 附录 100-280 / 附录N 200-360）
      + 居中 |cx-宽/2|≤130 + fill<0.45（两字间距大 ⇒ 列占用率低，实测 0.36-0.37）。
      ⚠️ 居中公式带 fill 可低至 0.30 —— 必须 find_heading（OCR 行）先行、墨带只做兜底，且宽度按种类。
    ② **超大开本（1225×1800pt，常规 595pt 的 2 倍）**：ink_audit 的行高/带宽判据是按常规页硬编码的，
      全部要按比例放（实测 --maxhead 900 --x0 100 --x1 1140 --dpi 120；行高 31pt、长标题宽至 854pt）。
      渲染 dpi 另按**原生扫描分辨率**定（本书原生 96dpi/1634px，取 2x=192dpi 供 WinOCR）。
    ③ **A.x 编号的 OCR 等价类**：罗马 I 与 数字 1/小写 l/L 与 卫 互混（'A.II.1'→'*A.II.I'/'* A 卫 · 1'、
      'A.1'→'*A.I'、'II'→'JI'），逐字符等价类 + 罗马段量词 {1,n}（II 可塌缩成单字符）。
    ④ **光标顺序定位的页级比较**必须 `p < cursor[0]`——写成 `(p, 0.0) < cursor` 会把光标所在页整页跳过
      （字母条全体假 MISS，实测 178→147 反向事故）。
    ⑤ **长题名字母条的覆盖率兜底按题名长度分档**：短(≤6字)严（cov≥0.75 且行短 ≤16），长宽
      （cov≥0.8，行长不设限——'g. cos μx 的展开式…'被 OCR 吞成 '寥 · cos 的 展 开 式…' 仍可凭 cov 0.9 命中）。
    ⑥ 内嵌文字层若是**两路旧 OCR 交叠**（同 y 重复行、繁简混、丢字），去重按 y±3 + chkey 相似度，
      且**不可作为唯一定位源**（'a. 参数表示'→'參表示'）；渲染重 OCR 更稳。
    ⑦ PageLabels 为**间接引用** (xref N 0 R) 时 set_toc 原样保留——快照对比要用 get_page_labels()
      或 xref 解析后的值，别拿字面量比。

21. **烂字型映射扫描本的 P-CN 变体**（汪林《泛函分析中的反例》350p/517 条坐实，2026-10-06 晚）：
    有些扫描本的文字层把 CJK 全部映射成控制字符（get_text 得 `` 垃圾），但**数字与拉丁存活**。
    ① 目录侧可全自动化：行首（x<80）token `N.` ＝条目行；条目 folio＝编号行之下第一条
      「尾词纯数字、x>350、且前一词以 `.`/`·` 结尾」的行（多行条目的 folio 在末行；前导点特征
      排除公式行尾的裸数字）——闸：每章序号 0..N 连续、folio 单调、0 缺。
    ② 正文定位＝期望页（印刷 folio+K）上找**行首 `N.`**（烂层里行首 `N.` 只出现在条目标题，
      一页多条靠编号区分）；页眉 `·N·` 游程直接给 K 与逐页 folio（本书 306 页 0 违例）。
    ③ **锚点必须 snap 到墨顶**（文字层行顶比墨顶高 ~3.6pt，ink_audit 的 gap 判据是 0–8pt）。
    ④ 短粗标题会把 ink_audit 退化成 h=1.1 sliver、章大字行 h=6.5<L1 门槛 8 —— **结论以拼版目视为准**。
    ⑤ 写门回读对账**必须按树序逐位配对**（get_toc 按树序返回），不能按 (lv,title) 建字典——
      15 章都有「0. 引言.」同名条目，键冲突出假偏差（实测白失败一轮）。
    ⑥ 题名粒度=印刷目录的粒度：反例书目录逐条列 500 个编号命题 ⇒ 517 条（15 章+500+参考文献+名词索引）。


## Pipeline (per folder, e.g. `F:/.../分析学`)
工作目录 `_build/`，脚本：`tlbmk.py`(解析引擎) `build_t1.py`(书签生成) `diag.py`(分类)
`verify.py`(全库校验) `probe_t1.py` `worklist.py` `recover_empties.py`；
OCR 相关：`wocr_all.py`(多 worker) `winocr.ps1`(WinRT) `render_pages.py` `wocr_build.py`(不可见文字层)
`copyback.py`；图像目录书专用：`inject_imagetoc.py`(前台 OCR 注入) `build_imagetoc2.py`(标题式抽取)。

**复用纪律（复制到新文件夹后必须重指路径）**：
- `diag.py`、`worklist.py`、`verify.py` 硬编码 `ROOT`（各自文件顶部）→ 改 `ROOT="F:/.../新文件夹"`。
- `wocr_all.py`、`copyback.py` 硬编码 `BUILD` → 改 `BUILD="F:/.../新文件夹/_build"`。
- `build_t1.py`/`tlbmk.py`/`recover_empties.py` **不依赖 ROOT**（走 worklist，路径由 worklist 提供），无需改。
- ⚠️ `verify.py` 的 `ROOT` 极易漏改：漏改会扫描到旧文件夹而误报/漏报，务必每个新文件夹都核对一遍。

### Phase 0 — 分类 (diag.py)
对每本 PDF 取文本层，按前 11 个分位采样文字密度：
- A-ok：已有合格书签（**别直接跳过**：先用 `bm_quality.py` 证明它真的合格，见 Phase 4）
- T1：有文字层、无书签 → 直接进入 Phase 2
- S1：纯扫描件（密度 < 50%）→ Phase 1 OCR 后并入 T1 管线
扫描件末页常有元数据文字骗过密度采样 → 必须**多分位采样**，否则误判 T1。

### Phase 1 — S1 扫描件 OCR（不可见文字层）
复用 `pdf-scanned-ocr-bookmark` skill 的 WinRT OCR 流程（Windows.Media.Ocr, zh-Hans-CN），
`winocr.ps1` 按原生 DPI 渲染、`wocr_all.py` 多 worker、`copyback.py` 把文字层 `saveIncr` 回拷原文件。
OCR 噪声大 → 后续 Phase 2 目录检测要用宽松模式。
⚠️ **但"精品单本"（用户会逐条对页查的那几本）不要走注入路线**：注入的不可见层会让定位器
跟自己的输出匹配（Phase 1b 头号缺陷）。单本请改走 **ROUTE P-IMG**——同一套渲染 + WinOCR，
但 dump 留在 PDF **外面**，目录由人眼转录，交付文件里只多一套书签字节。
批量库里 N 本书共用管线时才用注入（`copyback.py`）。

### Phase 1b — 目录页是图片、但正文有文字层（"图像目录书"，如 Ahlfors/Courant/林源渠）
正文能定位、只有目录页是扫描图 → 不必全本 OCR。轻量做法（实测有效）：
1. `inject_imagetoc.py <pdf>`：只 OCR 前台 ~60 页（`render_pages.py`+`winocr.ps1`），
   用 `is_toc_line` 找出连续 TOC 页，把那段 OCR 文字以 `render_mode=3` 不可见层
   注入**原文件对应页**（`wocr_build.py` 写临时 pdf 后 `shutil.copyfile` 回拷，按页数对校验）。
2. 先试 `build_t1.build_one`（标准行式解析）；若返回 None/很少，用
   `build_imagetoc2.py`：**标题式抽取**——从注入的 TOC 文字抓
   `第X章 / Chapter N / §N / 附录 / Part N / Volume N` 等标题，再到正文文字层
   `overlap>=0.62` 定位 (page,y) 写书签。
   这类书目录是"左栏章节名 + 右栏页码列"两栏布局，行式解析器配不上，必须用标题式。
2. ⚠️ **自匹配陷阱（本节的头号缺陷）**：第 1 步把目录 OCR 文字注入的正是**原文件的那几页**，
   于是第 2 步"正文逐页搜标题词元"会先撞上**目录页自己**——书签全落在 p2..p6，标题还是 OCR 乱码。
   → 正文搜索**必须排除目录页区间**（`inject_imagetoc.py` 已知道该区间，把它传给 `locate`），
   并且解析出的标题要过 `bm_quality.py` 的 `dirty` 检查（`leader`/`moji` 一响就是锚在目录页）。
3. ⚠️ **旧结论作废**：本节原先写"Ahlfors 23 / Courant 26 / 林源渠 21 条，均跳转到标题 y"——
   **实测是假的**。2026-10 复查：Ahlfors 中译本 23 条标题全是 OCR 乱码（`1.2.4 球面表示 “ 3.3.3.3.3.3 对称性灬对称性 “`
   这种两栏串行＋重复），dest 落在 p2..p6 的目录页上。三本都已退回重做队列。
   **只有 `bm_quality.py` + contact sheet 看图**能宣布一本书完成，脚本自述的条数不算。
   进度：Ahlfors 中译本已改走 **ROUTE P-TXT**（人眼抄目录 + 脏层两遍定位）重做完成，171 条；
   Courant / 林源渠 仍在重做队列，它们的正文层同样脏 → 优先试 P-TXT 而不是再跑一次 Phase 1b。

### Phase 2 — T1 / S1 书签生成 (build_t1.py)
核心函数 `build_one(path)`：
1. `find_toc_pages(doc)` 定位目录页（连续"左标题+右页码"行 run + 锚点验证）。
   严格检测 < 4 条时自动 `find_toc_pages_loose` 重试（容忍 OCR 噪声）。
2. `parse_toc` 用 **span 级 y 聚类**重建行（目录行常被拆成 序号/标题/页码 三个 span，
   且有重复 span 需去重），点线正则要求**至少两个点字符**。
3. `assign_levels` 按缩进定层级。
4. `locate` 解析每条到 (物理页, y)：
   - 先试印刷页偏移 `offset`（由页眉页码图 `header_pagemap` 推出，必须 `validate_offset` 抽样验证）；
   - 偏移不可靠则 `fit_offset`（定位前 ~16 条标题反推模态偏移）；
   - 仍无则**正文逐页搜索标题词元**（`overlap >= 0.72`），连续 10 条失败即截断（防"第二/三册"清单）。
5. `apply_toc` 写 `set_toc`，强制层级 + 页码单调（`p = max(cursor, min(p, n-1))`）。
   - 质量闸门：条目塌缩到 < 3 页 → REJECT（不写）；这比写垃圾书签好。

### Phase 3 — 校验 + 找回 (verify.py / recover_empties.py)
- `verify.py` 全库走一遍：统计总书签数、unopenable / out-of-range / non-monotonic / dead-dests。
  **本管线产出的书必须 0 上述异常**；既有 PDF 原有的脏书签不在范围内（报告即可）。
- 对全部 0 书签 PDF 跑 `recover_empties.py`（调用 `build_one`）：
  既恢复"日志记了但写入丢失"的书，又补回被严格检测误杀的教科书；真正无目录的书
  （答案是/勘误/单章习题卷/短论文/公式集）会自然 skip。

### Phase 4 — 质量复审与重做（bm_quality.py，本次新增）
`python references/bm_quality.py <ROOT> [--csv out.csv]` 只读不改（ROOT 走 argv[1]，**不必**改文件头），
逐本输出 `bm / top / pages / oor / nmon / flat / dirty / levels / labels / verdict`，
末尾再打一份 **dirty-title breakdown**（`leader / esc / moji / ctrl / tex` 逐类计数）——
标题缺陷在阅读器里全是**隐形**的，只有这份分类清单能看出是哪一类。
verdict 分类（阈值见文件顶部常量）：
- `page-top`：>20% 条目 dest y ≤ 0.5（含 `/Fit`、`(0,0)`）→ **必须重做**，这是用户最反感的形态。
- `flat`：>30 条全在 level 1 → 层级塌平，需重做（例：李红《复变函数与积分变换》230 条全 1 级）。
- `oor`：页号越界 → 重做。
- `dirty-title`：五类标题脏物（任一即计一次）：
  `leader` 残留点线＋页码（`3 柯西一黎曼条件 ∙ 22`，中文书常用单个 `∙` U+2219 当点线）、
  `escape` 字面 `\u00xx`、`moji` 编码错、**`ctrl` 标题里带 NUL/控制字符**、`tex` 残留 `$...$`/`\macro`。
  锚在目录页的那几类整本重建；只改标题不算修好。
- `nonmono`：(page,y) 序列回退 —— **提示级**，多为锚在目录页或页眉重复标题，逐条看图判定。
- `add-labels`：书签可用但没有 /PageLabels → 只需补页码标签，成本极低。
- `EMPTY`：0 书签，走 Phase 1/2 正常管线。
实测（分析学 347 本）：REWORK 175（其中 page-top 91 本、13435 条）、add-labels 75、OK 75、EMPTY 22。
⚠️ `ctrl` 这一类是**后补的**：加进去之前，谭小江/伍胜健《复变函数简明教程》57 条标题**全部**以
`\x00` 结尾却被判 OK。所以拿到旧报告别照抄——`bm_quality.py` 改过之后必须**重跑整个文件夹**。
重做顺序建议：先扫 `page-top` 里的**英文原版**（文字层多半存在，Phase 2 直接可跑），
再处理 `flat`/`dirty-title`，最后统一补 `add-labels`。

### Phase 5 — 单本精修：纯扫描英文巨著（Conway GTM159 打法，本次打通）
适合"这一本必须完美"的场景：412 页扫描本、无文字层、目录是图。模板脚本在 `references/`：
`scan_toc_data.py`（目录数据）+ `scan_build.py`（定位＋写入＋页码标签）+ `scan_verify.py`（看图校验）。
1. **人肉抄目录**：翻原书印刷 Contents，把每条 `(level, label, printed_page, kind, key)`
   逐字写进 `scan_toc_data.py`，并定 `K`（物理页 1-based = 印刷页 + K）。抄目录这一步不要相信 OCR，
   直接看图读页码；顺手把前置部分（Title Page / Preface / Contents）也写成条目。
2. **定 K**：找几个已知锚点核对（Chapter 13 起于物理 16 → 印刷 1 ⇒ K=15）；
   再用**页眉页码审计** `audit_folios()` 全本走一遍：每个正文页页眉带里的纯整数必须 == phys-K
   （Conway 实测 340 页全对，2 页为章起始页无页码）。注意本扫描本把 folio 印在**页眉**，
   不能只查页脚。
3. **渲染 dpi=72 的原生像素**：这类扫描页 `page.rect` 就是原生像素尺寸（2242×3857 pt），
   72 dpi 渲染 ⇒ **1 px == 1 pt**，`SC = 72/DPI = 1`，OCR 框坐标直接就是 PDF 磅值。
   **不需要** `wocr_build.py` 注入隐形层——只用 OCR dump 定位，原文件图像流一字节都不动。
4. **OCR 分块**：`os.link` 硬链接把 412 张 png 秒切成两块，2 个 worker 跑 `winocr.ps1`；
   dump 列序是 `y \t x0 \t x_end \t h \t text`（不是 x 先）。
5. **英文 WinRT OCR 归一化**（噪声专治：词内插空格 `Analyt ic`、`0→o`、`l→I`、`§→''`、标点变空白）：
   - `nrm(s)`：只留 `[0-9a-z]`，把词内空格全部消掉；
   - `variants(s)`：再试 `0→o`、`1→l`；
   - `sim()`：`difflib.SequenceMatcher` 比值；公共长前缀加分**必须**要求
     `min(len(c),len(g)) >= 10`，否则 `"List of Symbols"` 会匹配到光秃秃的一行 `"1"`。
6. **按字高认标题**（这是扫描本分层的关键，比缩进可靠）：
   chapter opener h≈117–119；section heading h≈57–60；后置材料居中大标题 h=66–92；
   正文 h≈44–47；页眉 running-head h≈40 且 y<200。
   于是 chapter 用 `h>=80`，section 用 `x0<=260 且 h>=40 且 sim>=0.6`（§N 号对上再加 0.05），
   后置材料用 `h>=55`。
7. ⚠️ **后置材料标题在页顶 y≈112**：`References`/`Index` 就印在页眉带里。若沿用
   `lines_of(skip_head=True)`（丢弃 y≤200）会永远 MISS。`find_back` 必须单独搜 `y<=400`
   并用 `h>=55` 把同词的页眉（h≈41）挡掉；阈值 0.75（OCR 把 `Index` 读成 `lndex`，ratio 0.80）。
8. **MISS 就拒写**：任何一条没定位到，整本不落盘（`refusing to write while N entries are unlocated`）。
9. **页码标签**（见下节）+ `set_toc`，一次性在 ASCII 临时副本上做完再搬回。
结果：Conway GTM159 = 84 条（16 个 1 级 + 68 个 2 级）、0 MISS、0 ink 失败、3 段页码标签、
体积 2652673 → 2684862 字节（只增元数据，图像几何与备份逐字节同）。

### Phase 6 — 单本精修：中文教科书扫描本（王晓光《101复变函数》打法，本次打通）
模板脚本：`references/cn_build.py`（骨架→定位→写入→页码标签）+ `references/cn_verify.py`
（结构 / folio / ink / contact sheet 四合一验收）。两者顶部常量（DPI、SRC、K、OLD、OCR dump 路径）
**逐本重指**，文件里带了重指清单。
和 Conway 的**三处本质差别**：① 页面是普通 PDF 尺寸（`page.rect`≈524×734 pt）而不是原生像素，
所以**必须** `SC = 72/DPI = 72/200 = 0.36` 把 OCR 像素框换算成磅——Conway 那套"1 px == 1 pt"**不能照抄**；
② 目录/正文里全是 `N.M` 编号，**编号本身就是最强的判别器**，不必像英文书那样靠字高硬分；
③ 旧书签列表本身是**可用骨架**（结构完整、标题干净），不必人肉重抄目录。

1. **以旧书签列表为骨架，以印刷目录＋正文标题为权威**。249 条旧条目给出层级和标题文字；
   印刷目录（OCR 后逐行解析）和正文标题用来**校验编号、纠正错字**。
   本次旧列表里揪出 3 处硬错并改正：`第二十三章` 页 41→241、`重道复偏导数`→`重温复偏导数`、
   `31.3 非连通域的双曲度量`→`单连通域的双曲度量`（放大 4 倍看印刷字才敢定）。
   ⚠️ 反过来别信 OCR 目录的**拉丁字母/公式**：`Arzelà-Ascoli`、`∫` 一类必然被读烂，
   这类标题保留旧列表写法或手写 Unicode。
2. **NUL 结尾的旧标题**：`DROP` 集合（封面/声明/版权…）明明写了却不生效、条数 249≠244，
   根因是**每条旧标题都以字面 `\x00` 结尾**，`t in DROP` 永远 False。
   → 任何"标题字符串比较"之前先
   `t = re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\ufffd]', '', title).strip()`。
3. **编号自洽即验收**：level-2 按出现顺序推导成 `N.1, N.2 …`、level-3 推导成 `N.M.K`，
   再和书里**印出来的**编号比。全库 0 MISS ⇒ 既没漏节也没多节（比"条数对上了"强得多）。
   推导出的编号还要 `bare()` 先剥掉标题里已有的 `N.M(.K)` 前缀，否则出现
   `17.4.1 17.4.1 火腿三明治定理` 这种双重编号。
4. **OCR "L 方言"**（WinRT 读这本书的序号专病）：序列 `1.` 被读成 `L`
   （11.1→`1L1`、21.2→`1.2`、21.5→`2L5`、31.4→`3L4`），分隔点还会变成 `·，．`。
   → `LEAD = re.compile(r'^([0-9lL.]{2,9})(?![0-9lL])')`，`lead_digits()` 把每个 `l/L`
   展开成 {'1', ''} 两种可能、丢掉所有点，**只比数字串**。`numok`（编号对上）比文字相似度更可信。
5. **落点判别的几何门限**（单位=磅，`SC` 换算后）：
   - 章首页 `第X章` 居中 y≈115–123；**字高不可靠**（`* 第十四章` 只有 h=6.5，正常 h≈15）
     → 章必须按**文字** `CHAP_HEAD` 匹配 + 中文数字相等，窗 ±1 页，**不要**加 `h>=` 门限；
   - 节标题 `N.M 标题` h≈9.4–10.8、x0≈68–98；**小标题**缩进到 x0≈113 → 门限写 `x0<=128`；
   - 页眉 running head 也是 `N.M 节名`（y≈40、x0≈350–440、h≈5.8–6.1）→ 用 `y>=58` 排除，
     但它同时是**免费的交叉校验**（页眉编号 == 该页所属节）；
   - 正文里同样有 x0≈75–105、h≈8.6–10.8 的行 → 光靠几何必然误命中，
     **`N.M` 数字前缀才是判别器**，几何只当过滤器。
6. **打分＋窗口**：`sc = 6*numok + 4*sim + 1*(p==expected) - 0.4*|p-expected|`，
   接受条件 `numok or sim>=0.72`，窗口 ±2 页（章 ±1 页）。±2 页足够窄，配上前缀匹配，
   错配会自己以 MISS 的形式暴露，不会静默指到别处。
7. **标题排版**：LaTeX 残迹换成可读 Unicode 数学（`$\int_{0}^{2\pi}...$` → `∫_0^{2π} Q(sin θ, cos θ) dθ 型积分`）；
   半角冒号后紧跟汉字要收成全角并吃掉空格 `re.sub(r'[:：] *(?=[一-鿿])', '：', t)`；
   `(续)/(一)` 之类括号统一成全角。注意 `bm_quality.py` 的 `tex` 只认 `$` 和 `\macro`，
   `^{`/`_` 单独出现**不算** LaTeX（那是有意为之的 Unicode 数学写法）。
8. **页码标签四段**（中文教材通用形态）：
   `{1:'a'}` 封面～前置无页码 → `{9:'r'}` 目录 i、ii… → `{17:'D',firstpagenum:1}` 正文 →
   `{402:'a'}` 出版社后置（版权页/郑重声明）用字母，绝不会被误读成书面页码。
   本次 K=16（物理 1-based = 印刷 + 16），**两条独立证据**：页眉 folio 审计 325 页全对，
   以及印刷目录里 `31.3 … 313` 这一行落在物理 329。
9. **丢弃项要报告**：出版社后置的 5 条（封面/声明/版权/101计划信息/郑重声明）不挂书签——这是**决定**，
   收尾时必须告诉用户，不能默默少掉。

结果：《101复变函数》= 405 页 / 244 条（45+197+2）、0 MISS、0 page-top dest、
0 ink 失败、folio 325 对 4 疑（那 4 处是页眉带里的公式数字，不是 folio）、4 段页码标签，
`bm_quality.py` verdict 从 `page-top(249)` 变 `OK`。

### ROUTE R（`python reanchor.py <pdf> [--write] [--report f.txt]`）
dry-run 出报告，**0 MISS 才允许 `--write`**。本轮为它新增的判别器（每条都是被某本书逼出来的）：
- **jammed 文字层**：出版商把空格整层丢掉（`Analyticcontinuation`）→ 去空格再比一次（`_score_fuzzy` 里 `an/bn`）。
- **乱码容错前缀**：扫描重排本标题有 OCR 残字（`Singnlarities`、`tind Cycles`、`Formnla`、`rf'-function`）
  → `pfr()` 双向截断取 `difflib` 比值，`r>=0.82` 才给分。
- **编号标题规则**：`_score_named()` — 前导小节号相同（`3.1`）且词元重合 ≥50% 即认定同一标题，
  专治正文把标题排成 `3.1 Theorem.` 这类 run-in 的书。
- **节号否决（NUMBER VETO）**：`score()` 里若两侧前导编号都存在且不相等 → `s -= 3.0`。
  没有它，fuzzy 的 4.7 会把 `3.1 The Exponential` 从 y=533.7 抢页到同页上方的章开场白 y=325.7。
- **前置材料兜底**：`Cover/Title page/Copyright` 根本没有印刷标题 → `FRONT` 集合 + `locate_front()`
  锚到该页第一行内容顶端（不是 y=0！）。
- **章开场白吸附**：命中的是 `Chapter 7` 显示行还是它下面那行标题 → `snap_head_block()` 把 y 抬到
  标题块顶；`CHAPWORD` 命中的行允许 90 pt 的块高（普通节只允许 22 pt）。
- ⚠️ **`LEADNUM` 剥罗马数字必须要求带分隔符**，否则 `Cover`→`over`、`Index`→`ndex`（两本书同时中招）。
- **无回归验证法**：改判别器前后各跑一次 dry-run，按条目下标 diff 两份报告（`changed=0` 才算没伤到别的条目）。
  只盯"这次修好的那条"必然引入回归。
- ⚠️ **跑 ROUTE R 之前先做"老树体检"**（本轮 48 本扫下来省掉的最多）：ROUTE R 是**以旧树为条目来源**的，
  旧树本身是垃圾时它一定失败，而 dry-run 一本要 3–200 秒。三条 5 秒钟的判据先分流：
  ① `bm_quality` 报 **`ctrl=N`（标题含控制字符）**＝第三方 OCR 垃圾骨架的指纹（Lax 中译本 `ctrl=397`、
  吉田中译本同类）→ **直接跳 P-CN / P-TXT，别跑 R**；⚠️ 但 `ctrl=N` 不必然＝OCR 垃圾，

### ROUTE H — 排版找锚点 ＋ 印刷目录当白名单（Schiff / Alpay，一本 5–6 秒，本次打通）
用户原始思路："福昕按字号/字重筛标题，快但不准"。福昕的三个失败点——run-in 的 `Theorem 3.4`
也挂、锚点落页顶/页眉、脏文字层的字号根本不可信——**都不必牺牲它的速度**，因为错在
"用排版决定条目集合"。把它拆成两半就成立了：**印刷目录决定条目集合/层级/印刷页码**（白名单），
**排版只决定这条落在哪页哪一行**（锚点）。正文多抓 1168 行标题，一条也进不了书签；
锚点取自正文而不是目录行，所以不犯 Phase 1b 的自匹配。前提：**正文有可信文字层**
（纯扫描判 NO-TEXT，回落 P-IMG / Phase 5-6）。

模板 = `references/heading_scan.py`（单文件、零手抄、零 OCR）。
```bash
python heading_scan.py <pdf>                        # dry-run：候选树 + 目录对齐 + 闸门
python heading_scan.py <pdf> --g3                   # 连 G3 墨顶全量一起验（仍只读）
python heading_scan.py <pdf> --g3 --against-toc     # 再与 PDF 现存书签逐条 diff
python heading_scan.py <pdf> --write --bak DIR [--labels] [--allow-miss]
python heading_scan.py <pdf> --labels               # 只看页码标签建议，不落盘
调参：--gap 12 --size-tol 0.8 --bf 0.8 --from/--to --maxhead --tilex1
```

**七道闸门**（任一 FAIL → REJECT，回落 ROUTE R/P；`--write` 遇 REJECT 直接 REFUSE 并列出 fail 项）：
`有印刷目录(白名单)` · `MISS=0` · `页码偏差={0:N}` · `G0 标题卫生` · `G1 编号连续` ·
`G2 (page,y) 单调` · `G3 ink_audit 全量`（`--items` 逐条喂，不拼 sheet）。
- **G1 有两道，只做第二道不够**（Bogachev《TVS》109 条时被逼出来的）：
  (a) **目录编号 vs 正文编号**——把两侧各自的 `N.M` / `N.M(i)` / `Chapter n` 前缀抽出来比对；
  凡是**罗马号/子编号由脚本自己排**的书，这一道是唯一的防线（词元相似度对 `(i)` vs `(ii)` 不敏感）。
  (b) **连续性**——每章 `N.M` 恰为 `1..n`、每组 `N.M(i)` 恰为 `i..`，缺一条就是漏条目。
PARTIAL 只允许"仅 MISS 这一条不过、且丢的 ≤ max(2, 3%)"，要写盘必须显式 `--allow-miss`。
- ⚠️ **G0 是本轮补的，别省**：一次把上下标碎片并错了位置，目录行被搅成
  `Basic properties of J | 214R Mandelbrot set`，而 MISS/偏差/单调/ink **四道闸门全部照过**
  ——**其余闸门只看锚点，不看字面**。G0 ＝ `bm_quality.py` 那五类脏物（直接 import，判据必须同源）
  ＋ ROUTE H 特有的两条：**行内引导线残留**（`|`／`｜`）、**页码粘进标题**（`\d[A-Za-z]`）。
- `有印刷目录` 这条同样是被逼出来的：沈维孝《复变函数笔记》`ent=0` 却"ACCEPT"了 11 条——
  只剩"排版筛标题"就是福昕本人。目录解析不出来的书**不许**走这条路。
- ⚠️ 但反过来 **`ent=0` ≠ "这本书没有印刷目录"**（筛子的假阴性高发区，泛函分析 48 本实测）：
  De Gruyter《Terse》`ent=0 align=115` → 人工指定 `TOCP=(11,12,13)` 后自动解析出 88 条；
  已完成的 Lax 英文同样 `ent=0 align=1667`，目录就在 p6–16（关键词式两栏布局，行式解析器配不上）。
  ⇒ 归入"无目录 / 只能人眼转录"之前**必须渲染前台 15 页看图**；`ent=0` 而 `align` 很大
  ＝"正文标题全在、只有目录页没认出"，是最值得人工指定目录页的一类等书。

**三趟定位**（报表里 `定位方式=` 会打印各趟占比，便于判断哪趟在干活）：
① 排版候选（字号 ≥ 众数+0.8，或加粗字符占比 ≥0.8 且字号不小于正文；上方留白 ≥GAP）↔ 目录标题，
   `tscore` 3 全等 / 2 长串包含 / 1 差一字符，另按与 `印刷页+K` 的距离给微小分；
② 页窗口（±3）内现找"排版像标题"的行；目录措辞 ≠ 正文措辞时限用**编号锚**
   （前导 `N.M` 全等即算命中，打 `how="num"` 交人复核——Alpay 就靠它救回
   `8.2 Rational multiplied by trigonometric…`）；
③ **目录顺序驱动的全文行搜索**：把搜索夹在"上一条已匹配"和"下一条已匹配"之间（顺序闸门）
   ＋节号否决＋有页码线索时仍限 ±3 页。放宽到 ±12 实测把 Narasimhan 的偏差直方图搅成
   `{0:16, -3:28, …}`——**宁可 MISS 也不要"看着对齐了"的错锚**。
K 定不下来（前置不印 folio 那类）就用①②③的结果反推众数 K 再跑一遍，
**只有"条目不减、MISS 不增"才采纳第二趟**（K 猜错会整体错位）。

**被具体书本钉死的细节**：
1. **上下标碎片必须在 span 层并回本行**（按 x 插进去、不加空格），不能"先并成下一行、
   再追加到上一行末尾"——目录行末尾本来就有页码，追加会把 `标题 | 214` 搅坏（Schiff）。
   判据四条：字长 ≤3、比本行小 ≥1.5 pt、`y0 − 本行 y0max ≤ 6 pt`、**自己的纵向中心仍在本行框内**。
   最后一条是关键：`τ²` 的上标 2 中心落在下一行，缺了它就粘到上一行末尾变成 `transformations2`。
2. **引导线正则要允许点之间有空格**（`标题 . . . . 55` 是最常见排版），否则标题里残留点线；
   而 `norm()` 把点全删光 → `--against-toc` **查不出来**，这是报表盲区（Alpay 首次踩）。
3. **页眉带要认"剥掉行首页码后跨页重复"的行**（`82 Contents`／`viii Contents`），只按整行重复会漏，
   HDR 跟着错（Alpay 34.0 → 51.6）。⚠️ 但**不能**一刀切"贴顶＋小字就删"——那样删掉了 Schiff
   3 条真目录行（139→136），HDR 只能由"确实跨页重复"的证据推出来。
4. **部/章开页常印成 2–3 行**（`Chapter 13` ＋ `Special Functions and` ＋ `Transforms`），
   合并条件：同页 ＋ 间距 ≤60 pt ＋ 字号不掉 ≥1.5 pt，最多并 3 行。不合就整章 MISS（Alpay 末两条）。
5. **章/部本身不印页码**的书（Alpay 21 条）→ **借页**：继承下一条有页码条目的印刷页，
   窗口 **(−25, ＋5)** ——章开在它第一个小节**之前**，所以窗口必须不对称。
6. **`--maxhead`／`--tilex1` 按本书版心自动算**（`CW+12`／`X1+10`），别拿中文书的 265/330 去判
   英文书：Alpay 那条 353 pt 宽的 `6.8 Liouville's theorem…` 被误判 BAD，自动值 366 → 130/130。
7. **页码标签只在原文件完全没有 `/PageLabels` 时才写**（`apply_labels` 见到已有标签就只报告不覆盖）。
   ⚠️ **`set_page_labels` 的 `startpage` 是 0-based**（Schiff 出版商标签 `{0,'R',1},{16,'D',1}`、
   Alpay `{0,'C'…},{2,'r',1},{12,'D',1}`、Conway `{1,'r',2},{16,'D',1}…` 全部核对过）：
   印刷页 1 在物理第 13 页 → 写 **12**；写 13 会让 `doc[12].get_label()` 抛 IndexError、
   阅读器整本偏一页。内部 `i["p"]` 是 1-based，出口统一 −1，且**写完必须逐段读回**
   （`verify_labels`：每段起点页的 `get_label()` 要等于该页书面 folio）。
8. **目录里没有罗马页码 ≠ 前置没有罗马页码**：Alpay 的 Contents 一条罗马页码都不印，
   纯目录推导只会给 `[{0,'D',1},{12,'D',1}]` → 封面显示"1"、`vii…x` 那几页显示 8–12，
   与书面不符。补 **folio 连续游程**：扫阿拉伯段起点之前的页，只认"页眉/页脚带里
   恰一个罗马 token 且逐页 +1"的 ≥3 页游程，`startpage = first_idx − first_value + 1`，
   大小写照书面实际（Schiff 印 `I…XVI` → `'R'`）。误抓的 `Part II` 会打断递推，形不成游程 →
   **宁可不写也不写错**，这条比"多一段"重要。实测 Alpay → `(2,'r')`，与出版商完全一致。
9. **带内判据用 `bbox[3] ≤ 0.10H`（上带）／`bbox[1] ≥ 0.90H`（下带）**，即"整条 span 在带内"。
   写成 `bbox[1] ≤ 0.10H` 会把起点刚过线的正文行当 folio：Alpay p10 `Part II`（y0 67.2 < 68.03、
   y1 79.2）混进候选 → 该页两个值被整页弃 → 游程断裂、罗马段消失（实测踩过两次）。
10. **别在批量扫描跑着的时候改 `heading_scan.py`**：每本书都是新进程重新 import 同一份源码，
    中途插进去的编辑会让后面几十本按"半份新代码"跑——本轮 `NameError: LEADER_RE` 一次废掉 20 本，
    `IndexError: ch.most_common` 一次废掉 3 本。先杀 sweep 再改。
11. 硬规则全部沿用：写盘前量 CropBox 位移并**只补偿一次**、dest 必须是 python `float`、
    `lv = min(lv, prev+1)`、锚点做**墨顶 snap**（bbox 顶比墨顶高 2–12 pt）。

### 验收（ROUTE R / P / P-CN / P-TXT / P-IMG / C / H 共用）
**ROUTE P-CN（三源交叉的中文扫描本）的八道闸门**，缺一道就可能有真错放行：
① 印刷目录白名单（条目集合/层级/folio 的唯一权威）· ② MISS=0 ·
③ `页码偏差直方图 = {0: N}` · ④ G0 标题卫生（控制字符/度量垃圾/点线/首尾空格）·
⑤ G1(a) 目录编号 vs 正文实证 + G1(b) 章节编号连续 · ⑥ **G1(c) 题名有序逐字差分**（查漏字，集合式查不出）·
⑦ **G1(d) 空隙逐字实测**（查空格印没印，只有跨 span 可信）· ⑧ G2 `(page, 墨顶)` 单调 +
G3 `ink_audit --every 1` 全量看图 + **回读活树 vs 报告** + **负对照**。
详见下面"ROUTE P-CN 变体（吉田中译本）"一节。

`python verify_r.py <pdf> --tag xx` → A 结构（levels/page-top/oor/nonmono/dirty）+ B ink（逐条
`[y+3, y+16]` 必须有墨、`[y-14, y-2]` 必须基本无墨）+ C **contact sheet 12 条一张，逐张用眼睛看**。
**优先用 `references/ink_audit.py <pdf> [--x0 48] [--x1 505] [--out prefix]`（硬规则 10）**：它按"落点上方是否有短标题带"逐条判分，
171/171 这种全量结论比"标题上下有无墨"强得多，且自带 contact sheet。
**它的六条判据都是被假阳性逼出来的**（文件头 docstring 逐条写了证据，改动前必读）：
① 落点＝读回的 `to.y`，**不要再加一次 shift**；② 取带窗口要**比带宽**（`landing-40..+70`，窗口窄了
灰度分位阈值跟着变，整个窗口并成一条巨带 → 假 NO-BAND）；③ **`--x0/--x1` 是文字块的边界不是页宽**
（stein 中译本块右沿 457、folio 在 461..484，不砍掉版心外就把每条都判 BAD，`--x1 455`）；
④ **尘埃带不算带**（左簇 <15 pt 或高 <3 pt 直接跳过——2.2×0.4 pt 的一个斑点曾在 引言 上方 0.3 pt 处
把完美锚点判成 BAD）；⑤ **线宽取带顶 11 pt**（标题与下一行正文并成 29 pt 巨带时整带宽，
但顶部那一截是标题自己），层级 ≥2 用 `gap≤8 且 顶宽≤265 pt` 把关；⑥ **lvl1 允许落在带内**
（章标题字大、上方空气里仍有 1–4% 暗像素，带顶会比锚点高 15 pt）；
⑦ **`--maxhead` 是语言相关的**：265 pt 只对中文书成立（中文标题短），英文 ALL-CAPS 节标题合法宽度
270–320 pt，不传 `--maxhead 340` 会把 16 条完美锚点判成 BAD（Lang 实测）；

## Page labels — 让阅读器页码 == 原书印刷页码
`doc.set_page_labels([{'startpage':P(0-based！), 'prefix':'', 'style':S, 'firstpagenum':N}, ...])`，
`S`：`'r'/'R'` 罗马、`'D'` 阿拉伯、`'a'/'A'` 字母。
⚠️ **`startpage` 是 0-based 的 `doc` 下标**（本轮实测坐实：Alpay 印刷页 1 在物理第 13 页 →
必须写 12；写 13 会让 `doc[12].get_label()` 直接抛 IndexError，阅读器整本偏一页。
Schiff 出版商 `{0,'R',1},{16,'D',1}`、Alpay `{0,'C'…},{2,'r',1},{12,'D',1}`、
Conway `{1,'r',2},{16,'D',1},{410,'a',1}` 三份现存标签都按此读）。
下面各例的 `p…` 也都是 `doc[p]` 下标。分段规则（Conway 实测）：
- 前置：`{'startpage':1,'style':'r','firstpagenum':2}` ⇒ 封面记为 `ii`，这样**每一张印了 folio 的页**
  阅读器数字都和书面一致（p6→vii、p15→xvi）。
- 正文：`{'startpage':16,'style':'D','firstpagenum':1}` ⇒ p16→1、p42→27、p409→394。
- 尾部**无页码**的插页（丛书目录、封底）：`{'startpage':410,'style':'a','firstpagenum':1}` ⇒ a/b/c，
  永远不会被误认为书面页码。
  ⚠️ **但"没有 folio"要分两种**（Lang 实测）：出版社**附加页**（丛书目录/郑重声明/封底）用字母段；
  而**编号内容的续页**（索引最后几页、编号文献表——书面只是不印页码，页码序列本身还在）必须
  **续十进制**（`{'startpage':499,'style':'D','firstpagenum':486}`），否则阅读器给读者 a/b/c/d，
  与书面 486..489 的位置感不符。判据：看这几页的**内容**是不是前面编号页的延续，别看有没有 folio。
- 前置罗马段**可能要两段**：扫描里常缺页（Lang 印刷 `viii` 整页不在），于是要
  `{1:'r',1}` 管 i..vii + `{8:'r',9}` 管 ix..xiv，一段并到底会让后面的 folio 全体偏 1。
校验：自己写 `label_of(p)`（本 PyMuPDF 版本**没有** `get_label_value`，罗马/字母要手写转换），
逐点打印 `p→label` 对照印刷页码；书签 `page` 字段永远是物理页，页码标签只改**显示**。
⚠️ **别只从目录条目推段**：前置不编号的书（Alpay）目录里一条罗马页码都没有，
纯目录推导会把封面标成"1"、把书面 `vii…x` 那几页标成 8–12。正确做法见 ROUTE H 第 8 条
（`heading_scan.roman_front()`：页眉/页脚带里"逐页 +1 的罗马游程"反推 `startpage`）。
**批量补标签**（库里 ~75 本 `add-labels`，不走 ROUTE H 的书）用
`python references/folio_runs.py <pdf> [<pdf> …]`：全本做同一套"逐页 +1 游程"反推，
阿拉伯段＋罗马段一起给，并把出版商已有标签并排打出来供人工核对（只读，不落盘）。

## 无损写入路径（中文文件名必读）
`shutil.copy2(SRC, "C:/Users/asus/_x_tmp.pdf")`（ASCII 路径，避开 fitz 的路径编码坑和跨盘
WinError 17）→ `set_toc` / `set_page_labels` → `doc.saveIncr()` → `shutil.move(tmp, SRC)`。
写前先 `shutil.copy2` 到 `F:/大学/数字资源/数学/_bm_rerun_backup/<相对路径>/<name>_pre1.pdf`。
写完必须 `fitz.open(SRC).get_toc(simple=False)` 复验条数、dest、页数不变。

⚠️ **三件写回时的硬坑（Lang 实测，每一条都会静默写坏）**：
1. **dest 必须是 python `float`**。`set_toc` 的第 4 字段若塞进 numpy 标量（`np.float64`，
   墨迹带测量 `top = cy0 + rows[0]/SC` 算出来的就是它），PyMuPDF **不报错**，但写出的 dest 变成
   垃圾（读回 `to.y = 630.14 = 页高 − 36.0`）。Lang 125 条里 4 条被这样写坏，只有读回才发现。
   → 凡是经过 numpy 运算的 y，写入前一律 `float(y)`；写完断言 `max|landing − asked| < 0.05`。
2. **`set_toc` 不允许层级跳级**（`ValueError: bad hierarchy level in row N`）。印刷目录里
   `Appendix` 是 1 级、它下面的 `§1…§7` 是 3 级时，必须 `lv = min(intended, prev_lv + 1)` 夹一下，
   并把夹后的层级写进 toc（Lang 附录 7 条）。
3. **封面/封底段不要给 `style` 键**。`{"style": "No Style"}` 会让 `set_page_labels` 抛
   `FzErrorSyntax: invalid key in dict`；出版商原文件里这两段本来就**没有** style，照抄即可。
4. **备份只存最初的原件**：`if not os.path.exists(BAK): shutil.copy2(PDF, BAK)`。
   无条件 copy2 会在第二次重跑时把"已经写过一轮书签"的文件当成原件存进备份，回滚点就没了。

## Critical gotchas (tlbmk.py / 通用)
- `_split_page_number`：对**单 span 行**访问 `row[-2]` 会越界崩溃 → `if len(row) < 2: return row, None`。
  宽松路径才会触发；崩溃时该书保持 0 书签而非写坏。
- 目录页可能含后续分册内容 → 连续 10 条定位不到即截断，避免把"下册目录"挂到本册。
- worklist 顺序会漂移：重跑时**不要**用旧日志的索引指认某本书，永远按路径核对。
- 若某本在旧日志显示很多书签、实测 0 → 多半是 worklist 顺序漂移指到别书，或该书 40+ 页是公式非目录（搜不到"目录"字样即图像目录，需另做"仅前台 OCR"）。
- **GBK 控制台**：打印 `§` / `é` / `–` 会 `UnicodeEncodeError` 中断整份报告 →
  脚本开头 `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`，长报告落文件再看。
- **Write 工具会二次转义**：想写 Cesàro / H^p 的上标时，常落成字面的反斜杠转义序列
  （如 `\\u02b0`）而不是真字符；涉及非 ASCII 的目录数据一律手写真实字符，
  写完 `grep -n '\\\\u'` 一遍确认没漏，再靠 Python 侧断言（K 一致、条数对）兜底。
- 比较 dest 时 `Point > int` 会 `TypeError` → 先 `dest['to'].y` 取值再比。
- **page-top 的判据是 `to.y <= 0.5`**：`y=1.0 / 3.5 / 5.8` 可能是印刷就顶到版心的章号，不是缺陷，
  别为了凑"0 page-top"把它们改掉。
- 备份不在 PDF 旁边：`next_bak()` 写到 `_bm_rerun_backup/<相对路径>/<name>_preN.pdf`。
  重跑几次就会攒出 `_pre2/_pre3`（内容可能完全相同），找不到备份先怀疑自己来错目录，
  **绝不要**因此删掉现存备份。
- `fitz` 导入会打 `deprecated, use pymupdf` 警告，无害；报告落文件时记得 `2>/dev/null`。
- 章起始页常**没有**页眉页码 → 页码审计要把"无 folio"单列，不能算 mismatch。
- **DPI 与坐标缩放要逐本确认**：只有当 `page.rect` 恰好等于扫描原生像素尺寸时（Conway 2242×3857）
  才能用 dpi=72 让 1 px == 1 pt。普通中文教材 `page.rect`≈524×734，必须 200 dpi 渲染并
  `SC = 72/200 = 0.36` 缩放 OCR 框，否则所有 y 都偏大 2.8 倍、"看起来对"但整本落点全错。
- **contact sheet 拼版时每条的 crop 文件名必须唯一**：PyMuPDF 按文件名缓存图片，
  复用同一个 `crop.png` 会让 21 张拼版全是同一张图（我第一次就这样白看了一遍）。
- 中文标题里的**全角/半角**、以及旧列表遗留的控制字符，都会让"字符串比较"静默失效；
  凡是用标题做匹配/过滤，先归一化再比（见 Phase 6 第 2、7 条）。
- **`bm_quality.py <路径>` 的参数是目录不是 PDF**：传单个 PDF 会得到 `PDFs: 0 / REWORK: 0`，
  看着像"没问题"其实是**一本都没扫**（本轮实测踩过）。"0 异常"只有在确认它扫到了 N 本之后才算数。
- **`get_toc()` 默认 `simple=True` 只给 3 元组**（没有 dest），所以"看起来这本书没有 y"；
  验 y 一律 `get_toc(simple=False)`，行是 `[lv, title, page, dest]`（page 在 `r[2]`，`dest['to']` 是 Point，
  ⚠️ `to` 是 Point 不是 dict，别写 `to['page']`）。
- **共享工具的默认输出落在用户主目录**：`ink_audit.py` → `C:/Users/asus/_ink_audit.txt` + `_ink_audit_sheet_*.png`，
  `shift_probe.py` → `_shiftprobe.txt`。**每轮收尾 `ls C:/Users/asus | grep '^_'` 必须为空**：
  报告 `.txt` 移进 `_工作产物/<书>/` 并改成自说明的文件名（例：`_旧树ink_audit-12条页眉锚全PASS.txt`
  ——它就是硬规则 11"ink 审计分不清页眉与标题"的证据），截图与 contact sheet 直接删。
- **⚠️ 大字号标题的 bbox 顶 ≠ 墨顶（`ink_audit` rule 7）**：42–47 pt 章号 / 23.5 pt 粗体大写标题，
  文字层 bbox 顶比自己的墨顶高 **6–21 pt**（Lax 章 22/26 实测 39.6 vs 59.8）。旧版把这类全判 `NO-BAND`
  （46 条假失败）。现在 `ink_audit` 在 `pick is None` 时才启用 rule 7（`--leadabove`，默认 24 pt，
  且要求 `b[1]>=12` 字号 + `b[4]>=15` 宽度），**已通过的旧书不受影响**。
- **`env VAR=… python …` 在 Git Bash 里会吞掉 stdout**（看着像脚本没输出）→ 用 `VAR=… python …` 前置赋值。
- **`page.get_pixmap(dpi=…)` 的 dpi 必须是 int**：传 `300.0` 直接 `TypeError`；条带裁片同理。
- **"PDF 有 /PageLabels" ≠ "页码标签是对的"**：Lax 英文本自带的标签就是错的。
  凡设标签，一律逐页读书面 folio 重新推分段，写回后 `get_page_labels()` + 抽查 `page.get_label()` 读回。
- **干净文字层也可能单字符乱码**（`8 function` = `δ function`、`Muntz` = `Müntz`、`B.l` = `B.1`）：
  字符串比对、`bm_quality`、`ink_audit` **三道都拦不住**，只有逐条看图能发现 →
  这就是"写完必须看图"要**全量 `--every 1`**、不能抽样的理由（Lax 218 条 14 张拼版全看完，改出 12 处）。
- **⚠️ 书签落在"章编号行"还是"章名行"，只有 ink 审计能替你发现**（Bogachev《TVS》5 个章全 BAD）：
  `CHAPTER 1`(10.9 pt) + 章名(14.35 pt) 两行式开场白，去空格比对时 `chapter1introduction…`
  会以 `a.startswith(b)` 命中 `CHAPTER1` 那行、章名行反而 0 分。落点给编号行不仅读者体验差，
  而且 10.9 pt 字的墨带只有 7.9 pt，过不了 `ink_audit` 的 L1 判据 `h >= 8.0` →
  **章条目要先剥掉 `^Chapter\s+\d+\.` 再比，并把候选字号下限抬到 `bs + 1.0`**。
- **⚠️ 凡是"编号由脚本自己排"的书（目录摘要段展开成 `N.M(i)`），必须跑 G1(a)**：
  词元相似度对 `(i)` vs `(ii)` 完全不敏感（0.98 相似照样命中），唯一防线是把目录标题的编号前缀
  和正文所匹配行的编号前缀**逐条比对**。Bogachev 实测 98 条带编号、0 错，才敢写盘。
- **`y < 50` 不能当"这是页眉"的判据**：Bogachev 的 `Author index`(y=37.6) / `Subject index`(y=40.0)
  是 14.35 pt 大标题、那两页根本没有页眉 → 一刀切会 MISS=2。判页眉要用**字号**
  （`sz < bs - 0.4`，或 `y < 50 and sz < bs + 1.0`）。
- **后记区（Comments/Bibliography/Index）的 folio 常在另一个 span**（`x >= 360`），
  不在标题行尾部 → 正则组是 `None`，`int(f)+K` 直接 `TypeError`；写 `f = m.group(2) or str(folio)`。
- **⚠️ 罗马前 folio 会跳号**（Bogachev p8=vii → p9=**ix**，viii 不存在，缺空白折页）：
  页码标签必须**四段**、第三段专管跳号（`{'startpage': 8, 'style': 'r', 'firstpagenum': 9}`），
  否则跳号之后阅读器页码全体比书面 folio 小 1。
- **`label_folio_check.py` 的编号空洞检查会误报**：`N.M(i)` 子标题曾被并进父组 →
  假 `HOLE dup=True`（Bogachev 5 章全中）。已改为罗马号单独成组（`groups=5(+5 罗马组)`）。
  见到 `dup=True, missing=[]` 先怀疑检查器，别怀疑书签。
