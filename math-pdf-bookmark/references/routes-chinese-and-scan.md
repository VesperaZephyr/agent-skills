### ROUTE R（`python reanchor.py <pdf> [--write] [--report f.txt]`）
dry-run 出报告，**0 MISS 才允许 `--write`**。本轮为它新增的判别器（每条都是被某本书逼出来的）：
- **jammed 文字层**：出版商把空格整层丢掉（`Analyticcontinuation`）→ 去空格再比一次（`_score_fuzzy` 里 `an/bn`）。
- **乱码容错前缀**：扫描重排本标题有 OCR 残字（`Singnlarities`、`tind Cycles`、`Formnla`、`rf'-function`）
  → `pfr()` 双向截断取 `difflib` 比值，`r>=0.82` 才给分。
- **编号标题规则**：`_score_named()` — 前导小节号相同（`3.1`）且词元重合 ≥50% 即认定同一标题，
  专治正文把标题排成 `3.1 Theorem.` 这类 run-in 的书。
- **节号否决（NUMBER VETO）**：`score()` 里若两侧前导编号都存在且不相等 → `s -= 3.0`。
  没有它，fuzzy 的 4.7 会把 `3.1 The Exponential` 从 y=533.7 抢页到同页上方的章开场白 y=325.7。
- **前置材料兜底**：`Cover/Title page/Copyright` 根本没有印刷标题 → `FRONT` 集合 + `locate_front()`
  锚到该页第一行内容顶端（不是 y=0！）。
- **章开场白吸附**：命中的是 `Chapter 7` 显示行还是它下面那行标题 → `snap_head_block()` 把 y 抬到
  标题块顶；`CHAPWORD` 命中的行允许 90 pt 的块高（普通节只允许 22 pt）。
- ⚠️ **`LEADNUM` 剥罗马数字必须要求带分隔符**，否则 `Cover`→`over`、`Index`→`ndex`（两本书同时中招）。
- **无回归验证法**：改判别器前后各跑一次 dry-run，按条目下标 diff 两份报告（`changed=0` 才算没伤到别的条目）。
  只盯"这次修好的那条"必然引入回归。
- ⚠️ **跑 ROUTE R 之前先做"老树体检"**（本轮 48 本扫下来省掉的最多）：ROUTE R 是**以旧树为条目来源**的，
  旧树本身是垃圾时它一定失败，而 dry-run 一本要 3–200 秒。三条 5 秒钟的判据先分流：
  ① `bm_quality` 报 **`ctrl=N`（标题含控制字符）**＝第三方 OCR 垃圾骨架的指纹（Lax 中译本 `ctrl=397`、
  吉田中译本同类）→ **直接跳 P-CN / P-TXT，别跑 R**；⚠️ 但 `ctrl=N` 不必然＝OCR 垃圾，
  born-digital 书被别的工具写过也会留 `\x00` 尾巴（Terse `ctrl=89`，文字层本身干净）——
  结论一样是"别跑 R"，只是**重建时目录可以直接自动解析，不必人眼转录**；
  ② 旧树标题里**纯数字 / ≤3 字符**的条数占比高（`sum(1 for t in titles if not t.strip('0123456789. '))`）
  ＝目录页码被当成了标题 → 同样跳过 R；
  ③ 旧树条数与印刷目录条数**量级不符**（245 vs 218 还算正常；58 vs 200 就是残缺）→ 也别指望 R；
  ④ ⚠️ **①–③ 全过也不等于旧树可用**：必须**与印刷目录做条目差集**（`_bg_toc.py` 那种三方对照：
  目录有旧树没有 / 旧树有目录没有 / 用词不同）。Bogachev《TVS》就是反例——旧树 `loc=108 MISS=0`、
  7 秒、标题看着干净，差集却查出它**整节漏了 `5.12(xi). Radonifying operators`**、5 个章标题带 `\r`、
  还有 `D\x04` 乱码 → 差集非空即当"没有骨架"，从印刷目录重建。
  ⑤ ⚠️ **④ 的差集全同也不等于旧树可用**：差集只比**条目集与页码**，比不出**标题字节脏**。
  De Gruyter《Terse Introduction》就是反例——旧树 89 条与印刷目录**条目集全同、页码 0 条不同**，
  却是 89/89 全 page-top、**每条标题尾部拖着 15–22 个 `\x00`**（`_ts_oldtoc.py` 用 `repr()` dump 才看得见）。
  ⇒ 落盘前对旧树跑一次 `sum(1 for t in titles if re.search(r'[\x00-\x08]', t))`，非 0 即重建。
  **一句话：条目忠实 ≠ 标题干净，落点正确 ≠ 页码正确，四根轴（条目集 / 标题字节 / 落点 y / 阅读页码）要分开查。**
  本轮 `_R_dryrun/_summary.txt` 实测：只有 Bogachev TVS（108/108，7 s）与 Terse（89/89，3 s）
  是"旧树可信、只差落点"，其余 10 本里 8 本 MISS 高到必须重抄目录。
  （前半个结论已被 ④⑤ 推翻：**两本最终都走了"印刷目录重建"**，见 ROUTE P-TXT-EN 变体 2 与变体 3。）

### ROUTE P（模板 = Schiff，印刷目录 p13-16 → 140 条）
1. `rows(page)`：把 `page_lines()` 按 y 聚类成**视觉行**（`<3 pt` 合并、span 之间补一个空格），
   丢掉 `y<40`（页眉）和 `sz<9.0`（页眉/running head 8 pt）。
2. **层级按本页缩进 `d = x - min_x(page)` 定**（奇偶页版心不同，必须逐页取自己的左边界）：
   `<20`→L1、`<40`→L2、`<66`→L3。Schiff 实测 d 恰好是 0 / 35 / 56。
3. 目录行正则 `^(.*?)\s*\|\s*([0-9]+|[IVXLC]+)\s*$`（这本书用 `|` 而不是点线）。罗马数字页码=前置，
   阿拉伯页码 + `K` = 物理页（Schiff K=16，由 ch.1 folio 1 → 物理 17 定）。
4. **标题保留印刷章节号，probe 才剥号**：书签里 `7 Harmonic functions` 是对的（正文排成
   `7Harmonic functions`，匹配用 `Harmonic functions`）；**罗马数字一律不剥**（否则 `Index`→`ndex`）。
   另外把粘在一起的 `10Analytic number theory` 归一化成 `10 Analytic number theory` 再写标题。
5. **目录页不会把自己列进目录**：`Contents` 这一条要手工插回（插在第一个 exp≥15 的条目前），
   否则旧骨架有、新树没有，用户一眼就看出来。
6. **解析失败的行必须打进报告**（`dropped`），不许静默丢——本次唯一被丢的行就是 `Contents` 标题本身。
7. 文字层把上标压平（`h1(U)`、`τ2= 4`）→ 用 `TITLE_FIX` 字典按印刷写法改成 `h¹(U)`、`τ² = 4`。
8. `find()`：只认 **bold + 左边界 ≤ mx+2.5 + 长度 ≤62** 的行，`^[0-9]+(\.[0-9]+)*\s*[A-Za-z]` 且
   字高 <14 的一律排除（那是 `3.1 Theorem.` run-in 引用），窗口 `exp-1 .. exp+3`，
   分够高且落在期望页就早停。

### ROUTE P-CN（中文扫描本、OCR 层乱码到不可解析 → 目录**人眼转录**）— 李红《复变函数与积分变换》73 条
模板 = `references/routeP_cn_lihong.py`。这本书目录页 OCR 成 `§ 9 口`、`§ 63`、`§ & 1`，
行式解析器配不上，只能把 p8/p9/p10 渲染出来**照图手抄**成条目表（Conway Phase 5 的老办法）。
手抄换来一个巨大优势：**每条都知道印刷页**，于是 K 不是"估出来的"，而是 73 条全部落在
`物理 = 印刷 + K` 上被逐条证实的（李红 K=10）。窗口因此可以收到 `exp-1 .. exp+2`，
不可能串页，dry-run 直接 0 MISS。要点：

0. **开工两件量具（孙永生轮沉淀，别再手搓）**：
   ① `python references/toc_zoom.py <pdf> <tag> 13-15 --bands 3` 把目录页切成高分辨率横带，
      逐张 Read 抄成 `<tag>_toc.py` 白名单（**条目表只能从图抄**：文字层会整行漏条目、凭空插空格、
      把纸污读成 `积分算子庵`、把简体 `赋` 读成繁体 `賦`）。
      ⚠️ **工具的 W/H 取自 `d[0]`**——封面若是与正文不同页幅的小图页（探针 `shifts` 出现两个值），
      默认切带全错：**必须显式传 `--x <宽> --rows <带边界>`**（Stein FA 2026-10-05 实测，封面 168×251）；
   ② `python references/size_census.py <pdf> --from <正文起始页>` 出**字号直方图**，
      直接读 `MIN_SZ`（孙永生 章 21.88–23.12 / 节 15.27–15.69 / 习题 14.45–14.86 / 正文众数 10.73）。
      ⚠️ 直方图里**大字号档可能是公式碎片**：本书 `16.92 pt` 有 26 行全是 `乥 max @的@）…`
      这类花体字母行，比节标题还大——定下限前必须用"含中文＋居中＋只在页首"过滤。
1. **标题身份绝不能靠字号**。同一层里 `本章小结` 记 sz=10.3、`§ 5.4 对数留数与辐角原理` 记 **sz=3.0**、
   而页眉 running head 是 sz=6.0–6.4。可用的判据只有两条：
   ① `y >= 35` 排除页眉（本书页眉在 y≈13–26：verso 章名 x≈120–130、recto 节名 x≈195–280）；
   ② **`§` 后的数字位数**——`§N.M` 是目录项（2 位），`§N.M.K` 是小节（3 位，印刷目录不收），
   小数点本身会乱成 `∙ ， ． 、`，只能"取数字、忽略分隔符"。
   另外**数字前缀不得含汉字**，否则 `例 1.2 写出复数…`、`定义 5∙6 …` 会冒充标题。
2. **重复出现的固定标题带图标前缀**：`目 本章小结 / 目 思考题 / 目 习题一` 的"目"被 OCR 成
   `围 / 田 / 囗 / 回`，于是 `t.startswith('本章小结')` 永远 False。用
   `^[^思]{0,3}思考题$`、`^[^习]{0,3}习题[一-九]$`、`'本章小结' in t and len(nz(t))<=8` 这一类
   **允许 0–3 个杂字符**的写法。`§ 1.2` 的 `§` 还会整个丢掉变成 `*1.2 复数的三角表示`。
3. **两层 OCR 同时漏掉的标题，用墨迹带测 y**（`references/inkband.py`）：渲染 4× 灰度，
   在左栏 x∈[25,150] pt 逐行统计暗像素，合并成带，再**减掉文字层已有行的 bbox**，
   剩下的"有墨无字"带里取 h≈9–12 pt、maxdark≥60 的那条 = 标题行。
   本书 习题一/二/三 三条正文层与 WinRT OCR(300 dpi) 都读不出，靠这个测出 y=238.2 / 317.8 / 303.8，
   contact sheet 复核三条**全部正中**。控制组（习题四…九，层里有字）不会报出多余带，方法可信。
   别退化成"锚到下一行正文"——那是把书签指到别处。
4. **深色条带里的标题**（`第五版前言/第一版前言/目录` 排成黑底白字横幅）：前言的白字层里能读到（y≈50），
   `目录` 整条读不到 → 取横幅顶边（全宽暗行扫描，p8 实测 y=42.5）。
   这类页 **ink 验收必然假阳性**（对比度反了：下方"暗"其实是条带本身），看图为准。
   同理，标题左上方有**二维码**的书（本书 §8.2/§9.4）也会假阳性。
5. **页码标签可能要两段罗马**：本书 前言 Ⅰ、Ⅱ（p6–7）与 目录 Ⅰ、Ⅱ、Ⅲ（p8–10）各自从 1 开始，
   `set_page_labels` 支持多个 range，写成
   `[{0,'a',1},{5,'r',1},{7,'r',1},{10,'D',1}]`。别把两段罗马并成一段（那会让 目录 读成 Ⅳ、Ⅴ、Ⅵ）。
   无印刷页码的封面/前言用 `'a'` 字母段占位。

实测：73 条 = L1 15（前言×2 + 目录 + 9 章 + 附录×2 + 答案）+ L2 58（34 节 + 9 小结 + 6 思考题 + 9 习题），
0 MISS / 0 page-top / 0 oor / 0 nonmono / 0 dirty，4 条 ink 失败全是上述两种假阳性，7 张 contact sheet 逐条看过。
注意**第六、八、九章没有思考题**（印刷目录就没有），条数比"章数×固定套路"少是正常的，别硬凑。

### ROUTE P-CN 变体：三源交叉 + **八道闸门**（吉田耕作《泛函分析》中译本第6版 160 条，2026-10-04）
模板 = `_工作产物/吉田中译本/_jz_bm.py`（构建）+ `_jz_g1d.py`（空隙度量）+ `_jz_readback.py`（回读）+ `_jz_negctl.py`（负对照）。
这本书的特殊性：**印刷目录、正文标题、第三方旧树三个来源两两互有出入**，所以任何"两方对照"都不够，
必须三方各管一段：**目录白名单**管条目集合/层级/folio，**旧树**管字形干净，**正文墨迹**管落点。
新长出来的两道闸（都是被真实缺陷逼出来的，此前七道闸**全部放行**）：

- **G1(c) 题名「有序」逐字差分**：把书签题名与正文那一行的 CJK 字符做**有序**子序列差分，
  只报"正文行多出的字"（＝标题疑漏字）。⚠️ **集合式对照查不出漏字**：
  `§9. 一般展开定理` 被旧树抄成 `§9. 般展开定理`，而题名后半"…的**一**个条件"里的 `一`
  会把开头漏掉的 `一` **遮过去**（集合相等）。有序差分抓到后，人眼 12× 看图确认目录与正文都印"一般"，
  进 `TITLE_FIX`。差分的**噪声**是变音符/圈号被读成汉字（`Arzelà`→`Arze怡`、`Gårding`→`G虹ding`、
  `空间①上`→`空间金上`、`L2(Rm)`→`L叮厅n)`），**逐条定性写进 `G1C_OK` 判定表**，
  闸门只放行"已定性"的条目 ⇒ 新出现的同类噪声仍会报警。
