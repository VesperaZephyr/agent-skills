## Pipeline (per folder, e.g. `F:/.../分析学`)
工作目录 `_build/`，脚本：`tlbmk.py`(解析引擎) `build_t1.py`(书签生成) `diag.py`(分类)
`verify.py`(全库校验) `probe_t1.py` `worklist.py` `recover_empties.py`；
OCR 相关：`wocr_all.py`(多 worker) `winocr.ps1`(WinRT) `render_pages.py` `wocr_build.py`(不可见文字层)
`copyback.py`；图像目录书专用：`inject_imagetoc.py`(前台 OCR 注入) `build_imagetoc2.py`(标题式抽取)。

**复用纪律（复制到新文件夹后必须重指路径）**：
- `diag.py`、`worklist.py`、`verify.py` 硬编码 `ROOT`（各自文件顶部）→ 改 `ROOT="F:/.../新文件夹"`。
- `wocr_all.py`、`copyback.py` 硬编码 `BUILD` → 改 `BUILD="F:/.../新文件夹/_build"`。
- `build_t1.py`/`tlbmk.py`/`recover_empties.py` **不依赖 ROOT**（走 worklist，路径由 worklist 提供），无需改。
- ⚠️ `verify.py` 的 `ROOT` 极易漏改：漏改会扫描到旧文件夹而误报/漏报，务必每个新文件夹都核对一遍。

### Phase 0 — 分类 (diag.py)
对每本 PDF 取文本层，按前 11 个分位采样文字密度：
- A-ok：已有合格书签（**别直接跳过**：先用 `bm_quality.py` 证明它真的合格，见 Phase 4）
- T1：有文字层、无书签 → 直接进入 Phase 2
- S1：纯扫描件（密度 < 50%）→ Phase 1 OCR 后并入 T1 管线
扫描件末页常有元数据文字骗过密度采样 → 必须**多分位采样**，否则误判 T1。

### Phase 1 — S1 扫描件 OCR（不可见文字层）
复用 `pdf-scanned-ocr-bookmark` skill 的 WinRT OCR 流程（Windows.Media.Ocr, zh-Hans-CN），
`winocr.ps1` 按原生 DPI 渲染、`wocr_all.py` 多 worker、`copyback.py` 把文字层 `saveIncr` 回拷原文件。
OCR 噪声大 → 后续 Phase 2 目录检测要用宽松模式。
⚠️ **但"精品单本"（用户会逐条对页查的那几本）不要走注入路线**：注入的不可见层会让定位器
跟自己的输出匹配（Phase 1b 头号缺陷）。单本请改走 **ROUTE P-IMG**——同一套渲染 + WinOCR，
但 dump 留在 PDF **外面**，目录由人眼转录，交付文件里只多一套书签字节。
批量库里 N 本书共用管线时才用注入（`copyback.py`）。

### Phase 1b — 目录页是图片、但正文有文字层（"图像目录书"，如 Ahlfors/Courant/林源渠）
正文能定位、只有目录页是扫描图 → 不必全本 OCR。轻量做法（实测有效）：
1. `inject_imagetoc.py <pdf>`：只 OCR 前台 ~60 页（`render_pages.py`+`winocr.ps1`），
   用 `is_toc_line` 找出连续 TOC 页，把那段 OCR 文字以 `render_mode=3` 不可见层
   注入**原文件对应页**（`wocr_build.py` 写临时 pdf 后 `shutil.copyfile` 回拷，按页数对校验）。
2. 先试 `build_t1.build_one`（标准行式解析）；若返回 None/很少，用
   `build_imagetoc2.py`：**标题式抽取**——从注入的 TOC 文字抓
   `第X章 / Chapter N / §N / 附录 / Part N / Volume N` 等标题，再到正文文字层
   `overlap>=0.62` 定位 (page,y) 写书签。
   这类书目录是"左栏章节名 + 右栏页码列"两栏布局，行式解析器配不上，必须用标题式。
2. ⚠️ **自匹配陷阱（本节的头号缺陷）**：第 1 步把目录 OCR 文字注入的正是**原文件的那几页**，
   于是第 2 步"正文逐页搜标题词元"会先撞上**目录页自己**——书签全落在 p2..p6，标题还是 OCR 乱码。
   → 正文搜索**必须排除目录页区间**（`inject_imagetoc.py` 已知道该区间，把它传给 `locate`），
   并且解析出的标题要过 `bm_quality.py` 的 `dirty` 检查（`leader`/`moji` 一响就是锚在目录页）。
3. ⚠️ **旧结论作废**：本节原先写"Ahlfors 23 / Courant 26 / 林源渠 21 条，均跳转到标题 y"——
   **实测是假的**。2026-10 复查：Ahlfors 中译本 23 条标题全是 OCR 乱码（`1.2.4 球面表示 “ 3.3.3.3.3.3 对称性灬对称性 “`
   这种两栏串行＋重复），dest 落在 p2..p6 的目录页上。三本都已退回重做队列。
   **只有 `bm_quality.py` + contact sheet 看图**能宣布一本书完成，脚本自述的条数不算。
   进度：Ahlfors 中译本已改走 **ROUTE P-TXT**（人眼抄目录 + 脏层两遍定位）重做完成，171 条；
   Courant / 林源渠 仍在重做队列，它们的正文层同样脏 → 优先试 P-TXT 而不是再跑一次 Phase 1b。

### Phase 2 — T1 / S1 书签生成 (build_t1.py)
核心函数 `build_one(path)`：
1. `find_toc_pages(doc)` 定位目录页（连续"左标题+右页码"行 run + 锚点验证）。
   严格检测 < 4 条时自动 `find_toc_pages_loose` 重试（容忍 OCR 噪声）。
2. `parse_toc` 用 **span 级 y 聚类**重建行（目录行常被拆成 序号/标题/页码 三个 span，
   且有重复 span 需去重），点线正则要求**至少两个点字符**。
3. `assign_levels` 按缩进定层级。
4. `locate` 解析每条到 (物理页, y)：
   - 先试印刷页偏移 `offset`（由页眉页码图 `header_pagemap` 推出，必须 `validate_offset` 抽样验证）；
   - 偏移不可靠则 `fit_offset`（定位前 ~16 条标题反推模态偏移）；
   - 仍无则**正文逐页搜索标题词元**（`overlap >= 0.72`），连续 10 条失败即截断（防"第二/三册"清单）。
5. `apply_toc` 写 `set_toc`，强制层级 + 页码单调（`p = max(cursor, min(p, n-1))`）。
   - 质量闸门：条目塌缩到 < 3 页 → REJECT（不写）；这比写垃圾书签好。

### Phase 3 — 校验 + 找回 (verify.py / recover_empties.py)
- `verify.py` 全库走一遍：统计总书签数、unopenable / out-of-range / non-monotonic / dead-dests。
  **本管线产出的书必须 0 上述异常**；既有 PDF 原有的脏书签不在范围内（报告即可）。
- 对全部 0 书签 PDF 跑 `recover_empties.py`（调用 `build_one`）：
  既恢复"日志记了但写入丢失"的书，又补回被严格检测误杀的教科书；真正无目录的书
  （答案是/勘误/单章习题卷/短论文/公式集）会自然 skip。

### Phase 4 — 质量复审与重做（bm_quality.py，本次新增）
`python references/bm_quality.py <ROOT> [--csv out.csv]` 只读不改（ROOT 走 argv[1]，**不必**改文件头），
逐本输出 `bm / top / pages / oor / nmon / flat / dirty / levels / labels / verdict`，
末尾再打一份 **dirty-title breakdown**（`leader / esc / moji / ctrl / tex` 逐类计数）——
标题缺陷在阅读器里全是**隐形**的，只有这份分类清单能看出是哪一类。
verdict 分类（阈值见文件顶部常量）：
- `page-top`：>20% 条目 dest y ≤ 0.5（含 `/Fit`、`(0,0)`）→ **必须重做**，这是用户最反感的形态。
- `flat`：>30 条全在 level 1 → 层级塌平，需重做（例：李红《复变函数与积分变换》230 条全 1 级）。
- `oor`：页号越界 → 重做。
- `dirty-title`：五类标题脏物（任一即计一次）：
  `leader` 残留点线＋页码（`3 柯西一黎曼条件 ∙ 22`，中文书常用单个 `∙` U+2219 当点线）、
  `escape` 字面 `\u00xx`、`moji` 编码错、**`ctrl` 标题里带 NUL/控制字符**、`tex` 残留 `$...$`/`\macro`。
  锚在目录页的那几类整本重建；只改标题不算修好。
- `nonmono`：(page,y) 序列回退 —— **提示级**，多为锚在目录页或页眉重复标题，逐条看图判定。
- `add-labels`：书签可用但没有 /PageLabels → 只需补页码标签，成本极低。
- `EMPTY`：0 书签，走 Phase 1/2 正常管线。
实测（分析学 347 本）：REWORK 175（其中 page-top 91 本、13435 条）、add-labels 75、OK 75、EMPTY 22。
⚠️ `ctrl` 这一类是**后补的**：加进去之前，谭小江/伍胜健《复变函数简明教程》57 条标题**全部**以
`\x00` 结尾却被判 OK。所以拿到旧报告别照抄——`bm_quality.py` 改过之后必须**重跑整个文件夹**。
重做顺序建议：先扫 `page-top` 里的**英文原版**（文字层多半存在，Phase 2 直接可跑），
再处理 `flat`/`dirty-title`，最后统一补 `add-labels`。

### Phase 5 — 单本精修：纯扫描英文巨著（Conway GTM159 打法，本次打通）
适合"这一本必须完美"的场景：412 页扫描本、无文字层、目录是图。模板脚本在 `references/`：
`scan_toc_data.py`（目录数据）+ `scan_build.py`（定位＋写入＋页码标签）+ `scan_verify.py`（看图校验）。
1. **人肉抄目录**：翻原书印刷 Contents，把每条 `(level, label, printed_page, kind, key)`
   逐字写进 `scan_toc_data.py`，并定 `K`（物理页 1-based = 印刷页 + K）。抄目录这一步不要相信 OCR，
   直接看图读页码；顺手把前置部分（Title Page / Preface / Contents）也写成条目。
2. **定 K**：找几个已知锚点核对（Chapter 13 起于物理 16 → 印刷 1 ⇒ K=15）；
   再用**页眉页码审计** `audit_folios()` 全本走一遍：每个正文页页眉带里的纯整数必须 == phys-K
   （Conway 实测 340 页全对，2 页为章起始页无页码）。注意本扫描本把 folio 印在**页眉**，
   不能只查页脚。
3. **渲染 dpi=72 的原生像素**：这类扫描页 `page.rect` 就是原生像素尺寸（2242×3857 pt），
   72 dpi 渲染 ⇒ **1 px == 1 pt**，`SC = 72/DPI = 1`，OCR 框坐标直接就是 PDF 磅值。
   **不需要** `wocr_build.py` 注入隐形层——只用 OCR dump 定位，原文件图像流一字节都不动。
4. **OCR 分块**：`os.link` 硬链接把 412 张 png 秒切成两块，2 个 worker 跑 `winocr.ps1`；
   dump 列序是 `y \t x0 \t x_end \t h \t text`（不是 x 先）。
5. **英文 WinRT OCR 归一化**（噪声专治：词内插空格 `Analyt ic`、`0→o`、`l→I`、`§→''`、标点变空白）：
   - `nrm(s)`：只留 `[0-9a-z]`，把词内空格全部消掉；
   - `variants(s)`：再试 `0→o`、`1→l`；
   - `sim()`：`difflib.SequenceMatcher` 比值；公共长前缀加分**必须**要求
     `min(len(c),len(g)) >= 10`，否则 `"List of Symbols"` 会匹配到光秃秃的一行 `"1"`。
6. **按字高认标题**（这是扫描本分层的关键，比缩进可靠）：
   chapter opener h≈117–119；section heading h≈57–60；后置材料居中大标题 h=66–92；
   正文 h≈44–47；页眉 running-head h≈40 且 y<200。
   于是 chapter 用 `h>=80`，section 用 `x0<=260 且 h>=40 且 sim>=0.6`（§N 号对上再加 0.05），
   后置材料用 `h>=55`。
7. ⚠️ **后置材料标题在页顶 y≈112**：`References`/`Index` 就印在页眉带里。若沿用
   `lines_of(skip_head=True)`（丢弃 y≤200）会永远 MISS。`find_back` 必须单独搜 `y<=400`
   并用 `h>=55` 把同词的页眉（h≈41）挡掉；阈值 0.75（OCR 把 `Index` 读成 `lndex`，ratio 0.80）。
8. **MISS 就拒写**：任何一条没定位到，整本不落盘（`refusing to write while N entries are unlocated`）。
9. **页码标签**（见下节）+ `set_toc`，一次性在 ASCII 临时副本上做完再搬回。
结果：Conway GTM159 = 84 条（16 个 1 级 + 68 个 2 级）、0 MISS、0 ink 失败、3 段页码标签、
体积 2652673 → 2684862 字节（只增元数据，图像几何与备份逐字节同）。

### Phase 6 — 单本精修：中文教科书扫描本（王晓光《101复变函数》打法，本次打通）
模板脚本：`references/cn_build.py`（骨架→定位→写入→页码标签）+ `references/cn_verify.py`
（结构 / folio / ink / contact sheet 四合一验收）。两者顶部常量（DPI、SRC、K、OLD、OCR dump 路径）
**逐本重指**，文件里带了重指清单。
和 Conway 的**三处本质差别**：① 页面是普通 PDF 尺寸（`page.rect`≈524×734 pt）而不是原生像素，
所以**必须** `SC = 72/DPI = 72/200 = 0.36` 把 OCR 像素框换算成磅——Conway 那套"1 px == 1 pt"**不能照抄**；
② 目录/正文里全是 `N.M` 编号，**编号本身就是最强的判别器**，不必像英文书那样靠字高硬分；
③ 旧书签列表本身是**可用骨架**（结构完整、标题干净），不必人肉重抄目录。

1. **以旧书签列表为骨架，以印刷目录＋正文标题为权威**。249 条旧条目给出层级和标题文字；
   印刷目录（OCR 后逐行解析）和正文标题用来**校验编号、纠正错字**。
   本次旧列表里揪出 3 处硬错并改正：`第二十三章` 页 41→241、`重道复偏导数`→`重温复偏导数`、
   `31.3 非连通域的双曲度量`→`单连通域的双曲度量`（放大 4 倍看印刷字才敢定）。
   ⚠️ 反过来别信 OCR 目录的**拉丁字母/公式**：`Arzelà-Ascoli`、`∫` 一类必然被读烂，
   这类标题保留旧列表写法或手写 Unicode。
2. **NUL 结尾的旧标题**：`DROP` 集合（封面/声明/版权…）明明写了却不生效、条数 249≠244，
   根因是**每条旧标题都以字面 `\x00` 结尾**，`t in DROP` 永远 False。
   → 任何"标题字符串比较"之前先
   `t = re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\ufffd]', '', title).strip()`。
3. **编号自洽即验收**：level-2 按出现顺序推导成 `N.1, N.2 …`、level-3 推导成 `N.M.K`，
   再和书里**印出来的**编号比。全库 0 MISS ⇒ 既没漏节也没多节（比"条数对上了"强得多）。
   推导出的编号还要 `bare()` 先剥掉标题里已有的 `N.M(.K)` 前缀，否则出现
   `17.4.1 17.4.1 火腿三明治定理` 这种双重编号。
4. **OCR "L 方言"**（WinRT 读这本书的序号专病）：序列 `1.` 被读成 `L`
   （11.1→`1L1`、21.2→`1.2`、21.5→`2L5`、31.4→`3L4`），分隔点还会变成 `·，．`。
   → `LEAD = re.compile(r'^([0-9lL.]{2,9})(?![0-9lL])')`，`lead_digits()` 把每个 `l/L`
   展开成 {'1', ''} 两种可能、丢掉所有点，**只比数字串**。`numok`（编号对上）比文字相似度更可信。
5. **落点判别的几何门限**（单位=磅，`SC` 换算后）：
   - 章首页 `第X章` 居中 y≈115–123；**字高不可靠**（`* 第十四章` 只有 h=6.5，正常 h≈15）
     → 章必须按**文字** `CHAP_HEAD` 匹配 + 中文数字相等，窗 ±1 页，**不要**加 `h>=` 门限；
   - 节标题 `N.M 标题` h≈9.4–10.8、x0≈68–98；**小标题**缩进到 x0≈113 → 门限写 `x0<=128`；
   - 页眉 running head 也是 `N.M 节名`（y≈40、x0≈350–440、h≈5.8–6.1）→ 用 `y>=58` 排除，
     但它同时是**免费的交叉校验**（页眉编号 == 该页所属节）；
   - 正文里同样有 x0≈75–105、h≈8.6–10.8 的行 → 光靠几何必然误命中，
     **`N.M` 数字前缀才是判别器**，几何只当过滤器。
6. **打分＋窗口**：`sc = 6*numok + 4*sim + 1*(p==expected) - 0.4*|p-expected|`，
   接受条件 `numok or sim>=0.72`，窗口 ±2 页（章 ±1 页）。±2 页足够窄，配上前缀匹配，
   错配会自己以 MISS 的形式暴露，不会静默指到别处。
7. **标题排版**：LaTeX 残迹换成可读 Unicode 数学（`$\int_{0}^{2\pi}...$` → `∫_0^{2π} Q(sin θ, cos θ) dθ 型积分`）；
   半角冒号后紧跟汉字要收成全角并吃掉空格 `re.sub(r'[:：] *(?=[一-鿿])', '：', t)`；
   `(续)/(一)` 之类括号统一成全角。注意 `bm_quality.py` 的 `tex` 只认 `$` 和 `\macro`，
   `^{`/`_` 单独出现**不算** LaTeX（那是有意为之的 Unicode 数学写法）。
8. **页码标签四段**（中文教材通用形态）：
   `{1:'a'}` 封面～前置无页码 → `{9:'r'}` 目录 i、ii… → `{17:'D',firstpagenum:1}` 正文 →
   `{402:'a'}` 出版社后置（版权页/郑重声明）用字母，绝不会被误读成书面页码。
   本次 K=16（物理 1-based = 印刷 + 16），**两条独立证据**：页眉 folio 审计 325 页全对，
   以及印刷目录里 `31.3 … 313` 这一行落在物理 329。
9. **丢弃项要报告**：出版社后置的 5 条（封面/声明/版权/101计划信息/郑重声明）不挂书签——这是**决定**，
   收尾时必须告诉用户，不能默默少掉。

结果：《101复变函数》= 405 页 / 244 条（45+197+2）、0 MISS、0 page-top dest、
0 ink 失败、folio 325 对 4 疑（那 4 处是页眉带里的公式数字，不是 folio）、4 段页码标签，
`bm_quality.py` verdict 从 `page-top(249)` 变 `OK`。

### Phase 6b — 中文扫描教科书的第二次实战（钟玉泉《复变函数论》第五版，166 条）
同一套管线的复跑，新增四条只有实战才逼得出来的规则：
1. **folio 审计必须加"版心门限"**，否则假 mismatch 会把你带偏：本次 3 处"页码不符"其实是
   页眉/正文里的孤立数字。可用的筛选是

   （页脚带 + 小字 + **靠版口**：verso 左、recto 右）。加上之后 225/225 全对，K=9 一锤定音。
