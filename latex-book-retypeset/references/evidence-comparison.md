# 原书—重排对照材料（对外展示与逐句校勘共用）

用途：把「同一处内容，原书长这样、重排长这样」做成可信的对页图与标注图。
既用于向他人汇报进度，也用于逐句审阅时定位两个 PDF 的同一页。

## 1. 先配对，再取图

扫描 PDF 常常没有文字层，`pdftotext` 返回空，无法直接比对。两条路：

| 情况 | 做法 |
|---|---|
| 扫描件有 OCR 逐页结果（PaddleOCR-VL 的 `*.json`） | `scripts/pair_page_by_text.py --scan-ocr ocr.json --latex main.pdf -o pairs.json` |
| 扫描件本身有文字层 | 两边 `pdftotext` 后同样取 12-gram 比对 |
| 只有图像 | 人工抽页 + 印刷页比对，不要猜 |

配对算法要点：字符 12-gram 集合、数字权重 ×3、**强制单调**（扫描页不得随重排页倒退），
先用中位数估计相邻偏移，再在 ±12 页窗口内做前缀最大值 DP。
分数低于 0.03 的配对必须人工复核——它只表示"文本重合得少"，不代表配错，也不代表配对。

`pairs.json` 只用来说明「这两页是同一内容」，**不是**内容正确的证据。

## 2. 取整页图

```bash
pdftoppm -f 214 -l 214 -r 150 -png main.pdf work/hi-latex-214
pdftoppm -f 187 -l 187 -r 150 -png scan.pdf work/hi-scan-187
```

- 150 dpi 足够做整页图；要裁小字块用 300 dpi。
- 300 dpi 的大开本扫描件会超过 Pillow 默认的 1.79 亿像素上限，脚本里必须 `Image.MAX_IMAGE_PIXELS = None`，并在裁切后立刻降采样。
- 页码要分清**印刷页码**与 **PDF 物理页**；配对结果给的是物理页，台账记印刷页。

## 3. 裁出「同一块内容」

选一处有辨识度的对象：同一道例题、同一个定理、同一个图表。要求：

- 两侧都在同一页内（跨页内容不要拿来对照，读者会以为漏了）；
- 左侧保留题号与「解」字，读者一眼确认是同一题；
- 裁切框按整页比例给（`x0,y0,x1,y1` 归一化），换 dpi 不换框。

```bash
python scripts/make_compare_crops.py --image work/hi-scan-187.png \
  --box 0.035,0.538,0.965,0.711 --out assets/xu-scan-cor.png --width 2400
```

输出宽度按最终显示尺寸的 1.5–2 倍给（1080p 里显示 1400 px 就裁 2400 px）。

## 4. 标注坐标靠量，不靠目测

`make_compare_crops.py` 会打印墨迹行带表：

```
[9] y 0.817-0.864  x 0.326-0.453
```

意思是「第 9 行内容占高度的 81.7%–86.4%，横向 32.6%–45.3%」。据此写进 CSS：

```bash
python scripts/make_compare_crops.py --image assets/xu-latex-cor.png --bands-only --highlight 9
# CSS: left:32.6%; top:86.8%; width:12.7%
```

红线/框选必须落在**同一行**（例如两侧都标 `dy/dx` 那一行），否则比不标更伤可信度。

## 5. 版式惯例（1080p 讲解片/汇报页）

- 第一阶段整页并排：页面高 ≤ 800 px，标「原书 P.x」/「重排 P.y」。
- 第二阶段单侧放大：关键块宽 1000–1450 px。
- 第三阶段收束：给一个数字（203 → 129 / 181 → 208），字号 90–110 px。
- 两页并排时轻微反向旋转（±1.3°）能明确"这是两张纸"，弧度再大就失真。

## 6. 诚实边界

对照图证明的是「同一处内容被放到了同一位置」，**不证明**数学推导正确、也不证明版式完全一致。
报告时必须写清：

- 用的是哪一版原书（版次/印次）；
- 页码是印刷页还是物理页；
- 是否有跨页搬移、补页、重排导致的页码漂移；
- 原书本身有批注/污损/缺页时要指出，不要裁掉当作没有。
