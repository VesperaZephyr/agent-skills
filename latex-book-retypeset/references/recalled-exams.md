# 中文回忆版试卷合集：重排与审阅

适用于多校、多年、各卷独立题号与分值的合集。先看原书，再选择计数器；不要把 GTM 的单计数器硬套到试卷。各卷可能交替使用“一、二”与“1、2”，有题组内重启和原书缺号；可保留显示题号，用独立隐藏计数器建立唯一锚点。

## 来源与生成

- 保留只读的原 PDF、原 OCR 与结构化数据。以“物理页 + 原始块索引”建立稳定来源 ID，修订同时记录原串、新串、核图依据。修订应能断言原串仍存在，禁止匹配失败后悄悄跳过。
- 建立卷清单，对比原目录的学校、年份、卷数与顺序。标题分隔符可能是句点、全角点或冒号；本次第 118 套标题为冒号，只认句点会漏整卷。
- 分开盘点正文块和被丢弃块。OCR 的 `header/footer` 是候选分类，不能直接当作可删除的事实。本次扫描第 176 页的“3. 计算”被归为页眉；须核图恢复，其余页脚是推广信息。去掉推广页不等于可以去掉正文题号。
- 相邻题块可能有重复粘接。本次第 98 套第 12 题既被粘到第 11 题末尾，又单独输出。删除重复须有原页依据；不能按文本相似度全局去重，不同学校重复题应保留。
- 结构化 OCR 里的 TeX 可能逐 span 混用正常反斜杠与二次转义。先取代表 span 的 `repr` 检查；不要全局将双反斜杠折成单反斜杠，否则 `array/cases/aligned` 的换行也会被破坏。检测双转义命令后按该 span 规范化，另核对行列。
- 长行内公式可在不改变数学含义的情况下改作行间公式。复杂公式应先分行，不能靠任意缩小字号掩盖超宽；记录实际缩放比例并核验可读性。

## 把忠实转录与数学审阅分开

正文保留回忆题面、忘题文字、分值和原编括注。确认是识别错误时，核图后恢复正文；原书题目确错时，另列勘误、反例与修订建议，不擅改成猜测的“正确原题”。用户明确要修订版时，再额外提供有标记的修订稿。

审阅记录至少包含：卷号、学校年份、题号或稳定块 ID、原书印刷页与物理页、分类、依据、建议、核图状态。区分：

1. **识别错误**：与扫描页不一致，修复源头并留证。
2. **结论错误**：题面与原书一致，有反例、代入矛盾或严格推导。
3. **条件缺失/题面异常**：定义域、初值、正则性、方向或题型不明确。
4. **回忆缺失**：仅有“忘了”“未知”或题型概述，不按常见题猜补。
5. **待核**：只有疑点，证据不足，不计入已确认错误。

“判断并证明是否一致收敛”容许答案为不一致收敛，不能误报为题目错误。“可能有误”也不等于确错：例如球面与同半径圆柱交于赤道，交线合法；Jensen 不等式也可能正确。

## 审阅顺序与典型检验

先查题型和量词，再查定义域、端点、零分母、积分两端、初值和正则性；随后用常数、线性、二次函数及标准反例检验，最后才考虑复杂推导。不要为寻找错误把相邻题的前提漏掉。

- 常数函数能发现漏初值、漏导数撇号及不可能的极限结论。
- 反常积分必须同时查零端与无穷端，如 `cos^2(x)/x^p` 两端分别要求 `p<1` 与 `p>1`，无收敛参数。
- 函数列用移动峰值检验一致收敛，例如 `nx(1-x)^n` 在 `x=1/(n+1)` 的值趋于 `1/e`。
- 闭区间无界点可能只有端点，不能擅将 `[a,b]` 写为 `(a,b)`；单纯无界不代表向正无穷无界。
- Green 公式应先固定径向量与外法向的约定；用简单调和函数或已知表示公式核符号。球上的加权积分恒等式可用 `u=1` 检验维数系数。
- 比较含根式题时，放大检查每层根号横线。此次安徽大学题 OCR 漏了外层平方根，误让正确的“发散”题看似错误。数学矛盾应先触发核图，不能直接写进原书勘误。

## 交付与范围声明

分别报告内容覆盖、排版编译、原页精校和数学审阅的完成程度。全部卷都生成、编译零错误、书签可用，均不能证明每题录入无误或数学正确。初筛结果称首轮审阅；未逐题完成证明就不要声称全题已证明正确。未决项保留可继续核查的位置。

PDF 验证包括：卷标题和目录数匹配，来源 ID 唯一、正文与审阅回跳都解析，物理页映射正确，清辅助文件后多遍编译，零缺字与超宽。目视核查普通卷、密集公式、跨页题、分段函数、目录及附录；不要只看封面。

原书可能已印有 `??` 公式引用或 `???` 回忆括注。须先核图区分原书字面占位符与本稿新增未定义引用；前者建立逐处白名单和审阅记录，校验保留位置与数量稳定，后者仍必须清零。不要为达到字面数量零而静默删改原题。


## 全书精校的新增验收经验

- 逐页生成“扫描原页—同页题块重排”的并排校样，建立物理页、印刷页、图像路径及实际查看状态台账；只给确实查看过的页面标记完成。紧凑对照稿用于核内容，最终成书另查版式，不能混为同一次验收。
- OCR可能只剩公式而整段前提消失。例如仅剩f(0)=0、f(1)=1和导数乘积，不能视为一道完整题；需核原图补回连续、可导及存在性叙述。另一例只识别L和两自变量，遗漏整段Lipschitz前提。块数量一致仍可能漏题面。
- 分段函数中的中文条件、互素条件和端点括注可能整段漏失。逐行核对每个条件；中文须放入text，长条件可分行，不可为压缩宽度删字。
- 单独成块的公式容易丢题号或子问号；允许修订块类型，明确区分原始公式块数与修订后的显示块数，不能为了通过数量检查拒绝恢复文字。
- 限式错位可能表现为错误行内极限再附一条重复行间限式。核图后应恢复唯一正确限式，不机械保留两个。
- OCR合并大题标题时，仅在数学环境外识别中文大题号并恢复段落；不得在公式内用全局替换。候选异常必须二次核图，不能把视觉缩放造成的错觉当作勘误。
- 原题量词相互矛盾（如正项递增且级数收敛）、常数缺正性或变量下标笔误，分别列入题面异常与条件缺失，附直接代入或简短证明。原题为判断题时，假命题本身不构成出题错误。

- 成书复验须防止卷标题孤立于页末：预留高度应覆盖标题、来源行、首个大题标题及首题开头，不能只留标题自身的高度。引出行间公式的“定义”“使得”等句末与下一公式之间应禁止分页。Needspace导致标题换页时，题块锚点必须放在预留空间之后，否则审阅回跳会落在前一页。原编长括注可移至定义后的独立段落，避免贴着分段大括号中部断行。
