# 数学书重排稿逐句审阅 · Conway 两册复盘

适用于用户要求按原书逐句、逐式核对现有重排稿的任务。按用户指定的章节、附页和链接范围安排审阅；全书审阅覆盖两份文件的首尾与正文。

## 先核印本，再定审阅范围

1. 给每份原书和校样记录文件名、SHA-256、PDF 物理页数。读原书扉页、版权页、印次数字列及目录，记录版次、印次和可见差别。冻结本轮的校样文件，注明源码位置对应冻结版还是当前稿。
2. 分开记录原书印刷页码、原书 PDF 物理页、校样 PDF 物理页和校样可见页码。先查正文首页、章界和书尾。某段确有固定偏移时才据此换算，并注明区间。前置材料、空白页、双页扫描、页码重启和卷末附页按实际页面登记。台账物理页从 1 数，调用 PDF 工具时确认索引基数。
3. 交接指定扫描缺失时，先核完整候选本的版次及实际覆盖。能用同版候选本和交接留图完成核对的区间继续审阅，逐页注明来源。留图与候选本对照一致的结论只覆盖所见印文。来源身份、内容覆盖、缺页或异文分别报告；遇实质异文或字形不可辨，记录版本差异和未决单元。

Conway 的 GTM 11 两份扫描均为 331 页，正文起页与书尾材料有差异。GTM 96 的第二版 414 页扫描与交接 416 页底本也有不同的正文偏移，另有一份 419 页本实为第一版。GTM 11 第 XI–XII 章的原书图相互对读，可以确认所存页的印文。原文件是否同一及差额对应哪些附页仍需原件证据。这类情况可明确写成「基于现有第二版的内容审阅已完成，交接扫描文件的身份及附页待复核」。

## 正反两向核对

- 以章、节或跨页单元分批。先独立盘点原书正文、陈述、证明、公式、习题及子问、脚注、表格和图。全书范围再列前言、目录、书目、索引、符号表、封面和补白。用下一节或下一章的开头核实批次末尾，保留跨页句的接续。交接错误示例与自动扫描命中项都纳入核验，整批仍须连续对读。
- **原书 → 校样**查漏排、符号、编号归属、字体语义和顺序。**校样 → 原书**追查新增推导、额外段落、重号和无来源的内容。按内容单元配对，允许一对多和多对一。分别对原书物理页和校样物理页核查并集；全文之外的补白页亦标记证据。页级记录写明已核单元或起止锚点，页内未核部分留在续审清单。
- 看实际页图。OCR、PDF 文本层和版面差分可定位候选。正文可先用约 260 dpi 的清晰页图，疑难公式按需要放大到 400–800 dpi；微小星号、撇号、共轭线和下标用局部高倍图，裁框保留上下邻字。项目已指定取证要求时按其要求执行。原件是位图时，提高渲染分辨率只扩大现有细节，仍不清楚的字形留待复核。
- 逐图确认几何关系、端点、箭向、虚实和子图位置。图题或正文仍有指图句时，追到实际放置页与相邻页。习题按原印题号、题干、子问和共用条件核对；逐节计数和连续性检查用于找候选，原书自身的跳号照实登记。脚注同时核正文标记、注体及续页。
- 审阅小组共享同一冻结校样。各批次单独落盘，交接时写实际核至何处、页内剩余对象、差异 ID 和证据。主持者验收正反两套页表、图证路径、差异 ID 唯一性与跨页衔接后再合并。

## 链接核到位置和语义

1. 目录核层级、显示页码和实际落点标题。索引与符号表按[索引专项审阅与回归](../SKILL.md#索引专项审阅与回归)确定范围。全量批查结构、页码和链接，按该范围复核正文语义。核验单元是「索引类别＋词条完整路径＋每一原引页码、区间或参见目标」。
2. 同时登记原引页、校样可见数字、实际 PDF 目标页、页内位置、建议目标和语义证据。并排记录可接受的续文、同页错段、异页错链、无链接、原书误引和缺正文。候选匹配须读上下文排除页眉、同名对象和相邻习题。原书只给打印页而该页有多处相关内容时，留下候选及取舍依据。
3. 用 PDF 实际链接和命名目标的解析结果核查锚点。先用一个已知位置验证坐标系，再按同一坐标系裁目标上下文。Conway 使用的 PyMuPDF 路径中，`resolve_names()` 返回的某些命名目标保留 PDF 的左下原点。对当时未旋转、页框一致的页面，距顶坐标为 `page.rect.height - y`。工具若已经返回页顶坐标就直接使用；有旋转或裁切偏移时按实际页面变换验证。页号正确、目标存在和语义正确分别核验。

GTM 96 的 622 个索引链接中，同一个词条的不同数字有复用同一锚点的情况。例子是 *adjoint* 的三个定位，分别讨论 Hilbert 空间上的伴随、Banach 空间上的伴随和稠定义算子的伴随，冻结校样三处都跳到物理页 50。同页跳转也会误入相邻定义，例如符号表中的曲线系统 Γ 跳到单曲线 γ 的定义。将此类异常作为优先复核对象，判定写入统一清单，见 [共用索引审阅流程](../../mathtranslation/references/index-audit.md)。

## 差异记录与交付

一条记录应能直接定位原印与校样。例如记录章、节、条目号或首句、原书印刷页和物理页、冻结校样物理页、源码行或生成器定位、图证、差异及影响。单独注明原书已有的疑误、不同印次、确认的重排差异和现稿已有的修复。读不清的符号可用数学关系缩小候选；数学上合理的读法仍需明确标记证据来源。用户只要求审阅时交付核对和修订依据。需要修订时，按真实源文件修改，重建后复查改动单元、相邻跨页、编号和受影响的索引跳转，更新成品证据的版本。

| Conway 实例 | 后续审阅应执行的检查 |
|---|---|
| GTM 11 的拉普拉斯方程漏排，原式号挂在前一组偏导公式上（C11-III-016） | 式号与公式内容成对核查，再查看引用该公式的定义。 |
| GTM 11 第 VII 章第 2 节习题 11–13 整题漏排（C11-VII-010） | 从原书先建立题单，包含末题、子问与跨页题。 |
| GTM 11 的绕数习题改画后，重绘路径对指定点的绕数成了 2，题面要求为 0（C11-IV-027） | 除检查标签与方向外，必要时验证图所表达的数学条件。 |
| GTM 96 的习题共用条件进了编号列表，七题错号，三处题内链接指错（F96-IV-022） | 将共用说明与有号条目分开，按实际题干验证引用。 |
| GTM 96 的 Fuglede–Putnam 证明漏掉伴随星号（F96-IX-020） | 在原图与校样都放大算子上下标，核对同一行前后的代入。 |

Conway 本轮核了 23 章及两册卷首卷末，正向覆盖两份现有第二版扫描的 745 个物理页，逆向覆盖 785 个冻结校样物理页，共登记 642 组记录，其中包括重排差异、原书勘误、印次和已处理项。两校样的 3,820 个内部链接矩形均能解析目标，仍发现误指以及未建立链接的页码。
