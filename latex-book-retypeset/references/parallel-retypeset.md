# 有界子代理与页级 OCR 底稿

## 普通连续页码教材的编号分流

Ahlfors 第三版不是 GTM 共享计数器，也不使用 Serre 的分章页码：书页连续，
节号在章内重新起算，定理号与公式号各自保留原书显示号且打印时不含章号。
Corollary 1/2 还会在同章不同位置再次起数，公式 (60)、(58) 也有原书重述。
因此内部 label 要含章号，重复的显示号再用节/物理页/块号消歧，不能把隐藏
锚点计数器的连续性强加给打印编号。带署名的 `Theorem 5 (Picard).` 与无号
Corollary 要纳入陈述盘点，不能只匹配 `Theorem <数字>.`。

全书重排且允许并行代理时，可把独立章节、插图盘点、索引/前置分给子代理。
主代理先确定公共宏、label 命名、原书页码映射和输出目录；每个代理只拥有明确
的生成器与生成文件，避免同时改 cls/main/公共交叉引用器。交接须包含生成器、
原书物理页范围、构建结果、未决项；主代理负责跨章引用及边界覆盖验收。
这可以缩小各代理的上下文，但不能用子代理自报完成代替原页核验。
长项目可给新代理只传独立工单、必要约定与原始资料路径，而不是整段历史；
支持时采用最小历史的 fork。已有审计任务变长时，可按剩余章节重分工，但
先通知原代理停止处理移交范围，并给各修订表独立文件名，防止补丁重复。

## 已验证的数据结构陷阱

Ahlfors 第三版的 MinerU JSON 被拆为 200 页 + 147 页两份，第二份 `page_idx`
从 0 重新起算。合并前先明确全局物理页号；不能只按局部索引派发页码。

同一底稿的 `para_blocks` 会把跨页段落开头搬到上一页，并在原页标记
`lines_deleted`。若项目依赖 `sourcepage`、原索引页码或页级核对，优先使用
保留原位的 `preproc_blocks`，或者显式保存跨页搬移映射；不能混合读取后
重复落盘。`discarded_blocks` 也可能含真实 `page_footnote`，不能统删。

一个 `image` 块不一定等于一幅有编号插图：原物理页 176 的一个块包含
Fig. 4-13 和 4-14。同页 `image_caption` 还可能吞入后续正文（原物理页133）。
须分别建立块、图号、图注与正文的关系，不能靠块数验收覆盖率。

## 原索引与新页码

保留原索引条目、子条目和原页码作为核对底账；新页码索引可由原页级
锚点注入索引标记，再运行 makeindex 生成。两者语义不同：原页链接是
“原书此页的对应文本”，新索引页码是“重排 PDF 的实际页码”。二者都需要
核对锚点实际位置，不能只验证链接目标存在。

## 验收状态

完整 OCR 底稿、编译通过、结构检查通过、逐页内容已审校是不同阶段。
报告中须分别记录，特别是公式、习题、脚注、插图和索引的目视覆盖范围。
无独立文献表的原书应保留脚注文献结构，不额外发明参考文献列表。

## 数学与脚注的独立复核

可按章派发“原书公式裁图—原始OCR式—生成LaTeX”的逐式核对，另扫全部
页边编号带。非数字 `tag` 只作异常候选：本书 OCR 把连接词 `or` 识成了
公式号；真正有号和无号须由原图判定。OCR 也可能把正文中的单个 `lim`
或 `f(z)` 错列为行间公式，仅统计显示环境数量无法发现这种分类错误。

脚注正文可能在 `discarded_blocks/page_footnote`，也可能被识成普通 `text`；
正文标记还可能被吞进数学 span。须把脚注正文、正文标记和双向目标分别
登记。处理重叠识别结果时先排除残片，不能把一条完整脚注和它的四个
残片计为五条。恢复漏标记须核对原图中的具体句子，不能就近插在同名
变量首次出现处。

引用解析优先读取显式上下文：`Chap. 5, Theorem 12`、`Sec. 1.3, Ex. 4`
不能当作当前章/当前小节裸引用。先解析完整限定形式，再处理本地引用；
扫描时排除源码注释，避免把页级来源注释计入已链接正文引用数。

## PDF 实际目标与索引范围

链接检查除 `get_links()` 的页号有效性外，还须遍历原始 `/Link` 注释的
`/GoTo /D` 与 PDF named destinations。Ahlfors 实测一些不存在的命名目标
未被仅查 `LINK_GOTO` 的脚本发现；这还找出了两条以 `\dagger i`、
`\dagger\theta` 数学 span 起头的脚注正文，不能只匹配文本字符 `†`。
定制脚注已有显式目标时可关闭 hyperref 自动脚注链接，避免空脚注号锚点。

如 hyperref 的个别 `page.<folio>` 目标缺失，页码索引可使用独立逐页
shipout 目标，并让索引页码链接指向这些目标；在最终 PDF 验证每一个被
引用的目标实际存在。不要因为 XeLaTeX exit=0 就宣布无死链。

原索引的连续页码往往表示整段讨论，而非每页都有字面词项。重排后优先
把能确认的词项精确定位，把其余源讨论映射为实际输出页码范围；同键相邻
范围先合并，避免 makeindex 嵌套范围警告。范围开端须随首个可见内容走，
不能让零宽源页锚点留在节标题前一页。浮图和分裂脚注仍需单独核验。

若独立 shipout 目标在最终 PDF 仍有缺失，可把目标补全作为可重现的构建
后处理，按最终 PDF 页标签建立所缺页顶目标。必须验证页数未变、既有
命名目标集合未丢失、每个既有目标仍指向原物理页，并再次遍历全部链接。
已有 `/Kids` 的 PDF name-tree 根节点不能再直接追加 `/Names` 数组：本次
实测该混合节点会使新目标被读取器忽略。可从克隆后的目标引用重建有效
name tree，不能把源 reader 的页对象引用直接带入新 writer。

索引中的 `101n.` 这类“第 101 页脚注”不可降格为普通数字后直接接受：
本书两个人名被误读为第 10 页，链接结构仍完全合法，却会跳错章节。
应单列所有 `n.`/罗马页码/续行数字，逐项核原索引与实际脚注；人名和
术语的 sortkey、显示文本也应分开，避免默认标点排序把 `Abel's` 放到
`Abel, N. H.` 前面。索引结构通过后仍要做这种语义核对。

日志中的包信息 `Package: rerunfilecheck ... Rerun checks ...` 并非重跑告警。
验收须匹配 `Rerun to get...`、`Please rerun...` 等真实请求，不能只对所有
`Rerun` 或 `rerunfile` 字样计数，否则新版本 TeX Live 的正常包信息也会
触发假失败。

行间公式前后的源码空白行会造成多余段落间距。OCR 生成器常给每个普通
文字块追加换行，拼接后在 `equation*` 前留下空行；公式修订表也可能重新
引入空行。应在所有内容、版式、引用和索引注入步骤之后，只清除紧邻
`equation`、`align`、`gather` 等行间环境的空白行，同时保留普通段落的
分隔。把“零处公式相邻空行”作为重建后的独立断言，并查看成品 PDF 的
代表性公式页，避免只检查源码就推定间距合适。

源码中没有相邻空行，成品仍可能出现过大的纵向空隙：书籍类默认的
`\flushbottom` 会拉伸页面可伸缩的行间公式间距。若原书页面允许页脚高度
自然变化，可在模板采用 `\raggedbottom`，并重新抽查公式密集页。
有原编号的习题若在页末只剩题号或“Show that”一行，可在建立该题锚点前
使用 `\Needspace{4\baselineskip}` 保留题号与开头几行。两项调整会改变分页；
必须重新编译并复验章节边界、索引页码链接、插图覆盖及全部 PDF 目标。

裸圆括号编号如 `(1)` 不能无上下文地链接到本章公式：原书可能在同一段
先列“条件 (1)、(2)”，随后连续引用这些条件，或在冒号后列三至五条
局部性质。应先识别并保护段内列表号，再链接真正的公式引用；成品抽查
列表号不跳转，且 “By (2)” 这类真实公式引用仍可点击。Ahlfors 此轮
发现 39 个合法目标却指向错误语义的链接，纯死链检查无法发现。

即使此前的显示公式专项审阅已完成，正文逐页校对仍可能发现 OCR 把
`y^2` 识成 `y^z`、把数字 `15` 记作 `1 5`、或将跨页尾词重复成独立段落。
可扫描数学源码中相邻数字被空格分开的候选、页界残句和等号条件等，
逐个回原书图像确认。TeX 数学模式会忽略普通空格，数字拆分未必改变
当前 PDF 外观，但应把准确写法存入原始修订表，避免后续解析误读。

原书的斜体陈述不一定有标题或编号。OCR 若把这类整段结论拆成普通正文，
应按原图确认起止范围，用不推进定理计数器的专用环境恢复字体，并检查
跨页续段是否仍保持斜体。带撇号的编号（如 Theorem 12′）也须保留印刷
编号和独立锚点，不可当作下一个整数定理；新增锚点后复核相邻引用和
标签唯一性。公式内的求和指标、围道下标一字之差也可能编译无误，应
同时看原图与成品，而不能靠 LaTeX 编译判定正确。

多名校对代理各自报告“原始稿唯一匹配”仍不足以保证修订表可同时应用：
先排序执行的一项整句替换可能已包含并修好后续表中的短片段。本次同一
习题的花体字母修订就与既有逐题表重叠。集成时须在干净生成稿上按真实
表顺序执行整套修订，遇唯一匹配失败先查是否重复，删除较晚的重复项；
不得在已部分修订的生成文件上重跑修订脚本。审阅代理写入的临时 `.py`
也必须满足项目的 UTF-8 无 BOM、CRLF 约束，否则内容编译通过后结构
验收仍会失败。

原书自身也可能印出不协调的上下标、重复括号或疑似反向不等号。原图
足以确认“印了什么”，却不足以授权悄悄改成数学上更自然的式子；应把
这种情况列为显式待决项，并把转写错误与原书疑误分开记录。
## 逐页审阅后的集成与证据有效性

- 子代理按物理页范围领取任务，并提交逐页覆盖表、精确替换表、原图证据路径、待核项及是否构建。报告应区分正文/行内式审阅与公式、习题、图、索引的专项覆盖，不能以“每页打开过”替代逐项保真验收。
- 代理因额度或异常退出时，先检查已落盘成果；退出失败不等于文件不存在，文件存在也不等于任务完成。核对覆盖范围、JSON 可解析性、原始稿唯一匹配及实际修订执行结果后再纳入；缺失的复核步骤继续登记。
- 数学字体可能承载对象身份。Ahlfors 第8章用粗体 f 表示全局函数，普通 f 表示函数元素；胚下标 ζ 被 OCR 识成 t、花体 r/t，路径 γ(a) 也会变形。发现这类问题时应按同一符号约定在有界范围专项复核，不做脱离原图的全章替换。
- 定义或定理的枚举条件可能跨多个 OCR 块：环境在第一条后提前闭合，会让后续条件丢失斜体；带文字的条件还可能被误转为行间公式。按原图恢复完整陈述范围，局部条件编号不建立公式引用目标，保留原有有号/无号状态。
- 上横线与波浪号、τ 与 r、σ′ 与 ζ′、求和下标、括号和指数均可能编译正常。修订后应定位当前 PDF 的实际页，目视复核改变的公式、字体范围与跨页续段。
- 最终图像审阅、索引验收和页码映射记录应绑定 PDF SHA-256。重新编译会使旧记录失效；结构脚本成功不能复用旧版本的目视结论。当前 PDF 的校样图须重新打开后，才能记录最终视觉验收。
- 交付记录分别列出来源覆盖、已应用修订、结构检查、当前成品目视范围及明确待决项。历史报告保留为快照，并指向最新报告；README 的修订数从本次实际应用结果取得，避免手工累计漂移。
- 行间公式前后不留源码空行是本项目明确偏好。将规范化及检查放入可重复构建链，只处理紧邻显示环境的空行，保留普通段落分隔；视觉间距仍需结合模板和成品检查。

## 索引语义终审与差异处置（Ahlfors 第三版）

索引验收要拆成互相独立的三件事：索引键是否确实讨论该概念、重排页码是否落到相关文本、PDF 目标是否可跳转。自动命中词项只能作为候选；对连续原书页码，应按“讨论范围”分组，抽查并读完整上下文，排除页眉、偶然同词和续页残句。每组记录原页、输出物理页、证据文本、判断和状态；用分组覆盖表证明审阅无遗漏，不能把导出上下文或代理生成的 pending 清单计为已审。

把疑点和更正分开记录：疑点先逐项判定为原索引误引、可接受的讨论延续、索引漏项或目标偏移；保留原印刷页码或改指新页必须有可复核的原图/当前 PDF 证据。对范围型词条，必要时将一个误导性旧目标改到真正的讨论页，并保留其余有效目标。改索引注入生成器或专门的重映射表，不改生成后的索引页；完整重建后验证新增目标存在、旧有效项仍在、页码落点正确，并逐页查看最终索引版面。

审阅报告须说明证据层级。对当前 PDF 文本和页级映射做了语义复核，不等同于把原书索引每个字逐像素对照；链接目标结构完整，也不证明词条语义正确。未查看原图的条目应明确保留这一限制，不能写成“所有原索引均经原图逐字认证”。

## 脚注与原书疑式的收尾核验

收尾脚注审阅应以原书所有已知脚注页为全集，逐页核底部影印内容、正文标记和生成稿脚注体，并检查最终 PDF 页面。跨页脚注要查看续页；一个源注释拆成多块时先合并识别残片，避免重复计数。字体也是内容：函数名称、集合符号、作者/期刊名等的斜体或正体依原版恢复。记录源页到成品页的映射和最终 PDF 哈希；重新编译后旧目视记录作废。

遇 OCR 看不清、但数学上可由标准公式检验的符号，不要仅凭猜测替换。可将候选代入边界值或已知特例，检验归一化、量纲、参数是否有定义；若证据支持修订，应在单独的编辑决策记录中写明原图可读性、数学推导和处理性质（转写纠错或编辑性校勘），将修订置于可追踪的输入表。源图若明确印出可疑式子，应将原书疑误留作待决或照录，不伪称原图支持改字。然后从生成器完整重建，查看对应成品页。

最终接受报告应绑定输出 PDF 的 SHA-256，并分别写出自动结构检查、人工语义审阅、原图目视范围和未决项。用新的哈希生成图像校样后，逐张实际打开且审阅完毕，才能把这一版本登记为目视完成；脚本生成联系表、代理“完成”消息或编译成功都不构成视觉证据。
