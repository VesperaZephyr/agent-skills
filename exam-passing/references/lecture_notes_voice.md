# 直陈文体基准 (跨科目通用)

> **定位**: 本文件补 `references/lecture_notes_spec.md` 第 3 节语言红线的**文体基准**. 红线管「不许写什么」, `writing_craft.md` 管「句子怎样写顺」, 本文件管**信息的组织方式与详略** —— 解决的是「每条红线都过, audit 全绿, 读起来仍像说明书 / 证明写得很防御」这一类反馈.
> **触发**: 新建讲义, 续写, 既有讲义复盘改造, 以及用户指定一份人写讲义要求「学它的写法」时一律加载. 与科目无关.
> **修订 (2026-11-11)**: 用户判定「思路显性化」实测效果不好, §3.1 与配套的思路框宏要求已整体移除, 跨科目不再要求补写题眼句.
> **修订 (2026-11-15)**: 用户确认三条根因诊断成立 —— 规则过载, 过度禁用正常中文衔接词, 强制封杀重点提示框. 据此: §1 起正常使用衔接词; §5 / §6 撤销「提示框默认 0 个, 总数不超 5 个」配额, 改为**核心结论必须分级显性标出**; 收尾边界, 题面是引文, 思路框禁用, 原生矢量图, 连读验收继续生效. 重点结论框与思路框是两类东西, 前者须配, 后者禁用.
> **裁决**: 半角标点, 零元话语, 禁考试管理语言三条红线不让步; 其余条款与本文件冲突时以本文件为准, 冲突对照见 §8. 若用户指定的参考讲义与三条红线冲突, 不照抄, 并在交付说明里写明取舍.

## 1. 一句话标准

写给读者看的数学讲义: **结论编号沉淀, 证明切入即计算, 前提只在首次引入与失效处写一次, 理由不铺满, 末尾不复述**. 读者若停下来问「作者为什么反复强调这一步」, 那就是防御信号. 若几何对象始终只有算式, 按 §7.1 配图.

合规不等于好读. `audit.py` 全绿只说明词面, 结构与编译没问题; 文体是否直陈, 只能按 §9 连读一章判断.

## 2. 防御式写法的四类症状

| 症状 | 典型形态 | 由哪条旧要求推出来 | 改写动作 |
| :--- | :--- | :--- | :--- |
| 方法论章导语 | 「本章把共面, 垂直, 距离化为代数关系」「只用到第 1, 3 章的结论」 | 规范 §1.6 要求章导语写依赖边界 | 章首直接给对象, 方程或本节要判的关系; 依赖确需交代时写成一句具体数学条件 |
| 末尾编者复述 | 「同一个重心坐标关系解决了符号与体积两问」「这也表明...」「此判断使用了题设的非退化条件」 | 流程里「练习后再用一段收束, 指出陷阱在哪」; 「结果检验与讨论」环节 | **默认整句删**; 含新数学信息 (另一支解不满足条件, 适用范围的实质限制, 与相邻结论的结构对照) 时**移出解答环境**作正文陈述, 见 §3.2 |
| 提醒框复述前提 | 「适用条件与前提」框, 知识卡讲「如何验证构造是否满足全部条件」 | 规范 §3.4 提示框全书 10 个上下, 内容含「如何验证」 | 默认不用提示框; 有结构性洞察升级为编号 `conclusion` / 命题, 正文 `\ref` 引用一次 |
| 证明先铺垫再排除 | 「若有一个向量为零, 等式两端均为零. 否则设...」「两边非负, 平方等价」「逐条验证前提」 | 规范 §2 推导「不跳步」, 前提「融入叙述」, §2.1.7 禁用「同理可得」 | 零情形 / 退化压进括号从句; 关键新论证保持完整; 同型重复允许留白 (§3) |

**第五类 (元话语总起句)**: 「下列两问依次...」「下列三问分别...」出现在多问题干前. 它不是数学内容, 是编写说明; 删掉直接写 `enumerate` (§6). 上一轮为满足排版条款补的这类句子, 恰是用户觉得「像说明书」的两项之一, 教训见 `lecture_notes_revision.md` §2ter.

## 3. 完整不等于铺满理由 (核心判据)

**完整解答 = 计算可复现 + 依据可追溯 + 结论明确**. 它不要求把每一步「为什么这么做」都写出来.

- 依据可追溯的三种合法形式: 编号结论 / 命题的 `\ref` 引用, 公式的 `\eqref` 引用, 定义或定理的名称. 不必在每处重抄内容.
- **允许留白**: 同型重复计算 (「其余三个顶点同理」), 标准代数变形 (「整理得」), 标准判据的直接套用 (「由韦达定理」), 显然的代入与移项.
- **不允许留白**: 本节的承重新论证, 参数分类的临界情形, 题设条件第一次被使用的那一步, 会翻转结论的退化分支.
- 两句可操作检验:
  1. 删掉「因此 / 因而 / 故 / 从而」后句子仍成立 → 该连接词只是节拍, 不是推理, 不靠连接词密度营造严谨.
  2. 删掉整句后计算仍可复现, 依据仍可追溯 → 该句是防御性铺陈, 删.

§2.1 第 4 条的「中间推导不省略」与第 7 条的「不得用同理可得代替推导」据此解释: 禁的是**用留白跳过承重论证**, 不是禁数学书里正常的留白.

> 本节原 §3.1「思路显性化」已于 2026-11-11 按用户反馈撤销; §3.2 沿用原编号, 使 `spec.md`, `SKILL.md`, `answer_integrity.md` 等处既有引用保持有效.


### 3.2 解答环境的收尾边界 (默认删, 少数外移)

§2 只说了「删」. 完整的一条规范是**解答容器本身有边界**: `solution` / `proof` (或其他载体里的答案块, 解答框, 折叠区) 内只放「推导 + 结论」, 推导结束即收口; 末尾的总结, 回顾, 对比, 校验, 延伸, 元讨论一律不留. 这与科目无关.

两类处置, 按顺序判断:

| 判据 | 处置 |
| :--- | :--- |
| 删掉整句后计算仍可复现, 依据仍可追溯 (§3 第二句检验); 句子只是把刚得到的结果换句话再说一遍 | **默认删 —— 这是多数情形** |
| 含解答里还没写过的实质信息: 另一支不满足条件的解, 适用范围的实质限制, 与相邻结论的结构对照, 反例带来的后果 | **移到环境之外**作正文段落; 改写成不带「本题 / 由此可见 / 这也说明」回指语气的陈述句, 值得复用时升级为编号结论 (§5) |

**为什么必须删或外移, 不能只留在环境里**: 解答环境由「证毕」这一收口信号结束, 读者据此判断哪一句是结论. 末尾挂一段讲评, 收口信号就落到讲评之后, 点评被读成结论的一部分; 以公式收尾时收口信号还须与公式同行 (LaTeX 用 `\qedhere`, 见 `answer_integrity.md` §6), 公式后面不能再跟文字. 别的载体同理: Word 的答案域, Markdown 的折叠块, 网页与 Notebook 的答案区, 都要靠同样的边界让读者认出结论.

连读验收: 每个解答的最后一段若是文字而非结论, 逐一判「删 / 外移」; 环境结束符之后若紧跟一段文字, 检查它是否已改写成独立的正文陈述 (§9). `audit.py` 的 `voice-tail-recap` 只定位命中行, 不代替这个判断.

### 3.3 题面是引文, 不受 §3 与 §2 的删减判据约束 (2026-11-13)

§3 的「删掉后计算仍可复现就删」与 §2 的「删编者复述」只适用于**自己写的叙述**. 题干是**引文**, 判定方向相反: 删掉任何一个前提, 计算就不再可复现.

四类必须原样保留的成分, 缺一即为题面失真:

| 成分 | 反例 (CMC 讲义 2026-11-10 版实测) | 原卷 |
| :--- | :--- | :--- |
| 存在性 / 非退化前提 | 「在四面体 $ABCD$ 内部取点 $O$」 | 「记**三维欧氏空间中不共面**的四点 $A,B,C,D$ 生成的四面体为 $ABCD$」 |
| 定义句 / 约定句 | 直接写「设 $O_1,O_2,O_3$ 分别为面 $BCD,ACD,ABD$ 的重心」 | 前面还有「三角形三条中线的交点称为三角形的重心」, 以及坐标约定 $\vect{AO_1}=x\bm e_1+y\bm e_2+z\bm e_3$ |
| 小问结构 | 「证明 … 及 …」「求 $X$, 证明 $Y$, 并求 $Z$」 | (1)(2) 或 (1)(2)(3) 分条, 各自独立设问 |
| 原问法 | 「判断类型」「证明结论」 | 「问 $\Sigma$ 是哪一类曲面?」「证明**你的**结论」 |

允许的转换只有两类: 排版符号 (原卷 $\overrightarrow{OA}$ → `\vect{OA}`, 全角标点 → 半角, 独立公式改 `\[ \]`), 以及**不改变任何条件与设问**的等价写法. 除此之外一字不加, 一字不减.

题源可选参数里的页码必须与该题面同页 (§2.1), 题面与出处不一致时先怀疑题面.

交付前用 §9 的机械比对跑一遍: 覆盖率低于 0.95 的题逐字回看原页.

`audit.py` 只检查题源标注有无, **不判断题面是否被改写**: 合并小问时字数几乎不减, 任何词面统计都查不出. 这一条只能人工比结构 —— 原卷有几问, 讲义就应有几个 `\item`.

## 4. 前提, 退化与边界: 一次原则

1. 条件在定义 / 定理 / 编号结论处写全一次, 用完整句融入叙述, 不发禁令.
2. 解答内只在条件**真正被用到**或**可能失效**处, 用括号或从句点一次; 不逐题重列条件, 不写「满足全部条件」「此判断使用了题设的...条件」.
3. 退化与零情形用括号从句带过: 「设 $\bm a, \bm b$ 的夹角为 $\theta$ (零向量时两端均为零)」. 不单独起句, 不写「先排除...再讨论」的两段式.
4. **例外必须展开**: 退化会翻转结论或产生另一支解时, 单独一句写清, 例如「平面束中未写出的第二个已知平面不满足条件」. 这是数学信息, 不是防御.

## 5. 结论编号沉淀与重点分级 (替代复述与提醒框)

- 可复用的结构关系, 判据, 不变量 → 编号 `conclusion` / `proposition` + `\label`; 正文与后续解答用 `\ref` 引用, **不在每处重新解释一遍**. 模板 `assets/lecture_notes_template.tex` 已给出 `conclusion` 环境的 `aliascnt` 写法.
- 短注 `remark` 一两句点出结构关系, 不写命令式「应当」.
- **核心必记结论升格为 `keyconclusion`**: 考场要直接调用的定理, 公式, 判据, 重要反例结论用暖色高光框 (`keystyle`), 标题 `$\bigstar$ 核心结论`; 一般支撑命题留在蓝色常规框. 两类框视觉不同, 读者翻开一页要能在 3 秒内扫出「这一页要记住什么」. 模板 `assets/lecture_notes_template.tex` 已给出 `aliascnt` + `\crefname` 写法; 星号用 `$\bigstar$`, 不要写字面 ★ (缺字符).
- 记忆卡 `\takeaway` / `\examtip` 在核心结论或典型方法之后一句话点透「记什么」「什么时候能用」「最容易和哪个结论混用」, 标题具体; 不复述题设前提, 不写「适用条件与前提」「如何验证」.
- 长计算用 `Step 1 / Step 2 / Step 3` 分步: 每步短句 + 公式, 不写「先...再...要注意...」的命令式.
- 检验: 同一句解释若在正文出现两次以上, 第一次应升级为编号结论, 第二次起改为引用.

## 6. 章导语, 题干与提示框

- **章首直接进数学**: 给对象, 公式或待判关系. 不写「本章把 X 化为 Y」, 不写「本节把若干同类型题收集在一起」(§1.1 的小节导语仍要讲共同构造与参数差别, 那是数学内容).
- **多问题干直接 `enumerate`**: 确需引入句时写数学内容 (「设 ..., 以下判定 ... 并求 ...」), 禁止「下列 N 问依次 / 分别...」式元话语. 若 `\label` 后紧跟列表在 `tcolorbox` 窄盒内触发 `Overfull \hbox`, 优先补数学引入句或调列表参数, 按 `lecture_notes_pitfalls.md` §4 以编译日志与渲染为准, 不把元话语当成编写要求.
- **不设提示框配额**: 判据是「这一页读者能否 3 秒扫出要背什么」. 核心结论按 §5 升格为 `keyconclusion`, 记忆卡按 §5 补点透句; 两者都**不写**「适用条件与前提」「关键技巧」, 也**不写**「如何验证构造是否满足全部条件」. 每次新增前只问: 它是不是复述了刚算出来的结果? 是则删; 不是则保留. 曾按「默认 0 个, 总数不超 5 个」一刀切, 结果全书重点与一般命题共用蓝框, 复习时抓不到记忆点 (2026-11-15 裁决撤销).

## 7. 版式: 连续排版

- **不强制每章 `\clearpage`**. 实测 10 处强制分页在 41 页讲义里造出一张几乎整页空白的孤儿页; 删掉后 36 页, 章标题落页底时导语仍完整. 确需章首页时用 `\needspace{12\baselineskip}` 按需换页.
- 连续排版下 `\leftmark` 会取页面内最后一个 mark, 页眉提前显示下一章名; `\topmark` 实测取不到值. 页眉右侧改固定文本 (课程名 / 讲义名), 不依赖 mark.
- 删分页后逐页扫稀疏页 (非空但正文少于 8 行), 排除孤儿空白页; 章标题落页底时确认导语未被拆散即可.


### 7.1 示意图与直观 (几何 / 空间类科目默认配图)

纯计算流水线读不出几何, 也没有阅读欲望. 空间解析几何, 多元微积分与几何类课程**默认配示意图**; 代数类可选. 图不是装饰: 每张图要能替读者省下一段文字, 或让人记住一个不变量 (混合积 = 底面积乘高, 旋转只保留高度与轴距, 截面倾角决定二次型符号). 用户点名 MATLAB / Mathematica 时, 它们只作数值计算, 成图仍要回到矢量.

- **原生矢量, 禁用位图**: 用 TikZ / pgfplots 直接画, 不 `\includegraphics` 引 `.png` / `.jpg`; 位图放大失真, 且与讲义源文件自包含, 正文风格统一的要求冲突. `audit.py` 的 `raster-graphic` 会定位这类引用.
- **图随内容走**: 放在用到该直观的段落或题目旁边, 不集中成图册.
- **统一视觉语言**: 全稿一套色板 (结构线 / 辅助线 / 隐藏线 / 强调色), 隐藏棱用虚线, 标注用符号而非长句, 2D 投影保持同一视角; 中文说明小字不小于 `\footnotesize`.
- **图注按章编号**: 计数器按 `section` 复位, 用 `\label` 支持 `\ref`; 图与图注同在一个 `minipage` 内, 不浮动, 不可分割.
- **必须渲染验收**: 逐张看曲线是否误导 (双叶画成一片, 马鞍画成椭圆), 标注是否压线, 文字是否超出版心; 编译日志的 0 Overfull 查不出几何错误. 画不准时宁可给简化的 2D 示意并写清「示意」, 不要拼出闭合曲线冒充 3D 曲面.

## 8. 与既有条款的冲突裁决

| 既有条款 | 冲突点 | 裁决 |
| :--- | :--- | :--- |
| §3.1 「推理连接词密度要高」 / 反向的「为简洁删掉衔接词」 | 一端堆连接词写成步步设防, 另一端删成电报体 | **正常使用**中文学术衔接词; 判据是因果有据, 不是词的密度. 不靠加连接词补救论证, 也不为求简短删掉必要过渡 (2026-11-15) |
| §2 推导「不跳步」; §2.1.4 「中间推导不省略」; §2.1.7 禁「同理可得」 | 与数学留白冲突 | 保留「承重论证不跳步」; 同型重复与标准变形按 §3 允许收束 |
| §2 前提「把边界, 退化, 失效情形融入叙述」 | 被读成每道解答逐条复验 | 按 §4 一次原则; 只在定义 / 定理 / 结论与失效处写 |
| 规范 §3.2（零元话语）, 第一人称限制 | 参考讲义大量「我们 / 显然 / 读者容易证明」 | 「我们」仍不用于编写安排; 「显然 / 读者容易证明」在不替代承重论证时允许, 但不主动模仿带读语气 (本项目无此要求) |
| §3.4 提示框配额 (默认 0 / 总数不超 5) | 把「删提醒框」误扩展成「删所有重点标注」, 复习抓不到记忆点 | 撤销配额, 以 §5 / §6 为准: 核心结论必须分级显性标出; 只删复述题设与「如何验证」的提醒框 (2026-11-15) |
| §4 「每章首行写 `\clearpage`」 | 孤儿空白页 | 以 §7 为准 |
| §4 / 验收清单「多问题干前有一句总起句」 | 元话语说明书腔 | 以 §6 为准: 总起句若写, 必须是数学内容 |
| 作业流水线五环节 (逐条写边界, 结果检验与讨论) | 蔓延到讲义解答 | 只约束平时作业交付; 讲义解答按本文件 |
| §3.3 禁考试管理语言 (禁「记忆要点」等备考攻略腔) | 「必背」曾被一并当成禁词, 导致末章改名为「公式与结论手册」 | 用户 2026-11-08 确认: 期末复习讲义末章章名「必背公式与结论手册」要保留, 对期末复习有实际作用; 「必背」只作章名, 不写成「必背知识点 / 必背清单」; `audit.py` 只放行章名中的该词 |
| §3「删掉后计算仍可复现就删」; §2「删编者复述」 | 曾被连带用于题干, 把前提, 定义句与小问编号当冗余删掉 | 以 §3.3 为准: 题面是引文, 删减判据一律不适用; 前提 / 定义句 / 分问编号 / 原问法全部保留 |



半角标点, 零元话语, 禁考试管理语言三条**不在裁决范围内**, 一律不让步. 参考讲义若用全角标点或口语化带读语气, 与用户既有排版红线冲突, 不跟, 并在交付说明里写明跟了哪几条、没跟哪几条及原因.

## 9. 人工验收 (机器查不出)

写完一章连读一次, 逐条标出:

- [ ] 读者第一次停下来问「为什么要写这句」的位置; 连续三句以上只解释理由而不推进对象, 或每道解答末尾都有一段点评 → 按 §2--§4 削薄, 不靠加连接词补救. 同时检查有没有反向问题: 该交代的过渡被删光, 读成电报体.
- [ ] 每个 `proof` 第一段是否已经在计算 (而不是铺垫条件 / 排除退化).
- [ ] 每节需记忆的核心结论是否已升格为 `keyconclusion` 并与一般命题框视觉可区分; 每个 `\takeaway` / `\examtip` 是否只是复述了刚算出的结果 (是则删).
- [ ] 每处「本章 / 本节 / 下列 N 问」是否可换成具体数学对象.
- [ ] 同一条解释是否出现两次以上; 若是, 升级为编号结论并改 `\ref`.
- [ ] 删分页后逐页扫过稀疏页, 页眉未提前显示下一章名.

- [ ] 每个 `solution` / `proof` 的最后一段若是文字而非结论, 是否按 §3.2 判过「删 / 移出环境」; 环境结束符后紧跟的段落是否已改写成独立正文陈述.
- [ ] 几何类科目每张图是否原生 TikZ 矢量, 按章编号, 图注与图未分离; 是否**逐张渲染**看过形状与标注.
- [ ] 逐题按 §3.3 回核题面: 前提与定义句在不在, 分问编号在不在, 问法是不是原问法; 再跑一次机械比对, 覆盖率低于 0.95 的题逐字看原页.

`audit.py` 的 `voice-meta` / `voice-recap` / `voice-tail-recap` / `key-emphasis` / `forced-pagebreak` 只用于**定位**高置信度信号, 清零不等于文体达标, 也不作分数或配额. 这一条与 `writing_craft.md` §5 的连续试读合并执行, 不另设一轮.
