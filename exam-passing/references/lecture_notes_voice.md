# 直陈文体与流畅叙述基准 (理工科通用)

> **定位**: 配套 `references/lecture_notes_spec.md`（结构与红线）。本文件合并了原 `writing_craft.md` 的核心方法，管两件事：**句子怎样写顺**（说人话、有承接、不写电报体）与**信息怎样组织**（直陈不设防、关键构造点出动机、重点分级显性）。
> **裁决**: 半角标点、零元话语、禁考试管理语言三条红线不让步；其余条款与旧文冲突时以本文件 §8 为准。

---

## 1. 一句话标准

写给读者看的理工科讲义：**先说清对象在刻画什么再落符号，结论编号沉淀，证明切入即计算，关键构造用半句话点出动机，前提只在引入与失效处写一次，末尾不复述。** 读者若停下来问「作者为什么反复解释这一步」，那是防御信号；若停下来问「第一步怎么想到这个构造/模型」，那是动机缺失。

合规不等于好读。`audit.py` 全绿只说明词面与结构过关；文体是否达标，必须按 §9 连读一章。

## 2. 防御式写法的五类症状

| 症状 | 典型形态 | 改写动作 |
| :--- | :--- | :--- |
| 方法论章导语 | 「本章把共面、垂直、距离化为代数关系」「只用到第 1、3 章的结论」 | 章首直接进数学/物理：给对象、方程或物理模型；确需交代依赖写成具体条件 |
| 末尾编者复述 | 「这也表明……」「此判断使用了题设的非退化条件」「同一个关系解决了两问」 | **默认整句删**；含新数学/物理信息时移出解答环境作正文陈述（§3.2） |
| 提醒框复述前提 | 「适用条件与关键前提: ……」「如何验证构造是否满足全部条件」 | 删掉复述；前提写进命题陈述，`\takeaway`/`\examtip` 只写具体记忆点或易混边界 |
| 证明先铺垫再排除 | 「若有一个向量为零，等式两端均为零。否则设……」「两边非负，平方等价」「逐条验证前提」 | 零情形/退化压进括号从句；承重新论证保持完整，同型重复允许留白（§3） |
| 元话语总起句 | 「下列两问依次……」「以下三问分别……」出现在多问题干前 | 删掉直接写 `enumerate`；确需引入只写数学/物理设定（§6） |

## 3. 完整不等于铺满理由 (核心判据)

**完整解答 = 计算/推导可复现 + 依据可追溯 + 结论明确。** 不要求每一步都写「为什么这么做」。

- **依据可追溯**：`\cref` 编号结论、`\eqref` 公式、定理/定律名称，不在每处重抄内容。
- **允许留白**：同型重复计算（「其余顶点/方向同理」）、标准代数/微积分变形（「整理得」）、标准判据直接套用（「由韦达定理」「由能量守恒」）。
- **不允许留白**：本节承重新论证、参数/物理状态的临界分类、题设条件第一次被使用的关键一步、会翻转结论的退化分支。
- **两句删冗检验**：
  1. 删掉「因此 / 故 / 从而」后句子逻辑仍在 → 别靠堆连接词营造严谨；但**正常使用**中文学术衔接词（「于是」「由此可见」「换句话说」「需要注意的是」「反过来」），不要删成电报体。
  2. 删掉整句后计算仍可复现、依据仍可追溯且不损失构造动机 → 属防御性铺陈，删。

### 3.1 区分「防御性铺垫」与「一句话动机 (Motivation)」

**严禁把“不写思路框 `\idea{}`”和“首段即计算”误解成“天降神兵”。** 面对非显然的辅助函数、换元、同态构造、高斯面/安培环路、参考系或分解方式时，读者最需要知道“第一步为什么想到它”。

- **防御性铺垫（禁）**：在动手前长篇检查题设、排除平凡退化、宣布“下面我们分三步验证”。
- **一句话动机（鼓励）**：融在推导句首的**半句自然数学/物理语言**，点出构造与目标的直接联系，然后立刻进入计算：
  - 数学例：「为把端点值与内部极值联系起来，引入辅助函数 $g(x)=f(x)-kx$」「方程两端同除 $x^2$ 后只含齐次比 $y/x$，令 $u=y/x$」；
  - 物理例：「电荷分布具有柱对称性，电场必沿径向且仅与轴距 $r$ 有关，故取同轴圆柱面作高斯面」「系统水平方向不受外力，优先联立水平动量守恒与机械能守恒」。

### 3.2 解答环境的收尾边界 (默认删，少数外移)

`solution` / `proof` 内只放「推导 + 结论」，推导结束即收口（公式收尾时用 `\qedhere` 让证毕符号同行），末尾不挂总结、回顾或校验段：
- 仅换句话复述刚得结果的 → **整句删**；
- 含解答内未写过的实质信息（另一支不满足条件的解、适用近似的实质边界、物理极限行为、与相邻结论的结构对照）→ **移出解答环境**作独立正文段落，去掉「本题/由此可见」等回指语气；值得复用时升级为编号 `conclusion` 或 `keyconclusion`。

### 3.3 题面是引文，不受删减判据约束

§2 与 §3 的删减判据只适用于自己写的叙述，**绝不用于原题题干**。四类成分必须原样保留：
1. **存在性 / 非退化 / 物理条件前提**（如「不共面」「光滑无摩擦」「准静态绝热」「忽略边缘效应」）；
2. **定义句与坐标约定句**（原题给出的符号定义、坐标系、正方向）；
3. **小问结构**：原卷 `(1)(2)(3)` 分条设问，不合并成「求 X 并证明 Y」；
4. **原问法**（如「问 $\Sigma$ 是哪一类曲面」不改为「判断类型」）。

只允许做排版符号转换（箭头向量改 `\vect{}`、全角标点改半角、独立公式改 `\[ \]`）。交付前用 `scripts/check_problem_fidelity.py` 机械比对，汉字覆盖率 `< 0.95` 的题逐字回看原卷。

## 4. 前提、退化与边界: 一次原则 + 句群承接

### 4.1 一次原则
1. 条件在定义 / 定理 / 定律 / 结论处写全一次并融入叙述，不发禁令。
2. 解答内只在条件**真正被用到**或**可能失效**处用括号或从句点一次，不逐题复验。
3. 平凡退化与零情形用括号从句带过：「设 $\bm a,\bm b$ 的夹角为 $\theta$ (零向量时两端均为零)」。
4. **会翻转结论或产生新分支的退化必须展开**（如临界阻尼、共振、平面束漏掉的第二个平面），这是实质信息，不是防御。

### 4.2 句子怎样写顺（原 `writing_craft.md` 核心）
- **先定本段动作**：引入对象、给条件、推导、比较或收束；连读前后句，确认后句接住了前句给出的对象，不用「对应」「相接」等空泛抽象词糊弄因果。
- **公式参与承接**：公式前写清正在定义或计算的对象与动词（「满足」「写为」「代入得」），公式后继续承接该结果，不丢孤立公式块。
- **逐命题判限定**：保留语义限定（适用范围、近似条件、精度、物理量单位）与证据归属，删掉「作者减责」（空泛谨慎尾句、同义重复）。
- **小词与回指**：慎删「会、就、才、仍、仅」等情态/范围词；「它」「该式」「此时」若可能指代两个对象，恢复原名。

## 5. 结论编号沉淀与重点分级

- **可复用关系沉淀为编号环境**：同一句结构解释若在正文出现两次以上，第一次升格为编号 `conclusion` / `proposition` + `\label`，后文一律 `\cref` 引用。
- **核心必记结论升格为 `keyconclusion`**：考场直接调用的定理、物理定律、核心公式、判据与重要反例用暖色高光框（标题 `$\bigstar$ 核心结论`），与常规蓝框视觉区分，让读者 3 秒扫出本页要背什么；控制每节 1–2 个，全篇占比不超过 45%。
- **记忆卡 `\takeaway{具体标题}{内容}` / `\examtip{具体标题}{内容}`**：一句话点透「记什么」「物理近似/适用边界」「最容易和哪个结论混用」，标题具体，绝不复述题设前提。
- **长计算分步**：用 `Step 1 / Step 2 / Step 3` 或编号列表写数学/物理动作，不写「先检查…要注意…」命令式。

## 6. 章导语、题干与提示框

- **章首直接进数学/物理**：直接给研究对象、控制方程或待判关系；同类题小节导语讲清共同构造与参数差别（这是实质内容，不是元话语）。
- **多问题干直接 `enumerate`**：禁「下列 N 问依次……」；若 `tcolorbox` 内 `\label` 紧跟列表触发 Overfull，补一句具体数学/物理设定句或调列表参数。
- **提示框不设硬配额，按信息增量决定去留**：新增前只问一句——它是不是复述了刚算出的结果或题设？是则删，否则保留。

## 7. 连续排版与原生矢量示意图

- **连续排版**：不强制每章 `\clearpage`（避免孤儿空白页），确需换页用 `\needspace{12\baselineskip}`；页眉右侧用固定文本。
- **7.1 原生矢量示意图（几何/空间/物理类默认配图）**：
  - 用原生 TikZ / pgfplots 绘制，**禁用位图**（`audit.py` 的 `raster-graphic` 报警）。
  - 图随内容走，每张图替读者省一段文字或钉住一个不变量（受力分解、高斯面、光程差、平行六面体体积、$p$-$V$ 循环面积）。
  - 全稿统一色板（结构线/辅助线/隐藏虚线/强调矢量），中文标注不小于 `\footnotesize`；图与图注同放 `geofig` 环境的 `minipage` 内不浮动，按节编号支持 `\ref`。
  - **必须逐张渲染验收**：检查几何/物理方向是否误导、标注是否压线、文字是否超版心。

## 8. 冲突裁决表

| 既有/直觉做法 | 冲突点 | 裁决 |
| :--- | :--- | :--- |
| 「不写思路框」/「首段即计算」 | 复杂构造/物理选模显得“天降神兵” | 禁用独立 `\idea{}` 色块，但鼓励在推导句首用**半句自然语言点出构造动机**（§3.1） |
| 「堆连接词」vs「为简洁删光衔接词」 | 一端步步设防，一端电报体 | 正常使用中文学术衔接词，判据是因果有据而非词频 |
| 「推导不跳步」vs「数学留白」 | 承重步省略 vs 机械变形铺满 | 承重论证不跳步；同型重复与标准变形允许“同理/整理得”收束 |
| 「禁提醒框」vs「重点不突出」 | 全篇蓝框抓不到要背什么 | 核心结论用 `keyconclusion` 暖色高光框 + `\takeaway`/`\examtip` 分级标出，只删复述前提的废话框 |
| 「禁考试管理语言」vs「必背公式手册」 | 末章章名被误杀 | 「必背」只放行作末章章名「必背公式与结论手册」，正文仍禁 |
| 「删冗余」vs「题面保真」 | 误删原题前提与分问编号 | 题面是引文，删减判据一律不适用（§3.3） |

## 9. 人工连读验收 (机器查不出)

写完一章从头连读一次，逐项检查：
- [ ] 有无读者需要停下来猜「为什么要写这句」（防御铺陈）或「第一步怎么想到这个构造/模型」（缺半句动机）的位置；有无过渡删光变成电报体。
- [ ] 每个 `proof` / `solution` 首段是否已进入计算/建模，末段若是文字而非结论是否已判「删 / 外移」。
- [ ] 每节核心结论是否已升格为 `keyconclusion` 且占比克制（3 秒扫出重点）；每张 `\takeaway`/`\examtip` 是否确实有信息增量。
- [ ] 同一解释是否重复出现两次以上（应沉淀为编号结论并 `\cref`）；全章无「本章/本节/下列 N 问」元话语。
- [ ] 题面覆盖率（`check_problem_fidelity.py`）与分问结构已核对；几何/物理类每张 TikZ 图已逐张渲染验收。

## 10. 反例与正例对照

| 位置 | 反面 (防御 / 天降神兵 / 电报体) | 正面 (直陈流畅 + 动机清晰) |
| :--- | :--- | :--- |
| 章导语 | 「本章把共面、垂直与距离条件化为可验证的代数关系」 | 直接给出核心方程或物理模型与各量的几何/物理意义 |
| 证明开头 | 「若有一个向量为零，等式两端均为零。否则设夹角为 $\theta$……」 | 「设 $\bm a,\bm b$ 的夹角为 $\theta$ (零向量时两端均为零)。由定义……」 |
| 辅助构造动机 | （直接写）「令 $g(x)=f(x)-f(a)-\frac{f(b)-f(a)}{b-a}(x-a)$，则……」 | 「为使端点值相等以套用 Rolle 定理，减去过端点的线性函数，令 $g(x)=\dots$」 |
| 物理选模动机 | （直接写）「取半径为 $r$、高为 $h$ 的圆柱面，由高斯定理得……」 | 「带电长直圆柱具有轴对称性，场强沿径向且仅依赖轴距 $r$，取同轴圆柱面作高斯面，由高斯定理得……」 |
| 电报体→叙述 | `\textbf{分离变量}: 令 u=XT; \textbf{本征值}: ...` | 「设非零特解 $u=X(x)T(t)$，代入方程并分离变量，空间与时间解耦为两个常微分方程……」 |
| 解答末尾 | 「此判断使用了题设的非退化条件，经检验与标准答案一致」 | 整句删；若含实质边界（如另一支解不满足条件），移出环境作正文 |
| 重点提示卡 | `适用条件与关键前提: 高斯定理要求曲面闭合` | `\examtip{高斯面选取的对称性条件}{高斯定理本身对任意闭合曲面成立，但只有当 $\bm E$ 与面元法向夹角及大小在面上分片恒定时，通量才能化成标量乘积直接解出 $E$。}` |

**一句话记住**：严谨写在**条件、动机与推导**里，不写在**反复声明自己很严谨**里。
