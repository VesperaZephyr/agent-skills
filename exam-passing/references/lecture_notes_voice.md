# 直陈文体基准 (跨科目通用)

> **定位**: 本文件补 `references/lecture_notes_spec.md` 第 3 节语言红线的**文体基准**. 红线管「不许写什么」, `writing_craft.md` 管「句子怎样写顺」, 本文件管**信息的组织方式与详略** —— 解决的是「每条红线都过, audit 全绿, 读起来仍像说明书 / 证明写得很防御」这一类反馈.
> **触发**: 新建讲义, 续写, 既有讲义复盘改造, 以及用户指定一份人写讲义要求「学它的写法」时一律加载. 与科目无关.
> **裁决**: 半角标点, 零元话语, 禁考试管理语言三条红线不让步; 其余条款与本文件冲突时以本文件为准, 冲突对照见 §8. 若用户指定的参考讲义与三条红线冲突, 不照抄, 并在交付说明里写明取舍.

---

## 1. 一句话标准

写给读者看的数学讲义: **结论编号沉淀, 证明切入即计算, 前提只在首次引入与失效处写一次, 理由不铺满, 末尾不复述**. 读者若停下来问「作者为什么反复强调这一步」, 那就是防御信号.

合规不等于好读. `audit.py` 全绿只说明词面, 结构与编译没问题; 文体是否直陈, 只能按 §9 连读一章判断.

## 2. 防御式写法的四类症状

| 症状 | 典型形态 | 由哪条旧要求推出来 | 改写动作 |
| :--- | :--- | :--- | :--- |
| 方法论章导语 | 「本章把共面, 垂直, 距离化为代数关系」「只用到第 1, 3 章的结论」 | 规范 §1.6 要求章导语写依赖边界; §3.1 要求讲清「为什么」 | 章首直接给对象, 方程或本节要判的关系; 依赖确需交代时写成一句具体数学条件 |
| 末尾编者复述 | 「同一个重心坐标关系解决了符号与体积两问」「这也表明...」「此判断使用了题设的非退化条件」 | 流程里「练习后再用一段收束, 指出陷阱在哪」; 「结果检验与讨论」环节 | 整句删; 有数学价值的例外 (另一支解不满足条件) 前移到该步并用从句带过 |
| 提醒框复述前提 | 「适用条件与前提」框, 知识卡讲「如何验证构造是否满足全部条件」 | 规范 §3.4 提示框全书 10 个上下, 内容含「如何验证」 | 默认不用提示框; 有结构性洞察升级为编号 `conclusion` / 命题, 正文 `\ref` 引用一次 |
| 证明先铺垫再排除 | 「若有一个向量为零, 等式两端均为零. 否则设...」「两边非负, 平方等价」「逐条验证前提」 | 规范 §2 推导「不跳步」, 前提「融入叙述」, §2.1.7 禁用「同理可得」 | 零情形 / 退化压进括号从句; 关键新论证保持完整; 同型重复允许留白 (§3) |

**第五类 (元话语总起句)**: 「下列两问依次...」「下列三问分别...」出现在多问题干前. 它不是数学内容, 是编写说明; 删掉直接写 `enumerate` (§6). 上一轮为满足排版条款补的这类句子, 恰是用户觉得「像说明书」的两项之一, 教训见 `lecture_notes_revision.md` §2ter.

## 3. 完整不等于铺满理由 (核心判据)

**完整解答 = 计算可复现 + 依据可追溯 + 结论明确**. 它不要求把每一步「为什么这么做」都写出来.

- 依据可追溯的三种合法形式: 编号结论 / 命题的 `\ref` 引用, 公式的 `\eqref` 引用, 定义或定理的名称. 不必在每处重抄内容.
- **允许留白**: 同型重复计算 (「其余三个顶点同理」), 标准代数变形 (「整理得」), 标准判据的直接套用 (「由韦达定理」), 显然的代入与移项.
- **不允许留白**: 本节的承重新论证, 参数分类的临界情形, 题设条件第一次被使用的那一步, 会翻转结论的退化分支.
- 两句可操作检验:
  1. 删掉「因此 / 因而 / 故 / 从而」后句子仍成立 → 该连接词只是节拍, 不是推理, 不靠连接词密度营造严谨.
  2. 删掉整句后计算仍可复现, 依据仍可追溯 → 该句是防御性铺陈, 删.

§2.1 第 4 条的「中间推导不省略」与第 7 条的「不得用同理可得代替推导」据此解释: 禁的是**用留白跳过承重论证**, 不是禁数学书里正常的留白.

## 4. 前提, 退化与边界: 一次原则

1. 条件在定义 / 定理 / 编号结论处写全一次, 用完整句融入叙述, 不发禁令.
2. 解答内只在条件**真正被用到**或**可能失效**处, 用括号或从句点一次; 不逐题重列条件, 不写「满足全部条件」「此判断使用了题设的...条件」.
3. 退化与零情形用括号从句带过: 「设 $\bm a, \bm b$ 的夹角为 $\theta$ (零向量时两端均为零)」. 不单独起句, 不写「先排除...再讨论」的两段式.
4. **例外必须展开**: 退化会翻转结论或产生另一支解时, 单独一句写清, 例如「平面束中未写出的第二个已知平面不满足条件」. 这是数学信息, 不是防御.

## 5. 结论编号沉淀 (替代复述与提醒框)

- 可复用的结构关系, 判据, 不变量 → 编号 `conclusion` / `proposition` + `\label`; 正文与后续解答用 `\ref` 引用, **不在每处重新解释一遍**. 模板 `assets/lecture_notes_template.tex` 已给出 `conclusion` 环境的 `aliascnt` 写法.
- 短注 `remark` 一两句点思路, 不写「注意 / 建议 / 应当」.
- 长计算用 `Step 1 / Step 2 / Step 3` 分步: 每步短句 + 公式, 不写「先...再...要注意...」的命令式.
- 检验: 同一句解释若在正文出现两次以上, 第一次应升级为编号结论, 第二次起改为引用.

---

## 6. 章导语, 题干与提示框

- **章首直接进数学**: 给对象, 公式或待判关系. 不写「本章把 X 化为 Y」, 不写「本节把若干同类型题收集在一起」(§1.1 的小节导语仍要讲共同构造与参数差别, 那是数学内容).
- **多问题干直接 `enumerate`**: 确需引入句时写数学内容 (「设 ..., 以下判定 ... 并求 ...」), 禁止「下列 N 问依次 / 分别...」式元话语. 若 `\label` 后紧跟列表在 `tcolorbox` 窄盒内触发 `Overfull \hbox`, 优先补数学引入句或调列表参数, 按 `lecture_notes_pitfalls.md` §4 以编译日志与渲染为准, 不把元话语当成编写要求.
- **提示框默认 0 个**: 全书每 10 页至多 1 个, 总数不超过 5 个; 标题不写「适用条件与前提」「关键技巧」; 内容不写「如何验证构造是否满足全部条件」. 每次新增前先问: 它能否改写成编号结论, 或直接删.

## 7. 版式: 连续排版

- **不强制每章 `\clearpage`**. 实测 10 处强制分页在 41 页讲义里造出一张几乎整页空白的孤儿页; 删掉后 36 页, 章标题落页底时导语仍完整. 确需章首页时用 `\needspace{12\baselineskip}` 按需换页.
- 连续排版下 `\leftmark` 会取页面内最后一个 mark, 页眉提前显示下一章名; `\topmark` 实测取不到值. 页眉右侧改固定文本 (课程名 / 讲义名), 不依赖 mark.
- 删分页后逐页扫稀疏页 (非空但正文少于 8 行), 排除孤儿空白页; 章标题落页底时确认导语未被拆散即可.

## 8. 与既有条款的冲突裁决

| 既有条款 | 冲突点 | 裁决 |
| :--- | :--- | :--- |
| §3.1 「推理连接词密度要高」 | 与直陈短句冲突, 会写成步步设防 | 改为「因果有据即可」, 连接词不充当严谨度 |
| §2 推导「不跳步」; §2.1.4 「中间推导不省略」; §2.1.7 禁「同理可得」 | 与数学留白冲突 | 保留「承重论证不跳步」; 同型重复与标准变形按 §3 允许收束 |
| §2 前提「把边界, 退化, 失效情形融入叙述」 | 被读成每道解答逐条复验 | 按 §4 一次原则; 只在定义 / 定理 / 结论与失效处写 |
| §3.2 零元话语, 第一人称限制 | 参考讲义大量「我们 / 显然 / 读者容易证明」 | 「我们」仍不用于编写安排; 「显然 / 读者容易证明」在不替代承重论证时允许, 但不主动模仿带读语气 (本项目无此要求) |
| §3.4 提示框「全书 10 个上下」, 含「如何验证」 | 提醒框是防御感主因 | 以 §6 为准: 默认 0 |
| §4 「每章首行写 `\clearpage`」 | 孤儿空白页 | 以 §7 为准 |
| §4 / 验收清单「多问题干前有一句总起句」 | 元话语说明书腔 | 以 §6 为准: 总起句若写, 必须是数学内容 |
| 作业流水线五环节 (逐条写边界, 结果检验与讨论) | 蔓延到讲义解答 | 只约束平时作业交付; 讲义解答按本文件 |
| §3.3 禁考试管理语言 (禁「记忆要点」等备考攻略腔) | 「必背」曾被一并当成禁词, 导致末章改名为「公式与结论手册」 | 用户 2026-11-08 确认: 期末复习讲义末章章名「必背公式与结论手册」要保留, 对期末复习有实际作用; 「必背」只作章名, 不写成「必背知识点 / 必背清单」; `audit.py` 只放行章名中的该词 |

半角标点, 零元话语, 禁考试管理语言三条**不在裁决范围内**, 一律不让步. 参考讲义若用全角标点或口语化带读语气, 与用户既有排版红线冲突, 不跟, 并在交付说明里写明跟了哪几条、没跟哪几条及原因.

## 9. 人工验收 (机器查不出)

写完一章连读一次, 逐条标出:

- [ ] 读者第一次停下来问「为什么要写这句」的位置; 连续三句以上只解释理由而不推进对象, 或每道解答末尾都有一段点评 → 按 §2--§4 削薄, 不靠加连接词补救.
- [ ] 每个 `proof` 第一段是否已经在计算 (而不是铺垫条件 / 排除退化).
- [ ] 每个 `\takeaway` / `\examtip` 能否改写成编号结论或直接删.
- [ ] 每处「本章 / 本节 / 下列 N 问」是否可换成具体数学对象.
- [ ] 同一条解释是否出现两次以上; 若是, 升级为编号结论并改 `\ref`.
- [ ] 删分页后逐页扫过稀疏页, 页眉未提前显示下一章名.

`audit.py` 的 `voice-meta` / `voice-recap` / `tip-density` / `forced-pagebreak` 只用于**定位**高置信度信号, 清零不等于文体达标, 也不作分数或配额. 这一条与 `writing_craft.md` §5 的连续试读合并执行, 不另设一轮.

## 10. 反例与正例 (科目中立)

| 位置 | 防御式 (改前) | 直陈式 (改后) |
| :--- | :--- | :--- |
| 章导语 | 「本章把共面, 垂直与距离条件化为可验证的代数关系, 得到方程后再反查几何范围」 | 直接给出本节的核心方程与其中各量的几何意义 |
| 证明开头 | 「若有一个向量为零, 等式两端均为零. 否则设两向量的夹角为 $\theta$, 利用数量积和向量积的定义, 右端为」 | 「设 $\bm a, \bm b$ 的夹角为 $\theta$ (零向量时两端均为零). 由数量积与向量积的定义, 右端为」 |
| 证明收束 | 「行列式大于零, 所以两垂足唯一. 两直线异面, 因此垂足互异, 确定唯一的公垂线」 | 「其行列式 $|\bm u\times\bm v|^2>0$, 故 $t,s$ 唯一; 两线异面保证 $P\ne Q$, 于是公垂线唯一」 |
| 解答末尾 | 「此判断使用了题设的非退化条件, 因此也满足严格的平行定义」 | 整句删; 条件已在所用结论处写明 |
| 多问题干 | 「下列三问依次判定位置关系, 求公垂线, 并求中点轨迹的一般方程」 | 删, 直接 `enumerate`; 需要时写「设两直线为 ..., 以下求公垂线及中点轨迹」 |
| 提醒框 | 「适用条件与前提: 相切判定要求直线与曲面有公共点」 | 该条件写进命题陈述, 命题编号后正文 `\ref` 引用 |

**一句话记住**: 严谨写在**条件与推导**里, 不写在**反复声明条件与推导**里.
