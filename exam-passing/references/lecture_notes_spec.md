# 期末复习讲义撰写规范 (跨科目通用)

> **适用范围**: 任意高校课程的期末复习讲义, 与科目无关. 数学, 物理, 计算机, 经管, 工科等课程一律适用. 本技能不绑定任何课程或教材, 具体课程的教材, 考纲与题源一律由当前项目提供.
> **文体样例**: 项目内如另有叙述体正面范本与清单式反面范本, 可对照理解文体差异; 二者仅用于说明文体, 不构成科目要求, 也不绑定任何课程或本机路径. 无范本或文件不可访问时一律按本规范执行.
> **性质**: 本规范是 `exam-passing` 技能中"期末复习讲义编写"能力的强制要求, 与"平时作业撰写""模拟卷命制"的规范相互独立.

---

## 0. 一句话标准

写一份**数学书式的叙述体应试讲义**: 目录即考纲, 每节讲清来源, 推导与适用前提, 把方法固化为步骤, 用带来源的教材原题配完整解答, 提示只讲结构, 末章按"适用条件—结论"收口. **同一个题必须合并成一道多问递进的例题, 同类题按解题方法聚在同一小节**, 不按题号或年份铺开; 这是成稿结构要求, 详见 §1.1.

**文体以 `references/lecture_notes_voice.md` 的直陈基准为准**: 证明切入即计算, 前提一次原则, 结论编号沉淀, 末尾不复述; 合规不等于好读, 静态验收全绿不代表文体达标.

**最容易犯的错**: 结构照抄正面范本, 语言却写成备考攻略. 把知识切成"标签 + 公式"清单, 加一堆"易错点 / 记忆要点 / 建议 / 时间分配", 再附上关于编写体例与勘误的编者说明, 即为反面教材. 骨架相似不等于合格.

**第二类最容易犯的错**: 逐条合规却写得防御 —— 章首写方法论, 逐题复验前提, 退化先排除再铺垫, 末尾加编者点评, 提醒框复述适用条件. 判据, 改写与冲突裁决见 `references/lecture_notes_voice.md`; 这类问题静态检查抓不到, 须按该文件 §9 连读一章.

## 1. 结构要求: 目录即考纲

1. **章节以考点, 方法或研究对象命名**, 不照抄教材章节名, 不写"第 X 章知识点整理". 读者只看目录就知道会考什么, 用哪招.
2. **主线按解题方法递进**, 按"基础概念 → 标准情形 → 各类变体 → 理论保证 → 综合结论"组织; 分类讨论要穷举典型情形, 不遗漏边界与退化情形.
3. **末章设"必背公式与结论手册"**: 期末复习讲义默认用这个章名. 它点明本手册是考场上要能直接调用的内容, 对期末复习有实际作用 (用户 2026-11-08 明确要求保留); 按"适用条件—公式 / 结论"编排, 开头写明选用顺序 (先判断对象, 条件, 再选哪一条); 收录本科目的常用恒等式, 正交 / 对偶关系, 算子或判据速查项. "必背"**只作章名**, 不写成"必背知识点 / 必背清单"一类备考指令; `lecture_notes_audit.py` 已把章名中的该词放行, 章名之外的用法仍报 `banned-borderline`. 非期末应试场景 (如竞赛复习讲义) 用户另有约定时按用户约定命名.
4. **编号交给 LaTeX**: 用 `\section` / `\subsection` 自动编号, 公式按节编号 `\numberwithin{equation}{section}`. 禁止手写 "0.1 / 2.9" 式节号, 禁止 `\setcounter{secnumdepth}{0}` 造成的博客提纲感.
5. **覆盖完整优先于压缩**: 可以为应试裁剪考纲外内容, 但不得为压缩而牺牲推导步骤与前提说明.

6. **真题驱动的章节优先级**: 连续两年及以上出现在卷面同一位置的题型, 反映命题结构, 应当独立成节, 必要时独立成章, 并配足变式练习, 不能只作为某一节的例题附注. 它的归属按**解题实际用到的工具**判断, 不按教材把它编在哪一章: 一道只用基解矩阵与伴随系统就能做完的题, 即使教材把它排在考纲外的一章, 也属于范围内, 应把需要的结论按范围内的工具重证后收进正文. 独立成章时章首直接进数学 (给对象, 方程或待判关系), 不写"本章把 X 化为 Y"一类方法论导语; 确需交代依赖, 写成一句具体数学条件, 不写"只用到第 x 章的结论"这类编纂说明 (见 `lecture_notes_voice.md` §6).
7. **同一个题先合并, 同类题再聚拢**: 题干相同或只是同一实例的不同考察方式, 属同一个题, 必须删掉重复并合并成一道多问例题; 数据不同但方法相同的属同类题, 按解题方法归类相邻排布. 两类动作互不冲突, 具体要求见 §1.1. 这是**新建与续写讲义时就要遵守的成稿要求**, 不是交付后才修补的复盘事项.

### 1.1 题目编排: 同一个题先合并, 同类题再聚拢 (强制)

> 本条是**成品要求**. 无论新建, 续写还是改写, 交到读者手里的讲义都必须满足. `references/lecture_notes_revision.md` 只规定「成稿未满足本条时怎么补救」, **不在那里定义要求**; 新建讲义在编写阶段就要按本条组织题目, 不要等交付后再重排.

**前置判据: 先分清「同一个题」与「同类题」**. 本节原有的要求是「同类题聚在同一小节」, 它和下面这条「同一个题必须合并」**作用在不同对象上, 并不冲突**: 先判关系, 再决定动作.

| 关系 | 判据 | 动作 |
| :--- | :--- | :--- |
| **同一个题** | 题干基本一致, 只是表述或出处不同; 或**同一个实例的不同考察方式** —— 同一个扩域分别问生成元, 次数, 元素形式与基, 极小多项式, 同一个群分别问各阶元素, 子群格, 正规性 | 删掉其余题, **合并成一道多问递进的 `example`** (含一个 `solution`), 全部原题出处并列写进可选参数 |
| **同类题** | **数据不同 (参数, 常数, 素数, 初值, 研究对象) 但方法相同** —— 例如 $\mathbb{Z}[\sqrt2]$ 与 $\mathbb{Z}[\sqrt3]$ 上的欧氏除式, 同一同态构造换素数 $p$ | **不合并**; 按本节原有要求放在同一个以方法命名的 `\subsection` 内相邻位置, 导语讲清共同构造与参数差别, 各题仍各自成题并给完整 `solution`, 再配一道只换参数的变式练习 |

**判据的关键**: 差别只在**表述**或**问法** → 同一个题; 差别在**数据** → 同类题. 不能用「方法相同」当作合并的理由, 否则会把 $\mathbb{Z}[\sqrt2]$ 与 $\mathbb{Z}[\sqrt3]$ 这种本该并排对照的题压成一道带参数的多问题, 读者反而看不到参数改变时哪一步会变.

**合并后的例题与练习**: 多问的次序按对象内部的依赖排 (先结构, 后计算), 不按教材题号或试卷年份; 每问只写新增的推导, 不重算同一个构造. 合并后另配一道 `exercise` + 完整 `solution`, 取一个**同类题**作平行但换实例的对象 (如例题算 $\mathbb{Q}(\sqrt2,\sqrt3)$, 练习算 $\mathbb{Q}(\sqrt2,\mathrm{i})$), 换实例要真正改变某一步论证, 让读者看到方法迁移时哪一步会变. 这道练习与本节原有的「变式练习」是同一类动作, 不另起一套要求.

**同类题省篇幅靠共用框架, 不靠并题**: 若几题只差一个参数, 可以把共用的计算写成带参数的公式或一段引理放在导语或正文 (如一次给出 $|u^2-dv^2|\le\max\{1/4,d/4\}$ 的上界), 各题引用它而不再重复推导; 但题目本身仍各自独立, 各有完整解答. 把同类题合成一道多问题不是省篇幅, 是删掉了对照.

**删块前的安全检查**: 统计所有 `example` / `exercise` 类 label 被 `\cref` 引用的次数, 外部引用改指保留块的 label; 被删题中独有的内容 (一个反例, 一条边界情形, 与后续命题的衔接) 必须并入保留块; 删完立刻算 `refs - labels`. 合并一组后**回头看新邻接的内容**: 删掉一个重复可能让保留块与紧邻命题变成同一结论, 需渲染该页确认. `audit.py` 的 `source-duplicate` 归零是没有「同一出处被拆成多块」的机器信号, 归零后不要再 `--ignore` 放行. 把 `exercise` 升格为 `example` 或把一节拆成几节时, 编号会连带变化, 同样先 `grep` 正文有无「例 6.9」「练 6.10」这类**硬编码题号引用**, 以及手册是否 `\cref` 例题标签; 全无依赖才可动 (常微分方程讲义实测两处均为 0, 拆节后未改任何引用).

**结论型环境与题目型环境的重复** (2026-11-08 抽象代数讲义实测, 第一章一次查出 22 组). 同一道教材习题被同时写成结论型 `proposition` / `theorem` (按 §2.1.6 本来就该这样写) 与题目型 `example` / `exercise` (题干是「证明 …」) 时, 两者是**同一个题**, 不是「先讲结论再练一遍」的合理分工: 命题标题里往往已带该题号, 练习又标一次, 而命题的 `proof` 已把结论完整证过. 处置与题目间合并不同 —— **结论由命题承担, 删掉题目块**, 把题目出处并入命题标题 (若标题尚无该题号或真题卷别), 把题目独有的反例, 边界情形, 第二种证法压成短句回灌命题 `proof`; 不要把命题改写成例题, 那会违反 §2.1.6. 删完常出现若干 `\subsection` 只剩结论型环境, 即 §2.1.3 的配比空档; **是否补题必须先问用户**, 不得默认补 —— 用户可能更看重精简并明确允许缺口. 若用户选择「改成应用实例」, 则保留题块而把「再证一遍」换成具体实例计算, 解答 `\cref` 命题而不重述证明; 若用户选择「专门出一个板块总结同一实例」(抽象代数讲义的 $S_3$), 就把散在多个小节的题收成一道多问例题, 出处并列, 另配换实例练习.



**要求 (同类题)**. 经过上面的前置判定后, 凡两道或多道题**数据不同**却使用同一个构造, 同一条定理, 同一套估计或同一串推导, 差别只在参数, 常数, 素数, 初值, 边界条件或研究对象, 就判为**同类题**, 必须放在同一个 `\subsection` 内相邻位置, 共用一节讲清方法, **但不合并成一道题**. 不得因为它们在教材里题号相隔很远, 或出现在不同年份的试卷上, 就分散到不同小节甚至不同章.

**小节写法**.

1. 小节标题用**方法或研究对象**命名 (如「Gauss 整数环的商环」「二次整数环上的欧氏除式」「具共振右端的特解」), 不用题号, 年份或「习题选讲」.
2. 开头用一段数学书叙述体的导语讲清**共同构造**与各题的**参数差别**; 不写「本节把若干同类型题收集在一起」这类编纂说明.
3. 各题连同其 `solution` 依次排布, 用 `\cref` 互相照应, 让参数变化与结论变化对照可见.
4. 至少配一道**只换参数的变式练习**, 给出与例题同等规格的完整解答, 让读者看到方法可迁移; 变式在题源标注中写明是哪道原题的变式, 字符串不得与原题完全相同 (否则 `audit.py` 报 `source-duplicate`). 由「同一个题」合并出的多问例题所配的平行练习也是同类题, 同样按本条写, 不另起一套要求.

**为什么是硬要求**. 按题号顺序铺开会让读者把同一招误认成多招, 每道题都要重新辨认结构, 方法无法沉淀; 而把同一个题写成好几道, 则让读者以为做了几件不同的事. 两者都是结构缺陷, 不是顺序偏好. 两层动作作用在不同对象上: **同一个题合并是删重复, 同类题聚拢是显出方法**, 并不冲突. 因此**规划题目时先判关系, 再按方法分组, 最后决定小节**, 而不是先排完知识点再往里插题.

**同类题的含义** (举例只为说明判据, 与科目无关):

| 相似之处 | 差别 | 处理 |
| :--- | :--- | :--- |
| 都把某个生成元送到有限域构造满同态, 用同态基本定理识别商环 | 素数 $p$ 与平方根 $t$ 的取值, 理想生成元 | 同一小节相邻, 导语点明 $p,t$ 的选取 |
| 都用同一个取整估计验证欧氏除式 | 二次整数环的无理数, 常数上界 | 同一小节相邻, 再补一个只换无理数的变式 |
| 都用塔式公式与极小多项式计算扩域次数 | 添加的根式与中间域 | 同一小节相邻, 共用一套基与次数的计算 |
| 都用同一个构造求特解, 差别在右端是否共振 | 特征根与重数, 待定形式 | 同一小节相邻, 按共振与否分类 |

**反面模式**: 一节一题按教材习题顺序平铺; 同一对象的四种问法并列写成四道题; 把数据不同的同类题也压成一道带参数的多问题, 丢掉参数对照; 同一套路的两题被「知识点归属」分到不同章; 小节标题写成「习题 1--3」; 只搬题干不搬 `solution`; 合并或聚拢后不复查 `\label` / `\cref` 与新邻接内容. 移动或删除环境前先备份, 之后复查全部交叉引用与题源台账.

## 2. 内容要求

| 环节 | 必须做到 | 禁止的反面模式 |
| :--- | :--- | :--- |
| 概念来源 | 从本学科的机理出发推导 (定义与定理, 守恒律, 算法不变量, 均衡条件), 讲清每个符号的语义, 量纲, 前提与适用范围 | 只列结论清单, 不讲"从哪来" |
| 推导 | 承重论证不跳步, 分情形讨论参数; 同型重复计算与标准代数变形允许"同理 / 整理得"收束, 依据由编号结论或公式引用可追溯 (`lecture_notes_voice.md` §3) | 公式堆叠配 \Longrightarrow, 承重新论证省略; 或为显得严谨把每一步的理由都铺满 |
| 结论 | 核心公式与最终答案用 `\boxed{}` 突出 | 每一步都加框, 强调泛滥 |
| 方法 | 把通用解法固化为编号步骤模板, 用完整句叙述每一步的道理 | `\textbf{步骤一}: 公式` 式电报体 |
| 定理 | 带名称, 条件, 完整证明, 并用 `\label` / `\eqref` / `\cref` 建立交叉引用 | 只陈述不证明, 或孤立的定理清单 |
| 陈述忠实 | 教材已有的定义, 定理, 命题按教材原文的骨架写 (量词, 限定条件, 并列条款齐全), 标题标教材编号; 证明只用教材用过的工具 | 只求内容不错就自行改写, 把 (1)(2)(3) 压成一段, 或用教材没有的概念把证明缩短 (§2.0bis) |
| 题目 | 课程指定题源中的原题 (教材习题, 课程作业, 历年真题, 教师补充题), 在可选参数中标明可追溯出处; 每个 `example` 必须配一个逐步完整的 `solution` | 自编题充数, "综合自测题 (附答案)"只给答案, 例题无解, 无出处标注 |
| 提示 | 提示框默认不用; 有结构性洞察时升级为编号 `conclusion` / 命题并在正文 \ref 引用, 短注用 `remark` 一两句点思路 (voice §5, §6) | "适用条件与前提"框复述已知条件, 或"如何验证构造是否满足全部条件"式提醒 |
| 前提 | 条件在定义 / 定理 / 结论处写全一次并融入叙述; 解答内只在真正用到或可能失效处用括号从句点一次, 不逐题复验 (voice §4) | 用"不能 / 注意"发禁令; 或每道解答重列一遍条件并附"满足全部条件"的复验 |
| 术语 | 定义环境与首次引入概念处, 把术语本身用 `\textbf{}` 标出 (定理体为斜体时写 `\textbf{\upshape ...}`), 读者一眼能看出本节引入了哪个名字; 术语一律沿用本课程教材的叫法 | 定义写成一整段无标记文字, 关键名词淹没在叙述里; 或改用教材没有的同义术语 |
| 课本外内容 | 正文只用本课程教材已引入的定义, 记号与术语; 教材没有的命名或更一般的观点只放进 `remark`, 并写清它与正文所用记号的关系 | 为省事在正文引入教材没有的概念 (例如二次整数环的"范数", 未讲过的引理或工具), 再用它作为证明的依据 |

### 2.0 课本外工具的三档边界

判「课本外」不能一刀切. 用户说「教材里没有的判别法不要擅自加」时, 指的是**教材未引入的一般化版本**, 不是把先修课里已学、考试默认可用的初等工具也一起禁掉.

| 档 | 内容 | 处理 |
| :--- | :--- | :--- |
| 可用 | 先修课程已讲、本课程考试默认允许直接用的判别法与初等工具 (例如有理系数多项式的有理根定理, 有理数域上的 Eisenstein 判别法) | 可以用, 但**必须在解答内把判据内容写全** (所用素数, 整除条件, 结论的适用范围), 不假设读者记得 |
| 不可用 | 教材未引入的一般化版本或别的判别法 (一般 UFD 上的 Eisenstein, 模 $p$ 判别法, 教材没有的命名与更一般观点) | 不进正文, 更不能作为证明依据; 只放进 `remark` 并写清与正文记号的关系 |
| 也要避免 | 把「不许加一般化版本」误读成「不许加任何判别法」, 于是绕开一行判据去写冗长的初等替代论证 | 同样违反 §1 第 5 条「覆盖完整优先于压缩」与叙述体要求; 拿不准就问用户确认边界, 别自行加码 |

判断顺序: 先在本课程教材 OCR 里搜该术语 / 判据, 再确认它是否属于先修课已学范围, 有疑问就把边界原样记进台账并问用户. **边界由用户确认, 不凭印象**. 实测教训: 用户确认 $\mathbb{Q}$ 上的 Eisenstein 与有理根定理可用 (高等代数已学), 而一般 UFD 上的 Eisenstein 与模 $p$ 判别法仍不许加; 上一轮因误读而把 $x^3-2$ 的不可约性改写成冗长的线性无关论证, 属过度反应.

### 2.0bis 定义, 定理与证明以教材原文为底本 (强制)

「内容没错」不等于「合格」. 用户对这一类问题的原话是「定义这些叙述的表示尽量与原书一致, 例如 1.8 这一节, 叙述与原书明显不一致 (不是说内容出错), 且原书明显更好一些 (严谨的数学符号更多吧). 证明也不要出现原书没有的内容, 例如定理 1.8.2 出现了群作用, 原书明显没有」. 因此凡教材已有的定义, 定理, 命题, 推论与证明, 一律以教材原文为底本改写; 教材缺环节或体系不连贯处才另写补充, 并让读者能看出哪一段是补充.

**八条动作**

1. **陈述照抄原书的骨架, 不是照抄文字**. 把教材那一句里的量词 (`对任意` / `存在唯一`), 限定条件 (有限, 非零, 互异, 整环), 并列条款 (教材常写成 (1)(2)(3)) 逐项落进自己的 `definition` / `theorem`; 口语化的改写 (「说得通俗些, 就是把 ... 重新排一下」) 换成符号化的准确表述. 教材用并列条款时讲义也改并列条款 —— 条款结构本身就是考点, 压成一段读者看不出要证几条.
2. **证明只用教材已经用过的工具**. 教材没出现过的概念 (典型: 群作用, 轨道, 稳定子, 奇偶置换与符号 $\sgn$) 不进证明, 即使它能把证明缩短一半. 判据是**在教材 OCR 里数出现次数**: 命中 $0$ 次即为教材外工具, 必须改用教材证法; 命中非零则可用, 但仍按 §2.0 的档位处理. 只删名词不改论证是最常见的假整改 —— 证明仍暗依赖它.
3. **每条结论标出教材编号**. 讲义自己的编号是「章.节.序」的流水号, 与教材编号毫无对应, 读者无法对照原书. 凡取自教材的定义, 引理, 定理, 命题, 推论, 在标题末尾标 `[教材 \S X 定义 X.Y]` / `[教材 \S X 定理 X.Y]`; 两套编号不一致是常态, **不要为了对齐去改讲义自身的计数器**.
4. **一条讲义结论对应教材多条结论时拆开**. 例: 讲义原有的一条「定理 1.8.2」实际等于教材命题 2.8 加命题 2.9, 两者条件与结论都不同, 拆成两条命题分别标号, 各自证明按各自教材原文写; 教材的推论 2.10 再单列为推论. 反过来, 教材一条被讲义拆成两条的, 两条都要注明同源. 把「2.8+2.9」并排写进一条定理的标题是错的 —— 它掩盖了证明结构.
5. **教材作为习题给出的结论降为 `remark`**. 例: 置换分解的唯一性教材放在 P.11 第 19 题, 讲义就不提升为定理; 写成注并标出处, 与教材的层级保持一致.
6. **被引用而未定义的概念, 先补定义**. 判据是「全篇检索该词的使用处, 再看有没有 `definition` 环境给出它」. 实测漏过五处: 「真理想」出现 10 次 (素理想, 极大理想, 极大理想存在定理的前提) 却从未定义; 「$n$ 元多项式环」在 $\Q[x,y]$ 与 $F[x_1,\dots,x_n]$ 处被用却无定义; 「Zorn 引理」在极大理想存在性的证明里是唯一依据, 全篇却只有这一处提及、从未陈述; 「分式域」在第三章开头被直接引用; 「极大主理想」在「PID 中既约即素元」的证明里被当作已知刻画. 补的时候按教材的层级走 —— 定义补 `definition`, 公理性的工具补 `lemma`, 只在习题里出现的概念写成正文一句并注明题号.
7. **锚点要核到题号对应的内容, 不能只看题号区间; 教材没证的东西不得当作已证**. 两个真实错例: ①一条「整环上次数可加」标了「教材 §2, P.44 第 1 题」, 但 P.44 第 1 题只是「举例说明 $f\ne0$, $g\ne0$ 而 $fg=0$」, 与次数可加无关, 真正出处是同书 P.56 第 3 题; ②定理「$R[x]$ 是 UFD」的证明写「由教材定理 7.13」, 而教材第二版明确删去了该定理的证明只保留结论 (见前言), 等于把未证的结论当公理用. 前者是**读题不读内容**, 后者是**把结论当证明**. 正确写法是承认缺口并写明「教材第二版删去该定理的证明, 本书不再补出」.
8. **教材有证明而讲义只给陈述, 缺的是最要紧的一块**. 抽教材编号表时除「编号 → 名称」, 还要记一项「该条后面有没有证明」. 教材写了证明而讲义只有陈述、没有 `proof`, 是这一类比措辞不一致严重得多的缺口 —— 读者看不到结论从哪来, 也无法判断哪一步是教材的工具. 实测第三章三条全是这种形态: 命题 2.4 (极小多项式的整除性与首一性) 原稿只有 (1)(2)(3); 定理 2.6 (单代数扩域的结构) 直接列出 $F(\alpha)\iso F[x]/\id{m(x)}$, $F(\alpha)=F[\alpha]$, 次数与基, 全无证明; 引理 3.3 (有限生成) 只有陈述. 补的时候照教材的论证路径分段 (这两条都是「先核 → 用第一同构定理 → 再论基」), 不要自己换一条更短的路, 否则又回到「证明用了原书没有的东西」. 同族缺口是**只给了一个方向**: 定理 2.6 只讲 $F(\alpha)\to F[x]/\id{m(x)}$, 教材同一段还给反方向「$F[x]/\id{p(x)}$ 是单代数扩域」, 缺了它, 后面写 $\Q(\sqrt[3]2)\iso\Q[x]/\id{x^3-2}$ 只能靠断言. 判据是把教材该段的**首句与末句**都读一遍 —— 反方向与附注常排在证明之后.

**定义同理**: 一条 `definition` 的标题里并列三个教材编号时, 几乎总该拆开 —— 教材把两三个概念分成互相独立的两三条定义, 中间常隔着一个命题, 合并会掩盖「哪条是公理, 哪条是后果」. 实测一轮拆了五处 (定义 3.2/3.5 理想与生成理想, 3.6/4.1 商环与环同态, 5.2/5.4 素理想与极大理想, 6.1/6.3 主理想整环与欧氏环, 7.1/7.2/7.6/7.9 整除/最大公因子/素元/UFD), 拆完页数只涨一页, 但「真因子」「极大主理想」「欧氏除式」这些被后文悄悄使用的概念都有了出处.

**两个反向动作**. 其一, 一个概念若在正文里只加粗过一次、既没有环境也没有 `label`, 而后文却要引它 (「素子域是素域」「$F(\alpha)=F[\alpha]$」), 那就该提升为 `definition` —— 实测第三章补了两条这样的 (素域提升为定义 2.6.2, $F[\alpha]$ 新增定义 3.2.8); 提升时把它从原句里摘出来, 原句改成承接语, 不要两处都留. 其二, 教材根本没有编号的概念不是拆的对象, 而是 `remark` 的对象: 代数闭域在教材里只是正文一句, 讲义就写成注, 不占结论编号 —— **编号是教材层级的投影, 多给一个编号等于擅自改了教材的层级**.

**操作顺序** (每节一次, 不要一次性全篇重写)

1. 从教材 OCR 抽出该节的定义 / 定理 / 命题 / 推论编号表, 得到「教材编号 → 名称 → 有无证明」三列清单;
2. 导出讲义该节同一清单;
3. 逐条配对: 配得上的按教材原文重写陈述并标编号; **教材有而讲义整条没有的, 补上** —— 这是最容易漏的一类, 反向配对 (拿教材清单查讲义) 才看得见; 讲义多出来的判它是「讲义自撰补充」(保留, 但写清与教材记号的关系) 还是「教材外内容」(按 §2.0 处理);
4. 证明逐段对读, 两头都要看: **只用了一行漂亮论证的地方**最可能是教材外工具; **整段没有 `proof` 的地方**则是缺口, 按编号表第四列逐条补;
5. 改完立即编译并渲染该节所在两到三页, 因为陈述写全后极易在页界被剖开.

**验收**: 该节每条定理型环境都有教材锚点; 全篇检索教材外术语命中 $0$; 三轮编译 0 error / 0 warning / 0 Overfull / 0 未定义引用; 页数变化能用「陈述写全 + 定理拆分」解释.

**实测** (抽象代数 §1.8, 2026-11-08): 定义 1 条拆为 2 条 (教材 §2 定义 2.4, 2.6 与定义 2.7), 定理 1.8.2 拆为命题 1.8.3 / 命题 1.8.4 / 推论 1.8.5 (教材命题 2.8, 命题 2.9, 推论 2.10), 唯一性降为注; 「群作用 / 轨道 / 稳定子」全篇 6 处降到 0 处; 另补全篇 19 处教材编号 (定义 8, 引理 1, 定理 6, 命题 2, 推论 2); 页数 81 → 83, 三轮编译全清.

**实测** (同书第二章节 §2--§7, 同日 22:36): 七个小节一轮做完, 85 → 90 页. 补了 11 个原本不存在的定义/引理 (多项式, 多项式环, $n$ 元多项式环, 平凡理想与真理想, 商环三条注意, 环同态的核像与自然同态, 偏序与 Zorn 引理, 分式域, 欧氏环, 平凡因子与真因子, 最大公因子, UFD), 补了两条被引用而未证的命题 (真因子与极大主理想, UFD 中既约即素元), 拆了五处合并定义, 纠了三处锚点 (次数可加, 理想对应定理, 素域定义重复). 页数增长 5 页全部来自「补定义 + 拆定义」, 可以逐条归因. 失败的写法也留了记录: 拆定义后一句长行内公式 (连写三个 $\id{a_i}$) 造成 36pt Overfull, 改「包含每个 $\id{a_i}$」即断得开.

**实测** (同书第三章 §1--§3, 同日 22:52): 90 → 92 页. 这一章的缺口类型与前两章不同 —— 不是「一条定义合并多个概念」, 而是**教材有完整证明、讲义只给结论**, 外加三个被反复引用却从未定义的概念 (子域与扩域, $F[\alpha]$, 素域). 三条补证明 (命题 2.4, 定理 2.6, 引理 3.3) 占本轮工作量的大头; 补的三个定义里有两个是把正文里的加粗词提升为环境; 拆了两条带多编号的定义 (素子域与生成域, 代数元与极小多项式); 补了教材的推论 1.5 与三处正文注意 ($F$ 中元素总是代数, 在中间域上仍代数, $n$ 次有限扩域的说法); 一处锚点从「定理 1.4」改到「定理 1.4 与推论 1.5」. 页数只涨两页, 因为补的都是必要内容, 没有一处是为对齐而注水.

### 2.1 题源, 标注与例题密度

1. **题源范围**: 优先使用课程指定的教材习题, 课程作业 (平时作业与教师新布置的作业), 历年期末真题及其解析, 教师补充题. 不使用无出处的自编题充数; 若确需补充, 数量必须极少并说明用途. 参考: 正面范本 43 个例题全部来自教材例题与习题, 反面教材有 11 处自编题.
2. **来源标注格式**: 每道例题与练习都在 `example` / `exercise` 的可选参数里写明可追溯出处, 例如
   - `[教材 P.11 第 6 题]`: 教材习题, 精确到页码与题号;
   - `[教材 \S 1.4 习题 11 (P.15)]`: 教材习题, 同时给出节号, 题号与页码, 便于对照原书核对题面与数据;
   - `[第一次作业 第 3 题]`: 课程作业, 精确到第几次作业与题号;
   - `[2022--2023 学年第一学期 (A) 卷 第三题]`: 历年真题, 精确到学年学期, 卷别与题号;
   - `[教材 \S 2.6 习题 1; 第四次作业]`: 教师新布置的作业题, 同时标教材节与题号.
   同一题被多处引用时标注保持一致, 并用 `\label{ex:...}` + `\cref{ex:...}` 做交叉引用.
   **真题若本就取自教材习题或教材定理, 卷别与教材出处必须并列写出**, 例如 `[2023--2024 学年第一学期 A 卷 第五题; 教材 \S 7 习题 3]`. 只写卷别会把课本原题误呈现为新题, 读者也无法回到教材核对题面. 标注前逐题比对教材习题表与教材正文: 确有原题的写原题号 / 定理号; 确无原题的真题, 可标其所依据的教材定义或定理 (如 `教材 \S 5 定义 5.1`) 作为概念锚点, 但不得虚构习题号. 交付前统计"只标卷别, 未标任何教材锚点"的环境并逐个核实, 避免有些标了有些没标.
3. **密度与位置**: 每个知识点 (通常每个 `\subsection`) 讲完后立即配题, 先 1~2 道**例题** (题干 + 完整逐步解答), 再 1~3 道**练习**. 练习与例题同等规格: 每道练习都必须紧跟一个 `solution` 环境, 给出完整逐步解答, 不得只给题干, 不得只给答案, 也不得把提示集中到章末或附录. 全书禁止 `\section*{...练习提示}` 之类的提示段. 全书例题数量级参考正面范本 (75 页 / 43 组例解), 题目不得集中堆到章末; 同一小节的题目先按 §1.1 判相似并聚拢, 再排先后.
4. **解答要求**: 例题用 `solution` 环境与 `example` 一一配对; 中间推导不省略, 最终结论用 `\boxed{}` 收口; 引用前文定理与公式时用 `\eqref` / `\cref`, 不重复抄写结论. **完整指计算可复现, 依据可追溯, 结论明确, 不指把每一步的理由铺满**: 同型重复与标准变形按 `lecture_notes_voice.md` §3 留白, 末尾不写点评与复验.
5. **题源台账**: 动笔前先按"知识点 → 题号 → 出处 → 是否已有解答"列出可用题源索引, 再决定每节挂哪几道; 避免同一题在不同章节重复占用, 或遗漏高频考点. 具体课程的题源路径由该项目记忆维护, 本规范只规定格式与密度.
6. **证明型学科的结论型习题融入正文**: 在以定义与定理证明为主线的学科 (抽象代数, 高等代数, 实分析等) 中, 许多习题的结论本身就是一条可复用的命题或推论, 例如"证明 $H\le G\iff ab^{-1}\in H$""证明指数为 $2$ 的子群正规". 这类习题应直接写进知识点正文, 用 `proposition` / `corollary` / `lemma` 陈述并给出完整证明, 在环境标题或正文中标注可追溯出处, **不再在该知识点后重复挂一道同题例题**. 区分判据如下:

   | 习题类型 | 处理方式 |
   | :--- | :--- |
   | 结论型: 陈述一条判定, 性质, 等价刻画或结构公式 | 正文命题 / 推论 + 完整证明 + 题源标注 |
   | 计算 / 构造 / 综合型: 求具体对象的阶, 生成元, 子群, 分类某个群, 构造并验证反例 | 节末 `example` + 完整 `solution`, 或 `exercise` |

   同一道题若既给出通用结论又要求具体计算, 把通用结论写入正文命题, 计算部分另作例题. 一个结论由多道题或多套试卷共同给出时, 在标注中并列全部出处. 这样既避免同一结论两处重复, 又让正文的命题网络覆盖课程作业与真题的全部结论.

7. **练习与例题同规格**: `exercise` 不是留给学生自己做的题, 而是就地给出完整解答的题. 每道 `exercise` 之后必须紧跟一个 `solution`, 推导密度, 交叉引用与文体要求与 `example` 的解答完全一致; 不得用"略"或把承重新论证交给"同理可得" (同型重复计算与标准代数变形用"同理 / 整理得"收束属正常留白, 见 voice §3), 也不在附录里集中放答案. 章末不再设练习提示段. `lecture_notes_audit.py` 把缺失的 `solution` 与任何练习提示段判为 ERROR.

8. **真题数据以用户确认的版本为准**: 流传的真题 (尤其回忆版) 常有一个符号的转抄误差, 而矩阵或方程里一个符号就足以翻转结果. 写进讲义之前, 题干数据 (矩阵元素, 系数, 右端项, 初值, 区间) 必须与原卷逐项核对; 回忆版一律先记为"待核", 拿不准就把题面原样交给用户确认, **不得按"哪种答案更像标准答案"反推题面**. 数据改正后, 讲义, 练习, 手册条目与真题源文件 (`.tex` 与其 PDF) 四处必须同步, 否则下次续写会把旧数据再抄一遍.
9. **合并去重后的配比与篇幅**: 按 §1.1 合并「同一个题」之后, 某些 `\subsection` 会变成「只有例题没有练习」或「两者皆无」. 这时按本条第 3 条的密度补题, 但守三条:
   - **先删多余的, 再补缺的**: 挂在 `\section` 直属、不补任何 `\subsection` 配比的题, 以及本就由教材命题承担示范的小节, 不额外补题; 补题数只覆盖真实缺口.
   - **补题最小充分**: 新题按「实例 / 变式」写, 优先复用已讲过的构造; 短显示公式能改行内就改行内; 不为了显得充实再补同型变式. 每块仍须完整 `solution` (第 7 条).
   - **篇幅变化要分阶段归因, 不许靠压解答换页数**: 把各阶段的 `.tex` 备份各拷进独立 ASCII 目录、分别三轮编译、用 `pdfinfo` 记页数, 同时统计全文行数, 题块数与块内源码行数. 合并省下的是重复题干与重复解题框架 (实测 33 块仅 149 行), 而新增题带题干盒与完整解答 (实测 12 块 315 行), 因此「块数减少」完全可能「页数增加」. 归因清楚后再与用户确认取舍; **禁止把解答压成「略」「同理可得」来换页数**. 完整归因表与对照编译方法见 `references/lecture_notes_pitfalls.md` §13.

## 3. 语言风格要求 (强制, 与科目无关)

> 本节是红线, 只定边界. 句子怎样写顺见 `references/writing_craft.md`, 信息组织与详略 (直陈不设防) 见 `references/lecture_notes_voice.md`; 三者冲突时以本节为准, 尤其第 2, 3, 6 条, 其余按 voice §8 裁决. 第 8 条是人工判据, 静态检查码清零不代表达标.

1. **叙述体**: 段落由完整因果句群构成, 讲清"为什么"; 但因果有据即可, **不追求连接词密度**, 也不把每一步的理由铺满 (直陈基准见 `lecture_notes_voice.md` §3). 不把段落切成"关键词 + 冒号 + 公式". 允许的加粗是术语与步骤名, 不是每行开头的标签.
2. **零元话语**: 正文不写编写体例, 摘要式自述 ("本讲义按...组织"), "本稿已...", 原书 / OCR 勘误章节, "自编" 标签, 考纲说明. 第一人称只用于证明行动 ("我们要证明", "我们来详细证明一下"), 不用于介绍写作安排.
3. **禁考试管理语言**: 不写"拿到题先判断用哪招", "记忆要点", "易错点", "高频失分点", "审题技巧", "答题规范", "建议", "必须闭卷默写", "考试时间分配", "先遮住答案", "了解即可", "考试主要考前 X 类", "题型 / 模板 / 操作模板 / 考纲", "Pitfalls Table", "避坑指南". 前提与限制用数学语言表达, 而非用备考指令表达.
4. **提示框默认不用**: 可复用的结构关系升级为编号 `conclusion` / 命题并在正文 \ref 引用; 确需提示框时只讲概念之间的结构关系与机理, 不讲"适用条件与前提", 不写"如何验证构造是否满足全部条件". 全书每 10 页至多一个, 总数不超过 5 个 (`lecture_notes_voice.md` §5, §6).
5. **题目语言**: 先把"考试用哪种语言作答"问清楚, 再定题面与解答的语言, 二者必须一致. 题干保持原题表述, 符号, 数据与措辞照抄, 不译写, 不改写, 出处只出现在可选参数里.
   - **母语作答** (双语课程常见: 教材与试卷英文, 讲授与答题中文): 题面保留英文原文, 解答用中文, 以"设, 由, 代入, 因此, 故"推进.
   - **英文作答** (试卷为英文且要求英文答题): 题面与解答**全部英文**, 解答即考场答题范本 —— 用 "Let ..., hence ..., therefore ..." 推进, 不出现中文与全角标点, 也不保留 "解" 之外的任何中文引导语. 正文讲解, 提示框与末章手册仍用中文, 于是全书的语言分工是"讲解中文 / 题目与解答英文".
   - 英文解答内的交叉引用不能用 `\cref` (它输出中文类型名"定理"), 改为 `Theorem~\labelcref{thm:xxx}`: 类型名手写英文, `\labelcref` 只给编号并保留超链接; `\eqref` 输出括号编号, 与语言无关, 可直接用. 定理证明 (`proof` 环境) 属于讲解, 不随解答改语言.
   - 同一份讲义不要在题面语言上混用两套做法; 改写语言后要重新扫一遍 `solution` 块, 确认无残留中文, 全角标点与 `\cref`.
6. **标点与字体强调**: 统一半角英文标点并在其后加空格; 源码中不写 Unicode 中文引号与全角分号 / 全角括号 (中文并列词语中的顿号可保留). 中文叙述确需引号时改用 LaTeX 成对引号 (源码以两个反引号开头, 两个单引号结尾), 不写 ASCII 双引号 `"..."`: XeLaTeX + ctex 下两处都会渲染成右双引号 `”`. 严禁 Markdown 标记 (`**text**`), 强调一律用 LaTeX 原生 `\textbf{}`.
7. **强调克制**: `\boxed{}` 只给核心公式与最终答案; 表格只用于"条件—结论"对照与速查, 不把整节知识切碎成表格.
8. **直陈不设防**: 证明第一段即进入计算, 不在开头排除退化或铺垫条件; 解答末尾不写编者点评, 复述与复验; 前提, 退化与边界按 `lecture_notes_voice.md` §4 的"一次原则"处理; 章首与多问题干不写方法论导语和"下列 N 问依次..."式元话语; 可复用的结构关系编号沉淀后引用, 不在每处重新解释. 文体基准与冲突裁决见 `references/lecture_notes_voice.md`. **这一条是人工判据, 词面检查码清零不代表达标.**

**改写示范 (把电报体改成叙述体)**:

- 反: `\textbf{分离变量}: 令 u=XT; \textbf{本征值问题}: ...; \textbf{时间方程}: ...; \textbf{叠加并定系数}: ...`
- 正: "设非零特解为 $u=X(x)T(t)$, 代入方程并移项, 空间与时间解耦为两个常微分方程. 代入齐次边界条件建立本征值问题; 分别讨论参数的三种情形, 只有一种给出非零解, 由此得到本征值与正交函数族. 由线性叠加原理写出一般解, 再利用正交性积分确定系数."
- 反: `\textbf{易错点}: 判别式不是 4a^2-4bc; 特征方程符号容易写反.`
- 正: "由于所取变换非退化, 判别式的符号在变换下保持不变, 因此可用它判定类型; 混合导数项的系数决定特征方程中交叉项的正负."

## 4. 版式要求 (LaTeX)

- 文档类 `article` + `ctex` (篇幅大时 `ctexbook`), 11pt / A4 / 约 22mm 页边距; 自定义主色与辅色, `hyperref` 彩色链接, `fancyhdr` 页眉 (左署来源, 右显当前章).
- `tcolorbox` 包装 `amsthm` 环境: 定义 / 定理 / 推论用淡蓝底 + 蓝色左边界线, **保留 `breakable`** (证明很长, 必须可跨页); 例 / 练习用橙色圆角盒, **默认去掉 `breakable`** —— 题干盒只装题面, 实测最长题干也远短于一页, 不可断时整盒下移即可, 页尾只留几行空白. 对照编译证明去掉它对页数 **0 代价**, 却根除了「(1)(2) 问被拆到两页、盒底边线被页脚切断」. 不要在每道例题前逐个 `\needspace` 打补丁. 模板 `assets/lecture_notes_template.tex` 的 `examplestyle` 已按此设置; 自定义 `solution` 环境带 QED 结束符; 重定义 `proof` 用黑体以规避中文斜体警告.
- 自定义 `\takeaway` 淡蓝知识卡与 `\examtip` 淡橙考点框; 注意参数个数与调用一致, 内容不得溢出框外.
- `booktabs` + `tabularx` 三线表; `\numberwithin{equation}{section}`; 关键公式, 定理, 表格均设 `\label` 并在正文交叉引用.
- 交叉引用统一用 `cleveref` 的 `\cref` / `\Cref`. 若定义 / 定理 / 命题 / 例 / 练习等环境为按 `章.节.序` 连续编号而共享同一计数器, 必须用 `aliascnt` 为每类环境建立别名计数器 (`\newaliascnt` + `\aliascntresetthe`) 并配置 `\crefname`; 否则 cleveref 只看到主计数器, 所有 `\cref` 都会误显示成同一种名称 (实测全部显示为「定义」). 公式引用另配 `\crefname{equation}{式}{式}`. 模板 `assets/lecture_notes_template.tex` 已给出可直接复用的写法.
- 自定义 `proof` / `solution` 时, 间距写作 `\topsep=6pt plus 6pt\relax`, 不要手写 `\topsep6\p@\@plus6\p@\relax`: 分隔符一旦漏写, `\p@\relax` 会变成未定义命令 `\p@relax`, 每个解答环境都会连带报 `Undefined control sequence` 与 `Illegal unit of measure`.
- 中文 XeLaTeX 正文中不要写 ASCII 双引号 `"..."`: 它们会都渲染成右双引号 `”`. 确需引号时改用 LaTeX 成对引号 (源码以两个反引号开头, 两个单引号结尾); 相邻引号短语之间用连接词或空格分开, 不要拼成 `"A""B"`.
- `tabularx` 的 X 列中 `\cref` 的中文名称可能从汉字中间拆行; 用 `\mbox{\cref{...}}` 固定引用. 若因此产生 `Underfull \hbox`, 按比例调整 X 列 (`>{\hsize=0.85\hsize}X>{\hsize=1.15\hsize}X`), 并在 `pdftotext` 或渲染抽样中确认表格未被拆断.
- 需要 `\cref` 引用的公式必须写在真正的 `equation` 环境内: 把 `\label{eq:...}` 放进 `\[ ... \]` 时, cleveref 会把该标签归到邻近的定理计数器, PDF 中显示成「定理 x.y.z」而不是「式 (x.y.z)」. 公式另配 `\crefname{equation}{式}{式}` 与 `\Crefname{equation}{式}{式}`.
- 数学源码中反斜杠误写成斜杠 (`/Q`, `/infty`, `</infty`) 不会产生任何编译错误或 warning, 只会在 PDF 里留下字面文本; 交付前用正则扫可疑的 `/(字母)` 组合, 并在 `pdftotext` / 渲染抽样中核对含公式的页面.

- **不强制每章 `\clearpage`**: 实测 10 处强制分页在 41 页讲义里造出一张几乎整页空白的孤儿页, 删掉后 36 页且章标题落页底时导语仍完整. 优先连续排版 (voice §7); 确需章首页时用 `\needspace{12\baselineskip}` 按需换页, 并在编译后逐页查空白页. 连续排版下 `\leftmark` 会提前显示下一章名, 页眉右侧改用固定文本 (`\topmark` 实测取不到值).
- `tabularx` 的 `p{...}` 定宽列里不要放"短汉字 + 行内公式 + 逗号 + `\mbox{公式}`"这种组合: 一行的剩余宽度放不下后半段时, `\mbox` 会整体推到下一行, 首行只剩几个字, 产生 `Underfull \hbox (badness 10000)`. 把条件句挪到 X 宽列, 或去掉连接用的逗号与"且".
- `.tex` 文件保持 UTF-8 无 BOM + CRLF 行尾; 用 XeLaTeX 多轮编译以稳定交叉引用; 交付前检查 0 error, 0 未定义引用, Overfull hbox 在可接受范围.
- **多问题干直接写 `enumerate`**: 不要为凑格式补"下列三问依次..."这类元话语总起句 (voice §6); 确需引入时写数学内容 (设某对象, 判定某关系并求某量). `\label` 后紧跟列表在 `tcolorbox` 窄盒内**可能**产生数百 pt 的 `Overfull \hbox` (实测三处 398.6pt / 360.6pt / 18.4pt, 另有一处同样写法却 0 Overfull), 以编译日志的 Overfull 计数与渲染抽样为准; 真出现时优先补一句数学引入句或调盒内列表参数, 不要靠缩字号或 `\needspace` 绕, **也不要把元话语总起句当成编写要求**. 这类写法不必然出错, 不设静态检查码.
- 内容长度变化后若出现 `Package tcolorbox Warning: nobreak failed`, 不要逐盒打补丁: 在该 `\section` 前加一次 `\usepackage{needspace}` 与 `\needspace{12\baselineskip}`, 只在空间不足时换页, 不留白.


> 注意: 本规范针对**讲义类**文档. 平时作业类文档若另有"禁用盒子, 不加注记框"的约定, 以那份约定为准, 二者不冲突.

## 5. 科目适配指引

| 抽象要求 | 数学类课程 | 物理 / 工科 | 计算机类 | 经管类 |
| :--- | :--- | :--- | :--- | :--- |
| 概念来源 | 定义与定理证明 | 守恒律与模型假设 | 不变量, 复杂度, 正确性证明 | 均衡条件与模型假设 |
| 方法步骤 | 标准解法与分类讨论 | 模型建立—求解—检验流程 | 算法模板与边界输入 | 求解与稳健性检验流程 |
| 教材原题 | 教材例题, 习题 (标注编号) | 课后题, 例题 | 题库, 历年题, 教材伪代码题 | 案例题, 课后题 |
| 必背公式与结论手册 | 公式, 定理条件 | 方程, 定解条件, 量纲 | 复杂度, 判据, 伪代码骨架 | 指标, 判据, 适用条件 |
| 提示框内容 | 定理条件与反例 | 假设, 量纲, 退化情形 | 边界输入与失效条件 | 前提与模型失效情形 |

无论哪类科目, 提示框讲**结构与前提**, 不讲"别写错"; 例题必配**完整逐步解答**.
