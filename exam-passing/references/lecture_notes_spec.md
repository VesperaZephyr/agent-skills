# 期末复习讲义撰写规范 (理工科通用，重点面向数学与物理)

> **适用范围**: 高校理工科期末复习讲义（数学、大学物理、力学、电磁学、信号与系统、控制、热力等推导与建模类课程）。具体课程的教材、考纲与题源由当前项目提供。
> **性质**: 本规范是 `exam-passing` 中「期末复习讲义」的强制规则；与「平时作业」「模拟卷」相互独立。句群写法、直陈文体与一句话动机见 `references/lecture_notes_voice.md`，论证自足见 `references/answer_integrity.md`。

---

## 0. 一句话标准

写一份**数学/物理书式的叙述体应试讲义**：目录即考纲，重点由真题频次驱动且一眼可见，每节讲清来源、推导、物理/几何直觉与适用前提，把通用解法固化为步骤，用带可追溯出处的原题配完整解答，末章用「题干特征路由表 + 必背公式与结论手册」收口。

两种最常见失格：
1. **备考攻略体**：把知识切成「标签 + 公式」电报清单，塞满「易错点 / 避坑指南 / 时间分配」与编者说明书。
2. **防御式合规**：静态检查全绿，但章首写方法论、证明先铺垫排除退化、解答末尾加复述点评、通篇同色蓝框抓不到要背什么。这类问题机器抓不全，须按 `lecture_notes_voice.md` §9 连读一章。

## 1. 结构要求: 目录即考纲

1. **按考点、方法或物理模型命名章节**，不照抄教材章名，不写「第 X 章知识点整理」。读者看目录就知道考什么、用哪招。
2. **主线按方法递进**：基础概念/物理模型 → 标准情形 → 各类变体与边界 → 理论保证 → 综合应用。
3. **末章设「必背公式与结论手册」**：
   - 开头放一张紧凑的**「题干特征 → 核心工具 → `\cref`」速查路由表**，服务考场逆向检索（看到什么结构/对称性/边界条件，立刻定位调用哪条公式或方法）。
   - 正文按「适用条件—公式/结论」编排，用 `\cref` 串联正文编号结论，收录常用恒等式、对称/守恒关系、量纲或判据速查项。
   - 「必背」**只作末章章名**，正文不写「必背知识点 / 必背清单」。
4. **编号交给 LaTeX**：用 `\section` / `\subsection` 自动编号，公式按节编号 `\numberwithin{equation}{section}`。禁止手写节号或 `\setcounter{secnumdepth}{0}`。
5. **覆盖完整优先于压缩**：可按考纲裁剪范围外内容，不得为压页数牺牲承重推导步骤与前提说明。
6. **真题驱动的章节优先级**：连续两年及以上出现在卷面同一位置的题型，应独立成节（必要时独立成章）并配足变式练习。题目归属按**解法实际用到的工具**判断，不按教材把它编在哪一章；只要工具在范围内，就重证所需结论后收进正文。

### 1.1 题目编排: 同一个题先合并，同类题再聚拢 (强制)

编写与续写阶段就要按本条组织题目，不要等交付后返工。先判关系，再定动作：

| 关系 | 判据 | 动作 |
| :--- | :--- | :--- |
| **同一个题** | 题干基本一致（仅表述或出处不同）；或**同一实例/同一物理系统的不同问法**（如同一扩域分别问基、次数、极小多项式；同一刚体/回路分别问受力、加速度、能量） | 合并成**一道多问递进的 `example`**（配一个 `solution`），全部出处并列写入可选参数；多问按内部依赖排序，每问只写新增推导 |
| **同类题** | **数据不同**（参数、素数、初值、几何构型、边界条件不同）但**方法相同** | **不合并**；放进同一个以方法命名的 `\subsection` 相邻排布，导语讲清共同构造与参数差别，各题各自独立并给完整 `solution` |

- **共用框架省篇幅，不靠并题**：同类题共用的一段推导或上界估计，先在导语或正文写成带参数的公式/引理，各题 `\cref` 引用，保留数据对照。
- **变式练习**：合并后的多问例题与同类题小节，均配至少一道**换参数/换构型**的变式 `exercise` + 完整 `solution`；变式出处字符串不得与原题完全相同（否则 `audit.py` 报 `source-duplicate`）。
- **结论型与题目型重复**：若同一习题既写成正文 `proposition`/`theorem` 又挂成「证明……」的 `example`/`exercise`，**由正文命题承担，删掉题目块**，出处并入命题标题；确需应用示范时改为具体数值/实例计算并 `\cref` 命题。
- **删改安全检查**：移动或删块前先备份，统计被 `\cref` 引用的标签与硬编码题号，删完立刻核算 `refs - labels = 空`，并检查新邻接内容是否重复。

### 1.2 重点显性分级与真题权重 (强制)

复习讲义区别于普通教材的关键在于**3 秒扫出要记什么**，且重点不能靠感觉乱标：

1. **以真题频次与枢纽作用定级**：在题源台账中统计考点在近 $N$ 年真题中的出现频次与考法。只有满足以下之一才升格为 `keyconclusion`（暖色高光框，标题 `$\bigstar$ 核心结论`）：
   - 考场必须直接调用的核心定理、物理定律、标准公式或判据；
   - 真题高频命中的枢纽方法结论；
   - 极易致错的高区分度反例或边界结论。
2. **三级视觉分层**：
   - 一般概念与支撑命题 → `definition` / `proposition` / `lemma`（蓝色常规框）；
   - 必记核心结论 → `keyconclusion`（暖色高光框）；
   - 一句话记忆锚点、近似条件或易混辨析 → `\takeaway{具体标题}{内容}` 或 `\examtip{具体标题}{内容}`。
3. **防泛滥上限**：每节通常 1–2 个 `keyconclusion`，全篇 `keyconclusion` 占比建议控制在结论型环境总数的 **45% 以内**。满页暖色高光等于没有重点。

## 2. 内容要求

| 环节 | 必须做到 | 禁止的反面模式 |
| :--- | :--- | :--- |
| 概念与模型来源 | 从本学科机理出发（定义与定理、守恒律、物理近似、对称性），讲清符号语义、量纲、前提与适用范围 | 只列结论清单，不讲“从哪来” |
| 推导与动机 | 承重论证不跳步，分情形讨论参数；非显然构造/换元/选模型处用半句话点出动机；同型重复与标准变形允许“同理/整理得”收束 (`voice.md` §3) | 公式堆叠配 `\Longrightarrow` 跳过承重步；或每步铺满防御理由 |
| 结论与重点 | 核心结论升格为 `keyconclusion`，最终结果用 `\boxed{}` 突出 | 通篇同色蓝框抓不到重点，或步步加框 |
| 方法固化 | 通用解法固化为编号步骤，每步写具体数学/物理动作 | `\textbf{步骤一}: 公式` 电报体 |
| 定理与证明 | 带名称、完整条件、完整证明与 `\label`/`\cref`；教材写了证明的不得只给陈述 | 只陈述不证明，或孤立定理清单 |
| 题目与解答 | 课程指定题源原题，可选参数标可追溯出处；每个 `example` 与 `exercise` 均紧跟完整 `solution` | 自编题充数、练习只给答案或集中到章末提示 |
| 重点提示卡 | `\takeaway{标题}{内容}` / `\examtip{标题}{内容}` 标题具体，点透记忆点、适用近似或易混边界 | 复述题设前提，或写“适用条件与关键前提”“如何验证” |
| 前提一次原则 | 条件在定义/定理/结论处写全一次并融入叙述；解答内只在用到或可能失效处括号点一次 | 每道解答重列前提并写“满足全部条件”复验 |
| 术语标粗 | `definition` 与首次引入概念处用 `\textbf{}` 标出术语（斜体环境用 `\textbf{\upshape ...}`），沿用教材叫法 | 术语淹没在长段中，或自造同义词 |
| 课本外工具 | 正文只用教材已有工具与经确认可用的先修初等工具（见 §2.0）；更一般观点只进 `remark` | 正文偷偷引入教材未讲的高级工具作证明依据 |

### 2.0 课本外工具的三档边界

- **可用**：先修课已学、考试默认可用的初等工具（如 $\mathbb{Q}$ 上有理根定理/Eisenstein 判别法、微积分基本公式、矢量微积分恒等式），**但须在解答内把判据/公式条件写全**，不假设读者记得。
- **不可用**：教材未引入的一般化版本或超纲理论（如一般 UFD 上 Eisenstein、群作用、分析力学拉格朗日方程用于普物基础题），不进正文证明，只可放 `remark` 并说明与正文记号的关系。
- **避免过度保守**：不要因怕超纲而绕开一行合法初等工具去写冗长替代论证；拿不准时在台账标明并问用户确认。

### 2.0bis 定义、定理与证明以教材原文为底本 (强制)

凡教材已有的定义、定理、定律、命题与证明，以教材原文骨架为底本，不凭“内容没错”自行改写：

1. **骨架忠实**：保留教材的量词、限定条件、物理近似条件与 `(1)(2)(3)` 并列条款；口语化改写换回准确符号表述。
2. **证明工具不越界**：在教材 OCR 中检索术语出现次数，命中 0 次即为教材外工具，不得进入正文证明（即使更短）。
3. **标出教材锚点**：取自教材的结论在标题末尾标 `[教材 \S X 定理 X.Y]`；不要为对齐教材而改动讲义自身计数器。
4. **多条结论拆开**：教材分条陈述的定义/命题不得合并成一条，避免掩盖公理与推论的层级；教材作为习题的降为 `remark` 或按 §2.1 处理。
5. **不引用未定义概念**：全篇检索被反复使用的术语，缺定义的补 `definition`，缺证明的照教材路径补 `proof`（同时核对教材段末是否有“反方向”或附注）。
6. **锚点核到内容**：核对题号/定理号对应的实际文本；教材明确省略证明的，如实写明不把未证结论当公理。

### 2.1 题源、标注与例题密度

1. **题源范围**：优先教材例题/习题、平时作业、历年真题、教师补充题；严禁无出处自编题充数。
2. **出处标注格式**：写入 `example`/`exercise` 可选参数，精确可追溯：
   - `[教材 \S 1.4 习题 11 (P.15)]`、`[第一次作业 第 3 题]`、`[2022--2023 学年第一学期 A 卷 第三题]`；
   - **真题源自教材原题时必须并列标注**（如 `[2023--2024 A 卷 第五题; 教材 \S 7 习题 3]`）；确无原题的补概念锚点（如 `教材 \S 5 定义 5.1`），不得虚构习题号。
3. **密度与配对**：每个知识点（`\subsection`）讲完立即配 1–2 道 `example` + 1–3 道 `exercise`；**每道 `example` 与 `exercise` 必须紧跟同等规格的完整 `solution`**，禁止「练习提示」段或章末集中放答案。
4. **证明型学科的结论型习题融入正文**：陈述判定、性质、等价刻画或通用公式的习题，直接写成正文 `proposition`/`corollary`/`lemma` + 完整 `proof` + 出处标注，不再重复挂同题例题；计算/构造/综合型挂 `example`/`exercise`。
5. **回忆版真题数据**：矩阵元素、系数、初值、物理参量一律先标「待核」，经用户确认后再写入，严禁按“答案是否漂亮”反推题面；确认改正后同步讲义、手册与真题源文件。

## 3. 语言风格红线 (强制)

> 本节定不可突破的底线；如何把句子写顺、平衡直陈与动机见 `references/lecture_notes_voice.md`。

1. **叙述体**：完整因果句群，**正常使用中文学术衔接词**（于是、由此可见、换句话说、需要注意的是、反过来）；引入复杂对象或物理模型先讲它在刻画什么再落符号。严禁「关键词: 公式」电报体。
2. **零元话语**：正文不写编写体例、摘要自述（「本讲义按……」「本稿已……」「下列三问依次……」）、勘误章节、考纲说明。第一人称只用于证明/推导行动（「我们要证明」「下面计算」）。
3. **禁考试管理语言**：不写「拿到题先判断」「记忆要点」「易错点」「高频失分点」「审题技巧」「答题规范」「时间分配」「先遮住答案」「了解即可」「避坑指南」「Pitfalls」。限制与边界用数学/物理语言表达。
4. **重点显性分级**：按 §1.2 用 `keyconclusion` 暖色高光框标出核心结论，用 `\takeaway{标题}{内容}` / `\examtip{标题}{内容}` 点透记忆点与边界；两类框与常规蓝框视觉必须可区分。
5. **题目语言与题面保真**：动笔前先确认「考试作答语言」（全中文 / 英文题面+中文解答 / 英文题面+英文解答），全书统一。英文解答内用 `Theorem~\labelcref{...}` 替代 `\cref`。**题面是引文，不受删减判据约束**：前提、定义/物理条件句、`(1)(2)(3)` 分问编号、原问法全部原样保留，只做排版符号转换（见 `voice.md` §3.3）。
6. **标点与强调**：交付源码统一半角英文标点并在其后加空格（顿号可留），禁用全角分号/括号/中文引号与 ASCII 双引号 `"..."`（引号用 LaTeX 成对反引号与单引号），禁用 Markdown `**bold**`（一律 `\textbf{}`）。*写作阶段可自然写中文，交付前运行 `scripts/normalize_tex.py` 自动归一化。*
7. **直陈不设防 + 动机清晰**：证明首段即计算，退化与零情形压括号，关键构造/模型前用半句点出动机，解答末尾不写编者复述与复验（`voice.md` §2–§4）。
8. **原生矢量图**：几何、空间、物理类课程（受力分析、场线/高斯面、光路、电路、热力学 $p$-$V$ 图）默认配原生 TikZ/pgfplots 矢量图，禁用位图，逐张渲染验收（`voice.md` §7.1）。

## 4. 版式要求 (LaTeX)

- **文档类与宏包**：`article` + `ctex`（40 页以上可用 `ctexbook`），11pt / A4 / 22mm 边距，`amsmath/amssymb/amsthm/mathtools/bm`，`booktabs/tabularx`，`hyperref`，`fancyhdr`，`tcolorbox`，`aliascnt` + `cleveref`，`tikz`。模板见 `assets/lecture_notes_template.tex`。
- **三类盒子分工**：
  - `definition` / `theorem` / `proposition` / `lemma` / `corollary` / `conclusion` → 淡蓝 `theoremstyle`（保留 `breakable`）；
  - `keyconclusion` → 暖色高光 `keystyle`（保留 `breakable`，标题星号用 `$\bigstar$` 禁字面 ★）；
  - `example` / `exercise` → 橙色 `examplestyle`（**去掉 `breakable`**，避免一道题的 `(1)(2)` 问被页脚切开）。
- **编号与引用**：共享计数器必须配 `aliascnt` + `\crefname`（含 `\crefname{equation}{式}{式}`）；需 `\cref` 的公式必须放 `equation` 环境，不得把 `\label{eq:...}` 放进 `\[ ... \]`；`tabularx` 的 X 列中用 `\mbox{\cref{...}}` 防汉字拆行。
- **连续排版**：不强制每章 `\clearpage`，必要时用 `\needspace{12\baselineskip}`；页眉右侧用固定文本，避免 `\leftmark` 提前显示下一章名。
- **编码与编译**：UTF-8 无 BOM + CRLF，XeLaTeX 3 轮，0 error / 0 warning / 0 undefined / 0 Overfull / 0 Missing character；源码无 `/infty`、`/Q` 类斜杠误写。
