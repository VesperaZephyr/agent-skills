# 答案与论证的自足性基准 (跨科目通用)

> **适用范围**: 任意高校课程中**含推理或论证的解答** —— 数学与统计的推导证明, 物理与工科的建模求解, 计算机的正确性 / 复杂度论证, 经管的均衡与最优化求解, 人文社科的要件比对与文献论证, 平时作业, 复习讲义, 模拟卷参考答案一律适用. 与科目, 教材, 载体无关.
> **性质**: 本文件管**答案与推理是否闭合**, 不管文字详略, 也不管是否忠于原始资料. 它是 `exam-passing` 中「平时作业撰写」「期末复习讲义编写」「模拟卷参考答案」三项能力共用的语义层基准.
> **分工**: `lecture_notes_spec.md` §2.0bis 管「忠于原始资料」(定义 / 定理 / 法条 / 文献的骨架, 量词, 限定条件不得超出原文); `lecture_notes_voice.md` §3 管「叙述的详略」(完整不等于铺满理由); 本文件管「论证自足」(答案集合是否完备, 辅助构造是否对齐, 条件范围是否穷尽, 自由度是否处理, 推理是否可复核). 三者不冲突: **补的是逻辑缺口, 不是解释性文字**; 补完仍按直陈文体收尾.

---

## 0. 一句话标准

**结构合规, 编译全绿, 与标准答案数值一致, 都不能证明解答合格.** 一份合格的解答还要经得住五问:

> 反过来呢 / 关键量算出来了吗 / 条件覆盖全了吗 / 自由度处理了吗 / 换一道题还能照做吗

这五问针对的是**语义层缺口**: 它们不会触发任何编译错误或静态检查, 答案往往还恰好是对的, 但读者合上书之后不会做第二道题. 本文件 §1 把五问写成五条可执行的判据, §3 给出各学科的对应形态, §5 是交付前逐题自检清单.

**与「忠于原始资料」冲突时**: 先照 `spec.md` §2.0bis 复刻原文骨架, 再在原文论证的断点处补一个注明「补充」的小段, 不要另起炉灶换一套方法. 原文若有真实错误, 按项目约定的勘误流程处理, 不在解答里悄悄改.

## 1. 五条通用判据

### 1.1 答案集合的完备性与双向性

**通用判据**: 凡题干要求「全部 / 所有 / 充要 / 唯一 / 刻画 / 分类 / 穷举 / 判定是否只有」, 解答必须同时给出两个方向:

- **充分性**: 列出的每一项确实满足题设;
- **必要性 (穷尽性)**: 任何满足题设的对象都在列表里, 没有第三类.

只做到前者是「给出一族候选」, 不是「求出所有解」. 若构造过程中出现了自由函数, 自由参数或待定常数, 必须**消干净或明确说明它为何不影响答案集合**, 否则得到的是松刻画.

**判定三问**: 题目要的是「一个」还是「所有」? 候选族之外是否可能存在别的对象? 推导中多出来的自由度最后去哪了?

**不该做**: 用一个方便的变换把问题化到已知结论, 套出一组对象便宣布完成; 或者用「容易验证」「由对称性显然」代替反向论证.

**特例**: 题目明确只要求「求一个解 / 举一例 / 给出一个构造」时, 不需要反向, 但题干须写清是特解, 不可与「求所有」混用措辞.

### 1.2 论证中引入的辅助构造必须与待证结论的关节点对齐, 且关键量要算出来

**通用判据**: 为推进论证而引入的对象 —— 辅助函数, 摄动量, 势函数, 归约实例, 试探解, 反例, 思想实验 —— 必须围绕**结论里那个关键对象**构造, 而不是围绕书写方便的点或随手可得的例子. 构造中的常数, 阶数, 初值, 边界值必须**实际算出数值或表达式**, 不能用「适当选取」「取充分小」「显然可构造」含混带过.

原因: 辅助对象取错中心或取错实例, 证明里的每一步不等式或比对可能仍然成立, 只是**推不出要证的结论**. 这类缺口隐蔽性最高.

**判定三问**: 这个构造对准的是结论里的哪个点 / 哪个对象? 关键常数是从哪一步算出来的, 数值写了吗? 换成随手取的构造, 结论还推得动吗 —— 若推不动, 说明对齐是必要的, 必须在解答里点明.

### 1.3 结论的适用边界要穷尽, 主论证覆盖题干允许的全部条件范围

**通用判据**: 先把题设允许的条件范围列全 (参数的正负零, 输入规模与边界输入, 退化与奇异情形, 约束绑定与否, 例外条款, 不同语境), 逐段检查主论证在哪一段失效. 正文用**一条主论证**覆盖完整范围, 一般情形若需化归到标准情形, **化归本身是论证的一部分, 必须写出来**; 其余证法只留一句必要的交代, 不并列铺开.

**判定三问**: 条件范围列全了吗? 把每个参数 / 每类输入取遍允许值, 主论证每一步还成立吗? 有没有哪一段是靠「同理」「类似可证」跳过而其实需要额外处理的?

**不该做**: 挑一条自己最熟的方法写到底, 却只在参数的特殊范围成立; 或把两条证法都完整写一遍, 篇幅翻倍而读者不知哪条是主证; 或因「本章刚讲过某工具」就省略化归那一步.

### 1.4 由等式推「为零 / 相等 / 唯一」前, 先处理推导实际给出的自由度

**通用判据**: 等式链解到底往往得到的是**差一个量**, 而不是「相等」: 导数为零给出常数而非零, 相差常数给出加法自由度, 相差非零倍数给出乘法自由度, 等价类给出代表元的选取自由, 单位 / 零点 / 参考系 / 参数化给出规范自由. 解答必须先承认这个自由度, 再补一句**它为何不影响所求量, 或按什么规则把它定下来**.

这句归一是论证, 不是讲评, 必须留在解答内; 漏掉它, 结论数值可能仍正确, 但推理不成立.

**判定三问**: 每处「故为零 / 故相等 / 故唯一」前面, 等式实际允许的是什么? 这个自由量是否被显式写出? 归一理由是否针对**本题所求的那个量**, 而不是泛泛一句「不妨设」?

### 1.5 答案自足, 可复核, 可迁移

**通用判据**: 可以引用**精确到编号或出处的结论** (教材定理号, 命题号, 法条号, 文献页码, 已证引理, 接口规范, 模型假设), 但**不能让引用充当推理步骤**. 关键中间量必须由题设自己定出来: 待定常数, 系数, 边界 / 初值条件, 分段取值范围, 分类的依据, 都要在解答内可见.

判据是「换一组数据, 读者照着这份解答能不能再做一遍」. 若某一步是「由标准结论即得」「查表」「代入通式」「与参考答案一致」「依相关规定」「众所周知」, 就是把求解外包给了读者找不到的东西.

**不该做**: 把「对答案」写进解答 (核对只能在写完之后离线做); 引用一条本身依赖未证结论的通式; 用「检验可知满足」代替把条件代回去算.

## 2. 两条交付性检查 (与学科, 载体均无关)

这两条不是数学推理, 但与上面五类缺口表现一模一样: **不报错, 看着对, 交付后才发现**.

**2.1 结论要落地**. 以「即得」「移项得」「因此」收尾时, 结论必须**真的写出来** —— 含适用条件, 取值范围与所有项. 停在「即得公式」而后面没有公式, 或只写前半截, 属未完成解答.

**2.2 删改要连带检查**. 删掉一段推导, 一个结论或整节之后, 所有指向它的东西要同步清理: 交叉引用, 硬编码题号, 目录与索引, 速记表 / 手册条目, 台账, 参考文献, 代码中的常量. 判据是「引用集合减标签集合为空」, 而不是「编译没报错」—— 有些载体 (Word, Markdown, 网页) 甚至不会报错.

## 3. 分学科映射表

同一条判据在不同学科里的**形态**不同, 判据本身不变. 换科目时按本表找对应形态, 不要照搬数学术语.

| 抽象判据 | 数学 / 统计 | 物理 / 工科 | 计算机 | 经管 | 人文社科 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1.1 完备性双向** | 通解, 所有解, 充要条件, 分类; 只由变换得候选族, 未证任意解都在族内 | 所有允许的模态 / 稳态 / 守恒量; 只解对称情形, 未排除非对称解 | 所有可能输出与状态, 正确性证明, 复杂度上下界; 只测样例或只给上界 | 所有均衡 (纯 / 混合), 所有最优解, 唯一性; 只解内点一阶条件, 漏角点解 | 全部构成要件, 全部适用情形与例外; 只列典型情形, 未处理边界判例 |
| **1.2 构造对齐且算常数** | 障碍函数, 摄动, Lyapunov 函数, 反例; 摄动中心取了坐标原点, 或「取充分小」没算常数 | 试探函数, 微扰阶, 参考系与规范选取; 试探函数不满足边界条件, 展开阶数与待证精度不匹配 | 归约实例, 势函数, 循环不变式, 对抗者输入; 构造的实例与困难实例不同构, 势函数初值未算 | 构造反例的效用函数, 比较静态的扰动方向; 构造的偏好不满足题设凸性 | 类比, 反例, 思想实验; 类比与争点不同构, 反例悄悄改了原命题前提 |
| **1.3 条件范围穷尽** | 参数正负零, 退化, 边界情形; 只证了参数非负 | 强 / 弱耦合, 高 / 低速, 奇点, 维度 | 空输入, 极值输入, 最坏情况, 溢出与并发 | 内点解 vs 角点解, 约束绑定与否, 参数符号 | 原则与例外, 不同法域 / 语境 / 时段 |
| **1.4 自由度归一** | 积分常数, 势函数加常数, 本征函数倍数, 规范变换 | 规范自由度, 势能零点, 参考系, 单位 | 等价类代表元, 随机化自由选择, 归一化基准 | 效用函数的正仿射变换, 计价单位, 参数化冗余 | 定义性约定, 分类口径的选取 |
| **1.5 自足可复核** | 可引定理编号; 不可让教材通式或书末答案代跑 | 可引守恒律与本构关系; 不可写「代入标准公式」而跳过定常数 | 可引接口规范与已证定理; 不可写「显然能跑」「参考标准库实现」 | 可引模型假设; 不可写「由均衡条件即得」而跳过一阶 / 二阶条件 | 可引法条号与文献页码; 不可写「依相关规定」「众所周知」 |

**共同点**: 五列里「不该做」的那一半, 本质都是**把本该在本解答内完成的一步, 藏进了读者的默认知识里**.

## 4. 与直陈文体的裁决

`lecture_notes_voice.md` §3 要求「承重论证不跳步, 同型重复允许留白」「末尾不复述与校验」. 本文件补的是**逻辑缺口**, 不是解释性文字:

| 该补 (逻辑缺口) | 不该补 (文体冗余) |
| :--- | :--- |
| 反向 / 必要性 / 穷尽性论证 | 「由此可见该方法很自然」 |
| 自由度为何可归一的一句话 | 逐步重述前提与适用范围 |
| 一般条件范围的化归步骤 | 把两种证法都完整写一遍 |
| 辅助构造中关键常数的计算 | 末尾「经检验结果正确」 |
| 待定系数由条件定出的过程 | 与上一题的对比讲评 |
| 结论公式的完整写出 | 「即得公式」之后补一段编者说明 |

一句话: **论证要闭合成环, 文字不铺成网.** 补完之后解答仍以结论收尾, 讲评, 对比, 校验类文字**默认删**, 确有实质新信息者**移出解答环境**作正文 (判据与收口机制见 `lecture_notes_voice.md` §3.2). 这一裁决对各学科, 各载体一致.

## 5. 逐题自检清单 (交付前人工过一遍)

对每一道含「证明 / 求所有 / 判断是否 / 分类 / 求解 / 论证」的题目, 依次问:

1. **反向**: 题目要「全部 / 所有 / 充要 / 唯一 / 穷举」吗? 两个方向都写了吗? 多出来的自由度消干净了吗?
2. **对齐**: 引入了辅助构造 / 反例 / 归约实例吗? 它对准结论里的关键对象吗? 常数, 阶数, 初值算出来了吗? 有没有「适当选取」「充分小」「显然」?
3. **范围**: 题设允许的条件范围逐段走过了吗? 主论证在每一段都成立吗? 备选方法是否只留了必要的一句?
4. **自由度**: 每处「故为零 / 相等 / 唯一」前, 等式实际给出的自由量写了吗? 归一理由针对本题所求量了吗?
5. **自足**: 有没有让「标准结论 / 查表 / 与答案一致 / 众所周知」充当推理步骤? 引用是否精确到编号或出处? 中间量是否都由题设定出?
6. **落地**: 以「即得 / 因此」收尾处, 结论是否真的写全 (含条件与取值范围)?
7. **连带**: 删改之后, 指向被删内容的引用, 题号, 目录, 速记表, 台账清了吗?

第 6, 7 条是工程性缺口, 但与前五条同样不会被编译或静态检查发现. 结构类检查 (例解配对, 题源标注, 交叉引用, 文体码) 交给 `scripts/lecture_notes_audit.py`; 第 1--5 条只能人工读.

## 6. 与验收工具, 与载体的关系

静态验收覆盖**结构**, 编译验收覆盖**版面与可解析性**, 本文件五条判据属于**语义层**, 两者都查不出来:

- 反向论证缺失 → 公式无误, 例解配对正常, 结果数值正确;
- 辅助构造中心取错 → 每一步比对仍「成立」, 只是推不出结论;
- 自由度被吞 → 结论数值正确;
- 条件范围漏一段 → 已写的那一段完全正确;
- 引用代跑 → 文面通顺, 无未定义引用.

因此**静态与编译验收全绿之后, 必须按 §5 做一次逐题语义通读**, 不能把「0 错误 / 0 未定义引用 / 0 Overfull」当作答案合格的证明. 这与 `lecture_notes_pitfalls.md` §3「编译零警告但 PDF 是错的」是同一类教训.

**载体相关的落地细节** (以下以 LaTeX 讲义为例, 其他载体按同等原则执行, 不是通用规范条款):

| 通用要求 | LaTeX 讲义 | Word / Markdown / 网页 / Notebook |
| :--- | :--- | :--- |
| 解答以结论收尾 | 显示公式收尾时用 `\qedhere` 让证毕符号与结论同行 | 结论独占一段或独占公式块, 不接讲评 |
| 交叉引用可解析, 删改后清理 | `\eqref` / `\cref`, 删节后跑「引用 − 标签」差集 | 交叉引用, 脚注与文献链接, 目录与索引, 锚点 |
| 引用精确到编号 | 教材定理号, 公式号 | 法条号, 文献页码, 接口文档章节, 题源编号 |
| 讲评不留在解答末尾 | 默认删; 保留者移出 `solution` / `proof` 环境, 结论公式末行用 `\qedhere` 收口 (voice §3.2) | 默认删; 保留者移出答案块 / 折叠区, 另起正文段落, 结论独占末段 |
| 结果与推导一致 | 常量, 系数, 边界值回代 | 代码块与其输出, 表格与其来源数据一致 |

## 7. 来源与案例索引 (仅用于说明落地, 不构成规范)

本规范的抽象来源是 2026-11-11 对一份《数学物理方程》期末讲义的一轮精修: 用户把五处「答案对但论证不成立」的写法逐一改掉, 并指出这是该轮最重要的改动. 下表是 §1 五条通用判据**在那门课里的具体投射**, 换科目时请按 §3 映射表找对应形态, 不要照抄这些术语, 也不要把这张表当检查项.

| 通用判据 | 该轮的具体修正 |
| :--- | :--- |
| 1.1 完备性 | 球对称波动方程通解: 由变换套公式给出一族解 → 补「任意解必属此族」的反向推导, 并消去多出的自由函数 |
| 1.2 构造对齐 | 极值原理的障碍函数: 以坐标原点为中心 → 以假定的最大点为中心, 边界估计的常数实际算出 |
| 1.3 范围穷尽 | 含参方程唯一性: 主证只覆盖参数的一种符号 → 改用本章标准工具, 并把一般符号化归到标准情形, 另一证法降为一句注 |
