# 期末复习讲义 LaTeX 排错速查 (跨科目通用)

> 规范条款见 `references/lecture_notes_spec.md` §4 / §6; 工程流程见 `references/lecture_notes_workflow.md`.
> 本表按「看到的症状」组织, 用于编译失败或版式异常时反查根因. 「发现层」一列说明该问题能被哪层验收抓到: 源码 / 日志 / 视觉 (三层定义见流程文档 §5).

---

## 1. 编译直接失败

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| 每个 `solution` / `proof` 各报一对 `Undefined control sequence` + `Illegal unit of measure (pt inserted)` | 自定义环境里写成 `\topsep6\p@\@plus6\p@relax`, 漏反斜杠后 `\p@relax` 被当成未定义命令 | 统一写 `\normalfont \topsep=6pt plus 6pt\relax` | 日志 |
| `Undefined control sequence` 指向某个新引入的数学宏 | 反斜杠误写成斜杠 (`/Q`, `/infty`), 或宏名拼错 | 逐处改回 `\Q`, `\infty`; 注意这类错误**有时不报错**, 见 §3 | 日志 / 源码 |
| `! Paragraph ended before ... complete` | 定理 / 提示框的可选参数里出现了未加花括号的 `]` | 可选参数整体加花括号: `\begin{proposition}[{...含 ] ...}]` | 日志 |
| `Missing } inserted` / `Runaway argument` | `\takeaway` / `\examtip` 调用参数个数与 `\newcommand` 定义不一致 | 让定义与调用的参数个数一致; 定义 `[1]` 就只传 1 个参数 | 日志 / 源码 |
| 一次补完几道练习后报 `\begin{solution} ended by \end{...}`, 或环境名不匹配 | 成段插入时只写了开头的 `\begin{solution}`, 漏写结尾; 插四道练习就漏四处, 前三处不报错, 报错位置与真正缺失处相隔很远 | 插入后立刻断言 `s.count('\\begin{solution}') == s.count('\\end{solution}')`, `example` / `exercise` / `proof` / `proposition` 同法逐个配对; 报错时不要顺报错行找, 从该处向前找最近的未闭合 `\begin{...}` | 日志 / 源码 |

## 2. 交叉引用与编号

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| PDF 里所有 `\cref` 都显示成「定义 x.y.z」 | 定义 / 定理 / 命题 / 例 / 练习共享 `definition` 计数器, cleveref 只看到主计数器 | `\usepackage{aliascnt}`; 每类 `\newaliascnt{X}{definition}` + `\newtheorem{X}[X]{名}` + `\aliascntresetthe{X}`, 再配 `\crefname` | 视觉 |
| `\cref{eq:...}` 显示成「定理 3.2.5 中的同构」 | `\label` 放在 `\[ ... \]` 显示公式里, cleveref 把标签归到邻近定理计数器 | 把公式改成真正的 `equation` 环境, 并把 `\label` 放在环境内; 配 `\crefname{equation}{式}{式}` 与 `\Crefname` | 视觉 / 源码 |
| 公式引用显示 `??` | 标签不存在, 或编译轮次不足 | 检查 label 拼写, 连续编译 3 轮 | 源码 / 日志 / 视觉 |
| 首轮上百条 `Reference ... undefined` | `.aux` 尚未稳定, 尤其是刚追加一整章 | 不要改源码, 连续编译 3 轮后再判断 | 日志 |
| `hyperref` 书签警告 / 书签乱码 | 章节标题含数学符号或 `\ref` | 用 `\texorpdfstring{$S_3$}{S3}` | 日志 |
| 目录里章节号是手写的 `0.1 / 2.9` | 用了 `\setcounter{secnumdepth}{0}` 或手写编号 | 编号交给 LaTeX, 用 `\section` / `\chapter` 与 `\numberwithin{equation}{section}` | 源码 |
| `\appendix` 后章标题不显示「附录 A」 | ctex 的章标题格式需重定义 | 在 `\appendix` 后重定义 chapter 标题格式 | 视觉 |

## 3. 编译零警告, 但 PDF 是错的 (最易漏)

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| PDF 中出现字面 `/Q`, `/infty`, `n</infty` | 源码把反斜杠误写成斜杠, XeLaTeX 把它当普通字符 | 改回 `\Q`, `\infty`, `n<\infty`; 源码扫 `/(infty\|Q\|Z\|R\|C\|alpha\|cdots...)` 并渲染抽样含新公式的页 | 源码 / 视觉 |
| 中文引号两端都是右引号 `”` | 源码写了 ASCII 双引号 `"..."` | 改成 LaTeX 成对引号 (两个反引号开头, 两个单引号结尾); 相邻引号短语之间用连接词或空格分开 | 源码 / 视觉 |
| 提示框只有标题被框住, 正文溢出框外 | `\examtip` 定义为 1 参数却按 2 参数调用 | 统一参数个数 | 源码 / 视觉 |
| 定理正文里的 `\textbf{...}` 仍是斜体 | 定理环境正文为斜体 | 写 `\textbf{\upshape ...}` | 视觉 |
| 日志出现 `Missing character: There is no 公 (U+516C) in font [lmroman10-regular]` | 中文占位文字直接写进 `\[ ... \]` 显示公式, 拉丁数学字体无 CJK 字形; 不报错也不给 warning | 显示公式内改用纯数学符号 (如 `\boxed{L u = f}`), 或把中文放进 `\text{...}` 由文本字体承载 | 日志 / 视觉 |
| 数学内容算错 (取值同态, 消去步, 反例条件) | 编译只管排版 | 人工逐条复核推导; 这一步没有工具可替代 | 人工 |

## 4. 断行与版面

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| `Overfull \hbox (10~20pt too wide)` 出现在证明中间 | 长行内公式与中文挤在一行 | 抽成显示公式 `\[ ... \]` 或 `equation` | 日志 |
| `Underfull \hbox (badness 5000+)` 出自手册表 | `tabularx` X 列中的 `\mbox{\cref{...}}` 把引用锁在一行 | 按比例调整 X 列, 如 `@{}l>{\hsize=0.8\hsize}X>{\hsize=1.2\hsize}X@{}` | 日志 |
| `\cref` 中文名称从汉字中间被拆行 | X 列允许在汉字间断行 | 用 `\mbox{\cref{...}}` 固定引用, 同时按上条调列宽 | 视觉 |
| `fancyhdr` 报 `\headheight is too small` | 中文页眉高于默认值 | `geometry` 选项加 `headheight=14pt` (或 15pt) | 日志 |
| 习题陈述孤立在页尾, 或 (1)(2) 问被拆到两页, 或盒底边线被页脚切断 | `tcolorbox` 的例题 / 练习样式带 `breakable`, 盒子可在任意位置断开; 内容恰在页底排完时仍判为断点, 而 `bottomrule at break=0pt` 又抑制了断处的线 | **把 `exstyle` / `examplestyle` 的 `breakable` 去掉** (实测最长题干仅 13 行源码, 远短于一页): 题干盒只装题面, 解答在盒外, 禁跨页后整盒下移, 页尾只留几行空白. 对照编译证明**页数 0 代价**, 只消除断盒; 不要在每个例题前逐个 `\needspace` 打补丁. **定理 / 命题盒保留 `breakable`**: 证明很长, 只能 `toprule at break=0pt, bottomrule at break=0pt` 去掉续页的圆角与横线. 模板 `assets/lecture_notes_template.tex` 已按此设置 | 视觉 |
| `$\bigstar$` 显示缺字 | SimSun / Fandol 常缺 Unicode ★ | 用 LaTeX 原生 `$\bigstar$` | 视觉 |
| 删掉章前分页后出现孤儿空白页, 或页眉提前显示下一章名 | 每章 `\clearpage` 在短章后强制换页, 留下整页空白; 连续排版下 `\leftmark` 取页面内最后一个 mark, 会提前显示下一章; `\topmark` 实测取不到值 | 优先连续排版, **不强制每章分页** (`lecture_notes_voice.md` §7); 确需换页用 `\needspace{12\baselineskip}`; 页眉右侧改固定文本; 编译后逐页扫稀疏页找孤儿空白页 | 视觉 / PDF 文本 |
| `Underfull \hbox (badness 10000)` 出自手册表的一行, PDF 里该行只有两个汉字 | `p{4.4cm}` 定宽列内"短汉字 + 逗号 + `\mbox{行内公式}`"放不进一行, `\mbox` 整体被推到下一行 | 把条件句移到 X 宽列, 或删掉连接逗号 (实测从 `同次齐次, 且 \mbox{...}` 改为直接写进结论列即消失) | 日志 |
| 盒标题里塞长题源标注后出现 `Underfull` / `Overfull` | 题目标题含 `[教材 \S 1.4 习题 11 (P.15)]` 等长串, 默认 `tcolorbox` 标题居中且两端对齐 | `\tcbset` 中加 `fonttitle=\bfseries, halign title=flush left`; 全局 `\hbadness=1500` 抑制盒标题的轻微 underfull, 并在源码注释说明原因 | 日志 |
| 章节标题里的 `$y$` / `$x$` 触发 `Token not allowed in a PDF string` | hyperref 生成书签时不能处理数学 | 标题内改用 `\texorpdfstring{$y$}{y}` | 日志 |
| `Overfull \hbox (398.6pt too wide)` 出自新写的多问题干, 报错行指向 `\label` 附近 | `\label{...}` 之后直接 `\begin{enumerate}`, 在 `tcolorbox` 的窄盒内 LaTeX 找不到可断点, 标签盒与列表被挤成一行 | 优先补一句**数学内容**的引入句 (设某对象, 判定某关系并求某量), 或调盒内列表参数; **不要**补「下列三问依次...」这类元话语总起句, 它是编写说明不是数学 (`lecture_notes_voice.md` §6). 不要靠缩字号或 `\needspace` 绕. 源码扫 `\label{...}` 后紧跟列表找候选, **以编译日志的 Overfull 计数与渲染页为准** —— 同样写法未必都出错 (实测有一处 0 Overfull), 因此不设静态检查码以免误报 | 日志 / 源码 / 视觉 |
| 内容长度变化后冒出 `Package tcolorbox Warning: nobreak failed` | 某节首个不可断的定理盒正好落在页尾 | 在**该 `\section` 前**加一次 `\usepackage{needspace}` + `\needspace{12\baselineskip}`, 只在空间不足时换页, 不留白; 不要逐盒打补丁 | 日志 |

## 5. 工具与文件本身

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| 批量替换脚本报命中, 文件内容却没变 | shell heredoc 把替换串里的反斜杠改写, `str.replace` 静默变成 no-op; 命中计数正常, 字节数不变 | 用 `chr(92)` 构造反斜杠, 或用文件写入工具生成 UTF-8 文本再字节级追加; **写完用另一个工具独立回读** | 人工 |
| 追加记忆时 `FileNotFoundError` 打断收尾 | 追加函数假定目标日志已存在 | 捕获 `FileNotFoundError` 时新建, 并按原文件行尾决定 CRLF / LF | 人工 |
| `.tex` 带 BOM 或行尾混杂 | 编辑器或 PowerShell 写文件默认带 BOM / GB2312 | 用 UTF-8 无 BOM + CRLF 字节级写入; 交付前用 `audit.py` 复核 | 源码 |
| PowerShell 写中文 `.tex` 乱码 | `-Encoding Default` 落 GB2312, `-Encoding UTF8` 加 BOM | 用 `[IO.File]::WriteAllText(..., [Text.UTF8Encoding]::new($false))`, 或改用文件写入工具 | 源码 |
| `ViewImage` 打不开 `/tmp/...` 路径 | 工具需要 Windows 绝对路径 | `cygpath -w /tmp/...` 得到 `C:\Users\...\AppData\Local\Temp\...` | 人工 |
| 生成的 md / json 每行末尾多一个回车 (`\r\r\n`), 编辑器显示空行翻倍 | 字符串本身已含 `\r\n`, 又用 `open(..., newline='\r\n')` 打开, 写入时把其中的 `\n` 再转一次 | 文本在内存里一律按 `\n` 组织, 最后 `text.replace('\r\n','\n').replace('\r','\n').replace('\n','\r\n').encode('utf-8')` 以 `'wb'` 一次写入; 写完用 `b.count(b'\r\r\n') == 0` 断言 | 源码 |
| 通过 `python - <<'PY'` heredoc 改含中文与反斜杠的 LaTeX, 编译 0 warning, 但 PDF 里出现 `$\varphi:/Z_2/to/Z$` | shell 层把 `\Z` / `\to` 的反斜杠吞成斜杠, 源码里已是错的, XeLaTeX 只当普通字符 | 含大段中文与反斜杠的 LaTeX **不要走 heredoc**: 用文件写入工具生成 `.py` 脚本再执行, 或用编辑器直接改; 写完 `pdftotext` 抽该页核对, `audit.py` 的 `slash-typo` 会报 | 源码 / PDF |
| 脚本里用三引号 raw string (`r"""..."""`) 加 `.replace(r'\n','\n')` 拼 LaTeX 显示公式, 断言失败却说不清哪里没匹配 | 该替换会把 `\ne0`, `\newcommand` 一类命令前缀里的 `\n` 也换成换行, 目标串被改得面目全非, `str.replace` 静默 no-op | 多行文本直接写**真实换行**的三引号字符串, 不用 `\n` 占位再替换; 整行匹配就用文件里读到的原文, 句中片段用子串替换并断言命中数 | 人工 |
| 一次性统计脚本把「带题源标注的环境」算成 0, 或漏掉一半真题标题 | 正则只认 `\begin{env}[{...}]` 带花括号的可选参数, 漏读 `\begin{env}[...]` | **复用 `audit.py` 的 `env_optional_args()`**, 不要自己写一次性正则; 实测曾把 32 处「只标卷别」误统计为 0 | 源码 |
| `audit.py` 报 `term-bold 0/0` 就想当然认为术语加粗已达标 | 该检查只扫 `definition` 环境; 全书没有 `definition` 环境时分子分母同为 0, **检查空跑**, 而术语其实散在正文「称为 / 叫做 / 叫作 / 定义为」句里 | 看到 `0/0` 一律额外 `grep` 导出全部术语引入句, 逐个核对是否 `\textbf`, 再渲染抽一页确认加粗不过度; 任何检查码都要先看**分母是否为 0** 再判达标 | 源码 / 视觉 |
| 改造后才发现用户改过拼接稿或片段 | 用户改了 `src/` 里某个片段 (如作者字段), 拼接稿还是旧值; 直接 `assemble.py` 会让两边互相覆盖 | 先 `cp` 备份**拼接稿**, 用 `difflib` 比对「当前片段重新拼接」与「现有拼接稿」的差异, 确认差异只在用户改动处; 以 `src/` 为唯一输入重新拼接, 不改拼接稿 | 源码 / 人工 |

## 7. 多章工程, 范围变更与内容核对

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| `scaffold.py add-chapter` 只生成空骨架, 分章写作时无法只重编一章 | 工具按"一次成型"设计, 不维护片段拼接 | 自建 `src/NN_chN.tex` 片段 (NN 为排序前缀) + `tools/assemble.py` 按文件名排序拼接, 统一转 UTF-8 无 BOM + CRLF 后写出主 `.tex`; 片段内部保持评审粒度, 主文件只是产物 | 人工 |
| 考试范围缩小, 已写好的整章作废 | 范围信息在写作中途才明确 | 不要删除, 用 `os.replace()` 把片段移到 `_parked/` 并在台账注明"超范围"; 之后 `grep` 该章全部 `\label`, 确认没有 `\cref` / `\eqref` 残留指向, 再重编 | 源码 / 日志 |
| 主 `.tex` 拼接后行尾或 BOM 不一致 | 片段由不同工具写入 | `assemble.py` 统一 `\r\n` 化并 `encode('utf-8')` (不写 BOM); 交付前用 `audit.py` 复核字节数与 `CRLF n/n` | 源码 |
| 正文里「必背」被 `audit.py` 判为 `banned-borderline` | 期末复习讲义只允许末章章名「必背公式与结论手册」使用该词; 其余位置属备考攻略腔 | 把章名之外的用法 (如「必背知识点」「必背清单」) 改成具体数学条件或结论; 章名本身无需改名 | 源码 |
| 批量把 ASCII 双引号改成 LaTeX 成对引号 | 手工逐处改易漏, 且改动多在长句中间 | `re.sub(r'"([^"\n]*)"', lambda m: "``"+m.group(1)+"''", s)` 一次替换, 再用 `s.count('"') == 0` 断言; 中文叙述中引号能删就删, 删不掉才用成对引号 | 源码 |
| 范围收紧后, 导语与提示框里还留着已删小节的指涉 | 只删小节, 没扫从属表述: 章导语写"去掉 Lipschitz 只能得到存在性", 小结框写"延拓问题要另行讨论", 手册小节名写"…与延拓", 小节一删全成悬空引用 | 删节后 `grep` 该节关键词(延拓 / Peano / 稳定性 …)扫全部片段与手册, 逐处改写; 同时改手册同名小节、台账条目与交付表、三层记忆的页数基线 | 源码 / 台账 |
| 引用的"经典反例"方程与解不配对 | 凭记忆写字面例子, 未回代验证 | 逐个回代: 如 Peano 定理说明唯一性失效时, $x'=1+x^{2/3}$ 的零解并不满足方程 (左端 $0$, 右端 $1$), 正确例子是 $x'=x^{2/3}$, 解为 $x\equiv0$ 与 $x=(t/3)^{3}$; 凡"例如"后接具体方程, 都要把解代入一次 | 人工 |

## 8. 整书切换作答语言 (解答由中文改为英文)

已经写完的讲义被要求"解答也用英文"时, 不要逐条手工改 `solution`, 也不要新写一份.

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |

## 9. 参考材料: 技巧漏抄, 课件抽取与二手标注失真

用户手里的 beamer / 往届讲义是"手法"的主要来源, 也是错误的次要来源. 两类问题都要按下面的方式处理.

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| 讲义题目覆盖完整, 用户仍说"beamer 里讲的技巧没放进去" | 只按题号对照, 没按手法对照; 技巧常写在 frame 之间的过渡句里, 不挂在任何题号上 | 通读参考材料, 把"这里可以这样做"的句子逐条摘成"手法 + 原理 + 它替代的常规做法", 再判断本书有无等价陈述. 参见 `lecture_notes_workflow.md` §1 | 人工 (结构层) |
| 整章撤出考纲后, 真题里同类的题也没人讲了 | 按"章"判范围, 而不是按"题"判范围; 被撤的章里含有跨章通用的手法 | 撤章前逐题过一遍该章占用的题源与手法, 只把真正需要被撤理论的部分 (如 Floquet) 归档, 其余手法移到保留章. 本次教训: 撤掉"渐近性与周期解"整章, 连带上丢了真题第五题 (一阶线性极限) 与模拟卷第四题 (常系数非齐次极限), 而这两题只用第 1, 3 章的方法 | 人工 (结构层) |

补技巧时的取舍: 优先补"能减少计算量"的, 例如

- 算子恒等式 $D+a=\e^{-at}D\e^{at}$, 把 $\lim(x'+ax)=0\Rightarrow\lim x=0$ 这类题化为一行;
- 秩一矩阵 $\bm B^{2}=\tr(\bm B)\bm B$, 判断 $\left(\bm A-\lambda\bm E\right)^{2}$ 是否为零不必做矩阵乘法;
- 可对角化时 $\Ker\left(\bm A-\lambda\bm E\right)^{j}=\Ker\left(\bm A-\lambda\bm E\right)$, 说明按 $\Ker$ 求广义特征向量算出零向量是必然的;
- 矩阵函数求导 $\left(\bm A^{-1}\right)'=-\bm A^{-1}\bm A'\bm A^{-1}$, 伴随系统的两条性质都由它一行推出;
- Riccati 特解用 $y=ax^{k}+b$ 待定系数, 观察不出来时也能机械地算;
- 结构代换族: 右端含 $ax+by+c$ 时取 $u=ax+by+c$, 含 $xy$ 或 $y/x$ 时取 $u=xy$ 或 $u=y/x$, 含 $\e^{ay}$ 时取 $u=\e^{ay}$, 含 $\sqrt{\cdot}$ 时取根式为 $u$; 换不出来时把 $x$ 当未知函数、$y$ 当自变量, 常一步化成线性;
- 已知齐次方程一个解 $x_1$ 时令 $x=x_1v$, 直接得到降阶公式, 不必猜第二个解;
- 常数变易不列方程组而用余子式形式 $c_j'=(-1)^{n+j}M_j f/W$, 四阶以内都是一行;
- 齐次恰当方程的通积分直接写 $xP+yQ=C$.

这些手法每条都能省掉一整段推导, 比再补三道同型例题有用. 只加例题不加手法, 讲义会变成题解汇编.

## 10. 真题: 回忆版数据核对与逐年重考题型

真题是最高优先级的题源, 但它以两种方式出错: **题目数据在转抄中失真**, 以及 **范围判定按教材章号而不按解法**. 两类都必须按下面的方式处理.

### 10.1 回忆版数据: 只按用户确认的版本写

| 症状 | 根因 | 修复 | 发现层 |
| :--- | :--- | :--- | :--- |
| 按回忆版数据算出的结论与题面"看起来的难度"不符: 判据恒为空, 解唯一, 出现 $1\pm\sqrt2\ii$ 这类本不该出现的无理特征值, 或算到一半卡住 | 题面在口耳相传中被抄错一个符号; 矩阵里一个元素就能改掉迹, 特征值, 单值矩阵与全部结论 | **停下来把矩阵或方程原样贴给用户确认, 不要按"哪种答案更像标准答案"自行改数据**, 也不要因为"算出来的结论也说得通"就放过. 本次实例: $\bm A=\begin{pmatrix}1&1\\-2&1\end{pmatrix}$ (错) 的迹为 $2$, 特征值 $1\pm\sqrt2\ii$, $\lvert\rho\rvert=\e^{2\pi}\neq1$, 判据为空, 解唯一; 正确的 $\bm A=\begin{pmatrix}1&1\\-2&-1\end{pmatrix}$ 迹为 $0$, $\bm A^{2}=-\bm E$, $\e^{t\bm A}=\cos t\,\bm E+\sin t\,\bm A$, $\bm C=\bm E$, 判据是两条正交积分, 解存在但不唯一. 两组数据各自自洽, 无法靠"哪组更漂亮"区分 | 人工 (内容层) |
| 数据只在讲义里改了, 真题源文件还是旧的 | 题源 `.tex` / `.pdf` 与讲义是两份文件, 改一处不影响另一处 | 回改真题源并重编 PDF, 用 `pdftotext -f N -l N` 核对改动所在行; 台账里该题的题面摘要同步更新 | 源码 / PDF |
| 用户指出"数据有错"后, 直接按自己推出的"合理结论"重写题目 | 把"答案应当如何"当成题面的证据 | 结论只能由题面推出, 不能反过来修题面. 用户只给方向 ("没那么复杂") 时, 给出一两个候选版本让用户挑, 选定后再动笔 | 人工 (内容层) |

回忆版真题在台账里先标"待核", 不要标"已占用". 一道数据待核的题被写成例题后, 它会连带污染例题, 练习, 手册条目与真题源四处.

### 10.2 真题逐题落点表: 按解法判范围, 不按教材章号

拿到考试范围 ("考到第 X 章") 后, 先做一张覆盖整份真题的表, 一行一题, 填完再决定归档什么:

| 题号 | 本题所求 | 实际用到的结论与手法 (写到小节与定理号) | 讲义落点 | 范围内 |
| :--- | :--- | :--- | :--- | :--- |
| 例: 第七题 | 周期解存在的充要条件 | 基解矩阵 $\bm\Phi$, 单值矩阵 $\bm C=\bm\Phi(\omega)$, 伴随系统的左零空间 | 周期系数系统一节 | 是 |

三条纪律:

1. **每行必须落到具体小节与定理**, 不写"第 2 章". 真题的"章"由解法决定: 一道用常系数基解矩阵与伴随系统就能做完的题, 即使教材把它编在一个考纲外的章里, 也不依赖那一章的任何理论.
2. **判据是"删去某节之后这题还能不能做"**. 只要解法里用到的定理全部在范围内, 就必须收; 若只有"某个结论的推广形式"在范围外, 就把该结论按范围内的工具重证一遍再收, 不要连题一起丢.
3. **同类失误会重复发生**. 本次两轮编写在同一处翻车两次: 先按"渐近性与周期解整章不考"丢掉一阶线性极限题 (只用第 1, 3 章), 再按"第 6 章不考"丢掉连年出现的周期解末题 (只用第四章). 两次都不是范围信息错, 而是落点表只填了教材章号一列.

### 10.3 逐年重考的题型独立成节

同一题型连续两年及以上压在卷末, 说明命题人把它当成固定结构, 应独立成节, 必要时独立成章, 不能只作为某一节的例题附注. 本次把教材周期系数系统一节扩成独立一章 (命题: 乘数递推, Floquet 分解, 周期解判据; 判据: 非齐次的正交条件; 例题: 真题原题; 练习: 五种问法), 手册同步加一节.

独立成章时章导语要写清依赖: 只用到哪几章的哪些结论, "不涉及第 N 章"要明写, 这样即使该章排在依赖章之前也不妨碍阅读.

## 12. 编译产物没落盘: 中文文件名与目标被占用

> 这一节的错误**不会出现在编译日志里**: 日志写 `Output written on ... (N pages)`, exit=0, 三轮全 0 warning, 但磁盘上的 PDF 仍是旧版. 交付前必须用 `pdfinfo` 核对页数与 `pdftotext` 抽一页确认内容.

## 14. 文体层改造的版面副作用 (2026-11-08)

按 `lecture_notes_revision.md` §2ter 删掉强制分页, 提醒框与末尾复述后, 页数会明显下降 (实测 41 → 36), **这是删版式与删铺陈的结果, 不是压了解答**. 验收顺序:

1. 结构计数 (题数 / `solution` / label / 题源) 与改造前一致;
2. 逐页扫稀疏页 (非空但正文少于 8 行的页) 找孤儿空白页;
3. 章标题落页底时检查导语未被拆散;
4. 连续排版下页眉是否提前显示下一章名.

**2026-11-09 第二轮实测 (常微分方程讲义, 86 → 81 页)**: 删 6 处 `\clearpage` 与 13 个提示框后逐页扫得 0 稀疏页; 末章标题与导语落在页中, 其后 `tabular` 不可跨页被推到下一页, 留下约三分之一页空白. 只要该页正文不少于 8 行且导语未被拆散就判通过, **不要为此加回强制分页** (只会把空白移到前一页并多出一页). 另外三条:
- `voice-meta` 只匹配「下列 N 问 / 依次 / 分别」等固定串, 连读仍抓到「考场上先看迹, 这是本题最省时的判断」「考点就转到」「下面的练习把两种情形并排比较」「下面的第 (2) 问」等**不在词表内**的备考 / 编纂腔. 词面全绿不等于文体达标, 必须按 voice §9 连读一章.

## 15. 删掉「命题-练习重复」的四类副作用 (2026-11-08)

抽象代数讲义第一章一次删掉 21 块「命题已证明, 练习再证一遍」的重复题后, 实测遇到四个非编译类的坑:

1. **`source-duplicate` 静默**: 命题标题形如「满同态的存在条件; 教材 P.38 第 2 题, 第二次作业」, 练习标题形如「教材 P.38 第 2 题; 第二次作业」, 字符串不同, 审计不会报重复. 必须自己把结论型环境也导出, 与题目型做相似度聚类 (字符 3-gram Jaccard ≥0.4 或覆盖率 ≥0.6 作候选), 再人工判定. 导出脚本的正则要用 `re.escape(B+'begin{')` 构造 —— 直接写 `\begin\{` 时 `\b` 会被正则当成单词边界, 一个环境都匹配不到.
2. **独有内容被一起删掉**: 重复题里常夹着命题没有的实质内容 —— 一个 $\F_3$ 矩阵群反例, 一条第二种证法, 一个具体群中的乘法不封闭. 删块前逐组读 `solution`, 把这类内容压成一两句回灌命题 `proof`; 已经写在命题 `proof` 里的反例 (常见于「结论不成立」型命题) 才可直接删.
3. **配比空档**: 结论型环境不承担 `example` / `exercise` 配比, 删完若干 `\subsection` 变成 0/0 或 1/0. 这是 §2.1.3 与「精简」诉求的真实冲突, **必须先问用户**, 不要默认补题 (上一次补 12 块直接把 89 页涨到 95 页, 用户立刻质疑). 用户允许缺口时, 在交接文档写明豁免的小节, 并更正验收基线里的配比描述.
4. **全局替换 `\cref` 造成前向引用**: 把分散题块合并成章末一个新板块后, 若机械地把旧 label 全部替换成新例题 label, 前面的小节会出现「由 例 1.10.1 …」这类指向后文的引用. 替换后要 `grep` 全部命中, 把**前文的引用改成直接陈述** (直接写出那三个子群, 直接写出 $H$ 的元素), 只在需要指引时用 `第~\ref{sec:...}~节`; 后文引用新板块则保留.

## 16. 与教材原文对齐时的六个坑 (2026-11-08)

按 `lecture_notes_spec.md` §2.0bis 把定义与证明改回教材原文、并补标教材编号时, 实测踩到以下六个:

1. **教材外术语不能只 grep 一个词形**. 搜「群作用」在抽象代数讲义里只命中 3 处, 实际有 6 处, 另外 3 处写的是「$G$ 在 $X$ 上的**作用**」「**轨道**」「**稳定子**」. 清零要按词根穷举: `作用|轨道|稳定|类方程|中心化子|正规化子|$\sgn$|奇置换|偶置换`, 再逐条看上下文区分数学用法与普通词语.

2. **拆分一条定理后 label 怎么分**. 讲义原有的「定理 1.8.2」被拆成命题 1.8.3 / 1.8.4 / 推论 1.8.5 时, **原 label 留给第一条**, 后两条用新 label. 若把原 label 给最后一条或删掉, 全篇 `\cref` 会立刻断掉一批; 若三条都新起 label, 引用处的类型名会从「定理」变成「命题」或「推论」, 得逐处改措辞. 拆完后跑一遍 `grep '\\cref{'` 人工核对每条引用读起来是否还通顺.

3. **降级为 `remark` 后, 引用措辞要同步改**. 唯一性从定理降成注后, 正文仍有「由定理 \cref{thm:...} 知分解唯一」这类句子, 编译不报错, 输出变成「由注 1.8.6 知」, 逻辑上也不通了. 降级时把引用处一并改成直接陈述结论.

4. **教材编号不是节内顺序号**. OCR 里「定义 2.4」的编号与正文常排在不同行, 按出现顺序硬对会错位; 而教材的编号是按**全书节内**连排 (第一章 §2 的定义编号是 2.4, 2.6, 2.7), 与讲义的「章.节.序」毫无对应. 所以必须读教材原文的首句来确认是哪一条, 不能靠序数猜. 补编号时把「教材编号 → 原文首句」做成对照表, 逐条核对再写.

5. **可选参数里的 `\S` 与方括号**. 标题写成 `[教材 \S 2 命题 2.8]` 是安全的; 但若标题文字里出现 `]`(例如「教材 P.11 第 19 题 [注]」), 会提前截断可选参数, 编译报 `Paragraph ended before \\` 一类怪错. 标题内不要出现裸方括号.

6. **陈述写全后定义会跨页剖开**. 把教材的三条并列条款补回定义后, 定义从 6 行涨到 14 行, 正好落在页界, 前半页断在半句. 处理顺序: 先看引导句是否过长 (压缩引导句常常就够了), 再看能否按教材原样把这一条拆成两条定义 (本轮就是这么解的, 拆分本身既忠于原书又缩短单块长度); **最后才考虑 `\needspace`**, 逐个打补丁会让版面到处是空白.

## 17. 补定义与拆定义的四个副作用 (2026-11-08)

按 §2.0bis 第 6、7 条补上「被引用而未定义」的概念、把合并定义拆开后, 新踩到的四个:

1. **拆出来的长行内公式会 Overfull**. 定义 3.5 之后的正文写「它也是包含 $\id{a_1},\id{a_2},\dots,\id{a_n}$ 的最小理想」, 三个 `\id{}` 串起来是一段不可断的行内公式, 编译报 `Overfull \hbox (36.03pt too wide)`. 改法不是加 `\allowbreak`, 而是换说法: 「它是包含每个 $\id{a_i}$ 的最小理想」—— 少写两个实例, 意思不减, 断行自然. 拆定义后凡出现「列举若干个同类记号」的句子都要重读一遍.

2. **定义收尾句被页界单独顶到次页**. 定义写成「若 $R$ 满足: (1) …; (2) … 则称 $R$ 是 X」时, 条款占满整页, 收尾的「则称 $R$ 是 X.」一行落到次页顶部, 视觉上是孤行. 改法是把判定语前移到引导句: 「设 $R$ 是整环, 若它满足以下两条, 则称 $R$ 是 **X**:」, 定义框结尾停在最后一条条款上. 这条对 `breakable` 的框尤其明显.

3. **补了定义就造出一处新重复**. 2.6 节按教材定义 5.9 写特征时, 顺手把「素域」也写进去, 而 3.1 节早有一条定义 1.3 定义了素域 —— 补定义的收益立刻被一处新重复抵消. 补之前先全篇搜该术语有没有已存在的 `definition`; 若两处都有, 保留**承担叙事线索的那一处** (本例是 2.6, 因为它连着「特征决定素域」), 另一处改成承接语, 但要注意别处的 `\cref` 指向哪一条, 改完逐条回读.

4. **补 Zorn 引理这类公理型工具, 用 `lemma` 不用 `remark`**. Zorn 引理在教材里是「数学中普遍接受的集合论公理」, 不编号也不证明. 讲义给 `lemma` 环境是为了让「极大理想存在性」的证明有可引用的锚点 (`\cref` 需要 label), 但正文必须写清「它是公理, 本身不予证明」, 否则读者会以为漏了证明. 同理, 教材里只作为习题出现的概念 (根理想 $\sqrt I$) 不进 `definition`, 写成正文一句并标出题号.

**一条经验**: 「一条定义标了多个教材编号」是本轮最强的拆分信号 —— 五个合并定义拆开后, 页数只涨一页, 但被后文悄悄使用的「真理想」「极大主理想」「欧氏除式」「$n$ 元多项式环」全都有了出处. 反过来, 教材把某个结论的证明删掉 (第二版前言明确说明删去 $R[x]$ 是 UFD 的证明), 讲义不得写「由教材定理 X」把未证的结论当依据, 要如实交代缺口.

## 18. 补证明与「教材顺序优先」的五个判断 (2026-11-08)

补证明 (`spec.md` §2.0bis 第 8 条) 时踩到的五条, 前两条是判断而非操作:

1. **教材顺序与「例紧随命题」冲突时, 保教材顺序, 不搬结构块**. 3.2.1 的例与练习要用 3.2.2 的定理 (读次数与基), 隔着约一页. 根因是教材先讲单超越、后讲单代数, 而讲义的例紧跟极小多项式命题; 要彻底消掉得把「$F[\alpha]$ 定义 + 定理 2.6 + 证明 + 推论 3.2.10」整块前移, 等于重排一章. 用户的选择是**保留教材顺序, 让引用显式跨页** (2026-11-08 22:55「先不改了」). 判据: 前向引用只有在「读者要翻过两三页才看到被引结论」时才算缺陷; 跨一个小节、而教材本身就这么排的, 属于可接受, 修法是正文里写清「见第~\ref{...}~小节的 \cref{}」, 不是搬块. 搬块的代价是把教材的叙事线索打断, 换来的是一个纯形式上的漂亮.

2. **锚点要区分「定义 X.Y」与「定义 X.Y 后」**. 教材里大量结论写成「注意到…」或「由定义 X.Y 直接得到」, 本身没有编号. 讲义若把这类结论标成「教材 §1 定义 1.1」, 等于给一条命题挂了一个定义号, 读者翻到定义 1.1 找不到这段话. 正确写法是「教材 \S 1 定义 1.1 后」或「教材 P.x 第 N 题后」. 反向同错也要查: 教材有推论编号却只引了定理 (子域之交原标「习题 1, 命题 1.2」, 实为「命题 1.2, 习题 1」; 每个域含素子域原只引定理 1.4, 教材另有推论 1.5). 补锚点时把该条**前后各一条编号**也扫一眼, 顺序与归属一起核.

3. **补证明会连带暴露「同一结论证了两遍」**. 命题 2.4 补完完整证明后, 原例题的 `solution` 里其实又证了一遍同样的整除性, 只是当时没有命题可引. 补证明前先看该结论的例题解答是否已经证过; 证过就把例题缩成「用 \cref{} 求具体多项式」的计算题, 别留两份论证.

4. **逐节推进到最后一章, 必须同步清空台账里的「尚未对读」清单**. 交接文档与项目记忆里各有一句「其余小节仍是压缩改写体」, 跨了几轮都还在, 会误导下一轮从已完成的小节重做. 每轮收尾时把这一句改成当轮的实际状态, 宁可写「全篇已逐节对读, 遗留见 §9」, 也不要留着过期清单.

5. **台账里的位置要精确到节, 不能凭印象**. 上一轮把 $(a+b)^{p^n}$ 记成「2.6 节末」, 实际在 3.1 节的练习里; 这类笔误不影响讲义, 但会让下一轮在错误的地方找内容. 写台账时把节号与 label 一起抄, 不要只写「某节末」「后半部分」.

## 19. 按 label 搬块的四个工程细节 (2026-11-09)

1. **块尾要连上 `solution` 与 `proof`**. 只从 `\begin{example}` 切到 `\end{example}`, 会把解答留在原地; 只从 `\begin{proposition}` 切到 `\end{proposition}`, 证明会留在原地. 「插到某命题后」若按 `\end{proposition}` 定位, 例题会被塞进命题与证明之间 —— 编译不报错, 版面上是命题说自己, 接着一道例, 然后才是这条命题的证明. 一律按「环境体 + 紧跟的 solution/proof」算整块.

2. **每搬一块重新读文件, 重新按 label 定位** (含 `span()` 的局部重算). 在同一个字符串上连续做 `s[:b] + s[e:]` 再记后续偏移, 极易错位; 而且错位后往往不报错, 只是章节顺序悄悄乱掉. 改用「load → 定位 → cut → save」与「load → 定位 → insert → save」交替, 17 次搬动零失误.

3. **shell 里的正则又踩了同一个坑**. 用 `python -c "...re.match(r'\\begin...')"` 时反斜杠被 shell 吃掉一层, 模式变成匹配字面反斜杠, `re.match` 返回 `None`, 报 `AttributeError: 'NoneType' object has no attribute 'group'`. 与 §13 记的 heredoc 坑同源: **含 LaTeX 与正则的脚本一律 Write 成 `.py` 再执行**, 不要走 `-c` 或 heredoc.

4. **搬完扫一遍「未定义记号提前使用」**. 例题换了位置就等于换了上下文: 原在 2.8 的例子里用 $(a,b)$ 表示最大公因子没问题, 搬到 2.7 就变成使用尚未定义的记号. 搬动清单里每个块都要重读一遍它引用的每个符号与每条 `\cref`, 确认都在新位置之前出现过. 同理, 原本靠「前面刚讲过」维系的承接话 (「与上一题对照」「这里沿用上面的记号」) 也要重新指认对象.
