# exam-passing 助教工作流与执行规范指南

本指南详细定义了 `exam-passing` 技能在处理平时作业、课件解析、复习讲义以及模拟卷命制时的四大标准流水线。

---

## 工作流一：PPTX 课件读取与考点萃取 (PPTX Parser Workflow)

### 1. 触发场景
- 用户上传了教师上课的 PPTX 课件，要求“总结课件内容”、“提炼重点模型”、“对照教材查找 PPT 补充考点”。

### 2. 执行流程
1. **执行抽取脚本**：
   ```bash
   python scripts/extract_pptx.py <课件路径.pptx> -o <输出.md>
   ```
2. **知识点归纳与三级映射**：
   - **概念层**：提取幻灯片核心定义、定理、背景问题。
   - **模型层**：提炼幻灯片中的数学推导公式、目标函数、约束方程。
   - **考点标记**：对比教材《数学建模(祁永强)》的对应章节，标注“教材重点”、“PPT 补充模型”、“课后思考题”。

## 工作流二：平时作业规范解答与 LaTeX 排版 (Homework Solver Workflow)

### 1. 触发场景
- 用户提出：“帮我写一下第 X 章习题第 Y 题”、“完成这周的数学建模作业”。

### 2. 解答质量红线（建模标准“五步法”）
1. **一、问题重述与背景分析**：
   - 绝不仅照抄原题，而是用简练的数学语言重构问题核心目标（如“在资源有限的前提下实现利润最大化”）。
2. **二、合理假设与简化**：
   - 列举 3~5 条机理假设，明确边界条件、忽略次要微弱因素。
3. **三、符号说明表**：
   - 必须使用三线表（`booktabs`），包含：符号、物理/经济含义、变量类型（决策变量/状态变量/已知参数）、单位。
4. **四、模型的建立与严密公式推导**：
   - 严格写出守恒定律、微积分平衡、规划目标函数与全部约束条件。
   - 公式居中并按需编号，避免跳步。
5. **五、模型求解与算法代码**：
   - 若有显式解析解，完整推导；
   - 若需数值计算，提供高可读性 Python（NumPy/SciPy）或 MATLAB 求解脚本与数值输出。
6. **六、结果分析与灵敏度评价**：
   - 对数值结果赋予现实解释；
   - 给出关键参数扰动下的解变动趋势（鲁棒性检验）。

### 3. LaTeX 交付规范
- 基于 `assets/homework_template.tex` 模板填充。
- 行尾保持 CRLF，UTF-8 无 BOM，统一使用英文标点符号。

## 工作流三：期末复习讲义体系化编写 (Review Notes Workflow)

### 1. 触发场景
- 用户提出：“帮我写一份第 X 章复习讲义”、“总结全书的微分方程模型考点”、“做一份期末知识手册”。

### 2. 讲义四大模块架构
1. **知识图谱与逻辑脉络**：
   - 章节主线图、概念依赖关系、由浅入深的推导链条。
2. **核心模型机理与公式精粹**：
   - 提炼模型标准型、物理意义、各参数的作用。
3. **典型题型分类精讲与解题套路**：
   - 挑选教材典型例题与高频考题，给出审题突破口与标准解法。
4. **易错陷阱与避坑指南 (Pitfalls Table)**：
   - 结晶过往易错点（如“忘记一致性检验CR<0.1”、“离散与连续复利混淆”、“变上限积分求导丢项”）。

## 工作流四：仿真期末模拟卷设计与评分标准命制 (Mock Exam Workflow)

### 1. 触发场景
- 用户提出：“出一份数学建模期末模拟卷”、“设计一套期末考题带答案和评分标准”。

### 2. 试卷题型与分值配比标准（总分 100 分，时长 120 分钟）
- **一、单项选择题（5 题 $\times$ 3 分 = 15 分）**：考察基本概念、模型假设适用前提、经典模型临界阈值。
- **二、填空题（5 空 $\times$ 3 分 = 15 分）**：考察核心公式、特征指标、判据边界值。
- **三、简答与机理推导题（2 题 $\times$ 10 分 = 20 分）**：考察微积分/物理守恒机理证明，如双层玻璃导热、AHP一致性检验步骤。
- **四、微分方程/连续动力学建模大题（1 题 25 分）**：如铅球最佳仰角、传染病相平面分析、减肥模型或作战平方律推导。
- **五、运筹规划/离散优化建模大题（1 题 25 分）**：如原料下料整数规划、动态规划最短路、报童临界分位数期望利润最大化。

### 3. 配套参考答案与评分细则
- 必须逐题给出每一步的得分点（如：设变量 3 分，写出目标函数 5 分，约束条件 7 分，推导 5 分，最终结论 5 分）。
