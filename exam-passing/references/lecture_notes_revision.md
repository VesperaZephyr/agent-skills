# 既有讲义复盘改造 SOP (跨科目通用)

> **触发场景**: 讲义已交付一轮, 用户按阅读体验给出结构性反馈 —— 成稿里同类型的题没放到一块 (违反规范 §1.1)、排序像按题号铺开、概念里的名词没标出、正文出现课本上没有的内容、真题源自课本却没标来源、希望补几道同方法的练习, 以及第六类: 「同一个题写了好几遍, 应该删掉合并成一道多问例题」.
> **分工**: `lecture_notes_spec.md` 规定成品长什么样, **其中 §1.1 要求同一个题先合并, 同类题再聚拢**; `lecture_notes_workflow.md` §4 规定新建讲义如何分章迭代; 本文件规定**已有成稿未达到这些要求时怎么改**, 并给出脚本骨架, 验收口径与工具检查码. **本文件不定义新的撰写要求**; 新建讲义不要走本流程, 直接在编写阶段按规范执行.
> **适用科目**: 任意高校课程. 文中例子取自抽象代数只为说明, 规则与科目无关; 涉及教材的判断一律以该课程的教材原文为准.

## 0. 八类反馈的判据与动作

| 反馈 | 判据 | 动作 | 易踩的坑 |
| :--- | :--- | :--- | :--- |
| 违反规范 §1.1: 同类型题分散, 排序按题号 | 两题或多题用同一个构造, 只是参数 / 常数 / 素数不同 (数据不同, 属同类题) | 按规范 §1.1 的目标形态新建一个以方法或研究对象命名的 `\subsection`, 把题目连同 `solution` 整块搬进去; 开头用一段叙述讲清共同构造与各题参数差别; 补一道只换参数的变式练习; **这类题只聚拢, 不合并** | 只搬题干漏搬 `solution`; 小节标题写成题号; 搬完没复查 `\cref`; 把同类题也合并成一道多问题 |
| 概念里的名词没标出 | `definition` 与首次引入概念处, 术语未用 `\textbf{}` 标出 | 逐个定义加粗术语; 术语一律沿用本课程教材的叫法 | 定理体为斜体, 内部需 `\textbf{\upshape ...}`; 顺手换成教材没有的同义词 |
| 正文出现课本外内容 | 正文用了教材未引入的定义, 记号或工具, 甚至以它作为证明依据 | 先在教材原文里核对该术语是否真的没有; 确无则**重写证明**改用教材已有的记号, 命名只放进 `remark` 并写清它与正文记号的关系 | 凭印象判"课本外"; 只删名词不重写论证, 证明仍暗依赖它 |
| 真题源自课本却没标来源 | 环境标题只有卷别, 没有教材锚点 | 逐题比对教材习题表与教材正文: 有原题则卷别与原题号 / 定理号并列; 确无原题则标概念锚点 (该定义或定理), 不虚构习题号 | 只补一部分, 仍"有些标了有些没标"; 给所有题硬塞一个习题号 |
| 想补同方法的练习 | 某方法只有一两道题, 读者看不出方法可迁移 | 补只换参数的变式, 就地配与例题同等规格的完整 `solution`, 标注写"教材 §X 习题 N 的变式" | 变式标注字符串与原题完全相同, 触发 `source-duplicate`; 练习只给答案 |

| 同一个题写了多遍 (第六类) | 题干基本一致只是表述 / 出处不同, 或同一实例的不同考察方式 (同一扩域问生成元, 次数, 元素, 极小多项式) | **合并**: 删掉重复题, 保留一道多问递进的 `example` + 一个 `solution`, 出处并列; 另配一道同类题作平行练习 (数据不同, 方法相同). 详细流程见 §2bis | 把「数据不同但方法相同」的同类题也合并掉; 删块前没查 `\cref` 外部引用; 被删练习里的独有反例没并入保留块; 合并后新邻接内容与命题重复 |
| 文体防御 (第七类, 2026-11-08) | 静态检查全过, 用户仍说「写得不够好, 证明写得很防御」, 并给出一份人写讲义要求学它的写法 | 不做同义词替换, 按 §2ter 改信息组织: 章导语改数学陈述, 删末尾复述与复验, 提醒框升级为编号结论或删除, 证明首段即计算; 加载 `references/lecture_notes_voice.md` | 只调措辞不动组织方式; 照抄参考讲义的全角标点与「我们」带读语气; 为求简洁删掉承重论证 |
| 与教材原文不一致 (第八类, 2026-11-08) | 用户说「叙述与原书明显不一致 (不是说内容出错), 原书明显更好一些」, 或指出某条证明用了原书没有的概念 (群作用, 轨道), 或要求标出「这条其实是原书命题 2.8+2.9」 | 按 §2quater 逐节对读: 陈述按教材骨架重写, 证明改用教材工具, 每条结论标教材编号, 一条对多条时拆开 | 只把术语名换成教材叫法而不动论证; 只改陈述不标编号; 为了对齐改讲义自己的计数器 |

八类反馈常同时出现, 但**不要一次性重写全文**. 按 §2 分三层做, 每层结束立刻静态验收; 第六类按 §2bis 的六步删块合并流程单独做; 第七类按 §2ter 单独做文体层, 通常不动结构, 也不改数学内容; 第八类按 §2quater 逐节推进, 一次只对读一节.

## 1. 动手前的三项盘点

### 1.1 先备份用户改动版

用户说"我简单做了一些改动"时, 这些改动必须原样保留, 不得被批量脚本覆盖:

```bash
mkdir -p "<项目>/.workbuddy/backup"
cp "<项目>/讲义.tex" "<项目>/.workbuddy/backup/讲义_用户改动版_<时间戳>.tex"
```

备份后再读文件, 确认 BOM / 行尾 / 字节数, 后续所有脚本都按这个行尾写回.

### 1.2 抽三张清单

用一次性脚本打印, 存成文本文件备查:

1. **结构清单**: 全部 `\chapter` / `\section` / `\subsection` 及行号 —— 判断题目当前散布在哪些节, 新方法小节插在哪里.
2. **环境标题清单**: 所有结论型环境与题目环境的可选参数 (含 `[{...}]` 形式) 及行号 —— 判断哪些标题只有卷别、哪些术语没加粗.
3. **规模清单**: `example` / `exercise` / `solution` / `definition` / `remark` 计数, `label` 总数与重复、未定义引用清单 —— 改造后逐项对齐.

正则必须兼容 `\begin{exercise}[{...}]` 这种带花括号的可选参数, 否则统计会算成 0.

### 1.3 把教材变成可检索的两张表

判"课本外"不能凭印象, 必须查教材原文:

```python
# 1) 全部习题题干: 以 "N. " 开头的行, 输出成带行号的清单
# 2) 争议术语在教材中的出现次数与上下文
for kw in ['范数', 'Zorn', '有限域', '共轭', 'Gauss 引理']:
    hits = [i + 1 for i, l in enumerate(L) if kw in l]
```

本项目实测: 教材 §6 定义欧氏环时写 `φ(a+bi)=a²+b²=|α|²`, 全书 0 次"范数", 故"范数"必须移出正文; 但"有限域"出现 28 次、Zorn 引理出现在定理 5.8 之前, 这两处保留. **先查再改**, 否则会误删教材里本来有的概念.

## 2. 分三层执行

### 2.1 文本层 (不动结构)

- 术语加粗;`sub(old, new, cnt)` 断言命中数, 每个替换串只在该位置出现一次时才用 `line()` 整行匹配.
- 课本外术语改写: 连同**依赖它的整段解答**一起重写, 不是只换名词. 例如把"取范数 N(α)"改为"复数模的平方 |α|² 满足 |αβ|²=|α|²|β|²", 并把 Z[√2] 的欧氏除式改用 `Φ(xy)=Φ(x)Φ(y)` 的展开式.
- 标题补教材题源; 新增 `remark` 说明课本外命名, 写清与正文记号的关系.
- 这一层结束后跑一次 `audit.py`, 确认 `label` 与环境计数未变.

### 2.2 结构层 (按 label 搬整块)

- 先 `cut()` 出所有要搬的单元 (题目 + 紧跟的 `solution` / `proof`), 再按新方法小节的次序 `insert_before()` / `insert_after()` 插回. **先全部切出再插入**, 否则行号会漂移.
- 每个新方法小节按 `lecture_notes_spec.md` §1.1 的目标形态组织 = 一段叙述导语 + 若干原题 + 一道同方法变式练习 (+ 完整解答) + 可选 `remark`. 导语里点明共同构造与参数差别, 不写"本节把...收集在一起"这类编纂说明.
- **原题按参数复杂度排梯度**: 同一构造的几道题, 让右端从常数、一次函数到含未知函数的项依次变难, 导语可点明"下面三题的右端分别是 ..., 覆盖 ... 三种情形", 读者一眼看出这组题的边界.
- **解答要体现小节的构造**: 某题原本可能走另一条一般路线, 搬进本小节后应把解答改为按本小节的共同构造写, 另一条路线在末尾用一句对照即可. 实测一题由 $p=y'$ 代换改为识别 $(y'/y)'$ 后少两次换元, 这正是"把同类题放一起"要展示的东西.
- 原节若同时含两类题 (如"缺 $y$"与"左端成导数"), 拆成两节而不是把异类题留在节中; 拆完逐题确认 `solution` 仍是完整解答, 不是只剩题干.
- 新小节的 `\label` 用独立前缀 (如 `rssec:` / `fssec:`), 插入前断言全书不存在同名 label.
- 所有移动都靠 `\label` 定位, 不靠行号; 定位函数断言 label 唯一, 找不到立即停.

### 2.3 收尾层

- 复查 `\cref` / `\Cref` / `\eqref` 全部有定义 (搬移最容易把某个 `\cref` 指向删掉的标签, 本项目实测抓到 `cor:pgroup`).
- 修导语措辞、概念锚点、长显示公式断行.
- 写回时保持原行尾与 UTF-8 无 BOM, 并用**另一个工具**独立回读确认内容真的改变.

### 2.4 为什么分层

文本层失败只影响若干行, 不会破坏结构; 结构层依赖文本层之后稳定的 label; 收尾层处理前两层引入的引用与版面问题. 三层各自可回滚, 比对全文重写安全得多.

## 2bis. 第六类反馈: 同一个题合并去重 (2026-11-08)
> **补充子类型 (2026-11-08 抽象代数讲义实测)**: 「同一个题」还包括「结论型 `proposition` / `theorem` 已完整证明 + `example` / `exercise` 再把同一结论证一遍」. 按 §2bis 第 1 步导出题干清单时, 环境列表必须**同时含结论型** (`definition` / `theorem` / `proposition` / `corollary` / `lemma`) 与题目型, 用「陈述 vs 题干」的字符 3-gram Jaccard / 覆盖率找候选对 (实测完全重复组 Jaccard 常 ≥0.45), 再人工剔除误报. `source-duplicate` 报不出这一类: 命题标题与练习标题常只差一个题号或多了个名称, 字符串并不相同. 处置仍是删题目而非合并题目: 结论留命题, 独有反例回灌 `proof`, 出处并入命题标题. 删题造成的配比空档**不要自动补**, 先向用户确认「允许缺口 / 改写成应用实例 / 补换实例短练习」; 用户选「允许缺口」时, 在交接文档里写明哪些小节豁免, 避免下个会话又自动补题.

> **两条提速判据 (2026-11-08 第二章实测: 93 个环境里 15 块重复, 占 16%)**: ① **同一教材题号是最强信号** —— 命题标题与练习标题若标着同一个「教材 P.xx 第 n 题」或同一条「习题 n」, 几乎必然是同一道题被写成了两处; 按可选参数里的题号做一次分组统计就能成批捞出 (第二章 15 块里 8 块属此类), 不必等相似度打分. ② **命题 `proof` 末段已写反例、已点明「某条件不可省」, 而练习整道就在讲这个反例**时, 3-gram 相似度往往不高 (实测 Jaccard 0.16--0.30), 最容易被漏掉 —— 聚类出候选后还要**逐条读命题 `proof` 的末两句**, 与候选练习的题干对读. 删块按「纯重复直接删 / 有独有内容先回灌 `proof` 再删」二分, 纯重复通常占一半以上.
>
> **反向纪律 (不变)**: 只是数据换了的属同类题, 保留独立成题, 最多在解答里点明「与命题平行, 把 $2$ 换成 $3$」. 第二章的实例: 命题证 $\id{x}$ 而练习问 $R[x]/\id{x-1}$; 命题证 $\id{2,x}$ 而练习问 $\id{3,x}$; 教材 §7 习题 7 与习题 8 结论互为对偶 (一为整除传递, 一为乘积整除) —— 三组都**不合并**.


> 触发: 用户指出「这些题本质是一样的, 应该删掉合并成一个多问例题」. 这条反馈比前五类更狠 —— 要**删块**, 不是搬块. 规范 §1.1 的前置判据是唯一依据: **同一个题才合并, 同类题 (数据不同, 方法相同) 只聚拢, 不合并**.

**第 0 步: 先按判据分两类, 别见「方法相同」就合并**.

- 同一个题 = 题干基本一致只是表述 / 出处不同, 或同一个实例的不同考察方式. 例: 同一个扩域分别问生成元, 次数, 元素形式, 极小多项式; 同一个群分别问各阶元素个数与子群格.
- 同类题 = 数据不同 (参数, 素数, 研究对象) 但方法相同. 例: $\mathbb{Z}[\sqrt2]$ 与 $\mathbb{Z}[\sqrt3]$ 的欧氏除式; 同一同态构造换素数 $p$. 这类**保持各自独立成题**, 只按 §2.2 搬进同一小节相邻位置, 并可把共用计算抽成带参数的公式放在导语 / 正文, 各题引用它而不再重复推导.
- 实测教训: 上一轮曾把 $\mathbb{Z}[\sqrt2]$ / $\mathbb{Z}[\sqrt3]$ 两道同类题合成一道带参数 $d$ 的三问练习, 按判据应保留两题. 判「能不能合并」只看**数据是否相同**, 不看方法是否相同.

**六步流程**.

1. **导出全量题干清单**: 用 `audit.py` 的 `env_optional_args()` 取出所有 `example` / `exercise` 的可选参数与题干首句, 连同行号存成文本文件; 人工按「实例 + 方法」聚类, 每组标明是「同一个题」还是「同类题」. 一次性脚本若只认 `\begin{env}[{...}]`, 会漏读无花括号的 `[...]` 标题, 统计会算成 0.
2. **机器信号交叉验证**: `audit.py` 的 `source-duplicate` 把「同一出处字符串被多块引用」逐条列出, 它正是「同一题写了两遍」的信号. 把 INFO 逐条对到人工聚类上, 两者应一一对应. 归零后再跑 `--strict` 不需要 `--ignore source-duplicate`.
3. **引用安全盘点**: 统计全部题目类 label 被 `\cref` / `\Cref` 引用的次数, 区分块内引用与外部引用; 外部引用必须改指保留块的 label. 实测 84 个题目类 label 中仅 14 个被引用, 逐一确认后才删块.
4. **删块与合并**: 保留一个 `example`, 按对象内部依赖把各题问法排成递进小问 (先结构后计算), 在一个 `solution` 里依次作答; 出处全部并列进可选参数. **被删题中独有的内容必须并入保留块** —— 一个反例, 一条边界情形, 一句与后续命题的衔接, 都可能只出现在被删的练习里. 实测把「$\mathbb{Z}_4[x]$ 中 $[1]+[2]x$ 可逆」这个反例从被删练习移进保留例题的解答.
5. **配平行练习**: 另起一道 `exercise` + 完整 `solution`, 取同类题作**平行但换实例**的对象 (例题 $\mathbb{Q}(\sqrt2,\sqrt3)$, 练习 $\mathbb{Q}(\sqrt2,\mathrm{i})$). 换实例要真正改变某一步论证, 才看得出方法迁移时哪一步会变.
6. **回头查新邻接**: 删一个重复可能造出一个新重复 —— 合并后的块与紧邻命题 / 例题可能变成同一结论 (实测 `ex:S3smallest` 合成两问后与 `prop:smallabelian` 完全重复, 渲染第 41 页才发现, 回退为一问并改 `\cref`). 顺手修掉合并组内暴露的历史缺陷: 题面与解答错配, 孤立残句, 只给结论没给推导.

**第 2 步的负向结论: 信号全零时不要硬合并**. 三条独立信号合起来才能证明「确实没有重复」: ① `source-duplicate` 为 0; ② 题面字符级相似度 (去掉题源标注后用 `difflib.SequenceMatcher`) 最高的一组也只是同一方法换了数据; ③ 没有任何两道题共享完全相同的长公式片段. 三条同时成立才写「无需合并」, 并**把改造动作转向补齐 / 改名 / 拆节**. 常微分方程讲义 2026-11-08 复盘实测三条全零, 于是补 1 道变式练习、16 处术语加粗、1 处节标题改名, 并把 1 例 7 练的混方法节拆成三节, **没有删任何题**; 反面教训见 §7 第 ③ 条 —— 为凑改造指标把同类题硬合并, 比漏合并更糟. 升格 / 拆节前按规范 §2.1 的引用安全检查再走一遍 (见下).

**去重后必做的两件事**: ① 逐 `\subsection` 盘点例题 / 练习配比, 合并常留下「有例无练」的空档, 按规范 §2.1 第 9 条最小充分补齐; ② 做页数归因 (见 `lecture_notes_pitfalls.md` §13), 别把「块数减少」直接当成「页数会减少」.

## 2ter. 第七类反馈: 文体防御 / 学某份讲义的写法 (2026-11-08)

> **触发**: 讲义全部静态检查通过, 用户仍觉得「写得不够好, 证明写得很防御」, 并指定一份人写讲义作为文风基准. 这类反馈**不是措辞问题, 是信息组织方式的问题**: 只做同义词替换不会改善.
> **先加载** `references/lecture_notes_voice.md`, 按其中 §1 的四类症状与 §8 的冲突裁决执行. 本流程不定义新要求, 只讲成稿的补救步骤.

**第 0 步: 先盘点, 别急着全局替换**. 用一次性脚本导出五张清单并人工判「删掉后计算是否仍可复现, 依据是否仍可追溯」:

1. 每个 `\section` 后的第一段 (方法论章导语);
2. 每个 `solution` / `proof` 的最后两句 (编者点评, 复述, 复验);
3. 全部 `\takeaway` / `\examtip` 调用 (是否只是复述前提);
4. 每个 `proof` 的首句 (是否在铺垫条件 / 排除退化);
5. 「下列 N 问 / 依次 / 分别」「本章 / 本节」命中行 (元话语).

**七步改写动作 (每层结束跑一次 `audit.py`)**

1. **章导语**: 改成具体数学陈述, 以公式或对象开头; 删「本章把 X 化为 Y」与「只用到第 x 章结论」.
2. **证明**: 首段即计算; 退化与零情形压进括号从句; 删「先排除...再...」两段式; 承重新论证保持完整; 同型重复允许「同理」收束 (voice §3, §4).
3. **解答**: 删末尾点评, 复述, 复验 (「这也表明」「同一个...解决了两问」「此判断使用了题设的非退化条件」); 有数学价值的例外前移到该步用从句带过.
4. **结构关系沉淀**: 把知识卡升级成编号 `conclusion` / 命题 + `\label`, 正文改 `\ref` 引用一次; 删「适用条件与前提」框; 长计算改 `Step 1/2/3` (voice §5).
5. **元话语**: 删「下列 N 问依次...」; 多问题干直接 `enumerate`, 需要引入时写数学内容; Overfull 以编译日志与渲染为准, 不当成补元话语的理由 (voice §6).
6. **版式**: 删强制 `\clearpage` 并逐页查孤儿空白页; 连续排版下页眉改固定文本 (`\leftmark` 会提前显示下一章, `\topmark` 实测取不到值); 重跑三轮编译.
7. **取舍记录**: 参考讲义若用全角标点或「我们 / 显然 / 读者容易证明」带读语气, 与本项目红线冲突的部分不跟; 在交付说明里写明跟了哪几条, 没跟哪几条及原因 (voice §8).

**验收**: 除 §4 四层外, 按 voice §9 连读一章. **结构计数 (题数 / `solution` / label / 题源标注) 必须与改造前一致** —— 文体改造不该动数学内容. 页数变化要归因: 删分页与删铺陈会减少页数, 不是压了解答, 禁止用「略 / 同理可得」换页数.

## 2quater. 第八类反馈: 与教材原文对齐 (2026-11-08)

> **触发**: 用户说「定义这些叙述的表示尽量与原书一致, 例如 1.8 这一节, 叙述与原书明显不一致 (不是说内容出错), 且原书明显更好一些 (严谨的数学符号更多吧). 证明也不要出现原书没有的内容, 例如定理 1.8.2 出现了群作用, 原书明显没有. 此外原书的定理尽量标出吧, 如定理 1.8.2 实际上是原书命题 2.8+2.9」.
> **规范侧**已写进 `lecture_notes_spec.md` §2.0bis (八条动作 + 操作顺序 + 验收). 本节只讲成稿怎么改, 不重复要求.
> **核心认识**: 「内容正确」和「忠于原书」是两件事. 讲义自己重写过一遍的陈述往往更啰嗦却更弱 —— 量词丢了, 并列条款被压成一段, 限定条件挪到了括号里; 而为了好写而引入的教材外工具, 让读者回原书时对不上. 用户要的是**能对着教材读的讲义**.

**逐节推进的六步** (一次只做一节, 每节结束编译验收)

1. **抽教材编号表**. 从 OCR 里按 `定义 \d+\.\d+|定理 \d+\.\d+|命题 \d+\.\d+|推论 \d+\.\d+|引理 \d+\.\d+` 抽取该节的清单, 得到「教材编号 → 名称 → 原文首句 → **有无证明**」四列. 第四列最容易被跳过, 而它是「缺证明」这类缺口的唯一探针: 教材写了证明、讲义只有陈述的条目, 逐条记下来就是本轮的工作量. 若 OCR 把编号与正文排在不同行, 就按「节内出现顺序」对位, 不要硬套正则.
2. **导讲义同表**. 用 `audit.py` 的 `env_optional_args()` 读, 别自己写正则 (可选参数带花括号与不带的两种写法都会出现).
3. **配对并分类**, 每条落进四类之一:
   - 一一对应 → 陈述按教材骨架重写, 标题补教材编号;
   - 讲义一条 = 教材多条 → 拆成多条, 各自标号, 各自证明 (这是本轮最主要的工作量);
   - 讲义自撰补充 → 保留, 但写清它与教材记号的关系; 教材缺的关键环节才能留;
   - 教材没有 → 按 §2.0 判档位, 能删则删, 不能删只进 `remark`.
4. **查教材外工具**. 在教材 OCR 里 `grep` 该术语的出现次数, 命中 0 次就是不能用的. 抽象代数实测的教材外概念: 群作用, 轨道, 稳定子, 类方程 (教材用共轭类计数但没有这个名字), 奇偶置换与 $\sgn$, $|\sigma|=\mathrm{lcm}$ 公式.
5. **重写证明**. 用教材自己的论证路径重排: 教材常常先给一个构造 (双射, 陪集代表系, 逐点求值), 再逐点验证, 最后收口; 这种三步比用轨道计数的两行推导长, 但读者能在原书找到同一段话. 重写后核对接 `\cref` 的引用是否还成立.
6. **批量补编号**. 全篇扫一遍其余的定理型环境, 凡教材有原位的都补上 `[教材 \S X 定理 X.Y]`. 这一步容易漏, 因为改一节时只盯着那一节.

## 2quinquies. 第九类反馈: 例/练与命题对位 (2026-11-09)

> **触发**: 用户说「可以试试例和练习插到后面, 前提是命题和后面的例及练习有较紧密的联系」, 同时允许「适当的补充」. 这是对「命题成串 → 例题成串 → 练习成串」这种结构的纠正.
> **与 §2quater 的关系**: 那条讲「教材顺序优先」, 指的是**命题与命题之间**的顺序不动; 本条讲**例题与练习放在哪条命题之后**, 二者不冲突 —— 命题顺序照教材, 题的位置按联系排.

**判据: 什么叫「有较紧密的联系」**

以下三种才搬:

1. **例是该命题的直接实例**. 命题说「有限整环是域」, 例就逐个求 $\Z_5$ 非零元的逆; 命题说「$R[x]$ 的单位即 $R$ 的单位」, 例就列 $\Z$, $\Z[\ii]$, $\Z[x]$, $F[x]$ 的全部单位.
2. **练习是该命题的变式或反向提问**. 命题给「$\id{2,x}$ 不是主理想」, 练习就换成 $\id{3,x}$; 命题给「素理想降链之交仍是素理想」, 练习就问升链之并.
3. **例/练的解答只引用该命题及更早的结论**. 一旦解答要调三四个后文命题, 它就是综合题, 不属这条命题.

以下三种**不搬**, 留在节末成组:

1. **跨节调用多个结论的真题**. 如「$\Z[\ii]/\id{1-2\ii}\iso\F_5$」同时用欧氏环、既约元、素理想、极大理想四条, 挂在任何一条后面都名不副实.
2. **题源不同、问法多于命题所讲**. 同一道题既问单位又问零因子, 说明它是复习题.
3. **整节是分类或速查性质**, 例题本身是这一节的综合演练 (低阶群分类, $S_3$ 全计算).

**施工: 块级搬动, 不要重排整节**

- 只切 `example`/`exercise` (连其 `solution`) 与 `remark`; 命题、定义、正文段落原地不动. 重排整节会把夹在环境之间的过渡句带走或落下.
- 块边界: `example`/`exercise` 的块尾要吃掉紧跟的 `\end{solution}`; `proposition`/`theorem` 的块尾要吃掉紧跟的 `\end{proof}` —— 否则「插在某命题后」会插到 `\end{proposition}` 与 `\begin{proof}` 之间.
- **每搬一块都重新读文件、重新按 label 定位**, 不要在一个内存字符串上连续做多次偏移运算. 抽象代数 17 次搬动无一错位, 靠的就是这一步.
- 搬完压掉多余空行 (`(\r\n){3,}` → `\r\n\r\n`), 否则块与块之间出现两个空行.

**副作用** (实测五条)

| 副作用 | 现象 | 处理 |
| :--- | :--- | :--- |
| 过渡句被例题隔开 | 「有限性只用在单射即满射一步 …… 反过来, 域的判定可以完全用理想来表述」被新插的例切成首尾两段, 后半接不上 | 拆成两句: 前半留在原命题证明后, 并加一句「下面这个例子把有限情形走一遍」作过渡; 后半前移到下一条命题前作引导 |

## 3. 可复用脚本骨架

以下代码只依赖 Python 标准库, 直接复制到项目里按科目改 `P` 与 label 列表即可. 关键纪律: **所有定位都断言唯一, 写出前后各做一次结构断言**.

```python
# -*- coding: utf-8 -*-
import io, re, collections

P = r'<项目>/讲义.tex'
raw = io.open(P, encoding='utf-8', newline='').read()
assert not raw.startswith('\ufeff'), 'BOM found'
assert raw.count('\r\n') in (0, raw.count('\n')), 'mixed line endings'
NL = '\r\n' if raw.count('\r\n') else '\n'
L = raw.split(NL)
ENVS = ('definition|theorem|proposition|corollary|lemma|'
        'example|exercise|remark')


def T(text):
    return text.strip('\n').split('\n')


def env_end(s, env):
    depth = 0
    for j in range(s, len(L)):
        if L[j].startswith('\\begin{' + env + '}'):
            depth += 1
        elif L[j].startswith('\\end{' + env + '}'):
            depth -= 1
            if depth == 0:
                return j
    raise RuntimeError('no end for ' + env)


def unit_range(label):
    """含该 label 的环境, 连同紧随其后的 solution / proof 整块的行区间."""
    idx = [i for i, l in enumerate(L) if '\\label{' + label + '}' in l]
    assert len(idx) == 1, ('label', label, len(idx))
    s = idx[0]
    while s >= 0 and not re.match(r'^\\begin\{(' + ENVS + r')\}', L[s]):
        s -= 1
    assert s >= 0, ('start', label)
    env = re.match(r'^\\begin\{([^}]+)\}', L[s]).group(1)
    e = env_end(s, env)
    k = e + 1
    while k < len(L) and L[k].strip() == '':
        k += 1
    if k < len(L):
        m = re.match(r'^\\begin\{(solution|proof)\}', L[k])
        if m:
            e = env_end(k, m.group(1))
    if e + 1 < len(L) and L[e + 1].strip() == '':
        e += 1
    return s, e


def cut(label):
    s, e = unit_range(label)
    blk = L[s:e + 1]
    del L[s:e + 1]
    return blk


def insert_after(label, lines):
    _, e = unit_range(label)
    L[e + 1:e + 1] = lines


def insert_before(marker, lines):
    idx = [i for i, l in enumerate(L) if marker in l]
    assert len(idx) == 1, ('marker', marker, len(idx))
    L[idx[0]:idx[0]] = lines


def replace_in_unit(label, text):
    s, e = unit_range(label)
    L[s:e + 1] = T(text)


def sub(old, new, cnt=1):
    """子串替换并断言命中数; 含反斜杠的 LaTeX 必须用 raw string 传入."""
    n = sum(l.count(old) for l in L)
    assert n == cnt, ('sub count', old[:70], n, cnt)
    L[:] = [l.replace(old, new) for l in L]


def line(old, new, cnt=1):
    n = L.count(old)
    assert n == cnt, ('line count', old[:70], n, cnt)
    L[:] = [new if l == old else l for l in L]


# 用法: 先全部切出, 再插入; 新 label 事先断言不冲突.
labels = ['ex:A', 'ex:B', 'exe:C']
for lab in labels:
    assert '\\label{' + lab + '}' in raw, lab
blocks = {lab: cut(lab) for lab in labels}
section = T(r'''\subsection{以方法命名的小节}
\label{ssec:method}

一段叙述讲清共同构造与各题的参数差别.
''') + blocks['ex:A'] + blocks['ex:B'] + blocks['exe:C']
insert_before(r'\takeaway{某节末的知识卡}', section)

out = NL.join(L)
io.open(P, 'w', encoding='utf-8', newline='').write(out)

# 写出后立刻断言 (用独立回读, 不复用内存里的 out)
chk = io.open(P, encoding='utf-8', newline='').read()
labs = re.findall(r'\\label\{([^}]+)\}', chk)
refs = set(re.findall(r'\\(?:cref|Cref|ref|eqref)\{([^}]+)\}', chk))
assert not [k for k, v in collections.Counter(labs).items() if v > 1], 'dup labels'
assert not (refs - set(labs)), 'undefined refs: %s' % sorted(refs - set(labs))
c = collections.Counter(re.findall(r'\\begin\{(\w+)\}', chk))
assert c['solution'] == c['example'] + c['exercise'], '例解未配平'
```

**含反斜杠的替换串**要写成 raw string 并通过文件写入工具交给 Python, 不要塞进 shell heredoc 或 `python -c`: shell 会改写反斜杠, `str.replace` 会静默变成 no-op (命中计数正常、字节数不变). 写完必须独立回读.
