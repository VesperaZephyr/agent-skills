## 二、 分章深度模型剖析与考点矩阵

### 第 1 章 数学模型基本概念
1. **数学建模的定义与核心环节**：
   - **定义**：针对实际事物的特征或数量依存关系，用数学语言概括近似表述的数学结构。
   - **六大基本步骤**：模型准备 $\to$ 模型假设 $\to$ 模型构成 $\to$ 模型求解 $\to$ 模型分析与检验 $\to$ 模型应用与推广。
2. **教材经典引导例题与思维模型**：
   - **例 1.1（球数置换平衡问题）**：两桶各 10000 蓝/红球交换 3 次，利用守恒定律 $10000 - x + y = 10000 \implies x = y$，证明甲桶红球与乙桶蓝球完全相等。
   - **例 1.2（登山相遇问题）**：连续函数介值定理。构造两日行程差函数 $H(t) = F(t) - G(t)$，由于 $H(8) = -d < 0, H(17) = d > 0$，由零点定理必存在时刻 $t_0$ 使得 $H(t_0) = 0$。
   - **例 1.3（三根长电线电阻测定）**：底层与顶楼各测一次回路电阻，建立三元线性方程组：$R_1+R_2=A, R_2+R_3=B, R_3+R_1=C \implies R_i = \frac{1}{2}(\Sigma - \dots)$。
   - **例 1.4（悬崖高度估算与阻力修正）**：由初等自由落体 $h = \frac{1}{2}gt^2$ 结合声音回传时间 $t = t_1 + t_2$ 解二次方程；进阶考虑空气阻力 $m\frac{dv}{dt} = mg - kv$ 积分展开。
   - **例 1.5（药品隔离区图着色问题）**：将化学药品相克关系转化为无向图的边，求图的色数 $\chi(G)$，转化为顶点着色最小分组。
   - **例 1.6（省力步长摆动共振）**：将人的腿简化为物理单摆，固有周期 $T = 2\pi\sqrt{\frac{2l}{3g}}$，行走步频接近共振频率时最省劲。

### 第 2 章 古典模型（初等数学与机理推导）
1. **2.1 初等数学方法**：
   - **欧拉多面体公式**：凸多面体满足 $V - E + F = 2$。应用：正多面体只有 5 种（柏拉图多面体）。
   - **鸽笼原理（抽屉原理）**：边长为 1 的正三角形中放 5 个点，必有两点距离 $\le 1/2$；8x8 方格行列对角线和不全相同性证明。
   - **奇偶校验法与图着色**：缺两对角的残缺棋盘不能用 $1 \times 2$ 骨牌完全覆盖（黑白格数不均）；圆周 4 枚黑白棋子异色放白同色放黑操作最多 4 次全黑（模 2 线性递推）。
2. **2.2 几何模拟与拓扑问题**：
   - **相识问题（Ramsey 定理）**：6 人集会中必有 3 人互相认识或互相不认识，$R(3,3)=6$。平面 6 个顶点连红蓝两色边，必含同色三角形。
   - **四脚桌放平问题（连续性与介值定理）**：四条等长腿正方形桌子放在连续不平地面上，利用中心对称性定义距离差函数 $f(\theta)$ 与 $g(\theta)$，转动 90 度后符号对调，应用介值定理证明必能在转动小于 90 度内四脚同时着地。
   - **3 对夫妻过河问题（状态转移图与广度优先搜索）**：状态向量 $(x, y, k)$（岸上丈夫数、妻子数、船位置），满足安全约束 $x=0$ 或 $x \ge y$，转移步长受船载人数 1~2 限制。
3. **2.3 力学物理问题（量纲与异速增长）**：
   - **四足动物体长与体重估算**：几何相似性原理，表面积 $S \propto L^2$，体积与体重 $W \propto L^3$；骨骼承重截面积力学修正（异速增长 Allometry）。
   - **双层玻璃窗保温功效**：一维稳态热传导傅里叶定律 $Q = k A \frac{\Delta T}{d}$。两层玻璃厚度 $d$，中间空气层厚度 $l$。总热阻串联：$R = \frac{2d}{k_1} + \frac{l}{k_2}$。因空气导热系数 $k_2 \ll k_1$，双层玻璃热流失仅为单层的数十分之一。
4. **2.4 离散模型与递推差分**：
   - **等额本息房贷月供模型**：借款 $A$，月利率 $r$，期数 $n$，每月还款 $x$。差分方程 $y_k = (1+r)y_{k-1} - x$，通解得 $x = A \cdot \frac{r(1+r)^n}{(1+r)^n - 1}$。
   - **席位分配模型与悖论**：Hamilton 最大余数法容易导致“阿拉巴马悖论（席位总数增加但某系反而减少）”与“人口悖论”。改进的除数方法：Huntington-Hill 方法与相对不公平度准则。
   - **常染色体遗传模型**：三种基因型 AA, Aa, aa，建立一代代概率分布马尔可夫转移矩阵，推导 Hardy-Weinberg 平衡定律（基因频率经过一代随机交配后保持恒定）。
5. **2.5 微积分建模与连续优化**：
   - **租客机还是买客机（现金流量折现）**：连续复利现值公式 $PV = \int_0^T C(t) e^{-rt} dt$。对比一次性支付现值与租金流现值 $600 \times \frac{1-e^{-15r}}{r}$，根据利率 $r=12\%$ 与 $6\%$ 得到不同决策临界点。
   - **除雪机模型**：降雪匀速累积，积雪厚度 $y(t) = c(t - t_0)$。除雪机速度与厚度成反比 $\frac{dx}{dt} = \frac{k}{y(t)}$，两端积分建立关于开始下雪时间 $t_0$ 的非线性方程。
   - **广告与利润最大化**：价格 $p$、广告费 $A$ 与销售量 $Q(p, A)$ 的二维最优化模型 $\max \pi(p, A) = (p - c)Q(p,A) - A$，求解一阶偏导偏驻点方程。

### 第 3 章 微分方程模型（动力学与相平面）
1. **3.1 微分方程基础应用**：
   - **浮沉振动**：边长 $a$ 密度 $\rho_0$ 立方体浮于水面，垂直扰动后阿基米德浮力回复力 $F = -\rho g a^2 x$，二阶常微分方程 $m \ddot{x} + \rho g a^2 x = 0$，振动周期 $T = 2\pi\sqrt{\frac{m}{\rho g a^2}}$。
   - **碳 14 衰变断代模型**：一阶衰变微分方程 $\frac{dN}{dt} = -\lambda N \implies N(t) = N_0 e^{-\lambda t}$，半衰期 $T_{1/2} = \frac{\ln 2}{\lambda} = 5730$ 年。用于测定古埃及木炭、梵·梅格伦伪造维米尔油画的铅 210/镭 226 衰变鉴定。
2. **3.2 铅球投掷轨迹优化**：
   - 考虑出手高度 $h$、初速度 $v$、仰角 $\alpha$ 的斜抛运动方程：
     $$x(t) = v \cos\alpha \cdot t,\quad y(t) = h + v \sin\alpha \cdot t - \frac{1}{2}gt^2$$
   - 落地时 $y(T)=0$，消去 $T$ 得到水平距离 $s(\alpha) = \frac{v\cos\alpha}{g} \left( v\sin\alpha + \sqrt{v^2\sin^2\alpha + 2gh} \right)$。
   - 对 $\alpha$ 求极值，最优出手仰角满足：$\tan \alpha^* = \frac{v}{\sqrt{v^2 + 2gh}} \implies \alpha^* < 45^\circ$。
3. **3.3 减肥与新陈代谢模型**：
   - 能量守恒定律：体重变化速率 $\frac{dw}{dt} = \frac{1}{\alpha}(C - \beta - \gamma w)$，其中 $C$ 为每日摄入热量，$\beta$ 为基础代谢，$\gamma w$ 为体重相关运动代谢消耗，$\alpha$ 为每千克脂肪等效热量。
   - 解方程求出渐近极限体重 $w_\infty = \frac{C - \beta}{\gamma}$，评估节食与运动的动态减肥轨迹。
4. **3.5 核废料海底处置下沉冲击模型**：
   - 桶受重力、浮力与二次流体阻力：$m \frac{dv}{dt} = mg - \rho V g - kv^2$。
   - 变换变量 $v\frac{dv}{dx}$ 积分得到触底速度 $v(h)$，判定是否超过临界破坏速度 $12.2\text{ m/s}$。
5. **3.6 传染病动力学模型（重点考点）**：
   - **SI 模型**：总人数 $N$ 恒定，$\frac{di}{dt} = \beta i(1-i)$，解为典型的 Logistic 曲线，感染率单调上升至 1。
   - **SIS 模型**：引入康复后无免疫力再感染，$\frac{di}{dt} = \beta i(1-i) - \gamma i$。定义基本再生数 $R_0 = \frac{\beta}{\gamma}$，当 $R_0 > 1$ 时趋向地方病地方稳态 $i^* = 1 - 1/R_0$；当 $R_0 \le 1$ 时病原消亡。
   - **SIR 模型（Kermack-McKendrick）**：
     $$\begin{cases} \frac{ds}{dt} = -\beta s i \\ \frac{di}{dt} = \beta s i - \gamma i \\ \frac{dr}{dt} = \gamma i \end{cases}$$
   - **相轨线求解**：$\frac{di}{ds} = -1 + \frac{\gamma}{\beta s}$，积分得 $i(s) = (s_0 + i_0) - s + \frac{1}{\sigma}\ln\frac{s}{s_0}$（其中相对接触率 $\sigma = \frac{\beta}{\gamma}$）。
   - **流行阈值条件**：若 $s_0 > \frac{\gamma}{\beta}$，传染病暴发；最终未被感染比例满足超越方程 $s_\infty - \frac{1}{\sigma}\ln s_\infty = s_0 + i_0 - \frac{1}{\sigma}\ln s_0$。
6. **3.7 人口增长模型**：
   - **Malthus 指数增长模型**：$\frac{dx}{dt} = rx \implies x(t) = x_0 e^{rt}$。适用于资源充足初期。
   - **Logistic 阻滞增长模型（Verhulst）**：环境容量容纳量 $K$，增长率随人口线性递减 $r(1 - x/K)$：
     $$\frac{dx}{dt} = rx\left(1 - \frac{x}{K}\right) \implies x(t) = \frac{K}{1 + \left(\frac{K}{x_0}-1\right)e^{-rt}}$$
   - 拐点在 $x = K/2$ 处，增长速度最大。
7. **3.8 作战模型（兰彻斯特方程 Lanchester）**：
   - **正规战争（平方律模型）**：双方均能远距离瞄准射击，损耗率与对方总兵力成正比：
     $$\begin{cases} \frac{dx}{dt} = -a y \\ \frac{dy}{dt} = -b x \end{cases} \implies b(x_0^2 - x^2) = a(y_0^2 - y^2)$$
   - 胜负判定常数：$b x_0^2 - a y_0^2$。有效战斗力与兵力平方成正比！集中兵力原理的数学推导。
   - **游击战争（线性律模型）**：盲目射击，损耗率与双方兵力乘积成正比：
     $$\begin{cases} \frac{dx}{dt} = -a x y \\ \frac{dy}{dt} = -b x y \end{cases} \implies b(x_0 - x) = a(y_0 - y)$$
8. **3.9 多级火箭发射与级数质量比优化**：
   - 齐奥尔科夫斯基单级理想火箭公式：$v = c \ln\left(1 + \frac{m_p}{m_0}\right)$，因结构死重比限制，单级火箭无法达到第一宇宙速度 $7.9\text{ km/s}$。
   - 多级火箭加速：$v_n = \sum_{k=1}^n c_k \ln \lambda_k$。利用拉格朗日乘子法求解有效载荷比最大化，证明各级有效质量比相等时最优，推导出为何现实航天工程采用三级火箭。

### 第 4 章 随机性模型（概率与博弈决策）
1. **4.1 离散随机模型与概率极限**：
   - 乒乓球新旧抽取（超几何分布与全概率公式）。
   - 车间机床同时开启电能超载概率：二项分布 $B(n, p)$ 利用正态分布中心极限定理进行连续化逼近。
   - **蒲丰投针实验（Buffon's Needle）**：针长 $l \le a$（平行线间距），二元几何概率区域积分推导相交概率 $P = \frac{2l}{\pi a}$，建立基于蒙特卡罗随机抽样的 $\pi$ 近似测定法。
2. **4.2 报亭卖报问题（经典的报童模型 Newsvendor Problem）**：
   - 设进价 $b$、售价 $a$、退回价 $c$（$a > b > c$），需求量 $r$ 具有概率密度 $f(r)$ 与分布函数 $F(r)$。
   - 进货量为 $x$ 时的期望利润：
     $$E[\Pi(x)] = \int_0^x [a r + c(x-r) - bx]f(r)dr + \int_x^\infty [(a-b)x]f(r)dr$$
   - 对 $x$ 求导令一阶导为 0（Leibniz 变上限积分求导）：
     $$\frac{dE}{dx} = (a-b) - (a-c)F(x) = 0 \implies F(x^*) = \frac{a-b}{a-c}$$
   - **期末核心结论**：最优订货量 $x^*$ 位于累积分布函数的临界分位数（边际超额利润与边际亏损的权衡）。
3. **4.3 零和博弈模型（矩阵对策）**：
   - 局中人 $I$ 与 $II$，赢得矩阵 $A = (a_{ij})_{m \times n}$。
   - 鞍点定理：$\max_i \min_j a_{ij} = \min_j \max_i a_{ij}$ 时存在纯策略纳什均衡。
   - 无鞍点时转入混合策略 $x \in \mathbb{R}^m, y \in \mathbb{R}^n$。von Neumann 极小化极大定理：
     $$\max_{x} \min_{y} x^T A y = \min_{y} \max_{x} x^T A y = V$$
   - 将博弈等价转化为线性规划问题（对偶规划）求解最优混合策略。
4. **4.4 航班超订机票问题（Overbooking）**：
   - 客机核准载客容量 $C$，航空公司超售订票 $n > C$ 张。每位持票旅客独立到场率 $p$（误机率 $q = 1-p$）。
   - 到场人数 $k \sim B(n, p)$。若 $k > C$，则溢出 $k - C$ 人需支付高额赔偿违约费；若 $k < C$，则空座损失机票收益。
   - 建立期望总损失函数，权衡两类风险确定最优超订票额 $n^*$。

### 第 5 章 运筹与优化模型（确定性规划与控制）
1. **5.1 线性规划（LP）模型与对偶理论**：
   - 产品排产煤电工时配额利润最大化模型。标准型、松弛变量、可行域凸多面体、单纯形法极点转移。
   - 产销平衡运输问题（两煤厂至三居民区）：双下标变量 $x_{ij}$，产地约束 $\sum_j x_{ij} = a_i$，销地约束 $\sum_i x_{ij} = b_j$，运费目标 $\min \sum c_{ij} x_{ij}$，表上作业法与闭回路法。
2. **5.2 实际典型离散与非线性优化**：
   - **0-1 整数规划指派问题**：匈牙利算法求解 $\min \sum c_{ij} x_{ij}$，约束 $\sum_i x_{ij}=1, \sum_j x_{ij}=1, x_{ij} \in \{0, 1\}$。
   - **货轮舱位平衡配载模型**：前中后三舱最大容许载重与容积限制，且实际装载质心要求各舱按容量比例配重，建立多线性等式与不等式规划。
   - **原油采购分段线性折扣模型**：进价随采购批量呈分段函数，引入 0-1 变量将分段线性成本函数等价转化为线性混合整数规划（MIP）。
   - **一维与二维下料优化模型**：
     - 钢管一维下料：列出所有合理切割模式（余料小于最小需求段），以模式选择次数为决策变量，建立原木消耗最少或余料最小的整数规划。
     - 易拉罐二维冲压板材下料：正方形/长方形镀锡板冲压圆形盖底与矩形罐身，建立模式组合与冲压时间约束下的材料损耗极小化模型。
3. **5.3 动态规划模型（DP）**：
   - **Bellman 最优性原理与逆序递推方程**：
     $$f_k(x_k) = \min_{u_k \in D_k(x_k)} \{ d_k(x_k, u_k) + f_{k+1}(x_{k+1}) \}$$
   - **最短路线问题**：各阶段节点编号，反向逆推求标号。
   - **机器负荷与资源分配**：资金或设备在多个生产项目间的离散分配。
4. **5.4 生产福利 10 年规划**：
   - 利润在扩大再生产资本积累与职工福利之间动态分配，连续时间最优控制模型（变分法/极值原理）。
5. **5.5 经典存储模型（EOQ 经济订购批量）**：
   - 需求率 $D$ 恒定，每次订货费 $K$，单位时间单位库存维持费 $h$。
   - 周期平均总费用 $C(Q) = \frac{KD}{Q} + \frac{hQ}{2}$。
   - 微积分求导得最优订购批量公式：$Q^* = \sqrt{\frac{2KD}{h}}$，最佳订货周期 $T^* = Q^*/D$。
6. **5.6 森林救火与资源调度**：
   - 火场面积与火势周长随时间二次方扩张，灭火队员到达时间延迟 $t_0$ 与灭火效率速率平衡模型。
7. **5.7 冰山拖运模型**：
   - 航行阻力与功率消耗、冰山随水温和航行时间的热传导融化微分方程、租船日租金与燃料成本的非线性综合优化。

### 第 6 章 数学建模范例（综合案例研讨）

7. **6.7 洗衣机节水模型（经典微积分优化）**：
   - 每次漂洗后的洗涤剂浓度衰减比例：$c_k = c_{k-1} \frac{W_0}{W_0 + x_k}$（其中 $W_0$ 为衣服含水量，$x_k$ 为第 $k$ 次漂洗注水量）。
   - 总注水量 $X = \sum_{k=1}^m x_k$ 固定时，证明**各次等量注水** $x_1 = x_2 = \cdots = x_m = X/m$ 使得最终残留浓度最小；若考虑排污清洁度阈值，求最优漂洗次数 $m^*$。
8. **6.8 螺旋线与平面的交点问题**：

9. **6.9 基金最佳使用与教育奖学金运营**：

10. **6.10 投资组合的收益与风险（Markowitz 模型）**：

11. **6.11 钢管订购与铁路公路调运网络流**：
    - 主管道铺设线路上各节点的钢管需求量，多个钢厂不同出厂价与产能上限，铁路沿线转运站与公路末端配送构成的复杂网络，建立最小费用流混合整数规划模型。

### 第 7 章 数学建模经典算法及 MATLAB 实例仿真
1. **7.1 动态规划算法及 LINGO/MATLAB 代码**：
   - 阶段、状态、决策、状态转移方程、阶段指标与最优值函数。
   - MATLAB 矩阵存储法与递归函数实现逆序最短路求解；LINGO 模型语言求解高维动态规划。
2. **7.2 层次分析法（AHP，期末必考重中之重）**：
   - **层次结构**：最高层（目标层）、中间层（准则层/指标层）、最底层（方案层/措施层）。
   - **判断矩阵标度**：Saaty 1-9 标度法及其倒数对称性质 $a_{ji} = 1/a_{ij}, a_{ii} = 1$。
   - **特征值与特征向量求解**：
     - 和法（归一化行和）：$w_i = \frac{1}{n} \sum_{j=1}^n \frac{a_{ij}}{\sum_{k=1}^n a_{kj}}$。
     - 根法（行几何平均）：$w_i = \frac{(\prod_{j=1}^n a_{ij})^{1/n}}{\sum_{k=1}^n (\prod_{j=1}^n a_{kj})^{1/n}}$。
     - 精确特征值法：求 $A w = \lambda_{\max} w$。
   - **一致性检验（Consistency Check）**：
     - 一致性指标：$CI = \frac{\lambda_{\max} - n}{n - 1}$。
     - 随机一致性指标 $RI$（教材表 7.2 给出 $n=1\dots 9$ 标准值：$RI = [0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45]$）。
     - 一致性比例：$CR = \frac{CI}{RI}$。
     - **检验标准**：当 $CR < 0.10$ 时，认为判断矩阵具有令人满意的一致性，通过检验；否则必须重新修正判断矩阵。
   - **层次总排序**：自上而下逐层合成权重向量，并做总一致性检验。
3. **7.3 插值与拟合算法**：
   - **多项式插值**：
     - Lagrange 插值：基函数 $l_k(x) = \prod_{j \neq k} \frac{x - x_j}{x_k - x_j}$，Runge 现象（等距高次插值边缘剧烈振荡）。
     - Newton 差商插值：递推计算各阶差商 $f[x_0, x_1, \dots, x_k]$，便于动态增添节点。
   - **样条插值（Spline）**：分段三次样条 $S(x)$，在节点处满足函数值相等且一阶、二阶导数连续。端点边界条件：自然边界（二阶导为0）、固定边界（一阶导已知）、非扭结边界（not-a-knot）。
   - **二维网格插值**：MATLAB `interp2(X, Y, Z, XI, YI, 'spline')` 与散乱点插值 `griddata(x, y, z, xi, yi, 'v4')`。
4. **7.4 曲线拟合与最小二乘法**：
   - 超定方程组与法方程：拟合模型 $y = X \beta$，残差平方和 $\|y - X\beta\|_2^2$ 极小化，正规法方程 $(X^T X)\beta = X^T y$。
   - MATLAB 常用工具函数：
     - 多项式拟合：`p = polyfit(x, y, deg)`，求值 `y_fit = polyval(p, x)`。
     - 线性约束最小二乘：`x = lsqlin(C, d, A, b, Aeq, beq, lb, ub)`。
     - 非线性最小二乘：`x = lsqnonlin(fun, x0, lb, ub)`。
5. **7.5 数据的统计描述与假设检验**：
   - 描述统计量：均值 `mean`、中位数 `median`、标准差 `std`、方差 `var`、偏度 `skewness`、峰度 `kurtosis`。
   - 参数检验：
     - 正态单样本/双样本均值检验：`[h, p, ci, stats] = ttest(x, m)`，`ttest2(x, y)`。
     - 方差齐性检验：`vartest2(x, y)`。
   - 非参数检验与分布拟合检验：
     - $\chi^2$ 拟合优度检验：`[h, p] = chi2gof(x)`。
     - Kolmogorov-Smirnov 检验：`[h, p] = kstest(x)`。
     - Wilcoxon 秩和检验（两样本中位数比较）：`[p, h] = ranksum(x, y)`。
6. **7.6 模拟退火算法（Simulated Annealing, SA）**：
   - 基于固体退火物理原理，引入 Metropolis 准则接受劣解：若 $\Delta f = f(x_{new}) - f(x_{old}) \le 0$ 则必定接受；若 $\Delta f > 0$，以概率 $P = \exp(-\Delta f / T)$ 接受。
   - 降温调度策略：初始温度 $T_0$、退火系数 $\alpha \in [0.8, 0.99]$、终止温度 $T_{end}$。
   - 应用：求解巡回旅行商问题（TSP）、航线路径规划。
7. **7.7 遗传算法（Genetic Algorithm, GA）**：
   - 生物进化模拟：染色体（编码方案：二进制编码或实数编码）、个体适应度评估（Fitness Function）。
   - 遗传算子：
     - 选择算子：轮盘赌选择（Roulette Wheel Selection）、锦标赛选择。
     - 交叉算子：单点交叉、两点交叉、算术交叉（交叉概率 $P_c \approx 0.6 \sim 0.9$）。
     - 变异算子：位翻转、高斯变异（变异概率 $P_m \approx 0.001 \sim 0.05$）。
   - MATLAB 全局优化工具箱函数：`ga(@fitnessfun, nvars, A, b, ...)`。
8. **7.8 蚁群算法（Ant Colony Optimization, ACO）**：
   - 模拟蚂蚁觅食外激素正反馈行为：路径 $(i, j)$ 上的信息素浓度 $\tau_{ij}$ 与启发式能见度 $\eta_{ij} = 1/d_{ij}$。
   - 转移概率公式：
     $$P_{ij}^k(t) = \frac{[\tau_{ij}(t)]^\alpha [\eta_{ij}]^\beta}{\sum_{s \in allowed_k} [\tau_{is}(t)]^\alpha [\eta_{is}]^\beta}$$
   - 信息素全局更新与挥发机制：$\tau_{ij}(t+1) = (1 - \rho)\tau_{ij}(t) + \sum_{k=1}^m \Delta \tau_{ij}^k$（挥发系数 $\rho \in (0, 1)$）。
