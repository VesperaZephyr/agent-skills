# 中文叙述体写作方法 (跨科目通用)

> **定位**: 本文件是 `references/lecture_notes_spec.md` 第 3 节语言红线的**正向补充**。红线讲「不许写什么」，本文件讲「怎样把句子写顺」；信息的组织方式与详略另见 `references/lecture_notes_voice.md`（直陈文体基准）。三者冲突时一律以规范红线为准，尤其半角标点、零元话语、禁考试管理语言三条不让步。
> **方法来源**: 借鉴本机 `chinese-writing` 技能 (Ou-Liu-Red-Sugar/chinese-writing) 的篇章编排、句子组成、必要限定与成稿校对方法，按讲义 / 作业 / 试卷场景裁剪。不复制其文件，也不引入其全角标点体系、多角色审读流程与分数化评分。
> **适用范围**: 任意课程的期末复习讲义正文、作业解答叙述、试卷题干与参考答案。不适用于 LaTeX 源码、公式内部、表格字段与题源标注格式。

---

## 1. 动笔前: 先定认识推进，再定材料详略

每章按考点 / 方法命名之后，先在题源台账或章节注释里留一份简短草图，回答六个问题：

| 检查问题 | 要给出的具体安排 |
| :--- | :--- |
| 本节要让读者理解什么 | 落实为要解释的对象、关系与要回答的问题，不能只列知识点 |
| 读者从哪里进入 | 承接上一节已建立的哪个对象或结论，本节第一句接住它 |
| 用哪些材料 | 定义、推导、例题、练习各帮助看清什么，为什么放在此处 |
| 哪里需要放慢 | 最难跨越又最影响中心结论的那一步，用什么解释、对照或推导展开 |
| 怎样承接与转进 | 从设定进入推论、从特例进入一般、从结论进入检验，各自依据什么 |
| 本节在哪里完成 | 哪些关系在此讲清，哪些交给手册或后文，不提前依赖后文概念 |

详略分配读者的注意力。最慢、最详细的部分落在中心难点；背景只保留接入重点所需的长度；一个例子已经完成解释、判别或检验的任务时，不再堆同型例子。需要换条件、区分相近情形或检验迁移时，才补另一个例子。

与规范 §1.1 的分工：题目合并 / 聚拢决定「挂哪些题」，本节的详略决定「讲多深」。两者先后执行，不互相替代。草图只定安排，不提前写完整正文。

## 2. 句群: 先定动作，再定句子

1. **先定本段承担的动作**：引入对象、给出条件、逐步推导、比较、推广、检验或收束。不要先写一串孤立短句再用关联词串起来。
2. **连读前后句**：前句给出了哪个对象、判断或动作，后句接住什么，读者凭已给出的信息能否走到这一步。主题相同、连接词齐全、段落职责旁注，都不能替代这项检查。
3. **伪承接检查**：连接词暗示的因果、转折或递进必须有前文依据；「对应」「相接」「回到」等抽象说法要还原为具体对象与动作。材料只支持并列或时间先后时，就按并列 / 先后组织，不能靠换一个连接词保留未经支持的推论。
4. **主干与承担者**：先找主要谓语，核清谁做什么；并列项共用的动词、宾语或修饰语逐项还原，不能为句式整齐强用一个动词。抽象名词若让读者认不出承担者与动作，改回有据的直接叙述。
5. **小词有作用**：「会、就、才、还、已经、再、了、首先」承担情态、条件、时点、进展与范围。删前把有字 / 无字两句连读比较，不能只问大意能否猜到；可能为事实、通常情形与实际结果各有不同写法，顺句时不得互换。
6. **公式也参加承接**：公式前写清正在定义或计算的对象，以及「写为」「得到」「满足」等具体动作；公式后用已得到的对象继续解释。不要把一个孤立公式交给读者去串起前后关系。
7. **适度从容**：铺垫、呼应、共同视点按对象转换与阅读节奏使用；同一处不反复播报「我们再看」「这样就明白了」。也不为追求简洁把承重解释压成标签 + 公式 —— 这正是规范第 3 节第 1 条禁止的电报体。

「我们」只允许出现在证明行动里（「我们要证明」），不用于介绍编写安排；不写「我们都知道」「我们显然同意」之类替读者宣布判断的话。

## 3. 限定与删冗: 逐命题判断

按句子的作用区分四类措辞，再决定去留：

| 作用 | 实际增加的信息 | 处置 |
| :--- | :--- | :--- |
| 语义限定 | 适用对象、成立条件、数值精度、可能性强度 | 删后会改变命题就保留，能写得更具体就改写成条件 |
| 证据归属 | 事实、来源主张、本次推论、假设之间的区别 | 保留必要出处与判断身份，不把假设写成事实 |
| 作者减责 | 只表示作者谨慎，未增加上述信息 | 删除空泛表态、同义重复与无信息的段尾提醒 |
| 社交礼貌 | 请求与反馈中的人际作用 | 不移植为讲义正文的谨慎尾句 |

四步处置：写明命题及其身份 → 试删限定，看是否扩大范围、提高确定性、丢失来源或改变计算 → 把限定放到受影响的那一句或那一组结论内 → 明确保留、缩到局部、改成具体条件或删除。

**防御性铺陈单列**。还有一类措辞既非语义限定也非证据归属：逐条复述前提、先排除退化再讨论、末尾加「这也表明…／此判断使用了…／同一个…解决了两问」，以及为每一步补一句「为什么」。它们不增加命题信息，却让读者觉得作者在自证。处置：删去整句后若计算仍可复现、依据仍可追溯，就删；含数学内容的（退化会翻转结论）前移到该步并用从句带过。判据见 `lecture_notes_voice.md` §2–§4。

「可能」「约」「一般」「尚未」都要放回命题判断，不按词表批量删。局部未知只限定受影响的结论，不笼罩整段；后文的摘要、练习解答与末章手册必须使用同一口径。

这一节同时服务两条红线：删掉作者减责与泛化提醒，正是零元话语与禁考试管理语言；保留定理条件、适用前提、数值精度与题源身份，则是规范第 2、3、6 节的硬要求。

## 4. 成稿校对: 五类人工核对

| 项目 | 要核什么 |
| :--- | :--- |
| 术语稳定 | 同一概念在一章内不换称；名称与本课程教材一致；定义首次出现用 `\textbf{}` 标出；英文缩写首次出现解释一次；命令、路径、代码实体原样保留 |
| 回指唯一 | 「它」「该式」「上述结论」「此时」能唯一定位；一个指代可能落到两个对象上时恢复名称；观察立场切换时写明 |
| 数值与单位 | 写明对象、单位、期间与比较基准；范围两端共用同一单位；「增加了 / 增加到」「降低了 / 降低到」不混用；临界值不取整到改变结论 |
| 来源可定位 | 题源标注能定位到教材页码题号、作业次第或卷别题号；回忆版数据经用户确认后才写入；引用第三方图表给出可定位来源 |
| 标题与层级 | 章节标题准确覆盖本节内容；无层级跳跃、同级只有一个小节、上下级标题同名 |

中英混排：中文与拉丁字母、数字相接处按本篇统一写法留半角空格；公式、代码、路径保留自身语法，排版规则不改变内容。**标点一律按规范 §3.6 用半角英文标点并在其后加空格**，本文件只借鉴「按结构定句界、不按词面批量删改」这一判断方式。

## 5. 连续试读: 补在三层验收之后

`lecture_notes_audit.py` 与 `lecture_notes_build.py` 只能查词面、结构与编译，查不出「读者接不上」。每章交付前另做一次连续试读：只按成稿从前读到后，标出第一次需要停下来猜对象、用途、理由或前提的位置。

重点看四处：转折与办法更换、新对象引入、从设定进入推论、公式与例题前后。每处指出前句给了什么、后句用了什么，缺的依据是文字没写，还是材料本身待核。审读不能由作者意图、章节职责旁注或「已按规范编写」代答；保持原文也要给出实际承接依据。

发现承重解释缺失，回到该章草图补内容，不靠追加一段泛化提示或加连接词补救；发现事实或推导错误，交回对应题源核对，再由文字层统一落笔。

连读时另问一句：这一段像在推进计算，还是像在向读者证明作者没有漏掉条件？连续三句以上只解释理由而不推进对象，或每道解答末尾都有一段点评，就是防御式文体，按 `lecture_notes_voice.md` §2–§4 削薄，不靠加连接词补救。这一项与该文件 §9 的人工验收合并执行。

不作分数化评分，不设固定修订轮数，不用词频、段长、连接词数量或禁用词命中数充当质量结论。词面扫描只用于定位，词面清零不等于讲义可读。

## 6. 明确不采纳的部分

| `chinese-writing` 的做法 | 本技能的处理 | 原因 |
| :--- | :--- | :--- |
| 中文全角标点体系、关联词后逗号、顿号与分号用法 | 只借鉴「按结构定句界」；实际标点用半角英文标点 + 后加空格 | 规范 §3.6 是用户明确的排版红线 |
| 「我们」共同视点、带读语气、口语化引导 | 只用于证明行动，不用于介绍编写安排 | 规范 §3.2 零元话语 |
| 开篇点题、学习理由、动员式起句 | 讲义按考点 / 方法直接进入定义与推导 | 规范 §3.3 禁考试管理语言 |
| 参考讲义的「显然 / 同理 / 读者容易证明」留白 | 不替代承重论证时允许，按 `lecture_notes_voice.md` §3；不主动模仿「我们」带读语气 | 零元话语只禁编写安排，数学留白不等于元话语 |
| 第 0 版 / 第 1 版多轮草图、文字与专业双角色审读、阶段状态机 | 简化为「每章一份安排草图 + 一次连续试读」 | 本技能已有分章迭代 SOP 与三层工具化验收，不叠加流程负担 |
| 五项门槛、十项诊断分、真实样文标点分布校准 | 不设分数与配额；样文只作人工文体对照 | 避免把词面指标当成文本质量 |
| 面向报告 / 参考记录 / 文学创作的声音选择 | 不采用 | 本技能只产出数学书式叙述体的讲义、解答与试卷 |
