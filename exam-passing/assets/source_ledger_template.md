# [课程名]期末复习讲义: 题源台账

> 依据 `exam-passing/references/lecture_notes_spec.md` §2.1 与 `references/lecture_notes_workflow.md` 建立; 动笔前先查此表, 每章交付后立刻把「预留」改成「已占用」.
> 标注格式: `[教材 P.11 第 3 题; 第一次作业]`, `[2021--2022 学年第二学期 A 卷 第三题]`, `[教材 \S 2.6 习题 1; 第四次作业]`.
> 处理标签: **结** = 结论型, 写成正文命题 / 推论 / 引理并带完整证明; **例** = `example` + 完整 `solution`; **练** = `exercise` + `solution` (题干 + 就地完整解答).
> 真题纪律: 回忆版的题干数据 (矩阵元素, 系数, 右端项, 初值) 先标「待核」, 经用户确认后才能写入正文; 改正后讲义与该题在真题源文件中的正文一起改. 范围的归属按解法实际用到的工具判断, 不按教材章号.
> 溯源纪律: 真题若源自教材习题或定理, 卷别与教材出处并列标注, 如 `[2023--2024 学年第一学期 A 卷 第五题; 教材 \S 7 习题 3]`; 确无原题的标概念锚点 (如 `教材 \S 5 定义 5.1`), 不虚构习题号. 交付前用 `audit.py` 的 `exam-source` 检查「只标卷别」的环境. 复盘改造流程见 `references/lecture_notes_revision.md`.
> 编排纪律 (规范 §1.1): 逐题登记时先填「题组」 —— 使用同一构造 / 定理 / 估计, 只换参数, 常数, 素数, 初值或对象的题归为一组; 一组对应讲义中一个以方法命名的小节, 组内题必须相邻, 并配一道只换参数的变式练习. **台账里的分组先定, 再排小节**, 不按教材题号或试卷年份顺序铺开; 这是新建讲义就要执行的要求, 不是交付后的重排事项.
