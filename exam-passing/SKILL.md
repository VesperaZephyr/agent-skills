# Exam-Passing 通用期末考试助教技能

## 概述

`exam-passing` 面向任意高校课程的期末备考，提供从课件解析、平时作业规范求解，到期末系统复习讲义与模拟试卷命制的完整闭环。技能内**不内置任何课程的教材索引、考纲或题库**：课程名称、教材、考试范围、题型结构与题源一律由当前项目提供（教材 OCR、作业、历年真题、教师课件），技能只负责解析、撰写规范与工具链。

其中**「期末复习讲义撰写规范」是跨科目通用标准**（见 `references/lecture_notes_spec.md`）：适用于任意高校课程的期末复习讲义，不以任何单一科目为限；在其他课程项目里撰写复习讲义时，同样必须加载并执行该规范。

语言质量由三条互补的规范保证：`references/lecture_notes_spec.md` 第 3 节给出不可让步的红线（叙述体、零元话语、禁考试管理语言、半角标点），`references/writing_craft.md` 给出把句子写顺的正向方法（句群承接、伪承接检查、逐命题限定、成稿校对、连续试读），`references/lecture_notes_voice.md` 给出「直陈不设防」的文体基准（结论编号沉淀、证明切入即计算、前提一次原则、提示框默认不用、末尾不复述）。红线定边界，正向方法定句法，文体基准定信息组织与详略；半角标点、零元话语、禁考试管理语言三条不让步，其余冲突按 voice §8 裁决。**合规不等于好读**，静态验收全绿后仍须按 voice §9 连读一章。

## 工作流与操作指南

### 1. PPTX 课件解析流水线
当用户上传或引用课件（`.pptx` 文件）时：
1. 调用内置脚本提取课件中的文本、表格与大纲结构，并**同时导出公式截图**：
   ```bash
   python scripts/extract_pptx.py <path_to_pptx> -o <output_markdown_path> --media <图片目录>
   ```
   课件里的公式与推导通常是图片，文字稿只覆盖目录与结论；导出后须逐张识别图片内容，否则整类公式会被漏掉。
2. 将课件提炼结果与**当前项目提供的教材、考纲或题源台账**进行对照匹配（技能不内置任何教材考点索引）。
3. 输出课件的核心重点、教师额外补充的例题或结论、以及潜在期末考试考察方向。

### 2. 平时作业撰写流水线（科目中立）
撰写任何课程的平时作业或习题解答时，必须严格执行规范化步骤：
1. **题目检索**：题目来源由当前项目提供；`scripts/homework_helper.py` 可用 `--textbook <教材OCR.md>` 按章节检索指定教材的课后习题，未指定教材时不检索、由用户给出题面。
2. **规范五环节**：
   - **一、题目复述与已知条件**：明确已知量、求解目标，指出所依附的定义与定理。
   - **二、前提与符号约定**：写清适用条件、边界与退化情形；需要时用 `booktabs` 三线表列出符号、含义、类型与单位。
   - **三、逐步推导与证明**：每一步给出依据，定理带条件，不跳步，公式编号对齐。
   - **四、求解与计算**：优先给出解析推导；课程确需数值计算时提供可运行代码与数值结果。
   - **五、结果检验与讨论**：用特例、边界情形、量纲或数值复核检验结论，说明适用范围与失效情形。

   > 五环节的「逐条写边界与退化」「结果检验与讨论」**只约束平时作业交付**；期末复习讲义的解答按 `references/lecture_notes_voice.md` 的直陈基准写，不逐题复验前提，不在末尾写检验点评。
3. **LaTeX 输出**：
   - 基于 `assets/homework_template.tex`（科目中立）生成 `.tex` 文件。
   - 保持 CRLF 行尾，无 BOM UTF-8 编码，统一英文标点符号。

### 3. 期末复习讲义编写流水线（强制加载通用规范）
编写任何课程的专题或全书复习讲义时，**第一步必须阅读 `references/lecture_notes_spec.md`**，并按其六节要求执行；该规范与科目无关，详见其中「科目适配指引」。要点：
1. **结构**：章节按考点/方法命名，目录即考纲；穷举典型情形；末章设「必背公式与结论手册」，按「适用条件—公式/结论」编排；该章名对期末复习有实际作用，须保留，「必背」二字只出现在章名，不写成「必背知识点」一类备考指令。
2. **题目编排（硬规则，成稿要求，两层判据不冲突）**：题干基本一致只是表述 / 出处不同，或同一个实例的不同考察方式（如同一扩域分别问生成元、次数、元素形式、极小多项式），判为「同一个题」，**必须删掉重复并合并成一道多问递进的例题**，全部出处并列，再配一道平行但换实例的练习；**数据不同但方法相同**（如 $\mathbb{Z}[\sqrt2]$ 与 $\mathbb{Z}[\sqrt3]$ 的欧氏除式）判为「同类题」，**不合并**，按 `references/lecture_notes_spec.md` §1.1 编在同一个以方法命名的小节内相邻位置，小节开头一段叙述讲清共同构造与参数差别，可抽带参数的公共公式避免重复推导，并配一道只换参数的变式练习（含完整解答）。两类动作作用对象不同，不可互相替代；规划题目时先判关系再定小节。`lecture_notes_revision.md` §2bis 只讲成稿里同一个题写了多遍时怎么补救，不在那里定义这条要求。
3. **内容**：每节从本学科机理推导概念与结论（讲清符号、前提、适用范围）→ 把方法固化为编号步骤 → 用标注来源的课程题源原题（教材习题、课程作业、历年真题，标注格式与例题/练习密度见规范 2.1 节）配**逐步完整的解答**，每个知识点后同时挂例题与练习, 且每道练习都紧跟一份与例题同等规格的完整 solution, 不设章末提示段 → 定理带条件与证明、建立交叉引用 → 提示框只讲数学结构与前提。证明型学科中「结论型习题」（判定、性质、等价刻画）按规范 2.1 节第 6 条直接写成正文命题 / 推论并标注题源，不重复挂例题。历年真题是题源中优先级最高的一类：确定考试范围后先做「真题逐题落点表」，按解题实际用到的工具判归属而非按教材章号，连年重复出现的题型独立成节或成章；回忆版题干数据须经用户确认后才能写入，改正数据要同步讲义、练习、手册与真题源文件四处。此外按规范 §2 补齐三项要求：定义与首次引入概念处的术语用 `\textbf{}` 标出，教材未引入的概念只放进 `remark`，源自教材的真题把卷别与教材出处并列标出。课本外工具按规范 §2.0 分三档：先修课已学且经用户确认的初等判据可以用（解答内写全判据），教材未引入的一般化版本不许进正文，也不要因过度保守绕开简单工具写冗长论证。**教材已有的定义、定理与证明按规范 §2.0bis 以教材原文为底本**：陈述照抄原书骨架（量词、限定条件、(1)(2)(3) 并列条款齐全，不压成一段），证明只用教材用过的工具（在教材 OCR 里命中 0 次的概念，如群作用、轨道、稳定子，不得作为证明依据），每条结论在标题标出教材编号，一条讲义结论对应教材多条时拆成多条分别标号，教材作为习题给出的结论降为 `remark`，教材没有编号的概念也写成 `remark` 不占结论编号；教材写了证明而讲义只有陈述的必须补证明（补前先看例题解答是否已证过、补后读该段末句核有没有被漏掉的「反方向」）；**「内容正确」不等于「忠于原书」**，交付前须逐节对读，不能因为编译全清就认为达标。
4. **语言风格（红线 + 文体基准）**：数学书式叙述体；零元话语、零考试管理语言、零「标签+公式」电报体；前提融入叙述而非发禁令；半角标点；`\boxed{}` 与表格克制。禁用词表与改写示范见规范第 3 节。**另按 `references/lecture_notes_voice.md` 执行直陈基准**：证明首段即计算，同型重复与标准变形允许「同理 / 整理得」留白，前提只在首次引入与失效处写一次，可复用结构关系升级为编号结论并 `\ref` 引用，末尾不写编者复述与复验，提示框默认不用，不强制每章分页。词面检查码清零后仍须连读一章。
5. **版式**：基于 `assets/lecture_notes_template.tex`（`tcolorbox` 包装 amsthm、自定义 `solution`、`\takeaway`/`\examtip`、公式按节编号、`booktabs` 三线表）；`.tex` 保持 CRLF 无 BOM，XeLaTeX 多轮编译；连续排版优先，不强制每章 `\clearpage`（实测会造出孤儿空白页），页眉用固定文本，见 voice §7。
6. **交付验收（工具化，不要靠肉眼数环境）**：按规范第 6 节清单逐项自检，直接调用 `scripts/` 中的工具链：
   ```bash
   python scripts/source_ledger.py init --out "<项目>/题源台账.md" --course "<课程名>"
   python scripts/lecture_notes_scaffold.py init --out "<项目>/讲义.tex" --course "<课程名>"
   python scripts/lecture_notes_scaffold.py backup "<项目>/讲义.tex"
   python scripts/lecture_notes_scaffold.py add-chapter "<项目>/讲义.tex" --title "<章名>" --sections "<节1>,<节2>"
   python scripts/lecture_notes_build.py "<项目>/讲义.tex" --passes 3 --copy-back --render <抽样页>
   python scripts/lecture_notes_audit.py "<项目>/讲义.tex" --strict
   python scripts/source_ledger.py scan "<项目>/讲义.tex"
   ```
   三层验收（源码层 / 编译日志层 / 视觉层）各自的职责、分章迭代 SOP 与常见失败模式见 `references/lecture_notes_workflow.md`；编译报错与「零警告但 PDF 是错的」类问题按 `references/lecture_notes_pitfalls.md` 反查。`audit.py --strict` 的 `source-duplicate` 首先当作「同一个题写了两遍」的信号，逐条对到人工聚类并合并；确属同一真题不同小问才用 `--ignore source-duplicate` 放行，问题仍保留在报告中，去重后该检查码应归零且不再放行。讲义交付后若发现成稿未满足上述要求（同类型题分散、同一个题写了好几遍、排序按题号、术语未标出、出现课本外概念、真题未标教材来源、想补同方法练习），不要重写全文：按 `references/lecture_notes_revision.md` 做既有讲义复盘改造（备份用户改动版 → 三项盘点 → 文本/结构/收尾三层改造 → 四层验收 → 四处回写）；`audit.py` 的 `exam-source` / `term-bold` 两个检查码会把「只标卷别未标教材」与「definition 未加粗术语」逐条列出；合并去重、篇幅归因与新版式坑（含「多问题干元话语总起句」与「文体防御」复盘）另见 `references/lecture_notes_revision.md` §2bis 与 `references/lecture_notes_pitfalls.md` §13；用户提出「叙述与原书不一致 / 证明用了原书没有的概念 / 要把原书定理编号标出来」时按 `references/lecture_notes_revision.md` §2quater 逐节对读，坑见 `references/lecture_notes_pitfalls.md` §16--§18（§18 含「教材顺序与例题就近冲突时保教材顺序、不搬结构块」这条判断；命题之间的教材顺序不动，但例题与练习放在哪条命题之后按 §2quinquies 排：只搬「与该命题讲同一件事」的例或练，综合题仍留节末，搬块纪律与五条副作用见 `references/lecture_notes_pitfalls.md` §19）。

7. **句子层面的正向方法**：红线只定边界，具体写法按 `references/writing_craft.md` 执行 —— 动笔前定本节认识推进与详略，正文按句群承接检查伪承接、主干搭配与小词情态，限定语逐命题判断，成稿核术语稳定、回指唯一、数值单位与来源可定位；三层工具验收之外另做一次连续试读，标出读者第一次需要停下来猜对象或前提的位置。标点仍以第 4 点的半角红线为准。文体层另按 `references/lecture_notes_voice.md` §9 连读一章：查方法论章导语、末尾复述、提醒框复述前提、证明首段在铺垫、元话语总起句；这一步不由工具验收代替。

> 旧版「知识图谱 + 审题技巧 + Pitfalls Table 避坑指南」的清单式讲义要求已废止，不得再作为编写依据。

### 4. 期末模拟试卷命制流水线
设计期末全真模拟卷时：
1. **先确认卷面参数**：从项目资料或用户处取得考试范围、题型、题量、分值、时长、允许携带的资料与往年真题；技能不预设任何科目的题型比例与题目内容。
2. **编制双向细目表**：按「知识点 × 题型 × 分值 × 难度」逐题落点，使覆盖面与分值结构可核对；回忆版真题的题干数据须经用户确认后才能写入。
3. **卷面排版**：基于 `assets/mock_exam_template.tex`（科目中立的空白卷面骨架）填充，题型标题、题量与分值一律按确认结果改写。
4. **配套答案**：每一套模拟试卷必须提供**完整参考答案与详细评分细则**（明确每一步骤的分值分布，并写出所依据的定义、定理或公式）。

## 资源清单与路径

- **脚本工具 (`scripts/`，纯 Python 标准库，跨平台)**：
  - `extract_pptx.py`：PPTX 解析器（无需额外外部依赖）。
  - `homework_helper.py`：通用作业辅助工具。`--textbook <教材OCR.md>` 指定任意课程的教材文本后按章节检索课后习题；`scaffold` 生成科目中立的作业解答 LaTeX 骨架，可用 `--course` 指定课程名。技能不内置任何教材路径。
  - `lecture_notes_scaffold.py`：**讲义骨架与分章迭代**。`init` 从模板生成新讲义；`backup` 建立时间戳备份；`add-chapter` 在 `\end{document}` 前追加章骨架并自动备份；产出恒为 UTF-8 无 BOM + CRLF。
  - `lecture_notes_audit.py`：**源码层静态验收**。检查编码行尾、例解配对、label / 引用、题源标注覆盖与重复、练习解答配对与禁提示段、禁用词、全角标点、斜杠错字、公式 `\label` 位置、提示框参数个数，以及复盘改造的 `exam-source`（真题只标卷别未标教材）与 `term-bold`（definition 术语未加粗），以及直陈文体的 `voice-meta`（WARN）、`voice-recap` / `voice-defense` / `tip-density` / `forced-pagebreak`（INFO，只用于定位）；支持 `--json`、`--strict`、`--ignore CODE`。
  - `lecture_notes_build.py`：**编译与 PDF 验收**。多轮 XeLaTeX、逐轮解析 error / warning / undefined / hbox / 缺字符 / 页数，`pdftotext` 检查 `??`、字面斜杠命令、cref 类型名与式引用，可选 `pdftoppm` 渲染抽样页与 `--copy-back`；构建目录固定用 ASCII 文件名以绕开 Windows 中文文件名编码坑，`--copy-back` 遇目标 PDF 被占用时自动另存 `*_终稿.pdf`。
  - `source_ledger.py`：**题源台账**。`init` 生成台账；`scan` 按章统计标注覆盖率、未标注环境、题源类别与重复出处（与 `audit.py` 共用解析核心）。
