# Exam-Passing 数学建模学业助教技能

## 概述

`exam-passing` 旨在为高校数学建模课程（特别是以祁永强《数学建模》为核心教材及课件的教学体系）提供端到端的高水平助教能力。涵盖从平时作业规范求解、课件考点萃取，到期末系统复习讲义与模拟试卷命制的完整闭环。

## 工作流与操作指南

### 1. PPTX 课件解析流水线
当用户上传或引用课件（`.pptx` 文件）时：
1. 调用内置脚本提取课件中的文本、表格与大纲结构：
   ```bash
   python scripts/extract_pptx.py <path_to_pptx> -o <output_markdown_path>
   ```
2. 将课件提炼结果与 `references/textbook_outline.md`（祁永强教材考点全景）进行对照匹配。
3. 输出课件的核心重点、教师额外补充的例题或模型、以及潜在期末考试考察方向。

### 2. 平时作业撰写流水线（建模“五步法”）
撰写任何数学建模平时作业或习题解答时，必须严格执行规范化步骤：
1. **题目检索**：通过 `scripts/homework_helper.py` 检索对应章节原题。
2. **规范六大模块**：
   - **一、问题重述与背景分析**：明确问题本质、输入参数与求解目标。
   - **二、合理假设与简化**：列明 3~5 项机理假设，界定模型边界。
   - **三、符号说明表**：使用 `booktabs` 三线表规范定义所有参数与变量。
   - **四、模型的建立与公式推导**：基于物理/微积分/运筹机理严密推导，公式编号对齐。
   - **五、模型求解与算法代码**：给出显式解析解或提供可运行的 Python/MATLAB 代码与数值结果。
   - **六、结果分析与灵敏度评价**：解释现实经济/工程含义，进行关键参数鲁棒性分析。
3. **LaTeX 输出**：
   - 基于 `assets/homework_template.tex` 生成 `.tex` 文件。
   - 保持 CRLF 行尾，无 BOM UTF-8 编码，统一英文标点符号。

### 3. 期末复习讲义编写流水线
编写专题或全书复习讲义时：
1. 查阅 `references/textbook_outline.md` 提取章节核心公式、理论推导、例题。
2. 架构四个核心层次：
   - **知识图谱与脉络**：展示由浅入深的逻辑主线；
   - **机理分析与公式精粹**：给出标准数学形式与推导切入点；
   - **典型例题剖析**：拆解审题技巧与关键求解步骤；
   - **常见错误与易错陷阱（Pitfalls Table）**：总结易混淆概念与推导盲区。
3. 讲义格式基于 `assets/lecture_notes_template.tex`，使用 `tcolorbox` 彩色卡片高亮重点定理与模型。

### 4. 期末模拟试卷命制流水线
设计期末全真模拟卷时：
1. 遵循标准化 100 分制卷面分布（时长 120 分钟）：
   - **一、单选题（5 题 $\times$ 3 分 = 15 分）**：概念理解与临界阈值判定；
   - **二、填空题（5 空 $\times$ 3 分 = 15 分）**：经典公式、评价指标与定理条件；
   - **三、简答与机理题（2 题 $\times$ 10 分 = 20 分）**：机理推导或算法步骤（如双层玻璃导热、AHP 一致性检验）；
   - **四、微分方程/连续动力学大题（25 分）**：斜抛极值、传染病相平面、作战平方律等；
   - **五、运筹优化/离散规划大题（25 分）**：原料下料整数规划、动态规划最短路、报童临界分位数等。
2. 每一套模拟试卷必须配套提供**完整参考答案与详细评分细则**（明确每一步骤的分值分布）。

## 资源清单与路径

- **脚本工具 (`scripts/`)**：
  - `extract_pptx.py`：纯 Python 标准库 PPTX 解析器（无需额外外部依赖）。
  - `homework_helper.py`：教材习题检索与作业解答 LaTeX 脚手架生成工具。
- **参考资料 (`references/`)**：
  - `textbook_outline.md`：祁永强《数学建模》全书 7 章核心模型与课后习题全景索引。
  - `workflow_guide.md`：作业解答、课件解析、讲义编写与试卷命制四大工作流细则。
- **模板资产 (`assets/`)**：
  - `homework_template.tex`：高质量平时作业解答 LaTeX 模板。
  - `lecture_notes_template.tex`：系统化期末复习讲义 LaTeX 模板。
  - `mock_exam_template.tex`：标准格式期末考试模拟试卷 LaTeX 模板。
