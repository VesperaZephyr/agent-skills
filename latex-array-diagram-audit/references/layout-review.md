# 交换图布局审阅：结构正确之后还要逐图检查

用于已有 tikzcd 图出现拥挤、弧线穿过节点或标签重叠时。布局审阅与原书逐边保真
分别记录；候选清单不是已审阅清单，编译成功也不是布局通过。

## 常见失败及修复顺序

1. **把分层图压成一行。** 核的泛性质原图可为顶行 P→M→N，核在 M 下方；
   余核是顶行 M→N→P，余核在 N 下方。将四个对象塞成一行、再叠多个长弧，
   会使唯一分解标签和邻边标签挤在一起。先看原书节点网格，恢复分层布局，
   不先靠整体缩放或白底盖线“修复”。
2. **余积图失去积图的镜像结构。** 若 M、N 在左侧上下两行，直和居中、P 在右，
   两个 i 映射在内侧，两个 ψ 映射走外弧。把 M、N 挤到同一顶行、直和放在
   下方，可能使外弧穿过直和节点或与中间映射相叠。按原图恢复网格及对偶结构。
3. **间距只按节点宽度设置，漏算标签。** `column sep=1.6em/2em` 对短对象可用，
   对复合映射、直和映射和“唯一存在”标签可能过短。局部增大列距/行距，
   再检查最终书页宽度。数值是实例，不是全书统一的固定阈值。
4. **长弧与内边共用通道。** 零复合弧线可放在外层，普通映射放内层；
   必要时改变 bend 的侧别、幅度或控制点，保持有向端点、标签和边类型不变。
   曲线相交不自动构成数学错误；只有证据支持的可读性改善才改路由。
5. **标签看似分开但碰到箭头头/钩。** 检查曲线两端、三箭头汇合处以及
   长标签的边界；调整标签侧别、`pos` 或局部标签间距。`description` 将标签放在线上，
   白底可能掩去线段；它和缩小字号都不能代替正确的几何布局。

## 可复用的审阅闭环

- 从实际构建源建立候选清单，按图登记源文件/行、原书物理页、译稿物理页与印刷页。
  用邻近陈述和文字定位，图可能跨页；不沿用修改前的固定页码。
- 先看原书页图，再独立列译稿节点/边。布局可以按用户要求调整，但须保留每条边
  的语义与特殊样式；声明节点重排是可读性修复，不能伪称位置与原书逐像素相同。
- 优先看多层 bend、密集对角线、长标签短边、窄行距、多个唯一分解标签、
  大型正合图和自定义 to path；这是检查优先级，不是自动问题判定。
- 同一文件修改串行、精确匹配并备份。先孤立编译一组图，目视检查后合并成批，
  再按原书项目样式全构建。小样通过后仍检查最终书页的缩放、相邻段落、分页和裁切。
- 同时检查对偶/镜像伴图，避免只修积而余积仍挤、只修核而余核仍有交叉。
- 台账分列：候选分类、结构/逐边核验、旧版目视、修改、小样目视、最终页目视、未决。
  “368 个图候选”或“7 图已修改”都不等于“全书全部审阅”。修改导致页码变化时刷新定位。
- 保留原图和最终页截图、批次修改记录及未覆盖范围，便于下一轮从未决项继续。

## 本轮校准实例的用途

Aluffi《Algebra: Chapter 0》译稿实战中，四幅积/余积/核/余核图的拥挤来自
压缩节点网格和错误重排；恢复原书分层比继续调整单条弧线更有效。
另有结合律图长弧标签拥挤、积图长标签超过短边、余核图外弧穿过 β 斜边。
这些是定位与修复模式；遇到另一幅图仍须重新取原书证据，不复制具体参数作为答案。
