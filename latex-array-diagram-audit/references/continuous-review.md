# 连续逐图审阅与修复回归

适用：对照出版版连续审阅数学书中的交换图、元素追踪、复形网格及带方向的同伦示意图。源于 Aluffi 图审实践；这里的数值和例图用于校准，不是其他图的默认答案。

## 先辨认图，再比较边

- 节点按“出现位置”编号，例如 `B_left_lower` 与 `B_right_lower`，即使都印为 B 也不能合并。一个 K→B 接到了投影的靶副本而非单射的源副本，字面节点集合不变，数学关系仍已改变。
- 先核图的身份：原图是否被另一幅完全不同的图替代？元素追踪的黑点/mapsto 是否被对象层复形替代？原书等式是否被扩成新图，或原图外弧是否被等价等式替掉？数学等价不等于逐边保真。按用户的保真要求裁定并记录，不把表达差异自动算成数学错误，也不擅自增删图。
- 零是实际节点，空格是布局位置，省略号及其续接边是图的延续；三者不可互换。像对象后接的 0 不应改成原对象并加 hook；证明尚未构造的提升不能提前画入。
- 同时检查整列/整行、最外端斜边、首末续接、图左侧行名之间的态射、外层复合弧、中央空方形/直和标记。只核中心矩形容易漏这些内容。
- 标签本身有逻辑力度：`∃!`、`∃`、候选提升的问号、零标签、帽号、复合符号不能凭正文隐含而略去。命名诱导映射也不自动替代其唯一性标记。
- 两组边“分别同向”不足以证明带标记方形等价。旋转或翻转图后，逐角核对哪些标签共源、共靶；例如源图同一角发出 f 与 δ−，改图不能变成发出 g 与 δ−。

## 端部与空间关系

- 分开检查头、尾与线身。单条边可以同时有单射尾和满射双头；`mapsto` 的直尾不是单射钩。恒等边可能是无头双线，边界短续接可能是无头实线；不要统一成普通箭头。
- 三维/透视图中，后景实线被前景横边遮断，不一定是数学上的虚线。先辨清遮挡与交点，再决定是否用 `crossing over` 等路径遮挡；这种图形透视遮挡与用白底掩盖标签碰撞不同。
- 扫描无法区分实虚线时保留该边的具体未决，不由“唯一映射通常画虚线”等习惯推断。源书记号疑似错误也单列：保留印刷事实与上下文疑点，未经裁定不静默改正。

## 放大取证的完整性

使用 `mathtranslation` 的 `references/figure-capture.md` 和 `scripts/capture_pdf_region.py`（安装可用时）：先导出并实际打开整页，定位后从原 PDF 重渲染局部，保存物理页、bbox、dpi、PDF哈希及图前后文字。高倍率图用于核端部，最终整页用于核实际尺寸与正文关系。

裁图要含所有节点、弧线及远端标签。发现旧裁框截掉顶部 A 或底部 i 标签时，应扩大框重新打开，再重做结论；不能沿用不完整裁图认证整图。扫描原图约150 dpi时，600 dpi导出只是放大观察，不增加真实细节。文件已导出、工具返回路径、侧车写着 exported_unreviewed 都不等于目视通过。

## 列距修改没有生效时

1. 用当前图制作小样，保留实际宏和全局样式；选一段最挤的边测量可用长度，确认是标签宽度问题还是路径通道问题。
2. 检查 `column sep`、`row sep`、首排单元格的间距和后排行内 `&[...]` 是否共同影响矩阵。实战中只在后排设置更大 `&[...]`，源码改了但图面没有展开。应检查矩阵生效参数，必要时在首排对应处或该图整体设置间距。不要据此推广“所有后排间距都无效”，也不要把某个 em 数值推广到全书。
3. 先确认新 PDF 的节点坐标/边长确实改变，再检查标签与节点上标、钩、箭头头及邻边的空隙。若两次图面相同，先查构建输入、宏覆盖和参数作用域，不要连续盲目加数并重复整书构建。
4. 标签的侧别和位置选项要分别书写，例如 `\ar[dl,"h^{i+2}"',pos=.32]` 或 `\ar[dl,pos=.32,"h^{i+2}"']`。字符串替换不能把它变成 `pos=.32'`，否则 PGF 会把撇号当作数值表达式的一部分。
5. 小样通过后再整书构建与最终页复查。标签移到源书同侧可能暴露原来被掩盖的长度不足；无 overfull 也可能明显压字。不能以缩小全图或删标签收口。

## 完整标签不是一列“标签有无”

另做一次逐字符/TeX结构挑战：次数、滤过上下标、负号、帽号、复合、0/id/+1、存在唯一性和拟同构标记。
例如12个节点都漏掉同一个小下标，图的轮廓与连边仍可完全合理。恢复长标签后重查列距，不能把新增文字挤到相邻节点上。
原图`gr_v^k(T)_i`与省略v的版本不是仅凭“全章约定”可默认等同；若采用记号简化，应有上下文依据并明确披露。

## 边界裁切与原生TikZ

规则网格的“窗口”不一定是有限对象图。先确认源书哪些是实际节点、哪些是边框裁去后留下的非节点线段；
不要凭无限格直觉在每个边界节点补短箭头。边界箭头头可能在框外而被裁掉，剩下的只是无头线段。

若源图确为整数格微分`(i,j) -> (i+dx,j-dy)`的矩形截取，可用
`scripts/generate_clipped_lattice.py`：绘制能穿过窗口的边并在矩形内裁切，再在裁切scope外绘制完整格点。
这自然保留顶边/侧边的非节点片段，也避免在节点外随意添加碎线。行列、dx/dy和窗口仍须从原书确认；
不能将6x7或任一格距复制为别书答案。一般有标签的对象图仍优先tikzcd。

手工续线要核实际长度和锚点：从宽节点中心加很短的相对位移，可能被节点边界吃掉，只剩小钩或碎点。
用明确的边界锚点或正确裁切模型，并实际编译打开小样，不以draw命令存在证明可见。
`execute at end picture`里矩阵名称/节点编号是否可用也须在当前TikZ版本验证。
