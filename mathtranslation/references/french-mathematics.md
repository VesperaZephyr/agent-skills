# 法语数学文献翻译与校准

用于法语数学讲义、论文和专著；与主技能的原 PDF 权威、独立审阅、编号及排版约定配合使用。本参考不更新模型权重；案例练习用于暴露、复核和记录翻译缺陷，不据此声称模型普遍能力提升。

## 法语到中文的语义边界

- 先标出句子的量词域、条件、结论和回指对象，再组织中文。`tout`、`un`、`il existe`、`unique` 的逻辑地位依定义语境确定，不能机械一词一译。
- `si ... alors ...` 是单向蕴含；`si et seulement si` 是当且仅当；`réciproquement` 明确开启逆向；`il suffit de` 只提出充分条件；`il faut que` 提出必要条件。保留 `à condition de`、`sous l'hypothèse` 等限制，不把它们译成无条件断言。
- `quitte à` 通常是“必要时作某变换后”或“适当重编号后”，不是自动允许“无妨设”任意强假设；先检查该操作是否保留当前数学对象。
- `à l'ordre près` 是“不计顺序”或“除顺序外唯一”；`à un inversible près` 是“相差一个单位因子”；两者不能只概括成“唯一”。`deux à deux` 为“两两”。
- `se donner` 依语境译为“给定／选定”，不要赋予“唯一确定”；`on en déduit`、`il s'ensuit` 只承接原文结论，不添证明步骤。`on se convainc` 不是已经给出了严格证明。
- `respectivement`、`ce dernier`、`celle-ci`、`dont`、`y`、`en` 须逐一核定回指；中文可以重复对象名消除歧义，不能因此增加假设。
- `ou` 是否排他由数学语义决定，通常保留普通析取；`ne ... que` 是“仅”，`ne ... pas` 是否定，`aucun` 的否定不能丢失。`non nul et non inversible` 必须同时保留两个条件。

## 术语必须跨语言核对义项

法语原词、英语义项、中文译名分列；主技能的 `newterm` 第三参数仍为英语，而非法语。可以在项目术语表另存法语。法语人物形容词不应机械音译，例如 `abélien` 对象采用“Abel 群”，`noethérien` 对象采用“Noether 环”，英语原词仍为 abelian group、Noetherian ring。

重点消歧：

| 法语 | 在相应数学语境中的中文 | 需核定的边界 |
|---|---|---|
| corps | 域 | 与 corps de nombres（数域）区分；是否默认交换须按作者定义 |
| anneau intègre | 整环 | 不是“整数环”；后者 anneau des entiers |
| entier algébrique | 代数整数 | 不等于 algébrique（代数的） |
| unitaire（多项式） | 首一 | 与带单位环的 unitaire 区分 |
| inversible | 可逆；单位（作元素名词时） | 不等于 inverse（逆元） |
| factoriel | 唯一分解的／唯一分解整环 | 不是“阶乘”；保留对象是否整环 |
| de type fini（域上代数） | 有限生成 | 不是有限维；与 extension finie、module de type fini 区分 |
| réduit（交换代数） | 既约 | 对照无非零幂零元条件，不译成不可约 |
| premier（理想） | 素 | 与整数的素数及 irréductible（不可约）区分 |
| premier(s) entre eux | 互素 | 与素元素/素理想区分 |
| principal（理想） | 主 | 不译作“主要”；是否非零由原文决定 |
| schéma；spectre | 概形；谱 | 使用数学义项，非日常“方案／光谱” |

这里的表是义项提示；正式中文沿用 confirmed-terminology.md，未确定条目按 exceptions 的规则处理。

## 原 PDF、OCR 与数学常识三方检查

法语字体中的 fi/fl/ff 连字、撇号、重音、长破折号及 PDF 控制字符，可能使 `fini`、`définition`、`différent` 等词破碎。可恢复纯文字词形，但不得据此自动改公式。逐页核查上下标、共轭横线、映射的复合顺序、包含关系、集合差和不等号。OCR 段落或“数学上应该如此”都不是原 PDF 的替代。

对每项异常区分：

1. OCR 与原 PDF 不同：按原 PDF 修复转写，保留定位和修复记录。
2. 原 PDF 本身有疑似错误：保留原式，单列原文疑点；若在译稿解释，明确标为译注。没有授权或充分证据不擅自改写。
3. 原文略证或存在推理空隙：忠实翻译其断言强度，记录问题，不能补出并伪装成原证明。

## 校准方法与可检验的完成标准

先用原文和上下文完成候选翻译，再揭示参考答案；审阅者先独立列源清单，再读冻结译稿。逐项记录条件/量词/方向/对象/术语/符号/增删的检查结果，保留失败样本和修复前版本。训练集与留出集按来源单元分离；仅在练习中出现的样本通过，不能推断未见文献已通过。

法语案例见 [french-calibration.json](french-calibration.json)。参考答案表示其义项下的语义约束，不是唯一中文措辞。每次新增案例应给出来源及上下文；从整本书抽取时同时记录页码映射，不能把已知原书错误当成正确数学答案。未经原 PDF 或独立审阅确认的案例须标注为候选，不纳入通过率。

校准状态 `reviewed-source-and-semantics` 只表示源页定位/内容核查与独立语义审查均已完成；它不表示训练后的翻译性能评测。`source_review` 和 `semantic_review` 分别记录两类证据。短语案例只检验该短语的意义；含省略号的答案不声称覆盖整句。原文疑误案例必须保留可见原式并明确加译注，不得把正确数学公式冒充原文。
