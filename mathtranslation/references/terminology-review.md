# 术语一致性审校规程（terminology pass）

本规程服务两类场景：三遍审校中的"术语遍"，以及对已完成译稿的专项术语审。
它补充 [forensic-review.md](forensic-review.md)（覆盖度取证）与
[review-checklist.md](review-checklist.md)（三遍清单），聚焦一个问题：
**同一概念是否全书只有一个译法，同一译法是否只指一个概念。**
产出物：分级问题清单、对照原书的误译清单、可审计的修复脚本、重建验证记录。
2026-10 于 GTM 304《微局部分析导论》（11 章，约 950KB TeX）实战校准。

## 0. 两类缺陷，两个修复方向

- **A 类：同一 EN 概念多种 CN 译法**（对易子/换位子/交换子）→ 归一为一个。
- **B 类：同一 CN 词承担两个 EN 概念**（对易子 = commutator 与 commutant；
  特征函数 = characteristic function 与 eigenfunction；余核 = 核与 cokernel；
  符号 = symbol 与 signature）→ **拆分**（给一个义项换词），不是归一。
  B 类更隐蔽、危害更大，且常在 A 类归一时被"顺手抹平"——归一前先排查 B 类碰撞。

## 1. 先建立"预定术语表"（不读全文）

从译稿自带工件反推译者的既定基准 G：
- 索引 `\index{拼音@中文 (English)}` 条目——CN↔EN 对照与拼音键质量；
- `\DeclareMathOperator` / 宏定义注释；
- 章节与节标题（TOC）；
- 首次定义处的英文括注；
- 交接文档声称的术语规范。

偏离 G 才算问题；G 内部自相矛盾（索引词 ≠ 正文词）是高信号缺陷。
**不要信任任何"文档声明"**：译者序本身可能违反全书基准（拟微分/共振/边界值问题），
交接文档可能过时或失实（声称存在的体例约定章节实际没有；页数 211 实为 307）。

## 2. 变体族 grep 扫描（确定性、便宜、全覆盖）

按领域预先准备高风险**变体族**清单（每族 = 同一 EN 概念的候选 CN 写法
＋ 易混的另一义项词），逐文件 `grep -o | wc -l` 得分布表；出现分裂的族再
`grep -n` 取行号与上下文。扫描范围必须包含：章节文件、frontmatter、
tikz/宏文件（**注释里也有术语**）、索引源。微局部分析实测高产族：
commutator、cut-off（切断/截断）、bicharacteristic（零双特征线/类光双特征线/双特征曲线）、
support（支集/支撑集/本质支撑/紧支撑）、symbol（符号/象征）、parametrix（拟逆/参数子）、
pushforward（前推/推前）、trapped（陷阱/束缚/捕获）、resonance（谐振/共振）、
test function（检验/测试）、linear wave（线性/线型）、smoothing（光滑化/平滑/磨光）。
**grep 找不到计划外变体**——这正是需要第 4 步的原因。

## 3. 索引专项审计（高信号、低成本）

- CN 词 ↔ EN gloss 配对错误（`正定性 (well-posedness)`，应为适定性）；
- 拼音键错误或复制残留（`sanse`→`sanshe`；键串与条目文不匹配会致排序错位）；
- EN 拼写（`null-bicaracteristic` 漏 h）；
- 索引条目 vs 正文实际用词失配、索引锚点无正文位置。
`.idx`/`.ind` 是生成物：**只修 `\index` 源，永不直接改生成物**。

全面索引审阅、同名词头分裂、父子项错置或章首占位索引，继续读
[index-audit.md](index-audit.md)。该规程补充排序键/显示路径去重、
原书层级与符号覆盖核对、安全批量修改和损坏恢复；关联词定位脚本不能替代这些检查。

### 术语修订必须闭合关联索引

每次改正文术语，均以英文概念、中文新旧译名、常见缩略词、派生词和已知
上位/下位条目为线索，在全部实际编译源码中查找相应索引（包括嵌套层级、
不同排序键、宏与注释中的候选）。运行 `scripts/audit_related_indexes.py --term <旧词>
--term <新词> --term <英文词> <compiled-files...> --output <ledger.json>`；脚本只定位，
可能漏掉拼写变体或宏生成条目，不认证含义或页码。补查项目特有索引宏及原书索引。

为每项记录完整层级、排序键、中文与英文释义、当前源位置、语义匹配的目标正文
及其原书证据、修订/保留理由和最终 PDF 页码。逐项核查：名实、义项、层级、拼音、
排序和落点；多层条目每一级都要通顺且表示真实关系。不要把“页上出现该词”
自动视为足够证据，也不要仅因某页缺字就删掉原书有意安排的交叉引用、页码范围
或间接引用。错位索引应移到实际定义或有意义的讨论处，重复页码按语义裁定；
不确定的保留待核并报告，不能只改显示名而让它仍指向错误页。

全索引内容的修复需独立清单和范围说明：对发现的批量无关条目，逐条核实并迁移，
不要凭数量、邻近段落或编译成功删除整批。所有变动只改源码，保留可审计的修订
清单与预期计数。重建后比对 `.idx`、`.ind`、PDF 可见索引及链接目标，抽取并实际
点击或解析每个修改条目的目标，确认到预期对象；记录合并项与条目数变化的原因。
旧词无残留不等于索引合格。若发现全局索引污染而仅修本轮关联项，应明确报告未覆盖范围。


## 4. 分组并行逐章通读（抓计划外不一致）

- 独立上下文审校 agent（[independent-review.md](independent-review.md) 纪律），
  按体积分组：**单 agent ≤ 约 170KB**，大章独占一个 agent。
- 任务书必备：基准表 G 摘要、**已登记问题排除清单**（防止 N 个 agent 重复上报
  同一问题；允许只补新行号）、OCR 原文路径与查证义务、统一报告格式
  （A 术语对照表 / B 新发现不一致 / C 对照原书存疑 / D 体例抽查）、"宁缺毋滥"。
- 并发受限时降级为分批派发（实测 6 并发只成功 1 个，按 3+2 分批全部成功）。

## 5. 汇总与人工复核（不信任转述）

合并去重后分级：**P0** 语义错误/自创术语（必须改）；**P1** 系统性多译法（全书归一）；
**P2** 局部一两处；**P3** 索引/体例；**D 决策项**（既有体系 vs 标准译名冲突，
如"谐振 vs 共振"——列明改动量交用户定夺，不擅自定）。
**每条高影响结论，协调者必须亲自取上下文复核后方可列入修复清单。**
实测纠偏记录：agent 声称的位置 1 条不存在、计数 1 条偏差（14 非 16）、
精确串 1 条不符——全部在复核环节纠正。

## 6. 归一方向怎么定

按序取：(1) 索引/首次定义已用的词；(2) 多数派；(3) confirmed-terminology 默认
（注意其"领域"列——抽象代数的 commutator=换位子与 PDE 语境可能不同权）；
(4) 最小改动量。**决策与有意保留的例外**（谓语形式"是椭圆型的"、另一义项
"正定性"、引文语境）必须写进交接文档/项目基准表，防止下次审校"回改"。

## 7. 脚本化修复（可审计）

- 每条替换写成四元组 `(文件, 旧串, 新串, 预期次数)` 持久化为脚本；
  全批写入前核对预期次数，**不符先停止写入并查明原因**，修订计划后再执行。
  保留逐批备份及编码/换行；结构删除和跨行迁移另按 [index-audit.md](index-audit.md)
  检查边界与非索引正文差异，不能用跨段通配正则猜测待删除范围。
- 用唯一子串而非整行，降低抄写错误；跨行改写单独精确处理。
- 注意词形制导：区分名词/动词（支撑集/支撑在/支撑于）与复合形态
  （截断函数/截断核/平滑截断），替换规则按词形精确制导，不能对字根一锅端。
- 修复后必跑**旧词残留扫描**：用全部旧词表 grep 全项目，期望 0；非 0 逐条
  语境裁定——三种可能：漏网（补刀）、另一义项正当用法（登记保留）、
  注释/生成物（顺手清理）。实测三类都出现过（截断函数漏网 ×4、
  正定性正当保留 ×3、tikz 注释 ×2）。

## 8. 重建与 PDF 层回归

- 全流水线重建，红线：0 错误 / 0 未定义引用（[build-verify.md](build-verify.md)）。
- pymupdf 全文抽取断言：每个旧词 = 0，每个新词 ≥ 预期。
  PDF 文本抽取存在空格/换行伪差（"正换位子 II"抽作"正换位子II"），
  判 0 命中前先用去空白弹性匹配复核。
- 更新交接文档：统一术语基准表、成品页数、保留例外清单、更新记录。

## 9. 典型误译模式清单（原书比对时优先排查）

自创术语名（原书无对应的 amplitude→"幅度函数"、正规符号、内缩映射、
径向点顺流估计）；增词（顺流）；脱字（径点）；自相矛盾复合词（亚纯全纯）；
笔误级词性错位（符号族写成算子族）；索引-正文失配；fig/caption 中的歧义词
（余核）。凡译名"看起来顺但书中仅此一处"，回查原书对应句再定。

## 10. 校准数据（GTM 304 实战回归基准）

950KB / 11 章 + frontmatter；变体族扫描命中约 30 组分裂；6 个并行审校 agent
（按 3+2 分批）发现计划外问题约 15 组；修复 188 处替换 + 8 处索引修正 +
约 20 处英文括注补充；重建 307 页 0 错误 0 未定义引用；PDF 层新旧词断言全部通过。
